# 法條之外：台灣法律人生

手機優先的 3D 生活 RPG。你是祐廷，首都帝大法律系的學生，從大一一路念到畢業以後。

- 你在一座虛構的大學（首都帝國大學）和公館、溫州街的生活圈裡自由走動，上課、讀書、參加社團、和同學吃麵、深夜回宿舍。
- 重要的對話會切到 2D ADV（立繪＋對話框），重要的時刻有事件 CG。
- 法律融在生活裡：課堂的討論、讀書會、期末考、朋友遇到的麻煩。

所有人物、事件、店家都是虛構的。遊戲用的日期是真實的日曆，但世界是平行世界。

## 故事

- 法律系的第一天，他坐進法律系館A 201 教室，被周教授點到名。

## 已完成並發布（線上版玩得到）

### 時間：法律系四年＋畢業以後
- **法律系大一～大四**（2025 年 9 月～2029 年 6 月），每學期 16 週。
- **大三以後的路**：留在臺灣，或交換去日本（大三下）、美國（大四上）——走哪一條，看你和誰走得比較近。交換回來延畢的，有大五上。
- **畢業以後**：考試、研究所、工作，和身邊的人各自的去向。

### 3D 校園與生活商圈
- **校園**：椰影大道、晨思鐘、校門、映月湖、行政大樓、文學院、校史館、圓窗館、社會科學院、新體育館。
- **法學院**：法律系館A（大廳、樓梯、電梯、201 階梯教室、各樓層、5F 研究室）、法律系館B、法律學院圖書館。
- **圖書館與教學館**：總圖書館（大廳、自習區、閱覽區、書庫、研究小間、多媒體中心、B1 二十四小時自習室）、社科院圖書館；普通、共同、博思三棟教學館。
- **宿舍與體育館**：宿舍房間、走廊、洗衣間；體育館一樓羽球場、B1 健身中心與游泳池、3F 主球場。
- **公館**：便利商店、茶室、咖啡店、早午餐、單車店、書店、鹹酥雞、唱片行等，多數走得進去；從街上看得到店裡。
- **溫州街**：2:30 AM（Café）、一盞茶屋（有前院）、小路（居酒屋）、木曜日、日常失速、林家乾麵、早午餐、影印店、小公園和橘貓。
- **118 巷**（法學院後門）：九間店改版——新的店名、招牌、室內和熟客招呼，多兩間外帶飲料店。
- **汀州路商圈**：公館往南的一段街和夜市巷；夜市的攤子晚上才擺，可以看、可以買。新店：泰米村食、洗樂洗衣坊、印得好（影印）、算命小店「禮貌生財」、花店「花序 Flower Notes」等，有室內。
- **新生南路**：山嵐書店、南洋戲院、大口漢堡、同弦樂器、大步球鞋、好拍運動、新生運動廣場，都進得去。
- **交換的地圖**：機場；美國的公寓、合租屋、校園、教室、法學院圖書館、超市與街道、會所；日本的宿舍。
- 白天黑夜、天氣、店的營業時間都會變；店打烊時窗戶和招牌會暗下來。公館、溫州街的店門口會跟著季節和節日換布置。

### 每天的生活
- **上課**：課表照真實的時間與教室，開學前選選修。出席分準時、遲到、沒去；討論課教授會問你的看法。體育課真的在體育館上。大一上三門課每一堂都有內容，坐著上課的對話可以略過。
- **118 巷午餐**：上午在法學院上完課，同堂認識的同學會約你去 118 巷吃午餐。
- **時間**：每個時段能做的事有上限；可以快轉「跳過一週」「到下一個事件」，快轉時收到訊息會停下來。
- **寒暑假**：每一天都過得到：住宿舍或回臺北的家、回老家的朋友真的不在臺北、實習、見習、出國。
- **社團與活動**：吉他社、法律服務社、系籃、社團博覽會、演講、服務學習、家族讀書會、打工、家教。
- **其他**：腳踏車（可以買車、換車，朋友可以坐後座）、每月生活費、健身（器材一台一台用，體態跟著體能變）、羽球、游泳、晨跑；從公館站搭捷運去校外的景點。

### 人物互動與約會
- 熟了以後，人物會一學期一學期慢慢說出自己的事；七位各有自己的故事線，在一起念書、吃飯、看電影的中途發生。
- **約人**：吃飯、咖啡、念書、散步、早午餐、茶屋、羽球、晨跑、健身、游泳、看電影；回覆照你們有多熟。約好了要真的到那裡，兩個人都在才開始；「一鍵前往」可以直接到約好的地方。
- **她們會主動約你**，也有自己的生活（手機動態）。她們傳來的訊息可以用選項回。
- **選項會改變故事**：影響交往的選項有「小心選擇」的提示；她有自己的想法，不是你建議什麼都照做。
- **曖昧有階段**：關係到一半才約得出去玩；還只是朋友時會直接告訴你。
- **校外約會**：三十多個地點，一日遊或兩天一夜；七位的約會台詞重寫過。一起吃飯、喝咖啡、看電影、逛書店、念書，每一場中途都有可以選的話；看完電影會聊那部片的情節。學期結束時也有可以選的話。
- **交往以後**：節日、生日、紀念日、遠距、出國時的時差。感情也可能磨合不了。同時和不只一個人交往，被發現了會有後果。
- **同學與路人**：法律系有名字的同學各有個性和一條小故事；店裡坐著的人會用筆電、寫筆記、聊天。
- **家人**：媽媽每週在家人群組問你回不回家；姊姊偶爾私訊。

### 法律課程與考試
- 沒有期中考；期末週照日曆，法律課真的要考（題庫四百多題）。
- 讀過的觀念卡，考試時會多一行提示；考前可以一鍵總複習。成績看你實際答得怎樣。
- 被當要重修，大四下被當先排補考；成績好有書卷獎。
- 這不是讀書打卡遊戲：不強迫每天念書，也沒有隱藏的每日懲罰。
- 課堂的法律內容只顯示通過法律審查的部分。**法律內容不代表法律意見。**

### 電影（南洋戲院）
- 新生南路的南洋戲院可以買票看電影：片單上每一部都有海報（共 72 張）。
- 可以約人一起看：在大廳會合，進 1 廳並排坐下，燈暗、散場再回大廳。

### 手機、找路與存檔
- 像通訊軟體的訊息：一對一、群組、要回的訊息會自己跳出來。
- 「今天」「課表」「朋友」（認識的人在哪）「活動」「地點」（地圖、快速前往）；日誌是月曆，可以搜尋。
- 目標與導航箭頭、會轉的小地圖；點小地圖打開大地圖：地名、入口、營業時間、朋友在哪。
- 自動存檔、3 個手動欄位、匯出與匯入（可以把進度帶到另一台裝置）。舊版的存檔都能繼續讀。

## 已知限制

- 手機實機只有零星確認，還沒有系統性地測過。
- 自動測試在三個地方跑：雲端的瀏覽器模擬（沒有顯示卡）、作者 Windows 電腦上的瀏覽器（有顯示卡）、GitHub Actions 的 Node 單元測試。都不等於手機實機。
- 很多 3D 模型與人物外觀之後還會換；有些 CG、立繪、背景還在等圖。
- 字型從 Google Fonts 載入；離線或連不到時會用系統字型，畫面略有不同。

## 給開發者

純靜態網頁（three.js），沒有 npm 相依，也不需要建置。

### 本機執行

```bash
# 在 repo 根目錄開一個靜態伺服器（直接用 file:// 開會載不到模型）
python3 -m http.server 8765
# → http://127.0.0.1:8765/
```

- **網址參數**：`?turbo`（測試加速）、`?lowres`（低解析度）、`?mdbg`（移動除錯面板）、`?dev`（顯示缺圖的標籤）。

### 測試

- 規則與分工：[`docs/rules/ROLE_BB.md`](docs/rules/ROLE_BB.md)；全遊戲清單與回歸指令：[`docs/TESTING.md`](docs/TESTING.md)；發布前要跑的清單：[`docs/rules/ROLE_LAWWW.md`](docs/rules/ROLE_LAWWW.md) 第 6.1 節。
- **Node 單元測試**（`tests/*_unit.js`，不需要瀏覽器）：推到 `claude/**` 分支、改到遊戲檔時，GitHub Actions 的 `node-unit-auto`（`.github/workflows/node-unit-auto.yml`）會自動全部跑一次。單支：`node tests/release_pack_unit.js`。
- **瀏覽器測試**（Playwright，手機模擬加觸控）：在有顯示卡的電腦上跑。例：`python3 tests/p0_movement.py http://127.0.0.1:8765/index.html`。
- 瀏覽器模擬不等於手機實機；Node 測試通過不等於玩得順。

### 部署與版本

- **部署**：推到 `main`，GitHub Pages 自動更新（Deploy from a branch → `main` / root）。只有通過發布前測試的版本才合併到 `main`。
- **版本只寫在一個地方**：`index.html` 標題畫面的「版本 vX（日期）」（發布腳本 `tools/handoff/mk_release_tree.sh` 寫入）。這份 README 最上面的版本那一行是 `python3 tools/release/sync_version.py` 產生的，`tests/readme_version_unit.js` 會檢查兩邊一樣。

### 打包（正式發行用；不影響平常開發）

```bash
python3 tools/release/deps.py                          # 依賴檢查：遊戲要的檔有沒有缺、哪些是開發檔
python3 tools/release/pack.py --target web --dry-run   # 只列清單與容量
python3 tools/release/pack.py --target all             # → dist/web/、dist/win-stage/（不進 git）
node tools/release/verify_dist.js dist/web             # 本機伺服器逐檔請求、比對雜湊
python3 tools/release/size_report.py                   # 容量報告
```

# 法條之外：台灣法律人生

手機優先的 3D 生活 RPG。你是祐廷，台大法律系一年級的學生。

- 你在參考台大校園、公館、溫州街做出來的 3D 世界裡自由走動，上課、讀書、參加社團、和同學吃麵、深夜回宿舍。
- 重要的對話會切到 2D ADV（立繪＋對話框）。
- 法律不是考卷：它出現在課堂的討論、讀書會、朋友遇到的麻煩裡。

所有人物、事件、店家都是虛構的。遊戲用的日期是真實的日曆，但世界是平行世界。

**▶ 線上遊玩：https://pyhuanglaw.github.io/Lawstudent/**
- 手機、電腦的瀏覽器都可以玩。
- 目前的發布版本是 **v9.9（2026-10-16）**，標題畫面最下面有版本字樣。
- 每一版改了什麼：[`docs/RELEASES.md`](docs/RELEASES.md)。

## 故事

祐廷在台大經濟系念過一年，重考進了法律系。

- 經濟系那一年，他認識了一群朋友，也認識了杜可昕。
- 現在可昕在政大法律，兩個人在不同的學校，遠距交往。
- 法律系的第一天，他坐進霖澤館 201 教室，被周教授點到名。故事從這裡開始。

身邊的人各有自己的生活。她們不是攻略對象，戀愛只是人生的一部分。

| 人物 | 是誰 |
|---|---|
| **沈以安**（小安） | 法律系一年級，同班 |
| **林芷若** | 外文系二年級，在溫州街「兩點半 Café」打工 |
| **陳語彤** | 社會系一年級 |
| **高子晴** | 資工系二年級，吉他社 |
| **溫書瑀**（溫學姊） | 法律系三年級，你的直屬學姊，法律服務社讀書會 |
| **杜可昕** | 政大法律系一年級，祐廷的女朋友（經濟系那年的同學） |

還有：阿哲的「麵店團」、小語、柏翰、芯慈、明軒、宥辰、沛珊，室友阿凱，經濟系的老朋友，以及一整個學期的教授與同學。

    - 總圖書館（大廳、二樓自習區、3F 閱覽區）
    - 法律學院圖書館
    - 社科院圖書館
    - 普通、共同、博雅三棟教學館
    - 宿舍
    - 兩點半 Café
    - 阿鳳麵店
    - 便利商店、書店
    - 溫州街的半熟（早午餐）、阿德影印輸出、一盞茶屋
    - 新體育館（一樓球場、B1 健身中心與游泳池）
- **每天的生活**：
  - 課表照真實的時間與教室，開學前可以選選修。出席分三種：準時、遲到、沒去。討論型的課，教授會問你的看法。
  - 社團（吉他社、法服讀書會、系籃、社團博覽會）、服務學習、演講與活動。
  - 一天能做的事照時段算（沒有體力條）；起床選單一鍵去上課。
  - 小睡、腳踏車（朋友可以坐後座）、每月的生活費、週末回臺北的家。
  - 從公館站搭捷運去西門町、北美館、大稻埕等景點，路上可能遇到認識的人。
  - 熟了以後，人物每學期會慢慢說出自己的事；約好的見面要真的一起走過去。
- **劇情**：
  - 迎新、麵店團、五位女主角的第一次見面。
  - 中秋烤肉、颱風假的泡麵之夜、期中考完的宵夜、聖誕交換禮物、宿舍頂樓的跨年。
  - 可昕的遠距：導遊、她第一次來台大、第一次視訊一起讀書；大一下的情人節視訊、每個月「我們的日子」、她的生日、春假開車去政大接她。
  - 大一下：芷若的早場電影、子晴的比賽、學姊的手機爭論、經濟系老朋友阿勳和品妤、麵店團春假兩天一夜、家教。
  - 重要的時刻有事件 CG。
- **手機**：
  - 「今天」：課和待辦。
  - 「課表」：這一週的課。
  - 「朋友」：認識的人在哪。
  - 「活動」。
  - 「訊息」：群組聊天、約朋友見面。
  - 「地點」：快速前往。
- **找路**：
  - 目標與導航箭頭、會轉的小地圖。
  - 點小地圖打開大地圖：地名、入口、開放時間、朋友在哪。
- **存檔**：自動存檔、3 個手動欄位、匯出與匯入（可以把進度帶到另一支手機）。舊版的存檔都能繼續讀。

## 操作

| 手機 | 電腦 |
|---|---|
| 左下搖桿移動（推到底是跑步），或點地面走過去 | WASD 移動，Shift 跑步，或用滑鼠點地面 |
| 單指拖曳轉鏡頭、雙指縮放 | 拖曳轉鏡頭 |
| 靠近人或物件時出現互動按鈕 | 空白鍵或 Enter：互動、推進對話 |
| 右下：跑、◎（鏡頭回正）；騎腳踏車時多一個「下車」 | Esc：選單 |
| 點小地圖：大地圖；📱：手機 | |

直向、橫向都可以玩。

## 已知限制

- **iPhone、Android 實機還沒有系統性地測過**。測試都在 Playwright 的手機模擬上跑（沒有 GPU）。
- 很多 3D 模型與人物外觀還在等美術驗收（`READY_FOR_ART_REVIEW`），之後會換。
- 課堂的法律內容只顯示**通過法律審查的那幾週**，其他週只寫主題。法律內容不代表法律意見。

## 給開發者

純靜態網頁（three.js），沒有 npm 相依，也不需要建置。

```bash
# 在 repo 根目錄開一個靜態伺服器（file:// 載不到模型）
python3 -m http.server 8765
# → http://127.0.0.1:8765/
```

- **網址參數**：
  - `?turbo`：測試加速。
  - `?lowres`：低解析度。
  - `?mdbg`：移動除錯面板。
  - `?dev`：顯示缺圖的標籤。
- **測試**：規則在 [`docs/TESTING.md`](docs/TESTING.md)，發布前要跑的清單在 [`docs/RELEASES.md`](docs/RELEASES.md)。
  - 測試是 Playwright（Python）手機模擬加觸控，以及 Node 的單元測試。
  - 例：`python3 tests/p0_movement.py http://127.0.0.1:8765/index.html`。
- **部署**：推到 `main`，GitHub Pages 會自動更新（Deploy from a branch → `main` / root）。
- **接手開發請先讀 [`CLAUDE.md`](CLAUDE.md)**：
  - 專案規則、目錄、架構、常見改動。
  - [`docs/AI_SESSION_HANDOFF.md`](docs/AI_SESSION_HANDOFF.md)：分工與交接。
  - [`docs/PROJECT_DECISIONS.md`](docs/PROJECT_DECISIONS.md)：長期決策。
  - [`docs/history/`](docs/history/)：從第一份企劃到現在的歷程。

### 程式在哪裡

```
index.html            入口（UI、CSS、載入順序）
src/engine3d.js       渲染、光線與天氣、鏡頭、觸控、分層導航、碰撞、NPC 行為
src/zones3d.js        各區域（校園、公館、溫州街、室內）
src/building3d.js、library3d.js、wancai3d.js、lawlib3d.js、soclib3d.js、teach3d.js
                      可以走上樓的建築與教學館
src/game3d.js         遊戲狀態、HUD、對話、存檔、主迴圈
src/story3d.js        劇情、作息、路人、閒聊
src/events3d.js       條件事件引擎；src/adv3d.js：2D ADV 與 CG
src/classes3d.js      課表、出席、課堂；src/phone3d.js：手機；src/guide3d.js：導航與地圖
src/data/             人物、事件、課表、日曆、地點、法律題庫、各建築配置
assets/               3D 模型（Blender 匯出的 GLB、VRM 人物）、立繪、背景、CG
tools/blender/        Blender（bpy）建模腳本
tests/                Playwright 與 Node 測試
```

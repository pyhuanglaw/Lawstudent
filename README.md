# 法條之外：台灣法律人生

手機優先的 3D 生活 RPG。你是祐廷，台大法律系的學生，從大一一路念到畢業以後。

- 你在參考台大校園、公館、溫州街做出來的 3D 世界裡自由走動，上課、讀書、參加社團、和同學吃麵、深夜回宿舍。
- 重要的對話會切到 2D ADV（立繪＋對話框），重要的時刻有事件 CG。
- 法律融在生活裡：課堂的討論、讀書會、期末考、朋友遇到的麻煩。

所有人物、事件、店家都是虛構的。遊戲用的日期是真實的日曆，但世界是平行世界。

**▶ 線上遊玩：https://pyhuanglaw.github.io/Lawstudent/**
- 手機、電腦的瀏覽器都可以玩。

- 每一版改了什麼：[`docs/RELEASES.md`](docs/RELEASES.md)。

## 故事

2024 年夏天，祐廷進了台大經濟系，十月辦了休學，在家重考。2025 年秋天，他考進了法律系。

- 經濟系那短短一段，他認識了一群朋友，也和杜可昕開始交往。後來可昕考上政大法律，兩個人在不同的學校。
- 法律系的第一天，他坐進霖澤館 201 教室，被周教授點到名。
- 開新遊戲可以選從**經濟系前傳**開始，或**直接從法律系大一**開始。

身邊的人各有自己的生活。她們不是攻略對象，戀愛只是人生的一部分：可能開始，可能一直走下去，也可能走散。

## 現在玩得到什麼（v9.10.11）

### 時間：經濟系那一年＋法律系四年＋畢業以後
- **經濟系前傳**（2024 年 8 月～2025 年 8 月）：宿營、上課、休學、重考、放榜。
- **法律系大一～大四**（2025 年 9 月～2029 年 6 月），每學期 16 週。
- **大三以後的路**：留在臺灣，或交換去日本（大三下）、美國（大四上）——走哪一條，看你和誰走得比較近。交換回來延畢的，有大五上。
- **畢業以後**：考試、研究所、工作，和身邊的人各自的去向。

### 每天的生活
- **上課**：課表照真實的時間與教室，開學前選選修。出席分準時、遲到、沒去；討論課教授會問你的看法。
- **考試**：期中、期末考真的要考（題庫四百多題）。被當要重修；成績好有書卷獎。
- **時間**：每個時段做一件主要的事；可以快轉「跳過一週」「到下一個事件」。起床選單一鍵去上課。
- **寒暑假**：每一天都過得到：住宿舍或回臺北的家、回老家的朋友真的不在臺北、實習、見習、出國。
- **社團與活動**：吉他社、法律服務社、系籃、社團博覽會、演講、服務學習、家族讀書會、打工、家教。
- **其他**：小睡、腳踏車（朋友可以坐後座）、每月生活費、健身、羽球、晨跑。從公館站搭捷運去西門町、北美館、大稻埕等景點，路上可能遇到認識的人。

### 人和人
- 熟了以後，人物會一學期一學期慢慢說出自己的事。
- **約人**：吃飯、Café、總圖、溫州街散步、早午餐、茶屋、羽球、晨跑；回覆照你們有多熟。約好了要真的到那裡，兩個人都在就開始。
- **校外約會**：三十多個地點，一日遊或兩天一夜。
- **交往以後**：節日、生日、每個月的紀念日、遠距、出國時的時差。感情也可能磨合不了。同時和不只一個人交往，被發現了會有後果。
- **家人**：媽媽每週四在家人群組問你這週回不回家；姊姊偶爾私訊。

### 地方
- **校園**：椰林大道、傅鐘、校門、醉月湖、行政大樓、文學院、校史館、洞洞館、社會科學院、新體育館。
- **法學院**：霖澤館（大廳、樓梯、電梯、201 階梯教室、5F 研究室）、萬才館（兩層樓）、法律學院圖書館；後門出去的 118 巷，九間店。
- **圖書館**：總圖書館（大廳、二樓自習區、3F 閱覽區、B1 二十四小時自習室與借還書）、社科院圖書館。
- **教學館**：普通、共同、博雅。
- **生活**：宿舍、公館、溫州街（兩點半 Café、阿鳳麵店、早午餐、影印店、茶屋、便利商店、水果攤、自助洗衣、二手市集、小公園）。
- **體育館**：一樓羽球場、B1 健身中心與游泳池、3F 主球場。
- **交換**：日本，以及美國的公寓、校園、法學院圖書館、超市街。

### 手機
- 像 LINE 的訊息：一對一、群組、要回的訊息會自己跳出來。
- 「今天」「課表」「朋友」（認識的人在哪）「活動」「地點」（地圖、快速前往）。

### 找路與存檔
- 目標與導航箭頭、會轉的小地圖；點小地圖打開大地圖：地名、入口、開放時間、朋友在哪。
- 自動存檔、3 個手動欄位、匯出與匯入（可以把進度帶到另一支手機）。舊版的存檔都能繼續讀。

## 操作

| 手機 | 電腦 |
|---|---|
| 左下搖桿移動（推到底是跑步），或點地面走過去 | WASD 移動，Shift 跑步，或用滑鼠點地面 |
| 單指拖曳轉鏡頭、雙指縮放 | 拖曳轉鏡頭 |
| 靠近人或物件時出現互動按鈕 | 空白鍵或 Enter：互動、推進對話 |
| 右下：跑、◎（鏡頭回正）；騎腳踏車時多一個「下車」 | Esc：選單 |
| 點小地圖：大地圖；📱：手機 | |

直向、橫向都可以玩。

## 製作中（還沒發布）

開發分支上正在做、測過以後才會放上線的：

- **她們主動約你**：熟了的女主角會自己用手機約你吃飯、念書、去校外的地方。
- **法律系的同學都有自己的故事**：每個有名字的同學都有個性、一條小故事、會請你幫忙或邀你去社團，也會主動傳訊息。
- **路人有各系的學生**：通識課、椰林大道、圖書館、體育館遇到的人來自不同科系，聽得到他們在忙什麼。
- **上課更像上課**：講台一定有老師、上課前同學陸續走進教室。
- **體育館、社團博覽會有人**：球場有人打球、櫃台有工讀生；社博照真實的攤位與時間。
- **答應媽媽回家**：答應了會記下、當天提醒；和別的約撞到時自己選。
- 118 巷每間店的小故事和熟客招呼、寒暑假快轉收到訊息會停、出國登機的字卡、學姊後面幾年的劇情補完、同時交往時每個人各自決定接不接受。
- 更多 Blender 正式模型：建築、室內、人物。

## 已知限制

- **iPhone、Android 實機還沒有系統性地測過**。測試都在 Playwright 的手機模擬上跑（沒有 GPU）。
- 很多 3D 模型與人物外觀還在等美術驗收，之後會換；有些 CG、立繪、背景還在等圖。
- 課堂的法律內容只顯示**通過法律審查的那幾週**，其他週只寫主題。法律內容不代表法律意見。

## 給開發者

純靜態網頁（three.js），沒有 npm 相依，也不需要建置。

```bash
# 在 repo 根目錄開一個靜態伺服器（file:// 載不到模型）
python3 -m http.server 8765
# → http://127.0.0.1:8765/
```

- **網址參數**：
  - `?turbo`：測試加速。
  - `?lowres`：低解析度。
  - `?mdbg`：移動除錯面板。
  - `?dev`：顯示缺圖的標籤。
- **測試**：規則在 [`docs/TESTING.md`](docs/TESTING.md)，發布前要跑的清單在 [`docs/RELEASES.md`](docs/RELEASES.md)。
  - 測試是 Playwright（Python）手機模擬加觸控，以及 Node 的單元測試。
  - 例：`python3 tests/p0_movement.py http://127.0.0.1:8765/index.html`。
- **部署**：推到 `main`，GitHub Pages 會自動更新（Deploy from a branch → `main` / root）。
- **接手開發請先讀 [`CLAUDE.md`](CLAUDE.md)**：
  - 專案規則、目錄、架構、常見改動。
  - [`docs/AI_SESSION_HANDOFF.md`](docs/AI_SESSION_HANDOFF.md)：分工與交接。
  - [`docs/PROJECT_DECISIONS.md`](docs/PROJECT_DECISIONS.md)：長期決策。
  - [`docs/history/`](docs/history/)：從第一份企劃到現在的歷程。

### v2（AA-B，2026-10-16 08:5x，照 LAWWW2-B 驗收的四點）

1. **`CAT_walk` 的腿和尾巴**：
   - 四條腿粗 30%（前腳半徑 1.9→2.5 cm、後腳 2.2→2.85 cm），腳掌粗 15%。
   - 尾巴不再放進體素重建，改成 `tail_tube()`：沿著通過六個點的平滑曲線（Catmull-Rom）的錐形管，每 1.6 cm 一圈、8 邊，從臀部裡面開始，3.0 cm 漸細到 1.7 cm，尾端收成一點。
   - v1 一節一節的原因：減面把細管子削出鋸齒，加上折線的轉角。管子不參加減面，身體的減面目標扣掉管子的三角形，總數不變。
   - 坐姿、趴姿的尾巴沒有改（v1 通過）。
2. **`CAT_lie` 的前腳**：加兩段前臂（`arm`，花色是沿前臂的條紋、fat 0.3），從胸口下面伸出來接到白色腳掌。
3. **眼睛的反光點**：**做法和規格不同，請你確認**。
   - 先照規格試了「畫在烘焙貼圖上」：眼睛在 512 貼圖上只分到幾個像素，最小的點也蓋掉半隻眼睛，而且接縫上的頂點有好幾塊 UV，點會散開。
   - 改成每隻眼睛表面一個 1.6 mm 的小六角形（6 個三角形），UV 指到配件格裡的白色那一小塊（繃帶區，`GLINT_UV`）。
   - **同一個材質**，沒有多一次 draw call；兩隻眼睛的反光在同一個方向（左上前方）。
4. **小深色點的真正原因（v1 的 bug，三個姿勢都有）**：
   - `bmesh.ops.create_uvsphere` 內部會刪掉幾個暫時的頂點，留下空位；之後新增的鼻子頂點補進那些空位，`to_mesh` 的順序就和建立順序不同。
   - 腳本用「建立順序」記眼睛、鼻子的範圍，所以眼睛、鼻子的遮罩套到錯的頂點：左眼邊緣偏粉紅、嘴角一個小黑三角、走路姿勢脖子後的小深色點。
   - 修法：每一組頂點建好就標上組別（bmesh 的 int layer），最後照組別排序再寫進網格。
   - 也把 `uv_tile` 的 island_margin 從 0.012 加到 0.035（島之間至少 8 px）。
   - 烘焙前先把整張貼圖塗成毛色、不清掉（`use_clear=False`）：比一個像素還小的 UV 島烘不到，v2 第一次重建時坐姿嘴角出現一個小黑三角；現在那裡是毛色，只有貼到臉的近景才看得到一小條橘色。
- **效能**：每個姿勢身體 2,684（多 12 個反光點三角形）＋項圈名牌 180＋繃帶 120＝2,984 三角形（3k 以內）；材質、貼圖數不變。
- 渲染：`cat_*` 八張換成 v2，多一張 `cat_eyes`（坐姿的臉，看反光點；鏡頭 `cat_views_eyes.json`）。
  - v2 的渲染都加 `--wall -0.5`（`render_wz6.py` 新選項）：走路的尾巴到 z=−0.32，預設 −0.30 的牆會把尾巴中段吃掉（v1 的總覽圖尾巴也有一點插進牆）。

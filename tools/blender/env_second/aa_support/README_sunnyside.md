## 醜點
1. 參考圖右邊是一整面落地窗。遊戲裡的窗在店面兩側、沒有側窗，從參考鏡頭的角度看不到窗。
2. 廚房的銅鍋和層架被出餐檯上方的矮牆擋住一部分，看起來比參考圖空。
3. 中間走道比參考圖寬。走道要讓進門到出餐檯那條路至少 1.5 m 寬，所以中間只放了一張方桌。
4. 鏡子是平面的深灰玻璃，沒有反射。
5. 吊燈燈罩偏黃。

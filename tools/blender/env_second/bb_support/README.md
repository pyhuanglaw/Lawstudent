### 和規格不一樣的地方（給 LAWWW2-B 決定）

- **洞洞板的格子是 0.2032 m**（8×8 孔）不是 0.2 m：孔距要 25.4 mm、格子又要剛好接得起來，只能用 8 孔的整數倍。邊上不滿一格的地方用部分 UV。
- **兩疊中心相距 0.52**（規格「約 0.5」）：10 吋＋12 吋外徑半徑加起來 0.453，再加上每條 ±1.3 cm 的偏移，0.5 會太擠。
- **升降台總長 1.99**：底座框 1.8＋斜坡板伸出去 0.19（斜坡板鉸在檯面後緣，往下 42°）。檯面 1.6×0.55。
- 起子、鉗子、捲尺、鐵鎚的位置、空鉤子的數量是我排的；斜靠的輪胎在乙疊 +z 前面、稍微偏 +x（x 0.285）。

# AA_1018　二十位同學說秘密：八句同一個開頭「其實……」

- AA-C 2026-11-14。DLG-FULL-REVIEW-1110「去 AI 腔」。
- 開發分支 src 裡以「其實」開頭的句子一共二十幾句，大多是自然的口語，照留。
- 只有同學（pool）說秘密那一刻，八個人都是「其實……我＋秘密」，同一個模板套在八個人身上。
- 照每個人的口氣、前後文換開頭，**秘密內容不動**，選項也不動。

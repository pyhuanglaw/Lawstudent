## 1. 規則

- **期間**：大二上第 1 週到大二下第 18 週。每週日 21:00 跳出「這週的訊息」：第一個是 9/13，最後一個是 6/27。
- **一週最多四則**。挑的順序：
  1. 綁在事件前後的（第 2 節「接哪件」有寫的）先挑。
  2. 其他的，上週沒出現過的人先挑。
  3. 只挑**認識的人**（照每一則的條件，沒寫的＝`FAMILIAR` 以上）。同一則只出現一次（語彤「阿姨問你週四來不來」例外，每四週可以再出現一次）。

- **沒回的**：不扣分、不改數值。下一次見面（兩週內第一次和他說話），對方用第 4 節那一句帶過；同一個人兩週最多說一次。
- **回了的**：那個人信任 +1。不另外排活動。要見面的，照原本的事件和邀約走。
- **在家的週日**（週末回家）：手機照樣跳出來（`AA_176` R11）。
- **記**：`G.needed = { asked: n, answered: n, byWho: { id: [被問幾次, 回幾次] } }`，預設 `{asked:0, answered:0, byWho:{}}`。大三主線 6 讀它：大家都習慣找他查事情，問的次數就是 `asked`。

## 4. 沒回的那一句（下一次見面）

> **2026-10-16 改寫**（使用者 18:2x「不要出現沒有上下文的台詞」；`AA_186`）：原本每人只有一句（例：柏翰「上週那個……算了，我自己查到了。」），沒說是哪一則，和訊息內容也常對不上。改成**每一則訊息配自己的一句**，句子裡帶那一則的主題。
> - 什麼時候說：沒回之後，兩個人**第一次見面**（麵店、總圖、課堂、讀書會），最多兩週；兩週內沒見面就不說了，不追溯。
> - 寫「—」的：那一則本來就不需要回（例：柏翰說「不用跟我說謝謝」），沒回也不提。
> - 阿哲每一句都用 `AA_12` 原文「你上週很忙齁。」開頭，後面接那一則的下文。

# ⑤ 既有事件：保留、改寫、延後、待決（AA 初稿，PROPOSAL）

判斷標準：
1. 是不是「玩家會記得的人」的事件。
2. 有沒有明顯的正解選項。
3. 時間點是否太早（四年的故事不能一個月講完）。
4. 和人物設定、其他事件有沒有矛盾。

# ⑦ 真正值得新增的重要劇情（AA 的提案，BB 會另外提）

1. **每年最後一天的同一個問題**：小安說過「一年後我再問你一次」。大一結束時她兌現；之後每年由一個不同的人問（大二可能是要畢業的溫學姊，大三可能是要出國的芷若，大四回到小安）。四次回答串成祐廷的成長線，不需要任何數值。
2. **祐廷自己的生活**（如果使用者決定他不是空白玩家）：例如家裡第一次有人念法律，親戚過年立刻拿出一份土地資料（spec 01 的原句）。一開始是笑點，大二、大三變成真正的家事，祐廷第一次發現自己不會的不只是考試。
3. **室友阿凱的小故事**（spec 07 要求過，目前很薄）：和子晴同系，可能是子晴遊戲的第一個玩家或合作者；大二宿舍重新抽籤，兩人分開。這是第一個「普通的離開」。
4. **溫學姊的畢業典禮**（大二六月）：第一次有人離開。適合用 CG。
5. **法服的第一次實務**（spec 07 §9）：大一大二只能做紀錄、整理時間線、旁聽，第一次發現課本上的「當事人」是真的人。不讓學生獨立給法律意見。
6. **期末成發**（子晴說過「你負責拍手」）：吉他社一年一次的成果發表，是全體人物能自然聚在同一個地方的場合。
7. **溫州街的貓**：小語提過咖啡廳門口的貓，子晴的遊戲主角也是貓。不當主線，只當四年的時間刻度：大一常在 Café 門口，大三被巷口的老太太收養，大四看到牠變胖了。屬於「非常普通的幸福」。
8. **窗邊那張雙人桌**：第二天小安帶祐廷坐的位子。四年裡每一年坐在對面的人不一樣，最後一幕回到這裡。
9. **考完試走出教室**（spec 03 §5 的原句）：每次期中、期末後的群戲，所有人的答案好像都不一樣，有人只想去吃飯。

# ⑧ 需要使用者優先決定的重大問題（AA 彙整，BB 會補充）

依「不決定就無法往下寫」的程度排序。

1. **參考圖和正式資料衝突，哪個才是正式設定？** 參考圖 04、05 寫的是：
   - 祐廷、沈以安：法律系二年級。
   - 林芷若：22 歲、咖啡店店員（05 甚至寫法律系三年級）。
   - 陳語彤：法律系一年級。
   - 高子晴：吉他社。
   - 溫書瑀：22 歲、法律系四年級。

   正式資料（D11）是：沈以安法律一、林芷若外文二、陳語彤社會一、高子晴資工二、溫書瑀法律三。目前預設以正式資料為準，但這會影響所有人的時間表。
2. **祐廷是空白的玩家化身，還是有自己過去的人？** 他有沒有家鄉、家人、經濟壓力、自己的煩惱？名字仍可讓玩家改嗎？
3. **故事範圍**：這一輪的「四年主線」寫到畢業就結束（第一部），還是要同時規劃畢業後的國考、研究所、職涯（spec 02、03 的大願景）？
4. **戀愛的範圍與界線**：
   - 五位都可以發展嗎（包含大兩屆、身兼導師角色的溫學姊）？
   - 玩家沒有和她們在一起時，她們可以和別的 NPC 交往嗎？spec 16 說可以，但這會很大程度改變玩家的感受。
   - spec 07 曾說戀愛對象不以玩家性別限制，現在還算數嗎？
5. **刑事訴訟法要放在大一嗎？** 題庫只有刑訴，所以遊戲把刑訴課排在大一；真實課程多在較高年級（需查證）。可以照真實把刑訴移到高年級，大一改從法服讀書會、學長姐接觸刑訴題。題庫答案都不改。
6. **故事可以多沉重？** 現有設定有家人生病、和父親冷戰、研究計畫被退、休學。主要人物可以休學、嚴重生病嗎？有沒有絕對不寫的事（例如主要角色死亡、自傷）？
7. **祐廷自己會不會出國交換？** 會的話，交換篇就是四年主線的一部分（spec 02 要求可遊玩的海外篇章）。
8. **開場要保留「開學第三週的網拍相機案例」，還是改從新生入學、迎新開始？**
9. **架構 C（一件事貫穿四年，例如溫州街老屋）要不要做？** 這是最有《法條之外》個性的方案，但題材要避開真實爭議，也需要法律審查。

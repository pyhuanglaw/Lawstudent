# 角色企劃：溫書瑀（溫學姊）

> 一句話：**她是全系最清楚自己要去哪裡的人，直到有一天她發現，自己從來沒有停下來問過為什麼要去。** 她是祐廷兩年後的預告片。

### 1-2. 她的核心：停下來

**一個從來沒停過的人，停下來以後還剩下什麼？**

- 她的每一天都排滿了：課、法服、讀書會、研究計畫、社長的行政工作。她說話條列式（「三件事」），常說「重點是」，因為她沒有時間說廢話。
- 她嚴格，但會照顧人：學弟妹的書狀她一定改，改完附一張便條。
- 她**不承認累**。她的保溫瓶永遠是黑咖啡。
- 她崩潰，不是因為脆弱，是因為**一直撐得太好，沒有人發現她早就累了**。
- 她的問題不是「要不要念法律」（這題交給祐廷），而是：**如果不往下一步走，我是誰？**
- 她是祐廷**兩年後的預告片**：祐廷大一看見她的樣子，大二看見她撐不住，大三看見她停下來以後怎麼活。

## 6. 另外兩個方向（精簡版，供使用者選擇）

| | 主版本「停下來」 | 方向 B「助教」 | 方向 C「出國」 |
|---|---|---|---|
| 一句話 | 她沒去面試，休息一年，找到不會過也想做的事 | 她考上本校法研所，大三成為祐廷刑訴課的助教，角色反轉 | 她畢業後馬上出國，用信件陪祐廷走完大三、大四 |
| 她在祐廷大三、大四 | 公館舊路書房，常常見得到 | **每週在刑訴課見到**；她帶法院旁聽（接以安版本 A 事件 14） | 不在台灣，只有訊息與兩次回國 |
| 停下來的方式 | 休息一年 | 沒有停：她把「停下來」延後到研究所二年級，碩論寫不出來的那個冬天 | 在國外第一次一個人生病，被迫停下來 |
| 優點 | 和祐廷的反轉最完整（W11、W12） | 「學姊變助教」的反轉很有戲；和以安、林教授、陳助教（同研究室）的交會最多 | 和以安版本 C 的「錯過的人」呼應；最苦甜 |
| 缺點 | 她的法律專業在大三、大四退場 | 她的倦怠沒有真正解決，只是延後 | 她在主線的存在感最弱 |
| 重點事件 | W11 書店、W12 換她照顧 | 「學姊，妳的投影片第三頁打錯字了」：祐廷第一次糾正她；碩一冬天她在研究室過夜，陳助教打電話給祐廷 | 第一封信只有三行條列；第二年的信沒有條列了 |

**企劃組的推薦**：主版本。理由：她的核心是「停下來」，只有主版本真的讓她停下來，而且讓祐廷在大三親眼看到「停下來以後的人還好好的」。這正是祐廷大三撐不住時最需要的東西。

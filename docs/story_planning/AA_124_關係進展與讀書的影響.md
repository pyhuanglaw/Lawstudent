> - (2)「我覺得遊戲有點讓玩家不知道讀書有什麼用除了在課堂上打得出來是不是應該要影響期末考分數之類的，然後影響一些角色對我的看法，或者畢業之後考上律師的速度考上司法法官的速度，不然我真的不知道不唸書好像也不會怎麼樣」

## 1. 關係進展的數值（AA 決定）

### 1-1. 現在的問題

- 約出去見面只加熟悉 2；閒聊只有「新的一句」加熟悉 1；畫面上沒有任何提示。
- 所以玩家約了人、聊了天，感覺不到任何變化。

### 1-2. 每種活動加多少

| 活動 | 熟悉 | 信任 | 自在 | 說明 |
|---|---|---|---|---|
| 聊天（這個人今天第一次） | +2 | | | 不管台詞新不新 |
| 聊天聽到新的一句 | | | +1 | 和上一列可以同時加 |
| 上課坐在他旁邊 | +1 | | | 同一堂課 |
| 一起去 Café 坐坐 | +3 | +1 | +2 | 約好的見面 |
| 一起去總圖念書 | +3 | +2 | +1 | 一起讀書，看得到對方認真的樣子 |
| 一起吃飯（阿鳳麵店） | +3 | +1 | +3 | |
| 溫州街散步（朋友以上才約得到） | +4 | +2 | +3 | |
| 幫忙（借筆記、占位、陪他跑一趟、回答他問的事） | +1 | +3 | | |
| 答應對方主動的邀約，而且赴約 | | +1 | | 加在見面那一列上面 |

- **戀愛**：日常活動**不加戀愛**，戀愛只靠事件（照使用者之前定的第 7 點，`src/invites3d.js`）。
- **放鴿子**：不扣分，只留一筆小記憶（照舊）。
- **事件**（AA、BB 寫的劇情）：照事件自己寫的數值，**不受下面的上限限制**。

### 1-3. 上限

- **同一個人、同一種活動，一天只算一次**。
- **同一個人一天最多**：熟悉 +6、信任 +4、自在 +5（只算日常活動）。
- 到了上限還去聊天：照常可以聊，只是不再加；那一天第一次碰到上限時，出現一行「今天和○○已經聊很多了。」，讓玩家知道不是壞掉。

### 1-4. 畫面提示（不顯示數字）

- 每次活動結束，出現**一行**提示，選加最多的那一項：
  - 熟悉：「和○○熟了一點。」
  - 信任：「○○好像更信任你了一點。」
  - 自在：「和○○在一起，比之前自在。」
- **換階段**的時候改成這一行，優先顯示：「你和○○變成朋友了。」（用 `S.describe` 的名稱：認識、有點熟、朋友、好朋友）。
- 人物頁：顯示現在的階段和最近的記憶（照舊）；要不要加一條沒有數字的進度條，由 LAWWW 決定。

### 1-5. 節奏試算（現在的門檻：有點熟＝熟悉 20；朋友＝熟悉 40＋信任 25；好朋友＝熟悉 60＋信任 45＋自在 40）

- **每週和同一個人見兩、三次**（例如 Café、總圖、吃飯各一次，加兩次聊天）：一週大約熟悉 +13、信任 +4、自在 +8。
  - 約兩週「有點熟」。
  - 加上劇情事件，大約一個多月變成「朋友」；只靠日常大約一個半月。
- **每天都和同一個人見面**（衝最快）：
  - 大約十天變成朋友，兩到三週變成好朋友。
  - 一兩天不會很熟。
- 劇情的條件（例如「`FRIEND` 以上」）還是要等事件的週次，日常走得快，劇情不會跟著提早。

## 2. 讀書的影響（提案，等使用者確認）

### 2-1. 原則

- **改的**：分數看得到；讀書和上課會改變成績；成績會讓人物說不同的話、多一些機會；影響畢業後考上的速度。
- **不改的**（`AA_103` 開頭、`AA_104` 第 10 節）：
  - 不靠運氣。
  - **不會因為成績看不到劇情**：成績只會「多一個機會」，不會鎖住人物或結局。
  - 祐廷可以翹課，不唸書也能過完四年，只是成績、機會、考上的速度不同。
  - **不把答對法律問題換成好感**（使用者的原則）：成績不加好感、不加戀愛，只改台詞和機會。
- **取代的舊規定**：`AA_104` 第 5 節、第 10 節第 2 點「成績單只寫過了、不錯、很好，不顯示分數和排名」——使用者確認後改照本節。

### 2-2. 考試：時間、科目、題型

| 項目 | 內容 |
|---|---|
| 時間 | 照 `AA_103`：每學期 18 週，第 8～9 週期中考、第 17～18 週期末考，考試週不上課 |
| 科目 | 當學期修的每一門課（服務學習只記次數，不考試、不進成績）。通識、國文、英文也有分數（期末報告或考試，照課表系統現有的做法） |
| 題型 | 法律科目以**申論題**為主：考卷上給一個案例，問「誰可以向誰主張什麼、依據什麼」；大一有些科目有選擇題、是非題。通識：選擇題加簡答，或期末報告 |
| 考試當天 | 照現有做法：「考卷發下來」加一段看準備多少的旁白（不是小遊戲） |
| 自己答一題 | **有題庫的科目**（目前是刑事訴訟法，`QBANK`）：期末考多一題玩家自己答，答對加 3 分，答錯不扣。題目照題庫，不改答案 |
| 期中考分數 | 考完那一週的週五發回考卷，看得到分數（柏翰「你考幾分」那一場用這個分數，`AA_40` 翰 1） |
| 成績單 | 學期結束的第一個早上（照現有做法），每一科一個等第和分數，加學期 GPA 和名次 |

### 2-3. 成績怎麼算

- 每一門課照現有的「**準備**」（`G.courses.prep`）累積：
  - 上一堂課：+1（現有）。
  - 自己讀這一科一小時：+1（現有）。
  - **考試週**讀這一科：一小時 +2，每一科每次考試週最多 +4（考前抱佛腳有用，但救不了全部）。
  - 讀書會讀這一科：+2。
  - 課堂上被點到、答得出來：+1。
- **學期分數＝60＋準備×1.15**（四捨五入，最高 99）。期中考分數＝60＋到期中為止的準備×2.3（最高 99），只是考卷上的分數，不進成績單。
- 換成台大的等第（`國立臺灣大學學生成績評量辦法` 附表一，AA 2026-10-14 查；實作前再確認現行版本）：

| 等第 | A+ | A | A- | B+ | B | B- | C+ | C | C- |
|---|---|---|---|---|---|---|---|---|---|
| 分數 | 90～100 | 85～89 | 80～84 | 77～79 | 73～76 | 70～72 | 67～69 | 63～66 | 60～62 |
| 績分 | 4.3 | 4.0 | 3.7 | 3.3 | 3.0 | 2.7 | 2.3 | 2.0 | 1.7 |

- 例子（一門課、一學期大約上 14 堂）：
  - 都沒去、考前讀 2 小時：準備約 4 → 65 分（C）。
  - 去一半、沒自己讀：準備約 7 → 68 分（C+）。
  - 每堂都去、沒自己讀：準備約 14 → 76 分（B）。
  - 每堂都去，再讀 6 小時：準備約 20 → 83 分（A-）。
  - 每堂都去，再讀 10 小時，加一次讀書會：準備約 26 → 90 分（A+）。
- **最低 60 分（低空飛過），不會被當**（第 2-7 節請使用者決定）。

### 2-4. 名次、書卷獎

- **名次**：照學期 GPA 換算全年級的名次（全年級 180 人，遊戲設定），用固定的表，不靠運氣：GPA 4.15 以上是前 3 名；4.0 前 10%；3.7 前 25%；3.3 前一半；再低是後一半。
- **書卷獎**：學期名次在前 3 名。遊戲簡化：實際的名額和資格照台大各系的辦法，各系不同。
  - 拿到的那一天：家裡的群組（五金行）傳來一張截圖和一句話；以安、柏翰的反應見 2-5。
- **同學的成績是固定的**（不隨玩家變）：以安每學期都在前 10%；柏翰大一上民總期中 81 分、第 6 名（`AA_40` 翰 1）；明軒「看起來不唸書，成績卻很高」（BB 的人物，現有設定）。

### 2-7. 要使用者決定的

1. **會不會被當？**
   - AA 建議：**不會**，最低 60 分低空飛過。
   - 理由：被當要重修，會打亂之後的課表和劇情（阿哲「差點被當」那一場是他的故事，不是玩家的）。

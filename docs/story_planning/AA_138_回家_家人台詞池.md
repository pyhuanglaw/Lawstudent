# AA_138　週末回臺北的家：家人台詞池（大一上）

> AA-B 2026-10-15。規格：`AA_137` 第 6 節、`AA_134` 第 3 節（使用者 2026-10-15：「祐廷是臺北人……假日也可以回家」）。定案，直接實作。
> 家人設定照 `AA_12` 第 0 節：爸媽在臺北開五金建材行（爸爸顧店、跑工地送貨；媽媽管帳），經濟寬裕；姊姊宜蓁大五歲，在台南的小出版社當編輯，偶爾回家；祐廷是家裡第一個念法律的人。全部【虛構】，不寫衝突、不寫真實人物資料。
> 語氣：爸爸話少、只講實際的事（天氣、車、店）；媽媽愛傳長輩圖、問吃飽沒、會問「法律系在學什麼」；宜蓁吐槽型。
> **2026-10-18 AA-C**（使用者：「媽媽 6/22 問我睡這麼晚、宿舍是不是很吵……我住家裡欸」）：早上第 3 句改成不提宿舍；**住在家裡的時候**（經濟系休學在家、放假住家裡）不出現群組 1、3，到家 2，晚餐 3、4（提到宿舍、室友、「回來」）——`AA_298` 第 4 節。

## 1. 流程與觸發

| 時刻 | 誰 | 怎麼播 |
|---|---|---|
| 週四 20:00（手機） | 家人群組 | 媽媽隨機一句（第 2 節「群組」） |
| 到家（週五晚上或週六白天） | 媽媽 | 「到家」池一句 |
| 晚餐（18:30～20:00，在家） | 爸、媽（宜蓁：每月第一個週末在家） | 「晚餐」池：媽媽一句問、玩家二選一、爸爸一句收尾；**同一句四週內不重複** |
| 早上在家醒來 | 媽媽或爸爸 | 「早上」池一句 |
| 取車 | 爸爸 | 「車」池一句（車鑰匙在玄關） |
| 回宿舍 | 媽媽 | 「回宿舍」池一句（有時塞一袋東西） |

## 2. 台詞池

**群組（週四晚上，媽媽）**：
1. 「這週回來吃飯嗎」
2. 「（長輩圖：週末愉快 天天開心）」
3. 「你爸說冰箱的水梨要吃掉」
4. 「回來的話先講 我多煮」
5. 「天氣變涼了 外套帶回去」
- 玩家回「會回去」→ 媽媽：「好」（後面加一個愛心貼圖）；「這週不回」→ 媽媽：「好 那下週」；不回 → 爸爸兩小時後：「？」

**到家（媽媽）**：
1. 「回來了。鞋子不要亂放。」
2. 「瘦了。……沒有？那是我記錯。」
3. 「你房間我沒動。只有吸地。」
4. 「宿舍的床睡得習慣嗎？」
5. 「洗衣籃在後陽台。不要整袋帶回來給我洗。……放著吧。」

**晚餐（媽媽問 → 玩家二選一 → 爸爸收尾）**：
| # | 媽媽 | 玩家 | 爸爸 |
|---|---|---|---|
| 1 | 「法律系現在在學什麼？」 | ▸「民法。在學契約什麼時候成立。」／▸「很多。很難講。」 | 「契約喔。店裡每天都在簽。」（爸爸夾一塊肉給你；2026-10-16 旁白照第二人稱，和開發一致） |
| 2 | 「同學好相處嗎？」 | ▸「還不錯。有人會借我筆記。」／▸「還在認識。」 | 「慢慢來。人跟木頭一樣，要放一陣子才知道會不會翹。」 |
| 3 | 「宿舍的飯好吃嗎？」 | ▸「公館很多東西吃。」／▸「還好，比不上家裡。」 | 「（不說話，把湯推過去）」 |
| 4 | 「你室友打電動到幾點？」 | ▸「很晚。我們訂了規則。」（有 `KAI_ROOM_RULES` 才出現）／▸「還好。」 | 「規則訂了要守。不然訂了做什麼。」 |
| 5 | 「錢夠用嗎？」 | ▸「夠。」／▸「這個月買書比較多。」 | 「書的錢另外算。跟你媽說。」 |
| 6 | 「你姊說她下個月回來。」（**姊姊在場的週末不選這一題**，2026-10-16 `AA_140` G49） | ▸「她又要帶書回來嗎？」／▸「好。」 | 「她上次帶的那箱還在樓梯下。」 |
| 7 | 「以後當律師，要幫我們看租約嗎？」 | ▸「我才大一。」／▸「好，但要收錢。」 | 「（笑了一下）先把書念好。」 |
| 8 | 「期中考考得怎麼樣？」（第 8～10 週） | ▸「還在等成績。」／▸「有一科不太好。」 | 「不太好就下次好。店裡也是這樣。」 |

**宜蓁在家的晚餐（每月第一個週末，多一句）**：
1. 「法律系的，借我看一下你的六法。……這麼厚，你們真的會讀完？」
2. 「我們出版社上個月出了一本跟法律有關的書。賣很差。不要問。」
3. 「爸，你的天氣預報又是兩天前的。」
4. 「祐廷，你現在講話開始有『原則上』了。很可怕。」

**早上（在家醒來）**：
1. 媽媽：「早餐在桌上。你爸去送貨了。」
2. 爸爸：「（在看報紙）今天下午會下雨。車開出去記得關窗。」
3. 媽媽：「睡到這麼晚。……昨天幾點睡的？」
4. 爸爸：「店裡今天要點貨。你要幫忙就來，不幫也沒關係。」

**車（爸爸，取車時）**：
1. 「鑰匙在玄關。油我加滿了。」
2. 「開慢一點。不是怕你撞，是怕別人撞你。」
3. 「後車廂有一箱礦泉水。不要拿出來，放著。」
4. 「停車的時候拍一張照片給我。……不是不信你，是你媽要看。」

**回宿舍（媽媽）**：
1. 「這袋帶走。是水果。不准說不要。」
2. 「到了說一聲。」
3. 「下週回來嗎？……不回也沒關係。回來先講。」
4. 「（塞了一個保鮮盒）滷肉。冰箱放得下吧？」

## 3. 數值與限制

- 回家不加任何人的好感，也不扣；只是生活。在家睡一晚，隔天精力回滿。
- 回家的那個週末，宿舍、校園的事件延後到下一次（不懲罰、不消失）；手機照常收訊息。
- 寒暑假住家裡時同一個台詞池照用；過年另外寫（`AA_71` 2-8，大一寒假）。

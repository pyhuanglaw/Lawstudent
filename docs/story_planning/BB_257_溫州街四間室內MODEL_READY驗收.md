### H. 不准複製貼上：**不合格**
`komichi_interior.py` 的寫法和近景渲染一致：
- **吧台檯面 22 件**（第 151 行）：x 等間距（`k*(cx1-cx0-0.5)/21`），照 `k % 4` 循環「盤、燭杯、瓶、醬油瓶」。同一種東西尺寸完全一樣、yaw 都是 0、z 都一樣。後面高台的東西照 `k % 2` 交替兩種。
- **橫樑上的酒瓶 26 瓶**（第 167 行）：全部 h 0.34、間距 0.24 m，只照 `BOTTLE[k % n]` 換顏色。
- 後牆層架的酒瓶：近景看到每層都是同高、同間距的一列。
- 結帳區的盤子 6 個（第 191 行）：3×2 方格、同尺寸、同顏色。
- 兩張海報：同一個人物。
- 參考圖的瓶子有一升瓶、四合瓶、燒酎方瓶、陶壺，高度從 0.2 到 0.4 m 都有，有的往後排、有的歪；小菜碟有方的、圓的、長的。

### 退件要改的
1. 「カルピス」換成虛構名或通用名，例如「乳酸飲料」「乳酸サワー」。
2. 吧台檯面：
   - 東西改成成組、間距不規則（有的地方 3～4 件擠在一起，有的地方空出來給客人放杯子）；
   - 每件給不同的尺寸（±15～30%）、yaw（±20°）、前後位置；
   - 小菜碟至少三種形狀（圓、方、長）；
   - 燭杯減半，而且從檯面邊緣往裡面移，讓檯面不再過曝。用 ref_match 同鏡頭看檯面亮度，接近參考圖的木色。
3. 酒瓶（橫樑上和後牆層架）：
   - 至少 4 種瓶型（一升瓶、四合瓶、方瓶燒酎、陶壺或德利），高度 0.18～0.40 m；
   - 間距不等、偶爾前後錯開、少數轉一個角度；
   - 每層留一兩個空位或倒放的杯子。
4. 海報兩張重畫：寫實的昭和電影海報風格（人物半身、手寫標題、褪色、邊角捲起或膠帶痕），兩張要是不同人物、不同構圖。
5. 排油煙罩改成有倒角、往下收斜的罩子（`L.lathe` 或 bmesh 斜面），不鏽鋼的粗糙度要有變化，不要一整塊發光。
6. 和紙燈籠加竹骨橫紋（法線或幾何）。
7. README 的規格改成 28,100 三角形、1.96 MB。

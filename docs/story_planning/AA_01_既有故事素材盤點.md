## 4. 現有內容裡的矛盾與問題（重寫時要處理）

1. **五女主的矛盾是照 spec 16 的範例抄的**，而 spec 16 明說「不要機械複製」：
   - 小安：有規劃但不知道想不想走法律。
   - 芷若：很會社交但親近的人很少。
   - 語彤：成績普通但直覺強，遇到家裡的事就變了。
   - 子晴：很優秀，卻不想參加大家認為她該去的競爭。
   - 溫學姊又是「看起來最清楚，其實懷疑要不要念法律」，和小安同一個核心，郭沛珊也在懷疑。三個人卡同一題。
2. **幾乎每個人的衝突都是「家裡期待」**：小安（書記官母親）、芷若（媽媽問誰顧店）、子晴（醫師父親）、溫學姊（公務員父母要她考司法官）、芯慈（會計師父親要她雙主修）。
3. **祐廷是空白的傾聽者**：所有人把秘密告訴他，他沒有自己的家庭、家鄉、經濟狀況與煩惱。
4. **節奏太快**：五人「說出秘密／崩潰」的事件，熟度夠了就能在大一上前幾週全部觸發，四年的故事一個月講完。
5. **選項有明顯正解**：常見模式是「問她想不想（大幅加信任）／務實建議／敷衍（扣分）」，違反 spec 17 §23。
6. **女主角的人生只在玩家在場時發生**：沒有她們彼此相處、或和其他 NPC 相處的事件（芷若和子晴是朋友，卻從沒一起出現）。
7. **小錯誤**：
   - 阿哲說小安「上學期就在那間店寫到店員都認識她」，但她是大一開學第三週，沒有上學期。
   - 芷若家的影印店在台中，她人在台北念書，「去交換誰顧店」說不通。
   - 芷若邀祐廷「一起修下學期的法律與電影」，但第五天的選課事件說「法律與電影沒選上」，時間對不起來。
   - 語彤的麵店糾紛是民事賠償＋偷錄音，卻出了一題刑訴基本原則的是非題，題目和情境不合。
   - 刑事訴訟法放在大一，是因為使用者提供的題庫只有刑訴；真實課程多半排在較高年級（需查證）。
   - 溫學姊大三上就交「法研所研究計畫」偏早：推甄一般在大四上（需查證），可以改成大學部的專題研究。
   - 子晴的 story_arc 寫「室友阿凱的同學」，但子晴資工二、阿凱資工一，是學姊（事件裡阿凱說「我們系有個學姊」是對的，資料欄位寫錯）。（BB 指出）

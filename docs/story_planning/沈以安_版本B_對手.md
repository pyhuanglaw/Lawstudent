# 沈以安 版本 B：對手

> 一句話：**全班第一名的她，第一次被一個人比下去。之後四年，他們一直站在彼此的對面，直到某一天，她發現自己想要他站在旁邊。**

## 0. 這個版本和版本 A 哪裡不同

| | 版本 A「書記官的女兒」 | 版本 B「對手」 |
|---|---|---|
| 她的核心問題 | 信任：能不能讓人看到她沒有計畫的樣子 | **驕傲：她能不能輸** |
| 故事的引擎 | 母女、失眠、旁聽席 | **成績、課堂辯論、模擬法庭比賽、研究所名額** |
| 調性 | 安靜、寫實、溫柔（日劇） | **有節奏、會吵架、有比賽的高潮**（韓劇式的青春與競爭） |
| 法律在故事裡 | 課堂問題在生活裡回來 | **法律本身就是兩人的戰場**：課堂辯論、模擬法庭的書狀與言詞辯論 |
| 媽媽 | 弧線的中心（旁聽席） | 背景。只在決賽那天坐在旁聽席，和版本 A 的位置剛好相反 |
| 戀愛 | 慢熱，信任到了才可能 | **吵出來的**：從「我一定要贏你」到「我想你一直在」 |
| 四年後她成為 | 民法研究者、理解媽媽的人、還在路上 | **訴訟律師**、民法研究者、或「終於可以輸的人」 |

**不變的部分**：
- 正式資料（D11）、外觀、說話方式、住中和、媽媽是書記官、黑色手帳；
- 年度重訪日：大一由她問，畢業典禮由她收尾；
- 明軒的界線、企劃組的決定（`沈以安_角色企劃_合併版.md` 第 9 節）。

## 1. 她在這個版本裡是誰

- 從小學到高中，**每一次考試她都是第一名**。不是因為她最聰明，是因為她最怕輸。
- 她只參加會贏的比賽。高中辯論社她只去了一次，因為那次輸了。
- 媽媽從來不要求她第一名，媽媽只說：「穩定就好。」**她要第一名，是為了證明自己不需要被照顧。**
- 大一第一次期中考，有一題她輸給了祐廷。她不生氣，她是**不知道怎麼辦**。從來沒有人在她擅長的地方贏過她。
- **四年後她要學會的**：輸了也還是自己；而且有一個人站在對面，比沒有人站在旁邊好。

**她的說話方式在這個版本的變化**：
- 冷面吐槽變多，而且大部分對準祐廷：「你那個論點，周老師聽了會笑。不是好的那種。」
- 緊張時突然很客氣：在比賽台上會變成「審判長，不好意思，我補充一點」。
- 輸的時候會**變得很安靜**，這是她最脆弱的樣子。

## 2. 她的四年一眼看完

| 學年 | 她自己的人生 | 和祐廷的事件 |
|---|---|---|
| 大一 | 第一次期中考有一題輸給祐廷；周教授在課堂上讓兩人正反辯論；加入模擬法庭社 | B1–B6 |
| 大二 | 模擬法庭校內賽、全國賽初賽。**第一次在比賽裡輸**。和媽媽第一次吵架：媽媽說「比賽不要影響成績」 | B7–B10 |
| 大三 | 全國賽決賽。被分到她不認同的一方。決賽那天，媽媽坐在旁聽席 | B11–B13 |
| 大四 | 研究所民法組推甄；如果祐廷也走研究的路，兩人搶同一個名額 | B14–B15 |

## 3. 事件

**格式**：和版本 A 相同（觸發／目的／流程與台詞／選擇與影響／畫面／遊戲能力／驗收）。和版本 A 相同的開場（下課後追上來、窗邊的雙人桌、報告）不重寫，只寫差異。

### 大一

#### B1｜下課後她追上來（版本 A 事件 1 的變體）

- **差異**：她追上來的理由不一樣。
  - 祐廷答得好時：
    > 小安：呼——你走好快。
    >
    > 小安：剛剛那個八十八條，我本來要講的。周老師點你，不是點我。
    >
    > 小安：（停了一下）……你講得比我準備的好。我不喜歡這樣。
    >
    > 小安：所以我要去 Café 寫民總報告。你要不要一起？我想知道你是怎麼想的。
  - 其他情況：和版本 A 相同（她還是會約，因為她想知道同班的人程度如何）。
- **影響**：答得好的玩家，記憶 `RIVAL_SPARK`（新）。之後她對祐廷的語氣比版本 A 多一點挑釁。

#### B2｜窗邊的雙人桌（版本 A 事件 2 的變體）

- **差異**：網拍相機的問題，她會**故意站在祐廷的對面**。
  - 祐廷選 A（保護粗心的賣家）→ 她說：「好。那我站買家。你說服我。」
  - 祐廷選 B（後果自負）→ 她說：「好。那我站賣家。」
  - 祐廷選 C（看有沒有過失）→ 她說：「……我本來也要這樣寫。」她把筆電闔上，第一次笑出來：「你很煩。」
  - 接著一段兩到三回合的小辯論（**需開發組評估**：用現有選項串起來即可）。
- **「一年後我再問你一次」**：照版本 A，四種回答都會說，寫進黑色手帳。

#### B3｜期中放榜（新）

- **觸發**：大一上期中考後，民總成績發下來的那天，霖澤館 201 下課。一定會發生（第二天沒有和她走的玩家也會，她會主動來問）。
- **故事目的**：對手關係正式開始。
- **流程與台詞**：

> （她拿著考卷走過來，站在祐廷桌子旁邊。）
>
> 小安：第二題，你怎麼寫的。
>
> 小安：我第一題、第三題都比你高。第二題你高我六分。
>
> 小安：……我想知道我漏了什麼。

| 選項 | 她的反應 | 影響 |
|---|---|---|
| 把考卷給她看 | 她看了很久。「你先寫結論，再寫理由。」「我都是反過來。」她把考卷還給他。「下次我也會先寫結論。」 | 記憶 `STUDIED_TOGETHER`：期中考卷 |
| 「運氣好而已。」 | 「不要這樣講。」她第一次有點生氣。「你這樣講，我輸給的是什麼？」 | 記憶 `RIVAL_SPARK`；尊重＋ |
| 「妳第一題比我好很多。教我。」 | 她愣住。「……交換。你教我第二題，我教你第一題。」 | 記憶 `STUDIED_TOGETHER`；之後每次考試前她都會提議「交換」 |

- **所需畫面**：201 教室下課（現有）；立繪 campus：serious、annoyed、surprised；道具：考卷（2D 特寫，分數用遊戲文字疊上）。
- **驗收條件**：不顯示祐廷的具體分數，只說「高六分」。

#### B4｜周教授的正反辯論（新；《The Paper Chase》式課堂）

- **觸發**：大一上期末前，週四民總課。周教授說：「下週，以安跟{name}。你們兩個吵一次。」（**需要民總課能每週重複上**，見版本 A 第 7 節）
- **故事目的**：全班第一次看到兩人當對手。法律內容放在課堂裡，不做成題庫。
- **流程**：
  1. 前一週：玩家可以選擇怎麼準備（讀判決、找阿哲練習、去問周教授）。準備的方式影響辯論中可用的論點。
  2. 課堂：周教授出題（例如：一位房客把租來的房子轉租給別人，房東能不能終止租約？**題目需法律審查**）。以安站房東，祐廷站房客。
  3. 三回合，每回合玩家從兩到三個論點中選一個。以安的論點固定、很強。
  4. 周教授不宣布輸贏，只說一句評語。
- **台詞**：
  - 周教授：「以安，房東。{name}，房客。不要看筆記。」
  - 以安（第一回合）：「條文寫得很清楚。轉租要經過出租人同意。沒有同意，就是違約。」
  - 以安（被反駁時，突然很客氣）：「……不好意思，我再補充一點。」
  - 周教授（結束）：「以安的條文很準。{name}，你剛剛那一句……（依玩家選的論點）。下課。」
- **影響**：
  - 玩家準備得好 → 記憶 `DEBATE_DRAW`：周教授的評語偏向祐廷。以安下課說：「下次我會贏。」
  - 準備得普通 → 記憶 `DEBATE_LOST`：以安下課說：「你下次認真一點。不然我贏得很無聊。」
  - 兩種都不扣關係；周教授的教授紀錄（`SOCIAL.prof`）＋。
  - 這是使用者「法律內容融入上課」的具體示範（D12）。
- **所需畫面**：201 教室，兩人站在講台兩側（**需要課堂上「站起來發言」的站位**，需開發組評估）；全班坐著看；周教授立繪 serious、smile；以安 serious、annoyed、surprised。
- **驗收條件**：不出現題庫題目；論點文字需法律審查；不宣布勝負。

#### B5｜你是我見過最煩的對手（新；大一下）

- **觸發**：大一下開學，萬才館大廳的社團招生攤位。模擬法庭社（新社團；指導是陳助教，他大學時拿過全國賽冠軍）。
- **故事目的**：對手變隊友。
- **台詞**：

> （她已經在報名表上簽了名，筆還在手上。）
>
> 小安：模擬法庭。兩人一隊。全國賽在大三。
>
> 小安：我想了很久要找誰。
>
> 小安：……你是我見過最煩的對手。所以我要你當隊友。

| 選項 | 結果 |
|---|---|
| 「好。」 | 她把筆遞給他。「簽這裡。不准退出。」記憶 `TEAMMATE`（新）。之後的事件走「隊友線」 |
| 「我想當妳的對手。」 | 她笑了一下。「好。那我找柏翰。比賽見。」走「對手線」：大二起，她和柏翰一隊，祐廷和芯慈（或阿哲）一隊 |
| 「我不想參加。」 | 「……好。」她把報名表收起來，沒有再問。她和柏翰一隊。祐廷之後在觀眾席看她的比賽（走「觀眾線」） |

- **三條線都完整**，差別在 B8、B12 祐廷站在哪裡。
- **所需畫面**：萬才館大廳社團攤位（現有區域＋攤位桌）；陳助教立繪 smile；以安 serious → smile。

#### B6｜一年後（年度重訪日 #1）

- **觸發與流程**：同版本 A 事件 8。
- **差異：她自己的回答**：

> 小安：我去年說，一半是因為我媽。
>
> 小安：……今年我發現，我念法律，是因為我想贏。
>
> 小安：可是我不知道，我想贏的是什麼。
>
> 小安：（看著祐廷）你知道嗎？你去年說的那個答案，我想了一整年要怎麼贏它。後來發現，那不是比賽。
>
> 小安：明年換別人問你。我想看你怎麼回答別人。

### 大二

#### B7｜萬才館的十點（新；訓練的夜晚）

- **觸發**：大二上，模擬法庭校內賽前，週一到週四晚上，萬才館研討室（隊友線）；或在萬才館大廳遇到她們那一隊（對手線、觀眾線）。可以重複，每週一次。
- **故事目的**：一起熬夜的日常。她的過度努力在這裡露出來。
- **台詞**（隊友線，每次不同；舉例）：
  - 小安：「書狀第三段，你的引用頁碼錯了。我改好了。」
  - 小安：「我們再練一次開場。你演審判長。……不要笑。」
  - （十點，閉館）小安：「我回去再寫一段。你先睡。」
  - 祐廷可以選「妳也去睡」→ 小安：「我睡不著。比賽前都這樣。……高中也是。」（失眠的伏筆，和版本 A 不同：她的失眠是比賽造成的）
- **影響**：每次一起練習，記憶 `STUDIED_ALL_NIGHT`；累積到三次以上，B8 輸了之後她會讓祐廷陪她。
- **所需畫面**：萬才館研討室晚上（**需要研討室**，或用大廳角落代替）；立繪 casual：serious、tired、laugh。

#### B8｜第一次輸（新；版本 B 的轉折）

- **觸發**：大二上，全國賽初賽（新場景：外校的模擬法庭教室，用 2D 背景）。一定會發生，照她的時間表。
- **故事目的**：她人生第一次在自己擅長的事上輸。
- **流程**：
  1. 言詞辯論。對方是一所外校的隊伍（虛構）。
  2. 以安在第二輪被法官問倒：她準備的條文很完美，但對方問的是她沒想過的事實。
  3. 結果：初賽**輸了**，但因為積分，全隊仍晉級下一輪（**比賽規則需查證**，可以設計成「以安個人表現最差，隊伍仍晉級」）。
  4. 比賽後，她不見了。
- **台詞**：

（祐廷在學校的模擬法庭教室外的樓梯間找到她。隊友線、對手線都可以觸發；觀眾線要熟度到朋友以上。）

> 小安：……我沒事。
>
> 小安：（很久）我從小到大沒有輸過。
>
> 小安：不是因為我很強。是因為我只參加會贏的比賽。
>
> 小安：高中辯論社，我只去過一次。那次輸了，我就再也沒去。
>
> 小安：今天我站在那裡，第一次不知道下一句要說什麼。

| 選項 | 她的反應 | 影響 |
|---|---|---|
| 「我也不知道。我站在妳旁邊，也不知道。」（隊友線） | 她轉頭看他。「……那我們兩個都很爛。」她笑出來，有點哭腔。「下一輪，我們一起不知道。」 | 記憶 `SHARED_SECRET`；信任大增 |
| 「妳輸給的是那個問題，不是那個人。」 | 「……你這樣講很像周老師。」她把臉埋在膝蓋上。「但是謝——」她停住，換了說法：「這句我記下來了。」 | 記憶 `IMPORTANT_CONVERSATION` |
| 什麼都不說，坐在下一階 | 過了很久，她說：「你可以不用坐在這裡。」祐廷沒動。她又說：「……好吧。坐著。」 | 自在＋ |
| 「下一輪會贏的。」 | 「你又不知道。」她站起來，拍拍褲子。「但我會練到知道。」 | 不扣分；她之後會過度訓練（B10 的伏筆） |

- **所需畫面**：
  - 新 2D 背景：外校的模擬法庭教室（法官席、兩方律師席）；
  - 3D：霖澤館樓梯間（現有室內）；
  - 立繪：formal（比賽穿的深色西裝外套＋白襯衫）；serious → sad → tired → 依選項。
  - **CG B1「第一次輸」**：樓梯間，她坐在台階上，西裝外套披在肩上，馬尾散了一半。
- **驗收條件**：她不能大哭。崩潰是安靜的。

#### B9｜媽媽說不要比了（新；她第一次對媽媽說不）

- **觸發**：大二下開學。以安的媽媽看到她上學期的成績掉了（從第一名掉到第五名）。照她的時間表一定發生；祐廷熟度到朋友以上，她才會說給他聽。
- **故事目的**：版本 A 的「她第一次說不」在這個版本的形式：對象是媽媽。
- **台詞**（Café，晚上）：

> 小安：我媽叫我不要比了。她說比賽不要影響成績。
>
> 小安：我說好。我每次都說好。
>
> 小安：……然後我剛剛在捷運上傳訊息給她。我說不要。
>
> 小安：（把手機推給祐廷看，螢幕上只有兩個字：「不要。」下面是「已讀」）
>
> 小安：她已讀了。一個小時了。

| 選項 | 她的反應 |
|---|---|
| 「她會回的。」 | 「你又不知道。」過了幾分鐘，手機亮了。媽媽回：「那妳要睡覺。」她笑出來，眼睛紅了。「……她只說這個。」 |
| 「要不要打給她？」 | 她想了很久，撥了。「媽。……嗯。我知道。……我會睡。」她掛掉電話。「她說她以前也想去考法官。」 |
| 陪她等，不說話 | 一個小時後，媽媽回了一張照片：她小學時拿著辯論比賽獎狀的照片（她只去過一次的那次，是第二名）。「……她留著。」 |

- **影響**：記憶 `SAID_NO_TO_MOTHER`（新）。媽媽在 B12 會出現在旁聽席。
- **所需畫面**：Café 晚上；手機畫面（遊戲現有的訊息畫面，需開發組評估）；立繪 serious、sad、smile。

#### B10｜不要練了（新；她的過度訓練）

- **觸發**：大二下，全國賽複賽前兩週。B8 選了「下一輪會贏的」，或 B7 一起熬夜三次以上。
- **故事目的**：她把輸的恐懼變成過度訓練；祐廷第一次叫她停下來。
- **台詞**：
  - 小安：「我們再練一次。」（凌晨一點，萬才館已經關了，兩人在兩點半 Café）
  - 小安：「審判長會問那個問題。我已經知道他會問。我只是要確定我答得出來。」
  - 小安：「……這是第十四次。我知道。」
- **選項**：
  - 「今天不要練了。」→ 她看著他。「……你在叫我停下來。」「對。」她闔上筆電。「好。只有今天。」記憶 `IMPORTANT_CONVERSATION`。
  - 「好，再一次。」→ 練到打烊。之後複賽她表現很好，但第二天她發燒了。（不是懲罰，是代價）
- **影響**：決定 B12 決賽前她的狀態。
- **所需畫面**：Café 深夜（同版本 A 事件 11 的場景）；立繪 tired、serious、smile。

### 大三

#### B11｜站在房東那一邊（新；和語彤的麵店線交會）

- **觸發**：大三上，全國賽決賽的題目公布。抽籤結果：以安的隊伍要站**房東那一方**：一棟老房子被賣掉，新屋主要求老房客搬走（**題目需法律審查**）。同一個學期，阿鳳麵店正在和新屋主協商（`AA_11` 事件 14）。
- **故事目的**：法律人的職責和個人感受的衝突（借自《八尺門的辯護人》，`BB_03`）。也是「課堂問題在人生裡回來」的反向：人生裡的事走進了比賽。
- **台詞**：

> 小安：我抽到房東。
>
> 小安：……你知道語彤阿姨的店嗎。
>
> 小安：我每週四在那裡吃麵。三年了。現在我要上台說，新屋主有權利。
>
> 小安：我不想贏這一場。

| 選項 | 她的反應 | 影響 |
|---|---|---|
| 「律師不是選邊站。是讓每一邊都被聽見。」 | 她想了很久。「……這句話很漂亮。我不確定是不是真的。」「但我會試試看。」 | 記憶 `IMPORTANT_CONVERSATION`；落點 A 加深 |
| 「那就輸。」 | 「你瘋了。」她笑了。「……但你講出來，我比較好受了。」 | 記憶 `SHARED_SECRET` |
| 「妳去問語彤。」 | 她去了。隔天她說：「語彤說，『妳去贏。如果連妳都講不出房東的道理，那我們就真的不知道他在想什麼了。』」 | 記憶 `TALKED_TO_YUTONG`（新）；以安和語彤成為朋友 |

- **所需畫面**：麵店（現有）；立繪 serious、sad、thinking。
- **驗收條件**：比賽題目要虛構，不和真實案件重疊；不能讓阿鳳麵店的結果被比賽影響（兩件事各走各的）。

#### B12｜決賽（新；版本 B 的高潮，必要 CG）

- **觸發**：大三上，全國賽決賽。地點：霖澤館的模擬法庭教室（**新室內場景，或用 2D 背景**）。一定會發生；祐廷在哪裡由 B5 的選擇決定：
  - 隊友線：在她旁邊；
  - 對手線：在她對面；
  - 觀眾線：在旁聽席。
- **故事目的**：她學會輸，或學會贏的方式不一樣了。
- **流程**：
  1. 開場，以安起身。她看向旁聽席，媽媽坐在第三排（B9 之後；和版本 A 旁聽席的位置**剛好相反**：這次是媽媽在旁聽席，女兒在台上）。
  2. 三回合。玩家在隊友線、對手線要選論點；觀眾線只看。
  3. 第三回合，審判長問了她準備了十四次的那個問題（B10）。
     - B10 選了「今天不要練了」→ 她回答時停了兩秒，說出一個她沒準備過的答案，比準備的更好。
     - B10 選了「再一次」→ 她答得完美，像背出來的。
  4. 結果（照隊伍的累積表現與玩家的論點；**大部分路線是輸**，但輸得很近）。
- **台詞**：
  - 以安（開場）：「審判長、各位評審。我們代表房東。……我們知道，這不是一個受歡迎的位置。」
  - 審判長（第三回合）：「被告律師，如果法律讓房客住到租約結束，然後呢？」
  - 以安（B10 停下來的版本）：「……然後，法律就做完了它能做的事。剩下的，不是法律能回答的。」（她第一次在台上說出「法律不能」）
  - （宣布結果，輸了）以安：（很安靜，然後轉頭，看祐廷，或看旁聽席）……
  - （散場，走廊）以安：「輸了。」
  - 以安：「但我剛剛在台上，第一次不覺得自己是一個人。」
  - （如果媽媽在）媽媽走過來：「妳最後那一句，誰教的？」以安：「……沒有人。我自己想的。」媽媽：「嗯。很好。」（這是媽媽第一次說「很好」）
- **影響**：記憶 `FINAL_ROUND`（新）；決定結局方向。贏的路線另有一句：「贏了。……好奇怪，我比輸的時候還想哭。」
- **所需畫面**：
  - 模擬法庭教室（法官席、兩方律師席、旁聽席）；
  - 新人物：審判長（評審，Tier 1）、對手隊伍（Tier 0）、以安的媽媽（同版本 A）；
  - 立繪：formal（比賽西裝）；serious、surprised、sad、smile。
  - **CG B2「決賽」（必要）**：從法官席的角度看下去，她站在律師席，回頭看旁聽席第三排的媽媽。
- **驗收條件**：
  - 結果由累積表現決定，但台詞要讓「輸」和「贏」都成為好結局。
  - 法庭用語要正確（審判長、被告律師等，**需法律審查**）。

#### B13｜我想你一直在（新；戀愛線，條件式）

- **觸發**：大三下，決賽後。關係到「說不清楚的關係」，明軒事件是 B 支（她婉拒），而且隊友線或對手線。地點：萬才館研討室，他們練習了一年半的地方，最後一次整理比賽資料。

> 小安：比賽結束了。我們不用再一起練習了。
>
> 小安：我這兩天一直在想，以後要用什麼理由找你。
>
> 小安：……我找不到。所以我只好講實話。
>
> 小安：我以前一直想贏你。現在我發現，我想要的是你一直在。在對面，或是在旁邊。

## 7. 這個版本的風險（企劃組自己的評估）

- **法律內容最多**：三場辯論都需要法律審查，工作量最大。
- **容易變成「比賽遊戲」**：要控制辯論的玩法份量，每場三回合、選論點，不做成獨立的小遊戲系統。
- **和祐廷落點 B 的連結很強**：走落點 A 或 C 的玩家，B14 只會看到她自己的結果，衝擊比較小。

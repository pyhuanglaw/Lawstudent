## 0. 先講我看到的三個結構問題

### 0-1. 大家煩惱的都是同一件事

把現有人物的「矛盾」排在一起：

| 人物 | 現有的矛盾 |
|---|---|
| 沈以安 | 看起來很有規劃，其實不確定想不想走法律（媽媽是書記官） |
| 林芷若 | 想出國念電影，又怕辜負家裡 |
| 高子晴 | 家裡要她念醫，她故意念資工；想做遊戲／音樂，說不出口 |
| 溫書瑀 | 對外說要考法研所，其實在懷疑要不要繼續念法律；父母要她考司法官 |
| 郭沛珊 | 懷疑自己為什麼念法律，想轉系，不敢跟家裡說 |
| 小語 | 想考司法官，不確定撐不撐得住 |

六個人裡有五個是「家庭期待 vs. 自己想要的路」，三個是「要不要繼續念法律」。每一個單獨看都合理，放在一起，玩家會覺得同一段劇情聽了五遍。使用者在 spec 16、17 明確說過不要讓角色變成模板，這是另一種模板：**「迷惘的優秀女生」**。

**建議**：「要不要走法律」這個問題留給**祐廷自己**當主線（見第 1 節），沛珊當配角的一個對照。五位女性角色各自換一個不同的人生核心問題（見第 2 節）：
- 以安：信任；
- 芷若：被看見；
- 語彤：責任與自己的人生；
- 子晴：才華與自由；
- 溫學姊：停下來。

### 0-2. 年級差距本身就是四年故事的骨架（現在的設定還沒用上）

祐廷大一入學時：溫學姊大三，芷若、子晴大二，以安、語彤大一。換算下來：

| 祐廷 | 溫書瑀 | 林芷若、高子晴 | 沈以安、陳語彤 |
|---|---|---|---|
| 大一 | 大三 | 大二 | 大一 |
| 大二 | **大四，最後一年** | 大三（交換、實習的年紀） | 大二 |
| 大三 | **已畢業**（研究所／國考／出國／休息） | **大四，最後一年** | 大三 |
| 大四 | 社會人第二年 | **已畢業** | 大四 |

這不是問題，是禮物：**每一年都有人要離開**。
- 大二結束，溫學姊畢業；
- 大三那年，芷若可能去交換、子晴面對畢業；
- 大四那年，只剩同年級的人還在校園裡。

日劇式的青春故事，最好的材料就是「我們只有這段時間會在同一個地方」。建議四年主線直接用這個節奏（給 AA 的架構參考）。

### 0-3. 祐廷現在是空白的

程式裡祐廷是預設名字，玩家可以改名（最多 6 個字），沒有家庭、動機、為什麼念法律的設定。開新遊戲時，他已經認識阿哲（熟）、阿凱（室友）、小安（有點認識）。

spec 10 給了選角氣質：高挑、清爽、斯文、安靜、書卷氣。這是外表和氣質，不是故事。

**祐廷要有多少「底色」，需要使用者決定**（第 4 節第 1 題）。下面的三種主線都假設：他有一個固定的出發點，但走向由玩家的選擇長出來。

## 1. 祐廷的三種可能成長主線（PROPOSAL）

共同的出發點（建議）：祐廷念法律，**不是因為熱情**，而是「分數到了、家裡覺得穩、自己也說不出別的想做什麼」。很多台灣法律系新生都是這樣，玩家容易代入。

他擅長的是**觀察**：安靜，看得到別人沒說出口的事；但習慣站在旁邊，不習慣替自己或別人開口。這和 spec 10 的選角氣質一致。

三條主線是同一個人可能長成的三種樣子，由四年裡的選擇累積決定，不在某一天的選單裡選。玩家也可以混著走，最後偏向哪一條，看他把時間和心力放在哪裡。

### 主線 A：「替別人開口的人」（法服／實務）

- **核心轉變**：從站在旁邊看的人，變成願意替別人說話的人。
- **怎麼開始**：大一下被溫學姊拉去法服招募。第一次值班遇到一個說不清楚自己問題的阿伯，祐廷是唯一聽懂他真正在擔心什麼的人。
- **中段的痛**：大二、大三，他會遇到「法律上沒有辦法」的案子。第一次明白法律的限制，也第一次對法律失望。語彤在這條線很重要：她看人的直覺比他準，兩個人會為了一個個案吵架。
- **結局方向**：大四時，他知道自己要什麼樣的法律工作，可能是律師、法扶、公益組織，也可能還在路上。重點是他開始用自己的聲音說話。
- **代價**：法服很花時間，成績和國考準備會落後。朋友圈會偏向法服的人，和一部分同學漸行漸遠。

### 主線 B：「從標準答案走到自己的答案」（學術／研究）

- **核心轉變**：從很會考試的學生，變成真的想知道「為什麼」的人。
- **怎麼開始**：大一的周教授課堂。他被點到名，答出一個標準答案，教授問「那你自己覺得呢？」他答不出來。這句話跟了他一整年。
- **中段的痛**：和柏翰、芯慈之間的成績競爭。讀書會從互相幫助變成互相比較。大三去許教授的 seminar，發現自己喜歡的東西和「好考」的東西不一樣。
- **結局方向**：法研所，或決定先工作、以後再回來念。這條線接得上 spec 16 的法研所生涯（研究志向從無到有）。
- **代價**：會變孤單。以安或溫學姊這樣的人會看見他的轉變，但他不一定有時間陪任何人。

### 主線 C：「離開也是一種回答」（懷疑／跨界）

- **核心轉變**：從「大家都念法律，所以我念法律」，到敢承認自己真正想要什麼。最後可能留在法律裡，也可能不留，但那是他自己選的。
- **怎麼開始**：阿凱和子晴的世界。他第一次看到有人為了一個沒人要求的作品熬夜，而且很快樂。
- **中段的痛**：轉系、輔系、雙主修、休學的念頭。要跟家裡談，大家都說他「浪費了分數」。沛珊是這條線的鏡子：她也在想同樣的事，但兩個人最後可能做出不同的決定。
- **結局方向**：法律加上另一個領域（科技法、文化產業、遊戲公司的法務），或者完全離開。**不能讓離開法律變成壞結局**；使用者在 spec 03 說過不要有「最佳 build」。
- **代價**：讀法律的朋友可能不理解他，家裡會有衝突，未來比較不確定。

### 三條主線的共同原則

1. 沒有一條是「正確的」。四年後回頭看，每一條都要讓玩家覺得那是一種真實的人生。
2. 主線不靠一個選單決定，是「時間花在哪裡、和誰走得近、在關鍵時刻說了什麼」累積出來的。是否技術可行：**需開發組評估**。
3. 戀愛和友情不是主線的獎勵，是主線的一部分：主線 A 和語彤、溫學姊的關係最深；主線 B 和以安、柏翰；主線 C 和子晴、芷若、阿凱。**這只是自然傾向，不是綁定**，任何主線都可以和任何人變熟。

## 2. 五位女性角色的人物弧線（PROPOSAL）

每一位都照同樣的格式：
- 她的核心問題（不是「要不要走法律」）；
- 她想要什麼、她真正需要什麼；
- 四年裡就算祐廷不在，她自己也會經歷的事；
- 祐廷可以怎麼參與（陪伴、見證、搞砸，不是替她解決）；
- 可能的結局。

**原則：祐廷不是任何人的救星。** 她們的家庭問題、人生選擇，最後都要她們自己決定。祐廷能改變的是「她做決定的時候，身邊有沒有一個懂她的人」，以及他們之間的關係變成什麼樣子。

### 2-1. 沈以安（小安）：信任

- **核心問題**：她能不能讓一個人看到她沒有計畫的樣子？
- **現有素材**：講話直接、有規劃；不擅長表達脆弱，也不會拒絕；壓力大會失眠；母親是單親、地方法院書記官；討厭被當攻略對象。
- **建議改寫**：她的迷惘不是「要不要念法律」，而是「這個計畫是我的，還是媽媽的」。
  - 媽媽在法院工作二十年，看過太多判決背後的事。她從小就被教「法律是穩定的工作」，也從小就看到媽媽很累。
  - 她其實很喜歡民法：喜歡那種「每個人的權利義務都能被寫清楚」的感覺。但她不確定這份喜歡是自己的，還是被安排好的。
- **她自己的四年**：
  - 大一：拿到全班前幾名，成了所有人借筆記的對象。她不會拒絕，所以越來越累。
  - 大二：第一次失眠到去看醫生。和芯慈從競爭變成互相理解。明軒喜歡她（現有社會圖），她有發現，但不知道怎麼回應。
  - 大三：媽媽生病，或者媽媽調職（**需使用者決定**：會不會太沉重）。她要選擇留在台北，還是回去。
  - 大四：國考或研究所。她做出的選擇第一次只為了自己，結果是什麼都可以。
- **祐廷的位置**：最早認識的人之一。兩個人的關係是「一起讀書」慢慢變成「一起不讀書」：某天她第一次說「今天不想念了，陪我走走」。
- **可以搞砸的地方**：祐廷太常依賴她的筆記，她會覺得自己又被當成工具。
- **可能的結局**：
  - 她選了民法、走進法研所，因為自己喜歡；
  - 她去考書記官或司法官，理解了媽媽；
  - 她暫時離開法律去做別的，仍是朋友；
  - 兩人漸漸淡掉。

### 2-2. 林芷若：被看見

- **核心問題**：一個記得所有人點什麼的人，有沒有人記得她喜歡什麼？
- **現有素材**：咖啡廳店員、外文二；很會社交但真正親近的人很少；週末大多一個人看片；想交換卻一直沒交件；台中人，家裡開影印店；想出國念電影研究。
- **建議改寫**：她的拖延不是懶，是怕。只要不交件，就不會被拒絕，也不用面對「我真的想離開」。她用照顧別人來避免談自己。
- **她自己的四年**（她比祐廷大一屆）：
  - 祐廷大一：她是兩點半 Café 那個總是記得他點什麼的店員。
  - 祐廷大二（她大三）：交換申請的截止日。交或不交，是她這一年的轉折。
  - 祐廷大三（她大四）：如果去了交換，大三下或大四上不在台灣；回來後畢業在即。
  - 祐廷大四：她已經畢業，在台北或國外。
- **祐廷的位置**：一開始是「客人」，慢慢變成「她會問你今天過得好不好，而你也反問她的人」。轉折點是祐廷第一次記得她說過的一部電影。
- **可以搞砸的地方**：祐廷勸她「去啊，你一定可以」，對她來說像是叫她走；祐廷勸她留下，又像是在綁住她。沒有標準答案，玩家要自己決定說什麼。
- **可能的結局**：
  - 她去交換，遠距或分開；
  - 她留下，在台灣找到自己的路；
  - 很好的朋友，多年後在電影院門口重逢。

### 2-3. 陳語彤：責任與自己的人生

- **核心問題**：一個一直在照顧家人的人，能不能有一點只屬於自己的東西？
- **現有素材**：社會一；話少但每句都說到重點，對人的直覺很準；成績中等；阿姨在公館開阿鳳麵店；母親身體不好，她常去幫忙；對法服個案很有天分。
- **建議保留，並加深**：她代表**經濟和家庭負擔**這條線。她不是在選「夢想」，是在選「時間」。
  - 她每週要去麵店幫忙，晚上才能讀書。她其實很喜歡社會學，但覺得喜歡是一種奢侈。
- **她自己的四年**：
  - 大一：在圖書館很常見到，但不熟；雨天沒帶傘那次才說上話（現有事件）。
  - 大二：被溫學姊拉去法服，第一次發現自己很會跟人說話，而這件事沒有人教過她。
  - 大三：媽媽的病變重。她考慮休學一學期（現有結局之一）。
  - 大四：社工、研究所，或為了家裡先去工作。
- **祐廷的位置**：她是最先看穿祐廷的人。祐廷在法服學法律怎麼幫人，她在法服學人怎麼被幫。兩個人可以在個案上吵架，也可以在麵店打烊後安靜地吃一碗麵。
- **可以搞砸的地方**：祐廷想「幫她」，例如借錢、介紹資源、替她決定。她會很生氣，因為她不想被同情。
- **可能的結局**：
  - 一起做法服；
  - 她休學一陣子，保持聯絡；
  - 她畢業後去做社工，祐廷在某個案子再遇見她；
  - 錯過。

### 2-4. 高子晴：才華與自由

- **核心問題**：一個什麼都做得到的人，敢不敢做一件可能失敗的事？
- **現有素材**：資工二，系上第一名但缺席率高；拒絕大家覺得她該參加的競賽；醫師家庭，和父親冷戰；想做遊戲或音樂，還沒說出口；吉他社；被期待時會逃。
- **建議改寫**：她逃避的不是期待，是**被評價**。只要不認真，就不會輸。
  - 她拒絕競賽、翹課、故意念資工，都是同一件事：不讓任何人有機會說「你也不過如此」。
  - 她真正想做的遊戲，是一款關於她和爸爸的小遊戲。她一直沒做完，因為做完就要給人看。
- **她自己的四年**（比祐廷大一屆）：
  - 祐廷大一：阿凱的學姊。在吉他社和萬才館社辦之間出沒，話多又愛笑，好像什麼都不在乎。
  - 祐廷大二（她大三）：翹掉的比賽、和爸爸的大吵（現有素材）。
  - 祐廷大三（她大四）：畢業製作。她第一次把作品給別人看。
  - 祐廷大四：她畢業，去了遊戲公司，或自己做獨立遊戲。
- **祐廷的位置**：她是最不像「法律系世界」的人。她問祐廷「所以你喜歡法律嗎？」，祐廷答不出來，這一題會跟著他好幾年。她特別適合主線 C，但不限於主線 C。
- **可以搞砸的地方**：祐廷誇她「你很有天分」。對她來說，這是最重的一句話。
- **可能的結局**：
  - 她做出第一個遊戲，你的名字在製作名單裡（現有結局，很好，保留）；
  - 和爸爸和好，或沒有和好但她學會不需要他的同意；
  - 各走各的，常聯絡。

### 2-5. 溫書瑀（溫學姊）：停下來

- **核心問題**：一個從來沒停過的人，停下來以後還剩下什麼？
- **現有素材**：法律三、前 5%；法服社長；說話條列式、常說「重點是」；嚴格但會照顧人；父母都是公務員，期待她考司法官；對外說要考法研所公法組，私下在想出國念別的；故事裡有「她崩潰的那天」。
- **建議改寫**：她是**祐廷的預告片**。她兩年後的樣子，可能就是祐廷大三、大四的樣子。
  - 她崩潰不是因為脆弱，是因為一直以來都撐得太好，沒有人發現她早就累了。
  - 「出國念別的」建議具體一點（**需使用者決定**），例如公共政策、人類學，和法服的經驗有關。
- **她自己的四年**：
  - 祐廷大一（她大三）：法服招募、讀書會。她是那個「什麼都知道」的學姊。
  - 祐廷大二（她大四）：研究計畫、推甄、社長交接。崩潰的那天在這一年。
  - 祐廷大三：她畢業了，可能在法研所、出國、或休息一年。她從「學姊」變成「朋友」，換她來問祐廷近況。
  - 祐廷大四：她在另一個地方過著另一種生活，偶爾回到溫州街。
- **祐廷的位置**：一開始是被她指導的學弟，後來變成她唯一說得出「我好累」的人。這個轉變需要很長的時間，也很容易錯過。
- **可以搞砸的地方**：祐廷察覺她很累，卻因為她看起來很強而不敢問。或者問了，卻不知道怎麼接住。
- **戀愛的注意點**：學姊與學弟的關係裡，她一開始握有權力（社長、指導者）。只有她畢業、身分對等以後才適合發展戀愛（**需使用者決定**）。
- **可能的結局**：
  - 考上法研所；
  - 出國；
  - 休息一年，然後找到自己的路；
  - 很多年後在別的城市重逢，她已經不說「重點是」了。

## 3. 人際關係設計（PROPOSAL）

### 3-1. 友情是主體，戀愛是一部分

使用者在 spec 17 說過：「整款遊戲的核心仍然是 LAW LIFE RPG」「玩家可以完全不談戀愛」。所以人際關係要先把友情寫好。現在的男性同學戲份很少，建議補上：

| 人物 | 建議的故事線（PROPOSAL） |
|---|---|
| 阿哲 | 系籃和成績的拉扯。大二差點被當，祐廷借不借筆記會影響他（舊 2D 版有類似設計）。他是祐廷最穩定的朋友，也是最不會說心事的人。 |
| 阿凱（室友） | 室友故事（spec 07 明確要求）。宿舍的作息衝突、半夜的泡麵、他做的第一個 App。他是祐廷看見「法律以外的世界」的第一扇窗。 |
| 許柏翰 | 「怕自己其實不夠聰明」。從讓祐廷有壓力的競爭對手，到某次考差後在圖書館樓梯間說真心話。很適合主線 B。 |
| 江明軒 | 家裡經濟困難，又喜歡以安（現有社會圖）。**一段不以祐廷為中心的感情線**：他可能和以安在一起，祐廷是旁觀的朋友。這是「玩家不是宇宙中心」最直接的示範。 |
| 郭沛珊 | 想轉系的同學，主線 C 的鏡子。 |
| 賴宥辰 | 夜裡的公館。他是祐廷看見「另一種大學生活」的人；適合輕鬆、荒謬的支線。 |

### 3-2. 戀愛的原則

1. **慢**：照 spec 16 的階段（陌生人 → 認識 → 熟 → 朋友 → 好朋友 → 有點在意 → 說不清楚 → 在一起），而且不一定往下走。
2. **她也會喜歡別人**：五位女性角色可能和別的 NPC 談戀愛（spec 16「甚至可能喜歡其他 NPC」）。建議至少一組實際發生：以安和明軒，或芷若和方奕廷。
3. **一次只跟一個人**：在一起以後，其他人的感情線轉成友情。腳踏兩條船不是遊戲要提供的選項；**需使用者決定**要不要允許「劈腿被發現」這種劇情。
4. **分手是故事，不是失敗**：在一起之後仍可能分開（交換、畢業、價值觀不同），之後還能當朋友，或不能。
5. **告白可以被拒絕**，玩家也可以拒絕別人。
6. **沒有愛心 UI、沒有好感數字**（現有系統已經是這樣：玩家只看到「這個人記得什麼」）。

### 3-3. 朋友之間的關係，玩家不在場也會變

建議每學年有一兩件「玩家只會事後聽說」的事，例如：
- 芯慈和以安在期末考前大吵；
- 阿哲和明軒的系籃隊拿到冠軍；
- 子晴和芷若一起去看了一場演唱會。

玩家不是所有人的唯一連結（spec 16 第十七節）。這些事要能改變之後的對話。技術可行性：**需開發組評估**（現有社會圖只有靜態關係）。

## 4. 我需要使用者優先決定的問題（BB 這邊）

1. **祐廷要有多少固定的背景？** 玩家可以改名，但家庭、為什麼念法律、個性底色要不要寫死？寫得越多，故事越有血有肉；寫得越少，玩家越能代入。我建議：固定「為什麼念法律」和家庭輪廓，不固定他最後變成什麼樣的人。
2. **戀愛對象的範圍**：spec 07 說過「戀愛對象不以玩家性別強制限制」。現在的祐廷是男生，五位重要角色都是女生。要維持現在的設計，還是讓其他角色（包括男性角色）也可以發展戀愛？或者讓玩家可以選主角的性別？這會影響整個故事結構。
3. **家庭事件的沉重程度**：以安的媽媽、語彤的媽媽、子晴的爸爸、溫學姊的崩潰都很重。要寫到什麼程度（疾病、休學、家人過世）？
4. **溫學姊的戀愛**：她在祐廷大一時是社長兼指導者。建議她畢業、身分對等以後才開放戀愛發展。是否同意？
5. **故事要不要延伸到畢業以後？** spec 02、03 原本規劃到律師、法官、檢察官、法務的職涯；目前的工作目標是「四年大學生活」。畢業後是要做成一個尾聲（多年後重逢），還是之後的另一個大章節？這會決定四年主線的結局要收得多完整。
6. **「每個角色的核心問題不同」這個方向是否同意**：也就是把「要不要走法律」主要交給祐廷，五位女性角色改成第 2 節的五個不同核心。

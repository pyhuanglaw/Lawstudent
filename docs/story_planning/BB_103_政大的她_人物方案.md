# BB_103　木柵大學的她：三個人物方案

## 0. 三個方案共通的寫法

1. **她有自己的地方**：玩家去木柵大學時，看到的是她在自己的系、自己的朋友、自己在意的事裡面發光；不是只在等祐廷。
2. **吵架有具體的原因，而且至少一兩次她是對的**（`AA_99` 3-3）。吵架的根是「兩個人的生活越來越不一樣、時間怎麼分」，**不是第三者**：沛珊只存在祐廷的獨白裡，她不知道、也不吃醋。
3. **修補要有實質內容**：把一天固定留給她、真的出現在她在意的場合、認識她的朋友、讓她走進法律系的生活；承諾之後會被事件檢驗。
4. **兩種走向都完整**：持續經營→她的畢業、工作，兩個人怎麼面對各自的未來，到五年後的長桌；沒有修補→大二前後溫和地分開，她之後仍偶爾出現在手機。
5. **年級**：三個方案都設定**和祐廷同年**——他在首都帝大經濟系念大一時，她是木柵大學大一；他重考進法律系那年，她升大二。所以她**比祐廷早一年畢業**（祐廷大三時她大四、祐廷大四時她已經在工作），這本身就是一個真實的考驗。
6. **和其他人物的區隔**：芷若（外文、Café、電影）、子晴（資工、遊戲、音樂）、語彤（社會、麵店、法服、社工）、以安（法律、公法）、沛珊（教育、重考）、學姊（法研所、法律扶助）都不重疊。

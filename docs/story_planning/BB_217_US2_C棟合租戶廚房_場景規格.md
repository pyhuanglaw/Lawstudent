## 1. 格局
- 學姊和兩位室友**三個人合租一戶**，在同一個社區的 C 棟。
- 進門的方式和祐廷那棟一樣：有屋頂的戶外樓梯，門開在樓梯平台上，沒有室內走廊。【BB 建議】放二樓，和祐廷家一致。
- **三房、一廳、一間獨立廚房**。
  - 廚房朝客廳開一個**窗口**，窗口下是**吧台**，吧台外側（客廳那一側）有**兩張高腳椅**。照使用者給的照片三和 BCG-32。
  - 房間門關著，玩家不用進去。三扇門不要一樣：一扇貼著便條，一扇掛著外套，一扇什麼都沒有。
- **冰箱上**：
  - 三個人的**輪值表**（倒垃圾、洗碗），手寫、有劃掉重寫的地方；
  - 一兩張便條。
  - 不寫真實品牌。
- **生活痕跡**：三個留學生合租的樣子。
  - 客廳：沙發上一條毯子、地上一個行李箱沒收完、一盆快乾掉的植物。
  - 廚房：三種不同的碗、一袋白米、一罐醬油。
  - 不要像樣品屋，也不要髒亂。

  - 玩家進門以後走到高腳椅，互動「坐下」就開始。
  - 不用進廚房，窗口隔著兩個人，這是這場戲的構圖。

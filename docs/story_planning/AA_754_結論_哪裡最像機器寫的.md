# AA_754 結論：全遊戲台詞統計看到什麼（給後面每一批改稿當靶子）

> AA（帳號 A）2026-11-11｜任務 DLG-FULL-REVIEW-1110（X324）；使用者 11-11「就是要像人在說話……製作一些工具」
> 數字來源：`AA_754_全遊戲台詞統計.md`（工具 `tools_aa/voice_stats.py` 對開發分支跑的；重跑就會更新）。人物歸屬是工具猜的，階梯、約會、期末飯這些檔準，事件檔不準。

## 看到的四件事

1. **每個人講話的節拍一樣。** 十四個人物，每一小句平均都是 7～8 個字，七成五到八成的小句在十個字以內。真人不會這樣：話多的人（芷若、可昕、Alison、阿哲）句子該長、該黏在一起；話少的人（語彤、柏翰）才短。現在話多話少的人量出來是同一個數字。
2. **七位女主角最常用的開頭是同兩個：「今天……」「上次……」。** 每個人各一兩百次。這是「報告今天做了什麼／提上次的事」的寫法，不是聊天。
3. **刪節號開頭（「……好。」「……嗯。」「……謝謝。」）全遊戲 1,600 多則**，可昕一個人就近 400 則——可昕是「不爽會講」的人，不該是全遊戲最常欲言又止的。
4. **三連短句**（「不知道。三月底放榜。現在先不想。」這種每句六個字以內連三句）：可昕 96、子晴 85、以安 82、學姊 53、芷若 47、沛珊 41、語彤 35。每個人都有、形狀一樣。

另外：不同人物共用同一句的還有幾十句（「嗯。謝謝。」「……謝謝。」「……你怎麼知道。」「第二次了。」「（往山上的步道）好陡。」）；同一則句子在同一個檔重複很多次的清單在統計檔 B 節。

## 之後每一批改稿要做到的（量得出來的目標）

- **句長要分得開**：話多的人平均小句 10 字以上、有黏在一起的長句；話少的人維持短。改完用工具量，七位女主角的數字不能擠在同一格。
- **「今天」「上次」開頭各砍掉一半以上**：換成直接講事、問對方、接對方的話、講眼前看到的東西。
- **刪節號開頭只留給真的說不出口的地方**：每個人物全遊戲各幾十則以內；可昕、子晴尤其要砍。
- **三連短句每個人物砍到十則以內**，而且只給本來就這樣講話的人（柏翰、語彤）。
- **不同人物不共用同一句**（統計檔 C 節逐句分掉）。

## 真人講話的參考（只當語感，不抄句子）

查到的公開資料不多，能用的原則是這幾條：
- 台劇對白常被批評的毛病：句型生硬的「是……的」、不自然的轉折詞「對了，」。（關鍵評論網的評論）
- 好的對白有三層：說出口的、沒說的、不能說的；把話講得太白，讀起來就平。（編劇談對白的文章、Final Draft 談潛台詞）
- 真的對話常省略主詞、會重複同一個意思；寫進作品要提煉，不能照錄，也不能磨到每句都一樣整齊。（小說家談對白）
- 台灣華語口語的語氣詞（喔、欸、啦、齁）各有功能，同一個「喔」高低音意思不同（意外、疑問／提醒、警告）——不是隨便加在句尾就像人。（中原華語文學報的會話分析研究）
- 「不是 X 而是 Y」、三個一組的排比，機器用得比人多；破折號不是可靠的指標。（《經濟學人》比對五萬多句的報導）
- 公開、可合法下載的台灣校園劇完整劇本這一輪沒有找到；文化部優良電影劇本的得獎作品有些會公開電子檔，之後要再找可以從那裡找。

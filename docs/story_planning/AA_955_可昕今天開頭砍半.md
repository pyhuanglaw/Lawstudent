# AA_955　DLG-FULL-REVIEW-1110：可昕「今天」開頭的台詞砍半（AA_754 目標）

- AA-C 2026-11-13。任務 DLG-FULL-REVIEW-1110（X324）。口氣照 `00_人物口氣表` 1-6 可昕（快、短、會算時間和步數、不甜；不跟祐廷比）。
- 來源：`voice_stats.py` 對開發分支 c77ddb5d11 抽出人物＝kexin、第一小句「今天」開頭的台詞，共 60 句。人物是猜的，**LAWWW 換之前請確認是可昕那一處**。msg_replies 裡有幾句其實是祐廷回她的（「今天補給妳」「今天晚上補給妳」用「妳」），不是她的，不動。
- 這一份改 27 句。留下的：「今天」有對比或就是在講這一天的（生日那幾句、週年、今天不行。淡水要一整天、今天不想動腦、今天你決定、今天我帶路、今天只做三件事。泡腳、吃、回家、今天說好要休息、今天還沒吵、今天只能看海、七夕……）。
- 規則同 AA_951。

## 1. 原則

1. **法律系時期，阿勳、品妤大部分時間不在遊戲的場景裡**，在上經濟系的課、打工。
   - 只在三種時候出現在 3D 場景：週五中午普通教學館的走廊、週四晚上共同教學館的自習區、期末考週法學院廣場的販賣機（只在事件時）。
   - 其他時間寫 `zone:null`＋`away`，給「找人」看的文字。
2. **P4d 之前不出現在 3D**（還沒重新認識，不能先被玩家點到）。
   - 例外是 10-3（第 11 週週四）。那一晚本身有「還沒見過」的重新介紹句，所以照常出現。
3. **週五午餐在學活，是 2D**（2026-10-16 改，`AA_186` 4-4：小松樓 2025/12/31 停業、2026/1/10 拆除，大一下以後改學活）：底圖沿用 `xiaofu`（學生餐廳一角，學活的自助餐也合用），場景名寫「學活」。週五午餐是 SK03 的事件，作息只寫 `away`。
4. **大四（Y4S1 起）不出現**：他們 2028-06 畢業（`AA_115` 第 6 節「共同教學館不會再遇到阿勳」，SK05 大四「販賣機前沒有人」）。

## 2. 要 LAWWW 加的一個欄位

`schedEnt` 的 `hit` 加一個條件欄 **`if`**（用 `EVENTS.cond`，寫法和 SMALLTALK、閒聊階梯的 `if` 一樣）：

```js
if(ent.if&&!(typeof EVENTS!=='undefined'&&EVENTS.cond(ent.if))) return false;
```

- 沒有這個欄位的話，退而求其次：拿掉第 3 節裡有 `if` 的那幾筆。這樣 P4d 之前，他們只會由事件放到場上。

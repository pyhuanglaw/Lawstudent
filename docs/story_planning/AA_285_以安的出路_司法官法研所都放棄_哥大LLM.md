## 2. 為什麼這樣選（她自己的理由，照口氣表 1-1）
- 她給自己的標準高，是因為媽媽是高等法院庭長，**不是想把媽媽比下去**。考上司法官、考上法研所，是證明她做得到；**證明完了，她才發現自己想要的不是在媽媽的那個系統裡往上走**——她不想一輩子被叫「庭長的女兒」。
- 日本交換那半年（行政指導：沒有命令卻人人照做）讓她想先看看別的國家的法律怎麼運作，再決定自己站哪一邊。
- 大事務所律師是她自己挑的：要的是處理真實的案子、自己負責，不是穩定。
- **不寫成叛逆**：她先告訴媽媽，媽媽沒有反對（媽媽的那句照 `交接包_v5` 新 18：「先把對方的理由講得比他自己還好」——她用同一招說服了媽媽）。

# AA_694 約會台詞整批拿掉沒必要的「……」（DATE-ELLIPSIS-1105）

- **使用者 11-05 03:4x**（對 LAWWW-C 答 AA 的「醒來要問的」第 2 題，LAWWW-C 03:53 轉述）：約會台詞 `date_lines.js` 選「**整批改**」（把沒必要的「……」拿掉）。
- 起因：`AA_674` 量過，約會台詞約 35% 有「……」（事件 13%）。題目裡給使用者看的三個例子：「（往山上的步道）……好陡。」→「（往山上的步道）好陡。」／「上次你借我外套。……今天我自己帶了。」→「上次你借我外套。今天我自己帶了。」／「……好。（她張開手保持平衡）……不要笑。」→「好。（她張開手保持平衡）不要笑。」
- AA-C 定（D109），2026-11-05。

## 1. 規則（照三個例子）

- **拿掉**：
  - 句首的「……」（含旁白括號、引號裡的句首）：「……好陡。」→「好陡。」
  - 句末標點（。！？）後面緊接的「……」：「……外套。……今天」→「……外套。今天」
  - 旁白括號「）」後面緊接的「……」：「（她張開手保持平衡）……不要笑。」→「（她張開手保持平衡）不要笑。」
- **留著**：
  - 詞中間的停頓（「拍照……我手不知道要放哪裡。」）——那是說到一半卡住，是那個人說話的樣子。
  - 句尾的「……」（話沒說完）。
  - 整句只有「……」（不說話）的不動。
- 字一個都不加，只拿掉「……」。

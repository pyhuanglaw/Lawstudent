# AA_111　校總區的跨學年場景構想

## 0. 這個世界觀帶來的新東西

- **法律系館A的台階正對著社科院**（`00_世界觀基準` 第 6 節）。祐廷在法律系的每一天，都看得到一年前的系館；經濟系的朋友就在對面。
- 所以「回去找舊朋友」不是一趟遠行，是**走一分鐘**。兩個朋友圈可以**自然地交疊**，不需要特地安排聚會。
- 每個場景都要讓玩家看到**人或情境變了**，不是同一句話換個人說。

### 寫作規則（每個場景都適用）

1. **劇情事實和玩家的選擇分開**：
   - 經濟系那一年的劇情事實（祐廷念過經濟系、阿勳是室友、和可昕一起重考），從法律系大一開始的玩家也成立，在開頭的摘要交代。
   - 玩家在經濟系那一年做過的**選擇**（E19 怎麼問、E12 說了什麼），**只有玩過的人**才會被提起；其他玩家看到替代句（`AA_108` 第 7 節的回聲規則）。
2. **經濟系朋友的人生不圍著祐廷**：每個人在這幾年都有自己的事，祐廷只是有時候在場。
3. **法律系大四時經濟系的朋友已經畢業（2028-06）**：大四的場景要用「他們不在了」來寫，不能讓他們照常出現。

## 1. 八個場景

### S1　對面的舊系館（法律系大一第 3 週起；之後變成日常）

- **地點**：法律系館A台階 → 法學院廣場 → 社科院門口。
- **情境**：法律系第一天下課，祐廷站在法律系館A的台階上，看到廣場對面的社科院。手機亮起來，是阿勳：「你在對面喔？我在二樓看到你了。」「下課來圖書館找我，我幫你佔位。」
- **選擇**：過去找他／先回宿舍（改天他會再傳）。
- **跨學年的意義**：法律系的第一個禮拜，經濟系的朋友就在。玩家第一次感覺到「**同一個校園的五年**」，而不是換了一款遊戲。
- **之後**：社科院門口成為偶遇點。經濟系那群下課經過廣場，和麵店團擦身而過；認識的人會打招呼。
- **條件**：劇情事實，所有玩家都有。玩過經濟系大一的人，阿勳多一句（例如提到經濟系那年的保齡球）。

### S2　廣場中間的販賣機（法律系大一～大三，每年期末考週；大四有變化）

- **地點**：法學院廣場的販賣機（兩棟樓之間）。
- **情境**：期末考週晚上十一點，法律系館A和社科院的燈都亮著。祐廷下樓買飲料，阿勳也剛好從對面下來。兩個人在販賣機前站五分鐘，各自抱怨各自的考試。
- **每年不一樣**：
  - 大一：阿勳問法律系考試考什麼，祐廷說要寫一整頁的論證。阿勳說：「經濟系至少有標準答案。……好啦，不一定。」
  - 大二：兩個人都累了，話很少，只交換一罐飲料。
  - 大三：阿勳在想要念研究所還是工作。他問祐廷：「你那時候是怎麼確定的？」
  - **大四**：販賣機前沒有人。手機裡阿勳從公司傳來一張加班的照片：「今天想到那台販賣機。」
- **跨學年的意義**：同一個五分鐘，四年裡慢慢變成兩個人各自的人生。大四的空位讓玩家知道時間真的過了。
- **給 BB**：這是**不需要台詞很多**的場景，留白比講滿好。

### S3　週五的重修和隔壁教室（法律系大一，每週五）

- **地點**：普通教學館（重修經濟學原理）→ 走廊 → 小松（大一上）／學活（大一下起；小松 2025/12/31 停業，`AA_186` 4-4）。
- **情境**：
  - 祐廷在普通教學館重修經濟學原理，經濟系那群升上大二，就在隔壁教室上課。
  - 下課在走廊碰到。品妤：「你坐第一排？重修生的覺悟。」
  - 之後的週五中午，**可以**一起吃飯（大一上小松、大一下起學活）。這不是必玩的事，是一個每週都在、玩家自己決定要不要參加的小習慣。
- **兩個朋友圈怎麼交疊**：芯慈（雙主修經濟）也在重修課上。幾週後她和阿勳發現彼此在同一門統計課，午餐自然多了一個人。法律系的朋友和經濟系的朋友就是這樣認識的，不用特別安排。
- **跨學年的意義**：重修不是丟臉的事。每週五是兩段大學生活交會的一天。
- **條件**：劇情事實。芯慈和阿勳同一門課，照 `AA_106` 2-6 的輕連結。

### S4　經濟系之夜的「前系友席」（法律系大一或大二，學期末）

- **地點**：社科院一樓（需要室內場景；做好之前可以用 2D 背景加立繪）。
- **情境**：
  - 品妤是系學會的幹部，邀祐廷回來看經濟系之夜：「你可以來。你又不是叛徒。」
  - 唐睿主持。台下有一排是「轉系、休學、重考過的人」，大家笑著叫它前系友席。
- **依關係分版本**：
  - 和可昕交往中：她也從木柵大學來。她也是那一年的同學，所以經濟系那群看到的是兩個老朋友成了一對。這是共同節奏③「兩邊的朋友」的自然場合。
  - 分開了：她可能也來，兩個人各自坐在朋友中間，散場時說一聲「好久不見」。
  - 沒有玩經濟系大一：照劇情事實演，不提經濟系那年的選擇。
- **跨學年的意義**：離開一個系，不等於離開那群人。
- **給 BB**：這場是讓**唐睿、品妤有自己的高光**的機會，不只是祐廷的回憶。

### S5　社科院圖書館的那張桌子（法律系大二或大三，期末考週）

- **地點**：社科院的社科院圖書館。
- **情境**：
  - 期末考週法律學院圖書館滿了，祐廷走到對面社科院的圖書館。
  - 經濟系那群一年級時常坐的那張大桌，這次只有品妤一個人。
  - 她嘴巴還是很毒，但這次說出她在煩的事。例如要不要出國念研究所，家裡怎麼想，她自己怕什麼。這部分由 BB 依她的人物設計。
- **選擇**：陪她讀到閉館／說一句話就回去讀自己的。兩種都可以。
- **跨學年的意義**：品妤不只是「經濟效益是零」的毒舌梗，她有自己的人生和煩惱。這是 `AA_108` 第 4 節「經濟系朋友一人一個梗」的修法之一。

### S6　兩個系的同一題（法律系大二，博雅；接 `BB_105` B6）

- **地點**：博雅的跨領域講座 → 散場後的走廊。
- **情境**：
  - 聽完「經濟和法律在同一張桌子上」，芯慈和阿勳在走廊吵了起來。題目是「違約的人只要賠錢就好嗎？」，阿勳講效率，芯慈講信賴。
  - 兩個人同時轉頭看祐廷：「你說。」
- **選擇**：玩家用自己的話把兩邊的意思「翻譯」給對方。這是 `AA_108` 的 B 類互動，沒有標準答案，但要講得出理由。
- **跨學年的意義**：祐廷是**唯一聽得懂兩種語言的人**。經濟系那一年不是浪費，變成他在法律系的特長（`AA_105` 經濟→法律那一條）。

### S7　阿勳的那條路（法律系大三）

- **地點**：社科院的小教室（阿勳的專題報告或研究助理的發表）。
- **情境**：
  - 阿勳真心喜歡經濟，留了下來，後來在做研究。他邀祐廷來聽他報告。
  - 祐廷坐在後排，看見自己「如果沒有離開」可能的樣子。
  - 散場時阿勳說：「你留下來的話，現在應該坐我旁邊。」停一下又說：「不過你現在的樣子比較好看。」
- **條件**：「比較好看」這句接的是經濟系大一 E24c 阿勳說的話（「你確定的樣子比較好看」），只有玩過的人才聽得到；其他玩家聽到的只有前半句。
- **跨學年的意義**：沒有選的那條路，也是好的路。兩個人都沒有選錯。

### S8　新生的自我介紹（法律系大四上，開學第一週）

- **地點**：社科院一樓。
- **情境**：
  - 祐廷來社科院還書，剛好碰上經濟系迎新，新生在玩「用一個經濟學名詞介紹自己」。
  - 經濟系那群已經畢業，這棟樓裡**沒有認識的人了**。
  - 一個新生說：「我是邊際效用遞減。」
- **依玩家分版本**：
  - 玩過經濟系大一、聽過可昕在 E02 說同一句的人：旁白：「第一次見面最好玩，之後越來越普通。……你現在知道，那句話是錯的。」
  - 和可昕交往中：他拍一張照片傳給她，她回：「告訴他，越來越普通是騙人的。」
  - 分開了：他沒有傳。只有旁白，或什麼都沒有。
  - 沒有玩經濟系大一：只看新生玩遊戲，旁白：「你自己也玩過這個。」
- **收尾**：系辦的助理認出他：「你不是那個轉去法律的？」（助理記錯了，他是重考進來的；祐廷笑著說：「重考。」）溫暖的一句，不展開。
- **跨學年的意義**：大一很熟的地方，大四回去已經不一樣了。這是使用者舉的例子。

## 2. 兩個小的日常設計（不是單一事件）

- **D1　大一女舍門口的長椅**：
  - 經濟系大一，祐廷在這裡等可昕（E35 考前一晚）。
  - 法律系大一，同一張長椅，等的是麵店團要一起出門的以安和沛珊。品妤剛好經過：「你又在等人？這次等誰？」
  - 一句話，讓同一個地方有兩年的記憶。
- **D2　社科院—法律系館A—博雅的日常三角**：
  - 這三個地方之間的偶遇表：經濟系那群往返社科院和三棟教學館、法律系的朋友、學姊經過。
  - 可昕來首都帝大時，社科院**也是她的舊系館**。她會自己去找品妤（她們經濟系大一同住大一女舍），所以她來首都帝大不只是為了祐廷。這一點接到 `AA_112`。

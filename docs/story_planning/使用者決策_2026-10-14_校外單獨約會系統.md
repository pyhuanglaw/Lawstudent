【一、核心原則】
1. 校園內與學校附近的約會，屬於日常好感累積，不算正式告白前提的「校外單獨約會」。

3. 玩家要對某位女主角告白，前提之一是：和她完成「超過三次」校外單獨約會。
   - 這裡的「超過三次」，請實作為至少 4 次，避免歧義。
4. 公館商圈屬於學校附近，明確排除，不可計入校外單獨約會次數。
5. 校外約會採「半互動約會」模式，不做純文字帶過，也不做完整自由探索。

【二、學校附近 vs 校外單獨約會的區分】
A. 學校附近（只累積好感，不算告白前提）
以下屬於校園或學校附近生活圈：
- 首都帝大校園內各地點
- 溫州街
- 公館商圈
- 公館夜市
- 學校附近咖啡廳、書店、餐廳
- 師大路、校園周邊步行可及生活圈（如仍與日常校園生活高度連續，也歸這類）
這類約會的功能：
- 增加友情、信任、自在或少量戀愛好感
- 觸發日常對話
- 建立熟悉感
- 幫助進入「願意私下約會」階段
但不計入「校外單獨約會次數」

B. 校外單獨約會（可計入告白前提）
以下類型才算：
- 真正離開學校生活圈的半日、一日或兩天一夜行程
- 明確以單獨約會形式前往
- 有出發、抵達、互動、回程等完整流程
例如可規劃：
- 淡水
- 貓空
- 華山
- 陽明山
- 北海岸
- 九份
- 宜蘭
- 電影院（若地點不在校園附近，且明確作為單獨外出行程）
- 後期開車前往的外縣市地點
以上請由 AA 進一步整理為「可算校外單獨約會」的正式地點表。

【三、校外單獨約會的用途】
1. 校外單獨約會比校園附近約會更重，會增加較多戀愛推進。
2. 每位女主角需個別記錄與祐廷的「校外單獨約會次數」。
3. 告白條件之一：
   - 該角色已達一定好感／信任／戀愛條件
   - 已完成至少 4 次校外單獨約會
   - 該角色自己的劇情前置條件也已達成
4. 即使約會次數足夠，如果人物自己的主線條件未達成，仍不可直接告白。
5. 校園附近的約會不能灌水替代校外單獨約會。

【四、半互動約會的結構】
每次校外約會流程建議如下：
1. 邀約成功
2. 出發（交通方式、時間、花費）
3. 抵達場景
4. 在同一個場景中進行 2～4 個互動點選擇
5. 互動結束後進入收尾對話
6. 結算：好感、記憶、是否增加校外單獨約會次數、是否解鎖新事件

普通約會不要每次都用完整 CG。
普通約會主要使用：
- 一張場景底圖
- 人物立繪疊圖
- 少量表情變化
- 可點互動點
- 對話與結算

一、正式定義「校外單獨約會」

將約會分為三類：

A. 校園與學校附近的日常相處

以下一律不計入正式校外單獨約會：

* 首都帝大校園內所有地點。
* 總圖、法圖、社科圖。
* 映月湖、椰影大道、晨思鐘。
* 公館商圈、公館夜市。
* 公館的二輪電影院。
* 兩點半 Café、阿鳳麵店。
* 溫州街。
* 寶藏巖、自來水園區及公館周邊河濱。
* 師大商圈、學校周邊日常活動範圍。
* 一般上課、讀書會、社團或順路同行。
* 去木柵大學找可昕、在木柵大學校園或附近吃平常的晚餐，不會自動視為正式校外約會。

這些活動可以累積熟悉、信任、自在及符合條件的戀愛好感，但不能增加正式校外單獨約會計數。

B. 正式校外單獨約會

必須同時符合：

1. 目的地位於學校周邊日常生活圈以外。
2. 祐廷與單一女主角事先約定正式外出。
3. 行程具有日期、出發時段、交通與時間安排。
4. 玩家選擇實際出發。
5. 完成行程及至少一個實質互動後，才計入一次。

不是只要離開首都帝大校門就算。

到西門町看電影可以算；在公館看電影不能算。

到淡水的朋友團體旅行不算；後來與某位女主角單獨再次去淡水，可以算。

同一天去淡水老街與漁人碼頭，若是同一趟連續行程，只能計一次，不能拆成兩次灌水。

同一地點不同日期再次正式約會可以計數，不強制四次都去不同地方，但日常加分可有遞減。

C. 特殊感情事件

生日、節日、告白、分手、和好與抓包屬特殊事件。

若特殊事件同時符合正式校外單獨約會條件，可以計數，但同一趟仍只能計一次。

已經完成的告白 CG、校園劇情或普通團體活動，不能因新系統上線而被錯誤補算。

二、告白條件

除既有交往關係外，每位可攻略女主角要完成：

1. 達到適當的友情、信任與戀愛階段。
2. 和該女主角完成至少四次正式校外單獨約會。
3. 曾與她完成一次「她最想去的地方」的專屬校外約會。
4. 完成她自己的核心戀愛劇情前置條件。
5. 她當時願意開始這段關係。

專屬地點那次可以算在四次裡面，不必額外變成第五次。

不能只達到四次就無條件讓對方答應告白。

五、約會出發的方式——正式決策

玩家不需要自己走到校外約會地點，也不需要先走到校門、停車場或車站。

1. 約會成立時

玩家透過手機或 NPC 主動邀約，確認：

* 對象。
* 地點。
* 日期。
* 出發時間。
* 交通方式。
* 預計花費。
* 預計回程時間。

成功後自動加入行事曆。

2. 到出發時間時

當遊戲時間到達約定出發時間，無論祐廷當時站在校園、宿舍、圖書館或一般可中斷的活動地點，系統都主動出現提示。

例如：

「今天 14:00，你約了子晴去三創生活園區。」

「現在要出發嗎？」

選項：

* 「出發」
* 「改時間」
* 「今天不去了」

如果女主角主動邀約，也使用相同流程。

3. 玩家選擇「出發」

立即：

1. 關閉目前可中斷的校園互動。
2. 淡出畫面。
3. 播放簡短交通過場或文字。
4. 推進遊戲時間到抵達目的地。
5. 扣除交通所需花費。
6. 進入正式校外約會的 2D 場景。

不需要玩家手動走路。

不需要玩家手動開車。

不需要在完整 3D 城市裡找路。

汽車已經解鎖時，對適合的目的地使用開車版本；其他行程可以使用捷運、公車、火車等交通工具。

4. 玩家選擇「改時間」

開啟可選日期與時間，重新檢查雙方日程，成功後更新行事曆。

5. 玩家選擇「今天不去了」

取消本次行程。

不增加正式校外約會次數。

不觸發約會 CG。

可以播放符合人物個性的取消回覆，但一次正常取消不應直接造成嚴重關係懲罰。

反覆臨時取消則可在人物關係中留下合理記憶，由 AA、BB 設計。

6. 強制事件優先順序

法律系強制期末考、不可中斷的重大主線事件，比普通約會優先。

如時間衝突，約會在預約時就應提示並禁止錯誤排程。

遊戲快轉、睡覺或切換場景跨過出發時間時，也要正確停下來詢問，而不是讓約會默默消失。

如果同一天有中午與晚上兩場約會，必須算進交通與回程時間。

不能讓角色同一時間出現在兩個城市。

7. 回程

行程結束後：

* 依照交通時間推進遊戲時鐘。
* 回到合理的原出發生活區域，例如首都帝大宿舍或當時的居住地。
* 繼續正常校園／生活遊戲。
* 完整保留時間、金錢、關係及約會回憶。

這是正常玩家流程的一部分，不是測試用傳送捷徑。

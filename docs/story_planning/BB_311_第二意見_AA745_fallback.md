**建議兩種改法擇一**
- (a) 把 kind 分細：meh 拆成「嫌片子」和「不同意片裡的人」；detail 拆成「注意到」和「疑問」；self 的回話不要預設是小時候或家裡。
- (b) kind 不動，但每一句都改成「這個 kind 的任何選項接上去都通」：拿掉睡著、小時候、你家、她的衣服、後面站著一個人、破綻這些預設。
- (a) 比較好看，(b) 比較快。不管哪一種，改完請用程式把每個 kind 的每個選項接上每一句讀一遍（216×3），或至少每個 kind 抽十個選項讀。

## 3. 口氣、設定
1. 子晴「你們文組的都這樣看電影嗎。」：口氣表「不會說：『法律系不是都早睡？』這種刻板印象」，這句是同一種。
2. 語彤「我住校，沒有那種經驗。」：總表只寫她大學一個人住新生南路；「住校」是新的事實（高中？），請對一下或拿掉。
3. 可昕「票是我買的耶。」：遊戲裡看電影是玩家付 150；沛珊「是我挑的」、五個人的「下次你挑」也預設這次是她挑的——片子其實是遊戲照規則挑的，玩家看到的是自己約的。
4. 其他都像她們：以安「不好笑。……有一點。」、語彤「你很吵。」「（她過了三秒才笑。）你剛剛那句，我現在才懂。」、學姊「我看電影不帶腦的，平常用太多了。」「挑爛的你請客。」、可昕「你家的事我比你媽還清楚。這個我聽過了。」「白痴喔。走啦。」、沛珊「你陪我看我就很開心了。」——請保留。

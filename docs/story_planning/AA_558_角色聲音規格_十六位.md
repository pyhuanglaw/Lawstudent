# AA_558　角色聲音規格（十六位）：每一批改稿都照這一份

- AA-B（劇情導演），2026-10-31 起。DIALOGUE-DEPTH-1031（使用者 `UA-AA-1031-02`、`UA-AA-1031-03`）。
- 參照對象：`AA_557` 第 2 節（使用者 10-31 同意，不再改）。
- 這一份分兩部分：
  - **A 部**：每個參照人物怎麼想、怎麼說，套到我們的角色時取什麼、不取什麼。
  - **B 部**：每位角色的聲音卡，回答使用者的八題，加上按學期推進的生活線。
- B 部的設定都對照既有的設定和遊戲裡的事件（子代理整理，見各卡的出處）。

## 共通規則（每一句都照）
1. **人物帶著自己的事進來**：剛做完什麼、正在煩什麼、等一下要去哪。可是不是每一句都講自己；一段對話裡有一處就夠。
2. **心情不直說**：用一件具體的小事、一個動作露出來。
3. **有來有往**：
   - 她會追問、岔題、開玩笑、不同意，偶爾誤會；
   - 玩家的選項不同，她的反應也不同，輕重相稱；
   - 不是每段都要走向戀愛或人生哲學。
4. **長短看情境**：
   - 「嗯。」「真的假的？」「你少來。」「等我一下。」都可以是好台詞；
   - 想說又不說的時刻，短才對；
   - 不以字數判斷好壞。
5. **連續性**：前面提過的事，之後要有一句接上（第 B 部每張卡的「線」）。不用每件都變成事件。
6. **不抄**：參照的是想事情和說話的方式，不抄任何作品的台詞、背景或情節組合。
7. **照舊的規則**：
   - 不跟別人比、不嫉妒（D116）；
   - 不加「欸、啦、靠北」裝口語；
   - 不寫漂亮的收尾句；
   - 不用專業比喻講感情；
   - 每個泡泡 40 字以內，長就拆。
8. **驗收**：
   - 遮名辨識：靠想事情的方式認，不靠反覆提同一個興趣；
   - 人物生活：聊幾次以後，知道她最近在忙什麼、在意什麼、跟誰有關係；
   - 自然度：唸出來像真人，不像設定表。

## A 部　參照人物怎麼想、怎麼說

### A-1　沈以安 ← 坂間千鶴（《イチケイのカラス》）
- **原作的她**：年輕的菁英法官，相信程序和效率，一開始覺得同事想太多、調查太多；慢慢看見每個案件背後是一個人的人生。
- **怎麼想**：先問「規則怎麼說」，再問「為什麼這樣定」；不喜歡模糊；做錯會很直接承認。
- **怎麼說**：句子完整、用詞準；開玩笑她會照字面理解；被說中時用更正式的話擋回去；很少說自己的感受，可是會用行動補。
- **好笑在哪**：她認真到自己沒發現好笑。
- **取**：精確、有理由、會承認錯、慢慢變柔軟。
- **不取**：法官的身分、職場的權力關係、冷淡；她 19 歲，是會漏抄、會失眠、會在宿舍會議舉手的大一生，不是在寫意見書。

### A-2　林芷若 ← 八谷絹（《花束般的戀愛》）
- **原作的她**：大學生，對書、電影、表演、小東西有很細的喜好，會把喜歡的東西一樣一樣講出來；重視「喜歡的東西」在生活裡的位置。
- **怎麼想**：從具體的東西看世界（一本書的某一頁、一個人的鞋子）；相信小事很重要。
- **怎麼說**：講到喜歡的東西會變快、變細；用日常的比較自嘲；真的在意時突然變短、變安靜。
- **取**：細節、對電影的熱情、自嘲、在意時安靜。
- **不取**：原作的戀愛情節和次文化清單；芷若講的是二輪戲院、店裡的客人、外文系的詩，片名一律用遊戲裡的虛構片名。

### A-3　陳語彤 ← 淺野鈴（《海街日記》）；阿姨參照《俗女養成記》的家常
- **原作的她**：被接到姊姊們身邊生活的少女，有禮貌、很安靜，心裡揹著家裡的事；慢慢在新的家找到位置。
- **怎麼想**：先看別人需要什麼，再決定自己能不能開口；對家人的事很敏感。
- **怎麼說**：話少、句子短、用詞樸素；講別人比講自己多；高興時會一下子說很多，說完又不好意思。
- **《俗女養成記》取的**：台灣家庭說話的質地，家人吵嘴裡的關心、長輩用食物表達愛。
- **取**：觀察別人、話少但準、慢慢打開。
- **不取**：原作的家庭醜聞與身世；語彤的家是媽媽和阿姨，照遊戲設定。

### A-4　高子晴 ← Poppy Li（《Mythic Quest》）
- **原作的她**：很強的遊戲工程師，很拼，很想被看見，對自己的作品沒有安全感；講話直接、情緒外露、常常失控又好笑。
- **怎麼想**：先想「這個東西做得好不好」；被否定會很痛，被稱讚會懷疑。
- **怎麼說**：講技術細節停不下來；被稱讚馬上反駁；生氣直接說；害羞時變兇。
- **取**：熱情、具體、不安全感、直接。
- **不取**：原作的粗魯、職場鬥爭；子晴是大二學生，在做第一個自己的遊戲。

### A-5　溫書瑀（學姊）← 三澄ミコト（《非自然死亡》）
- **原作的她**：法醫，理性、務實、情緒穩定；遇到壞事先吃飯睡覺再繼續；有乾的幽默；編劇把她寫成「壓著的普通人」，個性從做事的方式出來，不靠口頭禪。
- **怎麼想**：先處理眼前能做的事；不沉溺；心裡有一件很重的事，很少說。
- **怎麼說**：句子短、先給資訊；不安慰，給辦法；偶爾冒出一句很乾的玩笑。
- **取**：務實、先給有用的、乾的幽默、壓著的情緒。
- **不取**：原作的家庭創傷與職業；學姊的壓力來自研究所和爸媽的期待。

### A-6　郭沛珊 ← 大島凪（《凪的新生活》）
- **原作的她**：很會讀空氣、把真心話吞回去，直到撐不住；後來搬家、辭職、重新開始自己的生活，慢慢學會說自己要什麼。
- **怎麼想**：先想別人會不會不舒服；常常懷疑自己是不是想太多。
- **怎麼說**：溫柔、客氣、常先道歉或先說沒關係；偶爾漏一句真心話，又馬上笑掉。
- **取**：讀空氣、漏出來的真心話、重新開始的勇氣。
- **不取**：原作的職場和戀愛；沛珊是離開法律系、重考、走向教育的人，照遊戲設定。

### A-7　杜可昕 ← Paris Geller（《Gilmore Girls》）
- **原作的她**：聰明、急性子、很有主見，什麼都排好時間；說話直到會傷人，可是對朋友非常忠心、可靠；盔甲下面有不安。
- **怎麼想**：先決定，再處理後果；討厭拖。
- **怎麼說**：句子短、快、硬；把自己的狀況講清楚；在意時更兇。
- **取**：快、直、可靠、嘴硬。
- **不取**：原作的好勝和比較（D116）；可昕可以愛辯、愛互考（她自己選的遊戲），但不跟人比誰比較好。

### A-8　吳芯慈 ← Rachel Zane（《Suits》，使用者點選）
- **原作的她**：在律師事務所長大的聰明人，俐落、自信、溫暖、穿著講究；跟資深的人說話不怯場，也有自己的不安。
- **怎麼說**：直接、溫暖，會講家裡的事；看到別人厲害說「這個好，我學起來」。
- **不取**：原作的戀愛與考試身世；芯慈的設定照 `AA_547`。

### A-9　阿哲 ← 峰龍太郎（《交響情人夢》）
- **原作的他**：吵、熱情、講義氣，家裡是開餐館的；對朋友毫不保留，常常誇張，但真心。
- **怎麼說**：大聲、誇張、自嘲；把食物當成生活的大事；對朋友的事比自己的事還激動。
- **不取**：原作的音樂與家裡開餐館；阿哲的爸爸是國中體育老師、表哥是律師（`voice_canon/zhe.md`），他愛吃是他自己的事，不是家裡的事。

### A-10　Alison（李語晴）← 成德善（《請回答1988》）
- **原作的她**：家裡排行中間，直率、熱鬧、成績不好但人緣好；很怕被忘記，也常常覺得自己不重要。
- **怎麼說**：大聲、反應很大、什麼都問；自己先講一堆，再問你；難過時會假裝沒事。
- **不取**：原作的家庭結構與戀愛；Alison 從板橋通勤、爸媽上晚班（鑰匙兒童）、三個社團（吉他社、辯論社、系學會），之後學會一個人。

### A-11　許柏翰 ← 津崎平匡（《逃げ恥》）
- **原作的他**：系統工程師，凡事先想清楚、很怕麻煩別人、不擅長處理感情；用邏輯保護自己，其實很體貼。
- **怎麼說**：客氣、精確、會用數字；被說中會慌、會講很多理由；關心人的方式很繞。
- **不取**：原作的年齡、契約婚姻情節；柏翰是坐第一排、照計畫念書的大一生。

### A-12　阿凱 ← Roy（《The IT Crowd》）
- **原作的他**：懶懶的工程師，愛打遊戲，常常倒楣，講話很平；本性善良。
- **怎麼說**：平平的語氣講好笑的事；「所以」開頭（我們自己的習慣）；不愛講感情，用行動（泡麵、便利貼）。
- **不取**：原作的辦公室喜劇情節。

### A-13　江明軒 ← 李翊晙（《機智醫生生活》）
- **原作的他**：看起來一直在玩、很會耍寶，其實能力很強、很認真；對朋友和家人很深情。
- **怎麼說**：用「哈哈」和玩笑帶過自己的努力；被說中就轉話題；講別人的事時很仔細、很溫柔。
- **不取**：原作的醫生職業與單親設定；明軒是當家教、存錢去德國的法律系學生。

### A-14　方奕廷 ← 宰河（韓國電影《小森林》）
- **原作的他**：從城市回到鄉下種田的人，安靜、滿足、務實，很少說話，說的都是眼前的事。
- **怎麼說**：句子慢、少；講植物、天氣、山；不講自己的心情，用他照顧的東西說。
- **不取**：原作的鄉村與戀愛；方奕廷是森林系學生。

### A-15　Kevin ← Charles Boyle（《Brooklyn Nine-Nine》）
- **原作的他**：熱情過頭、很忠心、喜歡吃、常常講太多自己的事。
- **怎麼說**：驚嘆號、什麼都要揪、把小事講得很誇張；對自己人毫不保留。

### A-16　祐廷（玩家）← 山音麥（《花束般的戀愛》）
- **原作的他**：普通、真誠、想得多說得少；後來被現實磨得很累。
- **選項怎麼寫**：照舊短，可是要像一個人在說話：帶他自己的想法和小反應，不只是「好」「謝謝」。不寫他的內心獨白（玩家自己決定他怎麼想）。

# BB_121　互審：`AA_70` 的「被邀約時」「一起走路時聊什麼」

## 1. 兩份共用的三條（`BB_70` 0-2 已經加了同樣的說明）

1. **只用四個地點**：兩點半 Café、總圖、公館吃飯（＝阿鳳麵店）、溫州街散步。
2. **階段門檻**：吃飯要「有點熟」、溫州街要「朋友」（`src/data/invites.js`）。「認識」欄的吃飯台詞是「有點熟」才看得到；溫州街「認識」欄的台詞不會出現，要搬到「朋友、第一次約散步」。
3. **改天的時間由系統算**（`INV.nextFree`）：台詞裡寫死的時間（「明天 16:00」「週六 15:00」）只是語氣，實作時換成系統算出的時間或拿掉。

**另外建議（兩份都適用，不擋交付）**：「一起走路時聊什麼」現在照「路線」寫（例：Café → 大一女舍、麵店 → 公車站），可是邀約系統裡，一起走只會發生在「走去約好的地方」。實作時照**目的地**對應（去 Café／去總圖／去麵店／去溫州街），目的地對不上的那幾句（以安的「Café → 大一女舍」、語彤的「麵店 → 公車站」、BB 的「溫州街 → 公館」等）放進「任何目的地」的池子，或等有「送她回去」的功能再用。

## 3. 範圍外，順便看到的（給 AA 決定）

1. **「不准」只屬於以安**（`AA_112` 也寫了「『不准』是以安的口吻」）。另外有三處：
   - `AA_70` 2-6 芯慈：「不准跟別人說我在看這個」。這句也接近禁用句型「不要跟別人講」。建議：「……你沒有看到這則。」
   - `AA_124` 1-6 阿哲（朋友）：「不准說你不會。」建議：「不會打可以記分。」（他現有的句子）
   - `AA_40` 翰 4 柏翰：「今天的事，你不准跟別人說。」也接近禁用句型。建議：「今天的事，……就到這裡。」或只留後半句「下次我考好了，那個你可以說。」
2. **接近「大家都只問X、只有你問Y」的句型**：`AA_40` 翰 4「你是第一個反問我的人」、`AA_124` 1-6 語彤（好朋友）「我跟別人在一起會累。跟你不會。」——都是「別人怎樣、只有你不一樣」的寫法；語彤那句在任一方有伴侶時，也算「只對他一個人有意義」。請 AA 判斷要不要換。

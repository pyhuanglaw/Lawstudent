## 1. 使用者的十條原則（照原文，見參考檔）

1. 真正的對話不必有起承轉合，也不必有結尾金句。
2. 每個人說話都有當下目的（借筆記、問教室、約吃飯、趕著離開、不想談某件事）。
3. 朋友可以答非所問、理解錯誤、突然想到別的事，或因為沒空而結束聊天。
4. 不熟的人通常比較客氣，不是每個人第一次見面就互相吐槽。
5. 熟人之間會省略彼此已經知道的資訊，但不必刻意把所有句子縮到兩個字。
6. 很多日常對話沒有笑點，也不需要有。
7. 人物不需要每次聊天都說出自己的成長、人生觀或對友情的理解。
8. 法律系學生討論法律時可以精確、理性，但平常吃飯、上課、傳訊息仍然是一般臺灣大學生。
9. 「……」「我是說」「不要誤會」這類停頓和補充，不可成為全體角色的共同口頭禪。
10. 時事梗必須符合故事年份，不必每個角色都懂或都用。

## 2. 寫的時候怎麼做（操作規則）

### 2-1. 先寫「這句話要幹嘛」

- 每一句先想：他現在要什麼？
  - 要東西：筆記、充電線、位子。
  - 要資訊：教室、點名、截止時間。
  - 約人：吃飯、讀書。
  - 拒絕或延後：「我晚點」「下次」。
  - 趕時間：「我先走」。
  - 不想談：「先不要講這個」。
  - 關心：「要不要先吃飯」。
- 寫不出目的的句子，刪掉。
- **「有目的」不等於每句都推進劇情**（使用者 20:3x）：閒聊時，人也可能只是無聊、想找人講話，或隨口提到一件事。
- **人物的個性和改變，用「他要什麼、怎麼要」表現**。例：芯慈會主動約人，就是她變了，不用她說出來。

### 2-2. 怎麼結束

- 對話可以因為這些原因結束：鐘響、手機響、拿到要的東西、有人要走、另一個人來了、話題斷掉。
- **不要每場都有收尾金句。** 一場最多一句帶情緒的話，而且最好是動作。例：陪她走到校門口再繞回去（範例 97）。
- 閒聊階梯每一層也是對話，不是短文。三句交代一個人生道理的寫法，改掉。

### 2-3. 熟悉度決定說話方式

| 關係 | 怎麼說 |
|---|---|
| 不認識、剛認識 | 客氣、完整：「不好意思，這間是行政法嗎？」「這邊有人坐嗎？」不吐槽、不講私事 |
| 有點熟 | 會問實際的事、互相幫小忙（借線、幫買飯糰）；偶爾開玩笑 |
| 朋友 | 省略已知的事（「老地方？」）、答非所問、可以拒絕（「我今天好懶」） |
| 很熟、交往中 | 講很普通的生活小事；在意的事反而講得更少、更直接 |

### 2-4. 情境：人在忙，就不抒情（AA-B 負責檢查）

- **在忙的人**：
  - 包括：麵店顧店、Café 上班、上課中、考前、在搬東西、趕下一堂。
  - 這時候說話短、會被打斷、手上有事：「等我一下，我先送這桌。」
  - **不在這時候講童年、人生觀、對友情的理解。**
- **擦身而過**（走廊、路上的閒聊階梯）：
  - 適合問一件事、約一件事、抱怨一件事。
  - 不適合講三句的身世。
  - 身世、心事留給：坐下來的時候、兩個人都不趕的時候、事件裡。
- **深夜、私下、事件裡**：可以講比較深的話，但仍然是一般人的講法：「不太好。我晚點再跟你講可以嗎？」（範例 40）

### 2-4b. 會在任何地方說的台詞（BB-B 互審補）

- 好感升級（`rel_lines` 的 `up`）、道別（`bye`）、招呼（`greet.base`），會在**任何地點、任何時間**的下一次見面說：Café、總圖、麵店、溫州街、早上或晚上。
- 所以這些句子**不寫死地點、時刻、隔天的課**，例如不寫「你今天也坐三樓？」「已經六點了？」「明天早八」。
- 需要地點的，放進有 `location`／`time` 的 `greet.when`，或加條件。
- 問了問題就要有地方回答：加 `ch` 選項，或改成不用回答的句子。

### 2-5. 媒介不同，寫法不同

| 媒介 | 寫法 |
|---|---|
| 面對面 | 一般口語；可以有動作（旁白）；話會被打斷 |
| 私訊 | 一句一則；不太用句號，有時用空格代替標點；會打錯；「你在哪」「快了」；照片＋一句 |
| 群組 | 多人插話；有人已讀不回；有人只回貼圖；常常約到一半就改時間 |
| 短文社群（遊戲內虛構平台） | 發文語氣，像在對所有人說；留言接梗 |
| 課堂、法律討論 | 可以精確、用術語、句子完整；但下課走出教室就回到一般口語 |
| 手寫（便條、卡片、明信片、點單背面） | 可以條列，可以比說話感性一點，但一張只放一句心裡話。學姊的便條、可昕的週年卡片、芷若的明信片屬於這一類。條列和心裡話放在這裡最自然；說出口的照一般口語（BB-B 補） |

- 訊息體（不打標點、「所以」開頭、「哈哈」）只用在私訊、群組；同一個人當面講話是一般口語。例：阿凱、明軒（BB-B 補）。

### 2-6. 口頭禪和說話習慣

- **人物的個性靠行為、選擇、關心的方式呈現，不靠口頭禪。**
- 每個人可以有一兩個說話習慣，但：
  - 一場對話最多一次。
  - 一學期少量。重要的那次，要讓玩家感覺得到它被省著用。
  - **不能變成句子的格式**，例如「理由：X」「一、二、三」「這不是問句」「欸不是」。
- 「……」：
  - 只在真的停頓時用（想一下、講不出口、被打斷）。
  - **不是每場一定要有一個，也不是超過一個就錯**（使用者 20:3x 修正，取代原本「一場最多一個」的配額）。正常對話通常不靠省略號表現情緒。
  - 很多時候用逗號、句號，或什麼都不加，就夠了。
- 「我是說」「不要誤會」：全遊戲少用，不能當可愛的自我修正。
- **上限數字**（每人每學期；AA-B、BB-B 2026-10-16 定）：

| 人物 | 習慣 | 上限 |
|---|---|---|
| 以安 | 說出口的「理由：」（手帳畫面、旁白不算） | 2 |
| 語彤 | 「嗯。」開頭 | 每場 1；「阿姨也這樣說」全遊戲 2 |
| 柏翰 | 計時、精確數字（「一小時十二分」） | 2 |
| 芯慈 | 講自己的計畫表、顏色筆 | 1 |
| 子晴 | 「欸不是」／「這不是問句」（含「這是問句」「這是直述句」） | 2／1 |
| 學姊 | 說出口的條列（一、二、三；一件事） | 2（便條上不算） |
| 沛珊 | 「我可以問一個奇怪的問題嗎」 | 1 |
| 可昕 | 「假設」開頭 | 2 |
| 芷若 | 電影比喻 | 2 |
| 學姊 | 「重點是」（**學姊自己的語言設定**，不是祐廷的） | 遊戲進行到大一、大二：每學期最多 1，只用在實際事務；**大三起完全不用**（使用者 20:3x 確認；角色企劃：停下來以後不再說） |

### 2-7. AI 味句型（限量清單）

**下面這些不是永遠不能用，但每個人物每學期最多一句，只放在重要事件，日常閒聊、好感升級、手機訊息不用。**

- 「我原本以為……但現在我知道……」「我以前覺得……現在覺得……」
- 「這是我最近才明白的事。」「後來才發現……」
- 「因為你，我開始……」
- 「一個人很好，但兩個人……」
- 「原來重要的不是……而是……」
- 「不是 X，是 Y。」的格言句，例：「不是不行，是還沒。」「位子不是給妳的，是給我們的習慣。」
- 「這是我第一次……」「我第一次覺得……」
- 把物件擬人化當感情，例：「它看過很多碗麵。」「手的味道是我的行事曆。」
- 收尾的漂亮短句，例：「……今天沒有規則，也很好。」「今天很好。真的。」
- 用規則條文、數字精確來裝可愛，例：「我的規則第七條……」「今天用了一小時十二分。……很值得。」
- 用自己的專業或興趣比喻感情，例：子晴的存檔、讀取、新手教學；芷若的光、鏡頭、「不會散場」；方奕廷的植物；以安的理由欄、規則（BB-B 補）。

### 2-8. 也不要矯枉過正

**使用者 20:3x 點名的「新的 AI 化傾向」**（`AA_193` 第二節）：
1. 為了口語而強行縮短句子。
2. 為了口語而大量加入「欸、啦、靠北、笑死」。
3. 為了不抒情，反而強迫每句話都只講生活瑣事。
4. 為了表現角色特徵，安排固定口頭禪或象徵性道具。
5. 為了完成角色成長，刻意讓人物宣告自己的改變。
6. 為了呼應伏筆，安排第三個人出來解釋前面那句話的意義。
7. 為了寫出好笑的台詞，每段對話最後都安排一句吐槽。
8. 為了符合參考資料，強行追求標點符號、語助詞或句長的統計比例。**數字（`AA_192` 第 0 節）只用來發現問題，不是目標。**

**每次改稿都問**：「如果這是我的首都帝大同學，在這個時間、這個地方、跟這個熟悉程度的人講話，我會不會覺得奇怪？」覺得像在演戲，就重寫。


- 不要為了口語亂加「欸」「笑死」「靠北」「破防」。網路用語照 `AA_186` 4-2、4-5：看人物、看關係、看年份，大部分人大部分時候不用。
- 不要故意把句子縮成兩個字。「留啊」「不要問」「我很好」「理由：輪流」放在不合理的情境裡，一樣很假。
- 回答要對上對方問的內容和當下目的。
- 不要把 100 組範例的句子直接搬進遊戲、換名字。

## 3. 驗收清單（每段台詞交出去以前）

1. **目的**：這段每個人都有當下要的東西嗎？
2. **對上**：每一句都接得上上一句嗎？或者是故意答非所問，而且看得出來？
3. **情境**：人在忙、在趕、在擦身而過的時候，有沒有長篇抒情？
4. **熟悉度**：不熟的人有沒有太快吐槽、太快講私事？
5. **結尾**：結尾是不是一句金句？能不能改成「他要走了」「手機響了」？
6. **感悟**：有沒有第 2-7 節的句型？這學期這個人用過了嗎？
7. **口頭禪**：同一場有沒有同一個習慣出現兩次？「……」有沒有超過一個？
8. **媒介**：私訊像私訊、群組像群組嗎？
9. **上下文**：遮住上一則還看得懂嗎（`AA_186` 第 2 節）？
10. **認得出人**：把名字遮住，認得出是誰嗎？有沒有兩個人說一樣的話？

**三小時測試**（改完一個學期以後做一次）：
- 隨機抽 30 句日常台詞（閒聊階梯、好感升級、手機、招呼），遮住名字。
- AA、BB 互相猜是誰說的。
- 再數三件事：人生感悟有幾句？「……」開頭有幾句？有沒有兩個人用同一種句型？

## 5. 流程

1. **AA-B、BB-B 各自做第一批對照**：
   - AA：以安、語彤、阿哲、小語、柏翰、芯慈，加上情境、時序。
   - BB：BB 的人物，加上口氣、句型重複。
   - 兩個人一起：最常見的日常閒聊、好感升級、手機訊息。
2. **互審**以後合成一份，交**使用者確認**。
3. 使用者確認了準則和寫法，才：
   - 照同樣的方法改完其他台詞，一學期一學期改，每學期做一次三小時測試。
   - 交 LAWWW-B 整合。程式字串由 LAWWW-B 改。
4. **不動的東西**：
   - 已經定案的人物關係、事件、旗標、選項的數量和效果。
   - 法律內容的正確性：法律討論照 `AA_122`，判決字號不杜撰。
5. 改字的分級照 D50。這一次因為使用者要先看，**第①、②級也先不交整合**。

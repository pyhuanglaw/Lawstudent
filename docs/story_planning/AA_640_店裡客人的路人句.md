# AA_640 店裡客人的路人句（SHOP-DINERS-1103）

- 回 LAWWW 11-03 13:53：開發分支 9950721c4，17 間店營業時間有客人，客人點了現在不說話。
- 用法：玩家點路人客人（或走近）時，**聽到一句**，不接對話、不影響數值。同一位客人同一天只講一句；同一句一天內不重複。
- 規則：
  - D116：不跟別人比、不嫉妒。
  - D127：不叫使用者讀文件；書店、Café 讀書區的客人講話一律加「（小聲）」。
  - 不出現真實店名或品牌，不提真實學校或人物。
  - 講的是自己的事，不評論玩家，也不提女主角。
- 等級：第②級，AA 定稿（D109）。
- JSON 在最後一節，`speaker` 一律寫 `'路人'`（客人兩個人一桌時，第一句是 A、第二句是 B，照 `pair`）。

## ① 吃飯的店：兩人一桌的閒聊（聽一句；有的是兩句一組）
1. A：你那份報告交了沒？／B：交了。三點五十九分。
2. A：這家的湯可以續嗎？／B：可以，自己去舀。
3. A：週末要回家嗎？／B：要。我媽說再不回去就不用回去了。
4. A：明天早八你起得來嗎？／B：……我設了三個鬧鐘。
5. A：下學期要不要一起修那堂通識？／B：好啊，聽說作業很少。
6. A：你剛剛是不是加了兩次辣？／B：一次是不小心的。
7. A：我室友昨天半夜在煮泡麵。／B：然後呢？／A：我也吃了。
8. A：吃完要去哪？／B：回去睡。下午沒課。

## ② Café、書店的路人（一句；全部小聲）
1. （小聲）這本我上次看到一半，被別人買走了。
2. （小聲）我再坐一個小時就好。真的。
3. （小聲）插座在你那邊嗎？……謝謝。
4. （小聲）這段我看第三遍了，還是看不懂。……沒事，再一遍。
5. （小聲）明天要交的，我現在才開始寫。
6. （小聲）這本封面好看。……先拍起來，下次買。
7. （小聲）咖啡涼了。算了，涼的也好喝。

## ③ 便利商店：結帳一句
1. 載具，謝謝。
2. 這個有第二件六折嗎？……喔，那我拿兩個。
3. 不用袋子，我拿著就好。
4. 幫我加熱，謝謝。……不用，我在這邊等。
5. 欸，我零錢好像不夠。……刷卡好了。
6. 還有一個，我忘了拿。等我一下。

## 給 LAWWW 的小註
- ① 是兩個客人互相講，玩家只是聽到；不需要玩家坐下。
- ② 書店的第 1、6 句、Café 的第 7 句只適合各自的店：書店用 1～6，Café 用 2～5、7。
- ③ 是客人對店員講的；店員不另外回話（現有店員句照舊）。
- 考試週（第 16 週）可以加一句給 ②：「（小聲）考完這科就解脫了。」——要不要加你決定。

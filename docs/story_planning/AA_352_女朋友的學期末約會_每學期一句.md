# AA_352　女朋友的學期末約會：飯桌那一句每學期不一樣

> - AA-C 2026-10-21，劇情總監自主修訂（使用者 10-21：「不同學期是否有成長，而不是反覆演類似劇情」）。屬於「調整非關鍵的日常小互動」，不動感情走向。
> - **問題**：開發分支 `termend_lines.js` 的 `GF`（女朋友的學期末約會）有固定的流程：開場旁白 → **飯桌一句（`table`）** → 話題池兩句（`POOL[學期]`，每學期不同）→ 邀約鉤子 → 收尾。
>   - 可昕有自己的 `KX`，每學期都不一樣。
>   - 其他六位的 `table` **八個學期都是同一句**。例：以安每學期都說「這學期的手帳，很多頁都寫到你。……你不准翻。」，學姊每學期都說「今天我沒帶計畫本出門。」。
>   - 沛珊大三起在台南（`PS_TN`），也沿用同一句。
> - **改法**：照可昕 `KX` 的做法，每位每學期一句（`tableByTerm[學期]`；沒有的學期照原本的 `table`）。句子跟著她那學期真的在過的生活（話題池、presence、事件包裡已經有的事實），不新增設定。
> - 寫法照口氣表第 1 節：不宣告自己的改變、不用專業或興趣比喻感情、沒有模板句；不和同一場的話題池重複。

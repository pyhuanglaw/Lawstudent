## 2. 出題規則（照大四 `../exam_y4/` 的做法）

1. **參考律師一試、高考**：題型、考點、難度照律師第一試（綜合法學）與高考法制類的選擇題風格；**題目自己改寫，不照抄原題**。
   - 對到真的原題才寫出處（年度、科目、題號），對不到就寫「參考考點」，不編出處。
2. **四選一、唯一答案**；選項不重複；四門課的正確答案 A～D 平均分配，不固定規律。
3. **條文逐字核對**：每題的 `verify` 列出（法規代碼, 條號, 一段原文），檢查程式確認這段文字逐字出現在全國法規資料庫的現行條文裡。
4. **不杜撰判決字號、釋字、憲判字號**：要用的話必須查到原文，`verify` 寫得出來；查不到就不用，只講條文。
5. **解析**（`core`）：寫為什麼對、其他選項為什麼錯，每題寫依據（`basis`）。
6. **遊戲文字規則**：繁中；題幹不出現真實人名、店名、品牌（D77）；案例的人用甲、乙、丙。
7. **狀態**：作者自審完 `AI_SELF_REVIEWED` → 另一位 AI 交叉審通過 `AI_CROSS_REVIEWED`（`crossReviewedBy`）。**只有交叉審通過的才抽。**

## 3. 抽題順序（給 LAWWW）

期末考、期中練習每份 5 題，依序：
1. 課堂題（課堂提問 `ask`、討論課 `disc`）
2. 使用者的正式題庫（`../exam_official/`、`QBANK`）
3. **這裡的 AI 題（只用來補到 5 題）**

- 考卷上不標示題目來源。
- `course_bank_map.json` 的狀態改成三個來源合計 5 題以上就開考，由 AA 更新。

## 4. 檔案

- `AA_<課程>.json`、`BB_<課程>.json`：格式和 `../exam_y4/AA_enforcement.json` 相同，`source:'AI_Y1Y3'`。
- `tools/build_ai.py`：原稿（Python）→ JSON。會檢查條文逐字、格式、答案分配、週次；任何一項不符就停止。
- `basis_ai.json`：用到的現行條文快照（全國法規資料庫）。
- `REVIEW.md`：自審與交叉審紀錄。

## 1. 檔案

| 檔案 | 內容 |
|---|---|
| `course_bank_map.json` | 每門現行法律課的題庫狀態（ENABLED／INSUFFICIENT／PENDING_AA_REVIEW／NO_EXAM）與來源 |
| `civil_20_2026-10-14.json` | 使用者的民法 20 題（原文：`../使用者題庫/民法_20題_2026-10-14.md`），逐字轉換 |

| `tools/convert_user_md.py` | 使用者 Markdown → JSON；題幹、選項、答案、考點、解析逐字核對，不符就停止 |
| `tools/map_*.json` | 每題對到哪一門課、哪一週（AA 依教學範圍定），以及要回報使用者的問題（`flags`） |
| `tools/check_official.py` | 檢查：課程 id 是現行的課、沒有刪掉的課、四選一的格式、答案在選項裡、同一門課沒有重複的題目、狀態只有 `USER_CONFIRMED`、每門課的題數 |

## 3. 收到使用者新題目時

1. 原文存進 `../使用者題庫/`（照使用者的格式：每題選項下面附答案、考點、解析）。
2. 寫 `tools/map_<檔名>.json`：每題對到課程與週次（照 `syllabus` 每週的黑板）；看不出來或有疑問的寫進 `flags`，回報使用者。
3. `python3 tools/convert_user_md.py <原文> <對應> <輸出>`，再跑 `python3 tools/check_official.py`。
4. 更新 `course_bank_map.json` 的題數與狀態，通知 LAWWW。

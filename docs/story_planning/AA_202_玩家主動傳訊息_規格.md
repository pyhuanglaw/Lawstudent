# AA_202　玩家主動傳訊息給朋友（規格）

> - **依據**：使用者 2026-10-16 約 22:1x 問 LAWWW-B「還是沒有跟朋友傳訊息的功能？」（D79／D86，LAWWW-B 22:13 轉來要規格）。
> - 現在的手機只能看對方傳來的、回對方的提問、按「約」，玩家**不能自己開話題**。
> - **基礎**：`AA_70` 第 1 節（手機是生活不是選單、沒有已讀不回的懲罰），以及各人的手機習慣（`AA_70` 第 2 節、`BB_70` x-2）。
> - 照 `AA_188` 自然口語。AA-B 2026-10-16 22:1x。
> - 分工：系統規則和 AA 六位的回覆＝AA-B；BB 九位＝BB-B；實作＝LAWWW-B。

## 1. 玩家怎麼傳

- **位置**：手機「朋友」→ 某人的對話串 → 新按鈕「**傳訊息**」→ 選一個話題。現有的「約」按鈕照舊。
- **話題**（第一批四個；不是每個人、每個時候都有）：

| 話題 | 玩家傳的（祐廷的字，照情況挑一則） | 什麼時候有 |
|---|---|---|
| **在幹嘛** | 「在幹嘛」／「你在哪」 | 一直都有 |
| **問課** | 「今天那堂你有抄到嗎」／「下禮拜要交什麼」／「這題你怎麼寫」 | 學期中；對方是**同一門課**的同學（以安、阿哲、小語、柏翰、芯慈、明軒；**芷若只有大一**，經原同一門課；**沛珊只有大一上到大二上**，大三起她在別的學校）或學長姐（學姊不在美國時、Kevin） |
| **分享** | 傳一張照片：路上的貓／今天吃的東西／一張講義（玩家三選一） | 一直都有 |
| **晚安** | 「晚安」 | 21:30 以後；`CLOSE_FRIEND` 以上，或曖昧、交往中 |

- **次數**：同一個人**一天一次**（對方回了，玩家可以再回一句，就結束）。不同的人不限。
- **以後可以加**（第二批）：謝謝（對方幫過忙以後）、生日快樂（生日當天）、問你還好嗎（對方遇到事以後）、新年快樂（節日）。

## 2. 對方什麼時候回

照對方**那時候在做什麼**（人物作息、`AA_197` 1-4 的假期所在地），不是馬上回：

| 對方當下 | 什麼時候回 |
|---|---|
| 有空 | 1～10 分鐘（照個性：以安、阿哲快；語彤、方奕廷慢） |
| 上課、打工、社團、家教 | 結束以後 |
| 睡覺（各人的就寢時間，例：以安 22:30 以後不回） | 隔天早上（見 3-1 第 4 點：晚安只回「昨天睡了」這一類） |
| 在老家、旅行 | 照常回，內容會提到人在哪 |
| 在國外 | 照當地時間（時差表 `AA_144` 5-2） |
| 考試週 | 回得比較短 |

- **已讀不回**：不熟（`ACQUAINTANCE`）的時候，偶爾只回一張貼圖或「哈哈」，或隔很久才回。**不會永遠不回**。
- **沒有懲罰**（`AA_70` 1-9）：玩家不傳、不回都不扣分。

## 3. 回覆內容

- **每個人、每個話題，照關係分三層**：
  - A＝認識、有點熟；
  - R＝朋友、好朋友；
  - L＝曖昧、交往中（只有戀愛對象有）。
- 每層 2～3 則，輪流用。
- **情況版**（有的才寫，沒有的用一般版）：考試週、放假中、在老家或國外、深夜。
- **回問**：有時候對方回完會反問一句（例：「你呢」），玩家有兩三個選項，選完就結束。不要每次都問。
- **寫法照各人的手機習慣**（不是當面的口氣）：
  - 以安：快、短、只有一張兔子「收到」貼圖；
  - 小語：一句拆很多則、很多表情符號；
  - 柏翰：數字多、不用貼圖；
  - 語彤：沒有貼圖；
  - 阿哲：「走啦」「+1」、語音、食物照片；
  - 芯慈：追劇和經濟學；
  - BB 九位照 `BB_70` x-2。
- **不能說的**：還沒發生的事、還沒認識的人；不能讓熟的人重新自我介紹。法律問題不給答案以外的新判斷（問課只回「抄到了，拍給你」「我也不會」這類）。

### 3-1. 句子的條件和挑選順序（`BB_178` 互審後補，AA-B 2026-10-16 22:3x）

1. **每句都可以帶標籤**：時段（早上／下午／晚上／深夜）、平日或週末、學期中或放假、所在地（臺北／老家／國外）、學年、層。**沒有標籤的句子＝任何時候都說得通**。
   - 例：「剛下課」標「學期中、平日、有課的那天課後」；「在店裡」標語彤的店裡時間；「在社辦」標學期中。
   - 手機上說的地點要和這個人當下實際在的地方一致（`AA_197` 1-4）。
2. **挑哪一組的順序**：在國外 → 在老家或旅行 → 考試週 → 深夜 → 一般。前面的情況成立就用那一組；那一組這段期間已經播過，就回到一般組裡**沒有標籤**的句子。
3. **情況版不能只有一句**：寒暑假兩個月、一天可以傳一次，同一句會一直重播。每種情況寫 2～3 則，或者**同一段期間只播一次**，之後回到一般組。
4. **回覆延到隔天**（對方睡了、在飛機上）：只回「昨天睡了，現在才看到」這一類，**再接一般版**。玩家傳的如果是**晚安**，就只回「昨天睡了」那一句，**不接晚安的句子**（不然隔天中午會冒出「晚安」）。
5. **不寫死時間和科目**：「明天」「今天」「晚餐」「下午」、科目名、年級都不寫進會重播的句子；一定要寫的，加標籤（例：「明天早上有課」只在隔天真的有早上的課時用）。
6. **對方問問題，玩家就要有選項**：回覆結尾是問句的（「你呢？」「多少錢？」），一定配回問選項；配不了就改成不是問句。
7. **L 層每個人最多一句帶感情的話**，而且五個戀愛對象的句型不同。很熟、交往中的人講的是很普通的生活小事（`AA_188` 第 74 行）。
8. **「你就傳了」**（剛好在想要不要找你，你就傳了）：**只留子晴一個人，而且只在立即回覆時用**；延後回覆的時候不用（不然會變成「下午兩點才回，卻說剛好在想你」）。

## 4. 和現有系統的關係

- **熟悉度**：對方回了，**一天最多 +1**（同一個人）。一週內傳超過三次，那週就不再加。這是用來讓「常聯絡」有一點意義，不是刷好感的方法（`AA_70` 1-9：不用錢、不用次數買關係）。
- **閒聊階梯**（ladder，當面的）：手機訊息**不推進**。
- **戀愛**：
  - 交往中的「晚安」只是相處，不加特別的數值；
  - 不傳也不扣分；
  - 可昕的遠距線（她每晚的訊息、通話，BB）照舊，玩家主動傳的是另外一條。
  - **祐廷交往中**（法律系開場預設和可昕交往）：**其他女性角色一律友情版**（`AA_112` 8-1）。（**2026-10-17 改讀「她知道」**：「交往中」只在**她知道**祐廷在和別人交往時才算——可昕＝`knowsGF[她]`，其他女主角＝`knows[她][Y]`（`BB_191` §9、`AA_218` 17-8）；她不知道＝照一般版。）**不開晚安**；R 層不用曖昧的句子、不用深夜只給一個人的訊息；回覆時間照交往中的版本（例：芷若改在下班後回，`BB_70`）。分手以後、兩人都單身才回到一般規則。
- **群組**：這一批不做「在群組發言」。群組裡現有的 ask 選項照舊。
- **第一次能用**：**拿到這個人的聯絡方式以後**。每個人拿到的時間不同，照現有的「交換聯絡方式」條件（`BB_172`、`AA_134`）；BB 九位另有門檻的寫在 `BB_178`（例：子晴的私訊要到 Q6 之後；學姊沒有一對一的閒聊私訊，只回事務性的話，`BB_70`）。
- **存檔**：新欄位（每人今天傳過沒、這週次數、待回覆的訊息）預設空的。這一版不用相容舊存檔。

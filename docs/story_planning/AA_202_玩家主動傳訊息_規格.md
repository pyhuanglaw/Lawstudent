# AA_202　玩家主動傳訊息給朋友（規格）

> - **依據**：使用者 2026-10-16 約 22:1x 問 LAWWW-B「還是沒有跟朋友傳訊息的功能？」（D79／D86，LAWWW-B 22:13 轉來要規格）。
> - 現在的手機只能看對方傳來的、回對方的提問、按「約」，玩家**不能自己開話題**。
> - **基礎**：`AA_70` 第 1 節（手機是生活不是選單、沒有已讀不回的懲罰），以及各人的手機習慣（`AA_70` 第 2 節、`BB_70` x-2）。
> - 照 `AA_188` 自然口語。AA-B 2026-10-16 22:1x。
> - 分工：系統規則和 AA 六位的回覆＝AA-B；BB 九位＝BB-B；實作＝LAWWW-B。

## 1. 玩家怎麼傳

- **位置**：手機「朋友」→ 某人的對話串 → 新按鈕「**傳訊息**」→ 選一個話題。現有的「約」按鈕照舊。
- **話題**（第一批四個；不是每個人、每個時候都有）：

| 話題 | 玩家傳的（祐廷的字，照情況挑一則） | 什麼時候有 |
|---|---|---|
| **在幹嘛** | 「在幹嘛」／「你在哪」 | 一直都有 |
| **問課** | 「今天那堂你有抄到嗎」／「下禮拜要交什麼」／「這題你怎麼寫」 | 學期中；對方是**同一門課**的同學（以安、阿哲、小語、柏翰、芯慈、沛珊、明軒）或學長姐（學姊、Kevin） |
| **分享** | 傳一張照片：路上的貓／今天吃的東西／一張講義（玩家三選一） | 一直都有 |
| **晚安** | 「晚安」 | 21:30 以後；`CLOSE_FRIEND` 以上，或曖昧、交往中 |

- **次數**：同一個人**一天一次**（對方回了，玩家可以再回一句，就結束）。不同的人不限。
- **以後可以加**（第二批）：謝謝（對方幫過忙以後）、生日快樂（生日當天）、問你還好嗎（對方遇到事以後）、新年快樂（節日）。

## 2. 對方什麼時候回

照對方**那時候在做什麼**（人物作息、`AA_197` 1-4 的假期所在地），不是馬上回：

| 對方當下 | 什麼時候回 |
|---|---|
| 有空 | 1～10 分鐘（照個性：以安、阿哲快；語彤、方奕廷慢） |
| 上課、打工、社團、家教 | 結束以後 |
| 睡覺（各人的就寢時間，例：以安 22:30 以後不回） | 隔天早上 |
| 在老家、旅行 | 照常回，內容會提到人在哪 |
| 在國外 | 照當地時間（時差表 `AA_144` 5-2） |
| 考試週 | 回得比較短 |

- **已讀不回**：不熟（`ACQUAINTANCE`）的時候，偶爾只回一張貼圖或「哈哈」，或隔很久才回。**不會永遠不回**。
- **沒有懲罰**（`AA_70` 1-9）：玩家不傳、不回都不扣分。

## 3. 回覆內容

- **每個人、每個話題，照關係分三層**：
  - A＝認識、有點熟；
  - R＝朋友、好朋友；
  - L＝曖昧、交往中（只有戀愛對象有）。
- 每層 2～3 則，輪流用。
- **情況版**（有的才寫，沒有的用一般版）：考試週、放假中、在老家或國外、深夜。
- **回問**：有時候對方回完會反問一句（例：「你呢」），玩家有兩三個選項，選完就結束。不要每次都問。
- **寫法照各人的手機習慣**（不是當面的口氣）：
  - 以安：快、短、只有一張兔子「收到」貼圖；
  - 小語：一句拆很多則、很多表情符號；
  - 柏翰：數字多、不用貼圖；
  - 語彤：沒有貼圖；
  - 阿哲：「走啦」「+1」、語音、食物照片；
  - 芯慈：追劇和經濟學；
  - BB 九位照 `BB_70` x-2。
- **不能說的**：還沒發生的事、還沒認識的人；不能讓熟的人重新自我介紹。法律問題不給答案以外的新判斷（問課只回「抄到了，拍給你」「我也不會」這類）。

## 4. 和現有系統的關係

- **熟悉度**：對方回了，**一天最多 +1**（同一個人）。一週內傳超過三次，那週就不再加。這是用來讓「常聯絡」有一點意義，不是刷好感的方法（`AA_70` 1-9：不用錢、不用次數買關係）。
- **閒聊階梯**（ladder，當面的）：手機訊息**不推進**。
- **戀愛**：
  - 交往中的「晚安」只是相處，不加特別的數值；
  - 不傳也不扣分；
  - 可昕的遠距線（她每晚的訊息、通話，BB）照舊，玩家主動傳的是另外一條。
- **群組**：這一批不做「在群組發言」。群組裡現有的 ask 選項照舊。
- **第一次能用**：有聯絡方式就能傳（D81：大一上第一週）。
- **存檔**：新欄位（每人今天傳過沒、這週次數、待回覆的訊息）預設空的。這一版不用相容舊存檔。

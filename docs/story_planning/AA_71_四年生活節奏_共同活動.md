# AA_71　新版四年生活節奏與共同活動

## 0. 節奏原則

1. **一學期大約十六週**（16 週制 DOC-18W）。每學期的結構：
   - 2～4 個**固定節點**（開學、期中、期末、搬宿舍……，`AA_13`）；
   - 3～5 個**共同活動**（大家一起去做的好玩的事，第 2 節）；
   - 最多 1 個 **CG 等級的重大時刻**；
   - 其他時間都是**日常**：上課、邀約、群組、走路、吃飯（`AA_70`）。
2. **重大事件之間一定有好日子**。兩個情緒比較重的事件之間，至少隔兩週的日常與一個共同活動。
3. **同一個活動，每年都不一樣**：同樣是中秋烤肉，大一是第一次，大四是帶學弟。玩家用「同一件事的變化」感覺到時間（`AA_05` 的《One Day》原則，改成溫暖的用法）。
4. **不在台北的人也參與**：出國、回家、畢業的人，用視訊、照片、寄東西參加共同活動，不會從生活裡消失。
5. **玩家可以不去**：共同活動都可以不參加，不扣分；沒去的話，群組裡會有照片，下次見面有人跟他講發生了什麼。

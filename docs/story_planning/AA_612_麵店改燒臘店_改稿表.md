## 2. 總則（換字的規則）

1. **店名、地點字幕、事件標題、日誌、目標、群組名**：「阿鳳麵店」「麵店」→「**公館燒臘**」（「公館 阿鳳麵店」→「公館燒臘」，不要變成「公館 公館燒臘」）。
2. **台詞、旁白、手機、動態**：「麵店」→「**燒臘店**」。
3. **餐點**（照原句的意思換）：
   - 招牌「乾麵（加滷蛋）」→「**叉燒飯**（加滷蛋）」；「餛飩湯」→ 看句子換「燒鴨飯／油雞腿飯／例湯」；「大碗」→「雙拼／三寶飯」；「肉燥」→「多切一片叉燒／多淋一匙滷汁」；「不要蔥」→「不要淋汁」；「一把蔥」→「一匙薑蓉」。
   - 「一碗麵」→「一盤飯」；「麵要糊了」→「飯要涼了」；「麵來了」→「飯來了」；「吃麵」→ 說的是這家店就「吃燒臘」，只是「吃飯」的意思就「吃飯」；「煮麵／下麵」（阿姨）→「切叉燒／斬燒鴨」；「熬湯」→「醃肉、開爐」；「明年繼續煮」→「明年繼續烤」。
   - **剝蒜頭照留**（燙青菜、蒜蓉都要用）；語彤剝蒜頭的句子照 AA_630 改。
4. **「阿鳳」**：照留，當老闆的名字（「阿鳳阿姨」「——阿鳳」）和熟客的口語簡稱（「公館那家，阿鳳。」「阿鳳的叉燒」）；店名、招牌一律「公館燒臘」。
5. 程式 id、旗標名、背景圖檔名、3D 物件 id **都不改**；有程式拿「麵店」「阿鳳麵店」「乾麵」做比對的，列在 C 表，**要和句子一起改**（不然功能會壞）。
6. 語彤的句子：照 AA_630。
7. 人物口氣照 `00_人物口氣表.md`。
8. 「人」欄有「？」的是從程式結構推定的說話人（例如 JSON 裡最近的人物 id），LAWWW 照位置改就好。

## 7. 核對：原句都在開發分支裡

下面的腳本讀這份文件的 A／B／C 表，每一列照「位置」的檔案用 `git show origin/claude/confident-ritchie-8rwh7t:<檔案>` 讀出來，確認「原句」一字不差在那一行（找不到那一行就找整個檔），印出找不到的。

```python
#!/usr/bin/env python3
# 用法：python3 verify_612.py docs/story_planning/AA_612_麵店改燒臘店_改稿表.md
import re, subprocess, sys
B = 'origin/claude/confident-ritchie-8rwh7t'
subprocess.run(['git', 'fetch', '-q', 'origin', B.split('/', 1)[1]])
doc = open(sys.argv[1], encoding='utf-8').read()
row = re.compile(r'^\| ([AYC]-\d{3}) \| `([^`:]+):(\d+)` \| [^|]* \| (.*?) \| .*? \| .*? \|$', re.M)
cache, n, bad = {}, 0, []
for m in row.finditer(doc):
    rid, f, ln, orig = m.group(1), m.group(2), int(m.group(3)), m.group(4)
    if f not in cache:
        cache[f] = subprocess.run(['git', 'show', f'{B}:{f}'], capture_output=True, text=True).stdout
    src = cache[f]; lines = src.split('\n'); n += 1
    cands = {orig, orig.replace('｜', '|')}
    if any(c in lines[ln - 1] for c in cands if ln - 1 < len(lines)):
        continue
    if any(c in src for c in cands):
        bad.append((rid, f, ln, '行號不對（檔案裡有）')); continue
    bad.append((rid, f, ln, '找不到：' + orig[:30]))
print(f'核對 {n} 列；不符 {len(bad)} 列')
for b in bad: print(*b)
sys.exit(1 if bad else 0)
```

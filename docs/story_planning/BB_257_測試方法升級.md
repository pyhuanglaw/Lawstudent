# BB_257　測試方法升級（TEST-METHODS-1104）

- 起因：使用者 2026-11-04 14:2x 問「你沒辦法從github開源找一些更有效的測試遊戲方法嗎」。BB-C 用選擇題問要先做哪幾項，使用者回「自己參考github開源自己決定」，等於授權 BB 自己決定（user_asks_BB UA-BB-1104-TEST-METHODS-DELEG）。
- 原則：
  - 照開源專案常用的做法自己寫：屬性測試（fast-check／Hypothesis 那種：隨機產生輸入、用種子重現）、猴子測試（gremlins.js 那種：亂點找當機）、覆蓋率（Chromium 內建的 JS coverage）、多瀏覽器（Playwright WebKit）、CI（GitHub Actions）。
  - 遊戲本身不加 npm 相依。測試盡量用 Node 內建功能、Playwright 內建功能、已經有的 `tests/pg_harness.js`。
  - 判定照舊歸 BB；探針、執行歸 CC；GitHub Actions 的設定歸 LAWWW。
- 順序：都排在 v9.10.20 擋發布那一批後面；T0 和 T1 一起先做。T1、T3 可以在雲端寫、在雲端跑，不佔使用者電腦（D125：等 PC 的時候先做這個）。

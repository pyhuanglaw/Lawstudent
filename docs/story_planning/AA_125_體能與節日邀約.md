## 1. 手機約不了的原因（AA 決定）

- 原因：v9.6 聊天大多只加熟悉 1，很多人還沒到「認識」（熟悉 5），手機上就約不了。
- `AA_124` 第 1 節的新數值（今天第一次聊天熟悉 +2）會改善。
- LAWWW 會讓手機列出所有認識的人，約不了的寫原因。原因的文字：

| 情況 | 手機上寫 |
|---|---|
| 還不到「認識」 | 「你們只打過招呼。先在學校多聊幾次。」 |
| 吃飯要「有點熟」 | 「再熟一點，才約得出去吃飯。」 |
| 散步要「朋友」 | 「散步要等你們變成朋友。」 |
| 不在學校（交換、畢業） | 「她這學期在國外。」／「他已經畢業了。」 |
| 已經有約 | 「你們已經約好了：（星期）（時間），（地點）。」 |
| 任一方有伴侶、兩個人單獨的邀約（`BB_70` 0-2） | 「兩個人單獨出去不太好。找大家一起吧。」 |
| 那個時間沒空（上班、上課、社團） | 照現有的做法：直接給「改天」的時間 |

- 「她／他」照人物的性別。不寫數字。

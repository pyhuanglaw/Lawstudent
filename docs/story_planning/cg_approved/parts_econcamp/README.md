## 合成第一版（2026-10-17 00:5x，BB-B，作廢）

- 使用者 00:5x：「為什麼他們後面一堆人合照他們自己拍自己的」：第一版背景的學生站在遠遠的台階上，和七個人像兩張照片。下面是第一版的做法，第二版照用。

- 成品：`../cg_econ_camp.webp`（1920×1080），**READY_FOR_REVIEW**，等使用者看。
- 做法：
  - 去背：`../parts_cg69/tools/cutout.py`（同第 69 組）。
  - 合成：`compose_econ.py`。背景放大 1.1 倍、往左裁（讓後面的學生群在七個人後方），鏡頭當作 2 m 高（拍大合照的人站高一點），用地平線算每個人的腳在哪、多大；後排每公尺 280 px、前排再近一點（×1.09）。
  - 身高：站著的照「頭頂到腳底」縮放；半蹲的（品妤、可昕、祐廷）用頭的大小換算（約 7.55 頭身），所以蹲下的人頭不會變大或變小。家豪學長原圖的頭比較小，用 172 cm 算，頭才不會比別人小太多。
  - 影子：腳下接觸陰影；投影往人的右後方倒、大部分被人擋住。
- 站位（`BB_132` 第 71 組）：後排 唐睿、阿勳、家豪學長、韋綸；前排半蹲 品妤、可昕、祐廷；唐睿、品妤在左邊（別隊）。
- 已知不足：
  - 背景的陽光方向不太一致（建築正面亮、石板右邊有反光），人物是左上方來的光，近看人物比背景平一點。
  - 家豪學長的頭還是比別人小一點點（原圖的頭身比較高）。

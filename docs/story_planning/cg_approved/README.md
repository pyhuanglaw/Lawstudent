> **這是什麼**：使用者用 AI 生成、BB 檢查通過的事件 CG。全部人物都是虛構的。

> **LAWWW 整合時**：
> - 放到 `assets/cg/<character_id>/<檔名>.webp`，`CG_REGISTRY` 的路徑照遊戲現有的設定。
> - 尺寸放大到 1920×1080（`docs/CHARACTER_ART_SPEC.md`）。
> - 授權記錄寫進 `LICENSES.md`：使用者用 AI 生成。
> - **CG 完成不等於事件可以實作**：還沒批准的主要人物劇情照舊等使用者批准。

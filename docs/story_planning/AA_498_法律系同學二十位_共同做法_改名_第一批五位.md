## 2. 共同做法
### 2-1. 每個人固定一個樣子、固定在一個地方
- **3D**：
  - 每人固定一個路人底模（不再每換一次區域就輪換）；
  - 一個道具或外觀記號（第 3 節的表；LAWWW2 做得到的先做，做不到的先只有描述）。
- **地點**：取代現在「五組、每組取前幾位」的分法（`story3d.js` 的 `pick`）。每人照第 3 節的表，在自己的地點和時段出現。
  - 這樣三位永遠不出現的（廖芸萱、嚴守誠、馬佳蓉）也有自己的地方。
- **在校時間**照舊（`AA_120` 7-3）：
  - 大三的到祐廷大二結束；
  - 大二的到大三結束；
  - 同屆的四年都在。
  - 學長姊畢業那一週，各人有一場或一則（各人的節），之後不在校園出現。

### 2-2. 認識之前、之後怎麼稱呼
- **認識之前**：按鈕寫「和〈外觀描述〉說話」。外觀描述照第 3 節，**和出現的地點對得上**；同一個人在兩個地方的，各有一句。
- **認識之後**：
  - 按鈕寫「和〈名字〉說話」。
  - 人物頁：名字＋一行記號（第 3 節「人物頁」欄），例：「曾靖雯｜每天六點在傅鐘旁邊吃早餐的同學」。
  - 做過的事一行一行加在下面。
- 「被生成 3 次以後外觀描述進朋友頁」那個規則拿掉：沒說過話的人不進朋友頁。

### 2-3. 第一次說話＝認識的那一場
- 取代現在「你是我們班的吧／我是○○。／（facts[0]）。……你呢？」那一套。每人一場，各人的節寫。
- 沒有回答選項的「你呢？」不再出現。

### 2-4. 閒聊
- 每人 8～10 句，照學期、熟悉度、做過的事解鎖，每句一次，一天一句。原本的三句都留在裡面。
- 說完以後不再只點頭：每人三句「之後的招呼」輪流，是他自己的小動作或一句話。
- 「開學、期中、期末共用的短招呼」照舊（三句都說完以前，也可以穿插）。

### 2-5. 「其實……」（秘密）
- 照舊記 `SHARED_SECRET`，**加三個選項**（各人的節）。選了什麼會改他之後的一句話或一場戲。
- 有些人的秘密改在「順手的事」或他那條線裡說（各人的節寫明），不再是第三天自動冒出來。

### 2-6. 順手的事（支線）
- 照 `sideq3d.js` 的系統：
  - 開口那一句 → 兩個選項（答應／婉拒）；
  - 答應＝掛在手機「今天」那一格（標題、下一步、期限）；
  - 做完＝痕跡（之後一句、人物頁一行、有的有房間物品）；
  - 婉拒、過期＝不扣任何數值，他的那條線照「沒幫」那一版走。
- 同學的順手的事算在「同時最多兩則」（`S.MAX`）裡面，跟店員的一起算。

### 2-7. 聯絡方式、手機
- 聯絡方式只在各人節裡寫的那一場交換（多半是順手的事）。沒交換的人，手機訊息都不送，改當面（各人的節寫明）。
- **頻率上限**：
  - 二十位加起來，劇情以外的私訊一週最多一則；
  - 同一個人一個月最多一則；
  - 考試週不送閒聊型的；
  - 劇情那幾則（各人的表）不算在上限裡。
- 寫法：每人自己的手機習慣（各人的節），不用「最近好忙」「考試加油」這種流水帳。

### 2-8. 關係上限
- 現在最多「有點熟」，因為信任只有說秘密那次 +4。
- 改成：
  - 做完順手的事：熟悉 +6、信任 +6；
  - 他那條線的每一段：熟悉 +3、信任 +3；
  - 閒聊照舊 +2。
- 所以做完他的事、走完他的線的，可以到「朋友」；**不會有戀愛**（`npcRom` 不加）。
- 升到朋友時，人物頁照 `personality` 欄。二十位都補 `personality`（第 3 節「一句話」那一欄）。

### 2-9. 修 `AA_496` 列的兩個問題
- `ev_pool_greet` 的旁白「你確定在教室看過」：只給在教室出現的人；其他人的換成「在〈他的地點〉看過」。
- `pool_greeted` 旗標：一次見面用完就清掉，選「假裝看手機」不加熟悉。

### 2-10. 舊存檔
- 已經說過的舊三句照記號算說過，新的閒聊從沒說過的開始。
- 已經說過秘密（`SHARED_SECRET`）的不重問，選項記成「沒選」，後面照「沒選」那一版。
- 已經過去的場景不補；已經畢業的學長姊不補。

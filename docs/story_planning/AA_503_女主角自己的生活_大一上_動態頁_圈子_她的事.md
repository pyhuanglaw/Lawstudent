# AA_503　女主角自己的生活：大一上（HEROINE-LIFE-1028，USER_WANTS X122★）

> - AA-C 2026-10-28，照 D109 AA 定，第②級：她們的朋友、她們自己的小事、手機一頁新的「動態」。不改任何人的設定、重大關係、主線。
> - 使用者 10-28 01:2x 對 LAWWW-C：「可攻略女主角 感覺都沒有自己的生活」。和「她們主動約你」（`AA_494`）、「同學補故事」（`AA_498`～`501`）是同一個方向：世界不是繞著祐廷轉。
> - 這一份是大一上（2025-09-01～2026-01 底）；之後每學期一份。

## 0. 方向
玩家知道她有自己的生活，靠四種管道：
1. **3D 裡看得到她和她的人在一起**：作息加「和誰」，那個人站在她旁邊、坐同一桌。
2. **手機「動態」**：她貼自己的事（照片＋一句），像限時動態（第 1 節）。
3. **別人說起她**：二十位同學、麵店團、家族群組的閒聊。
4. **她私訊你講她自己的事**：不約你、不回你，只是跟你說。

另外三條：
- 她的事照日期發生。玩家沒參與，結果照劇情走；玩家能參與的地方各節寫明。
- 沒看、沒回不扣任何東西。
- 交往中的她，自己的事一樣照常發生，不會因為交往就只剩約會。

## 1. 手機「動態」頁（新的一頁，在「訊息」旁邊）
- **誰會出現**：有聯絡方式的人。七位女主角＋已經在手機上的配角（麵店團、Kevin、二十位同學裡交換過聯絡方式的）。
- **一則的內容**：
  - 一張照片（文字描述，寫法同訊息的「（照片：……）」）；
  - 她的一句（照她手機的寫法）；
  - 時間。
- **保留七天**，最新的在上面。
- **提示**：新的動態只在「動態」頁籤上亮一個小點。不跳通知，不算在私訊的頻率上限裡。
- **頻率**：
  - 女主角每人一週最多兩則；
  - 配角每人兩週最多一則；
  - 全部加起來一天最多四則。
- **看得到哪幾則**：每則標一個階段（認識／朋友／很熟／交往中），玩家和她到了那個階段才看得到。沒到的那幾則就是沒有，不顯示「鎖住」。
- **回應**：點一則 → 三個選項（各則自己寫）：
  - 「（按愛心）」→ 她不回。
  - 一句留言 → 她回一句（進私訊對話串）。
  - 「（私訊問一句）」→ 那一則寫的那個問題和她的回答。
  - 同一個人一天只算一次熟悉 +1。
- **交往中**：約會之後，她自己貼一則有祐廷的（照片的描述裡有「你」）。這一種由約會系統產生，台詞在之後的批次寫。
- **舊存檔**：從讀檔那一天開始有，以前的不補。

## 2. 她的圈子在 3D
- **作息**：作息的一筆可以加 `with:[人物 id]`，那個人照現有的 `pairUp` 站在她旁邊、坐同一桌或一起走。
- **玩家走過去**：
  - 先「聽到」她們兩個在講什麼（一句，各人的表）；
  - 接著她照常說話；
  - 第一次她會介紹那個人；
  - 那個人如果是二十位同學裡還沒認識的，就在這裡認識（取代他自己的認識那一場，或照他那一場的第二版）。
- **旁邊有人的時候**：她的邀約、私密的話題不出（照現有「有第三人在場」的條件）。

## 3. 每學期她自己的事
- 每位每學期 1～2 件主要的事，加上幾則動態。
- 主要的事的寫法：
  - 什麼事、哪一天；
  - 玩家怎麼知道（動態、別人說、她私訊、在場）；
  - 玩家可以做什麼（有的話）；
  - 之後她提起的一句。

（第 4 節起：七位，各一節。）

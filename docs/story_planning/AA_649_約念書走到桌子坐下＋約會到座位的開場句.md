# AA_649 約念書：走到桌子坐下一起念；其他約會到座位以後的開場句

- **使用者 2026-11-04 01:3x 對 BB（BB 轉）**：約一起念書，不能走到圖書館門口約會就結束，至少要走到桌子旁一起坐下，要安排得自然一點。
- 等級：第②級，AA 定稿（D109）。總圖裡說話照 D127 加「（小聲）」；大廳門外照平常說話。
- 系統（走到哪、坐哪、時間過多久）是 LAWWW 的；這份只寫台詞和順序。

## 1. 約念書在總圖（流程）
1. **門口會合**（照現在的約會開場）。
2. **進大廳，她帶路**：
   - 她：「（小聲）二樓靠窗那排比較安靜。」
   - 一起走上樓梯（或電梯），到二樓自習區的長桌。
3. **二樓沒有位子**（考試週、或二樓長桌坐滿）：
   - 旁白：（二樓的長桌都坐滿了。）
   - 她：「（小聲）去三樓好了。三樓沒有人講話。」→ 走到三樓閱覽區。
4. **坐下**：旁白「（你們在長桌的一角坐下。她把書攤開，把手機翻過來蓋在桌上。）」＋她的一句（第 3 節的表，每段關係第一次用她自己那句，之後隨機用一般句）。
5. **念書中途**（時間過到一半時出一次；隨機一則）：
   - （她把一張便利貼推過來：「這一題你會嗎？」你在下面寫了答案推回去。她看了一眼，比了一個讚。）
   - 她：「（小聲）……休息五分鐘。」（她趴在桌上。五分鐘後準時坐起來。）
   - 她：「（小聲）你的筆借我。我的沒水了。」
   - （她讀到一半，把一顆喉糖放在你的書旁邊。）
6. **收書**：
   - 到閉館：旁白「（閉館前十分鐘的廣播響了。）」
   - 沒到閉館：旁白「（她闔上書，伸了一個懶腰。）」她：「（小聲）走吧。」
7. **起身道別**（走出大廳，照平常說話）：她的一句（第 3 節的表）。一般句：「今天讀得比我想的多。……下次再約。」
- 念書照現在的讀書系統算（讀書進度照算）；坐下到收書之間可以照現在的時間快轉。

## 2. 一般句（沒有列的人、第二次以後）
- 坐下：「（小聲）我讀到六點。你呢？」
- 坐下：「（小聲）手機先收起來。」
- 道別：「今天讀得比我想的多。……下次再約。」
- 道別：「好累。……可是很好。」

## 4. 其他約會地點，到座位以後的開場句（每次隨機一則；店有自己的句子就用店的）
- **吃飯（餐廳、小吃店）**：
  - （你們在靠窗的位子坐下。她先把菜單推到你面前。）她：「你先點。」
  - （位子有點擠，你們的膝蓋碰在一起。她往旁邊挪了一點，又挪回來。）
- **咖啡（兩點半、半熟這種）**：
  - （你們點好飲料，在窗邊坐下。）她：「這裡的位子我喜歡。」
  - （她把兩杯飲料的吸管都插好，一杯推給你。）
  - 木曜日、日常失速照 AA_618、AA_645、AA_648 店自己的句子。
- **電影**：
  - （你們找到位子坐下。燈還沒暗，她把爆米花放在中間的扶手上。）她：「（小聲）預告片開始了。」
  - 散場：（燈亮了。她還在看片尾的字幕。）她：「……等一下再走。」
- **頁間書屋**（公館，新店）：
  - （你們在閱讀桌坐下。她從書牆上抽了一本書，放在你面前。）她：「（小聲）這本你會喜歡。」

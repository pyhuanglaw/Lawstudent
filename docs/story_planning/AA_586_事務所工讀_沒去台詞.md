# AA_586 事務所工讀：「沒去」的反應台詞（`WZ_JOBS_DATA.x.office.miss`）

- **起因**：BB 11-02 轉述 CC 測試的結果。溫州街三家店、Café、家教都有「上週沒去」的反應（`miss`），事務所沒有。玩家沒去，聽不到任何反應，累計到三週就直接跳出 ask3。
- **等級**：第②級，一般日常的小補充。流程：AA 寫 → BB 口氣審 → LAWWW 整合。下一版做就好。
- **格式**：照其他店的 `miss`，是一組變體，每次挑一句：`miss:[ [[說話人,台詞]], ... ]`。上次沒去的話，下一班開始時說一句。
- **口氣**：事務所的人比較客氣、公事公辦。不責備，講一件實際的事，再告訴他下次怎麼做；不說教，不提考試。

```js
office:{ miss:[
  [['事務所的助理','上週二的卷宗，律師自己影印了。下次不能來，前一天傳訊息給我就好。']],
  [['律師','上週沒看到你。有事的話先講，班可以換。']],
  [['事務所的助理','上週的信是我幫你寄的。郵局那個阿姨問你是不是不做了。']] ] }
```

- 說話人照 `WZ_JOBS_DATA.jobs.office` 的設定：`boss:'律師'`、`contact:'事務所的助理'`。
- 如果事務所的 `days` 是週二、週四，第一句的「週二」要換成實際沒去的那一天。不方便換的話，改成「上次的卷宗，律師自己影印了。」

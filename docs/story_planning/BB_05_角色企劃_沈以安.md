## 2. 她的核心：信任

**她能不能讓一個人，看到她沒有計畫的樣子？**

- 她看起來是全班最有規劃的人：筆記有目錄，報告提前寫完，總圖幾點會被太陽曬到都知道。
- 規劃是她的保護殼。只要每件事都在計畫裡，就不會有人看到她慌張、不確定、累。
- 她**不會拒絕別人**（【現有】弱點）。借筆記、幫忙印講義、報告當組長，大家都找她，她都說好。
- 壓力大的時候會**失眠**（【現有】弱點），但不會告訴任何人。

**她真正的問題不是「要不要念法律」**（`BB_02` 第 0 節：這一題交給祐廷）。她的問題是：**「這個計畫是我的，還是我媽的？」**

- 她從小聽媽媽講法院發生的事：誰哭、誰吵、誰被帶走（【現有】台詞）。
- 媽媽希望她念法律，因為法律「穩定」。她也念了，而且念得很好。
- 但她**其實是真的喜歡民法**：喜歡那種「每個人的權利和義務，都能被寫清楚」的感覺。只是她不確定這份喜歡是自己的，還是被安排好的。
- 四年後她要學會的是：喜歡一件事和媽媽希望她做這件事，可以同時成立。

**寫她的台詞時要避免**：
- 撒嬌、長篇大論、直接說出自己的感受（她會繞路說）、動漫式的「才、才不是呢」。
- 現有台詞常用語助詞（「很敢耶」「好啦」「欸」），和設定「少用語助詞」不一致。建議保留少量，讓她像真的大學生；但重要時刻的台詞一律不加。這份文件的新台詞照這個原則寫。
- 現有劇本已經重複的模板，**她不要再用**：「大家都只問 X，只有你問 Y」「不要跟別人講」「你不用那個表情」。

## 6. 她和祐廷的關係會怎麼變

```
同班但不熟（第 1 週）
→ 她追出來約他（第 3 週）
→ 一起寫報告、一起讀書（大一上）
```

**這條線的節奏**：信任一層一層打開，每一層都要等。四年裡她讓祐廷看到自己沒有計畫的樣子，一共只有三次（事件 9、11、12）。
- **不一定變成戀愛**：最後可以是「我最信任的朋友」，也可以是戀人，看玩家怎麼選、她當時的狀態。
- **會讓關係破掉的事**：把她當成筆記和報告的工具；在她說「我還好」的時候真的以為她還好。

## 事件 2｜窗邊的雙人桌 【現有，保留，小改】

- **故事目的**：她把「網拍相機」的法律問題變成兩個人的對話；第一次問「為什麼念法律」。這是四年主線的種子。
- **場景**：兩點半 Café 窗邊雙人桌（或總圖二樓長桌）。
- **故事流程**：現有內容保留。
  - 「那個賣家——少打一個零的那個。你覺得法律應該保護他嗎？」
  - 「欸，剛剛路上你說『分數到了就填了』。真的假的？」
- **改動建議**：現在只有回答「還可以」時，她才說「一年後我再問你一次」。建議**四個回答後她都說**，只是語氣不同：

| 祐廷的回答（現有選項） | 她的回應（現有）＋加上的一句（新） |
|---|---|
| 「真的。但現在覺得還可以。」 | 「『還可以』。好，我記住了。一年後我再問你一次。」（現有，不改） |
| 「騙你的。我想幫人打官司——像電視那種。」 | 「電視那種法庭，我媽說一年看不到一次。但……好啦，這個理由我喜歡。」＋「一年後再問你，看你還喜不喜歡。」 |
| 「家裡希望我念。我還在想自己要不要。」 | 「那你要早一點決定。念這個系，不是自己想的話，會很累。我看過。」＋「……一年後我再問你一次。」 |
| 「還不知道。可能念到一半才會知道。」 | 「念到一半才知道。這句話很像我。」＋「那一年後，告訴我你知道了沒有。」 |

## 事件 3｜報告發回來了 【現有，保留，修觸發條件】

- **現有的問題**（背景整理讀程式推得，未實測）：
  - 這個事件只認咖啡廳路線的記憶，走總圖路線的玩家永遠看不到。建議兩條路線都會發生，台詞只差一句（「那天在總圖，你說……」）。
  - 拒絕小安邀約的玩家，現在仍會在總圖觸發「報告的結論」，聽到「……謝謝你那天陪我」，和事實矛盾。建議拒絕的玩家改成另一句：「報告寫完了。……下次你有空再一起。」

- **故事目的**：她把祐廷說過的話寫進報告，周教授在旁邊寫了一行字。這是她第一次「分享」。
- **改動建議**：選項「周老師寫給妳的，不關我的事」現在會降低舒適度，等於明顯的錯誤答案（AA_01 第 4 節第 5 點）。建議改成她的反應：「……也是。」然後把報告收起來。**不扣分**，但這句話會被記住；大四畢業典禮那天，她會提起：「你那時候說不關你的事。我還記得。」說的時候在笑。

## 事件 10｜明軒 【新提案，有條件，界線由使用者決定】

**A. 她和祐廷是「說不清楚的關係」（ROMANTIC_TENSION）以上**：

>
> 以安：我拒絕了。
>

- **使用者要決定**：玩家正在追以安時，她可以選擇別人嗎？還是這個事件只在玩家沒有往戀愛方向走時發生？

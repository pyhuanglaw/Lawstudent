# 基調調整：溫暖版

## 1. 為什麼之前會這麼悲情（企劃組的錯）

- 我們把四年的主題定成「**身邊的人一個一個離開**」（版本一「離開的四年」、`AA_00` 第 8 節第 3 條），每條線都靠失去推動：麵店收掉、家人住院、休學、分手、撐不住、落榜、錯過。
- 一條線一個失去還好，疊在一起，整個故事就變成在送別。
- 企劃組把「苦甜」當成「有深度」，這是錯的。深度來自人物有理由、會改變，不來自失去。

## 2. 新基調

> **四年是一群人一起長大、互相留下痕跡的故事。**

1. **主調溫暖、明亮**，像青春群像日劇的好日子：吃飯、上課、熬夜、吵架又和好、一起做成一件事。
2. **可以有煩惱和小挫折**（考差、吵架、累了、被拒絕），但**都會往好的方向走**，而且通常是靠人物自己和朋友一起解決。
3. **法律在生活裡幫得上忙**：課堂上學到的東西，真的在朋友的生活裡派上用場（《法條之外》從「法律做不到的事」改成「法律和人一起做到的事」）。
4. **畢業和出國寫成「往前走、會回來」**：大家去追自己的事，但聯絡沒斷，重要的日子都會回來。
5. **戀愛照舊要有理由、有深度**（四個條件不變），但結局以「在一起」或「很好的朋友」為主；不以錯過、分手當主要結局。

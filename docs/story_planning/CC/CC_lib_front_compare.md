## 一致的地方
- **中央立面**：石材中央板、大拱窗、山牆、圓窗（oculus），上下位置一致。
- **整體輪廓**：紅磚 5～6 層，兩翼退縮，有白色石材腰線與窗框。
- **前景**：正前方一大片草坪，兩側是修剪過的高綠籬，再往外是成排的大王椰子。
- **夜景**：窗戶亮暖光，中央大拱窗最亮（new_views 第 6、7 格）。

## CC 初判
- 平台、台階、草坪這三樣東西的位置有三處矛盾（#1、#2、#3）：
  - 2D 的順序是：草坪 → 寬磁磚帶 → 中間台階 → 有矮牆的高平台廣場 → 退後的拱廊入口。
  - 3D 的順序是：草坪 → 窄條 → 全寬台階 → 直接進門。
- 3D 如果要和 2D 對得上，需要加三樣東西：寬磁磚帶、兩側矮牆、平台深度；台階也要縮到中段。
- 這會動到碰撞、找路，也會影響門口互動點 (86.4,0)、門外 (80,0) 和門廊前 (82,0) 的位置。要怎麼改，由 BB／使用者判斷。
- 另一條路：如果決定不改 3D，就要回頭重畫 2D 背景，讓兩者一致。

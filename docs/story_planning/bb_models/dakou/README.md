### 改了什麼（LAWWW2 的意見）
1. **晚上的暖光**：燈板改暖光（約 3000K，#ffc98a）、橘色吊燈和燈條的發光加強；牆改奶油色（#e8c492）、地板的灰帶一點暖、天花板偏暖。渲染用 `--night`（沒有太陽），一樓 `--exposure 1.25`、二樓 `--exposure 0.3`。

### 和參考圖不同的地方
1. **配置**：二樓參考圖的鏡頭在樓梯口（樓梯在左下、直幅在左邊）往裡看；照 layout，樓梯在東牆、直幅也在東牆（樓梯上來的右手邊），所以同角度圖的構圖是「窗在左、大牆面和插座吧台在右」，樓梯口在右邊。
2. **出入口（遊戲必須）**：一樓的門照 LAWWW2 的外觀移到 x 0（見上面）；外觀圖右邊那一段是用餐區，照 layout 是樓梯（上二樓必須）。
3. **尺寸照 layout**：外觀的店面寬 13.2 m、室內 12 m。
4. 品牌：沒有真實品牌。

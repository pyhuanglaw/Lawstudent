# AA_117　朋友的案子：四個問題

## 0. 為什麼改

- 現在的做法（`AA_70` 1-7、`BB_70` 8b）：祐廷的回答跟著年級自動變，玩家只選語氣（直接、溫和、開玩笑）。
- 問題：玩家看得到祐廷在長大，但**不是玩家自己想出來的**。上課、自學也不會讓答案變好。
- 改法：朋友丟來一件事，玩家幫祐廷**整理四個問題**：誰、向誰、依據什麼、請求什麼。
  - 去過的課和自學，會讓其中一兩個問題**多一個更準的選項**。
  - 沒有那個理解也沒關係：老實的選項（「我不確定，我們去問法服」）永遠在，朋友一樣得到幫助。
  - **不考條號、不計分、不卡主線**。

## 1. 怎麼玩（一件約兩分鐘）

1. **朋友說事情**：訊息或當面，兩到四句。
2. **整理**：畫面上是祐廷的手機筆記，四行：
   - 誰：誰遇到這件事。
   - 向誰：要找的是誰。不一定只有一個人。
   - 依據什麼：用白話說是哪一種關係，例如「說好的事沒做到」「東西有問題」「因為別人不小心受到損害」。
   - 請求什麼：朋友到底要什麼，例如退錢、修好、照說好的付、停止使用。
   - **每件只有一到兩行要玩家選**，其他自動填好。這是生活裡的一件事，不是考卷。
3. **祐廷回覆**：照玩家整理的內容說一段。語氣選項保留（`BB_70` 8b）。
4. **下一步**：一定有一句，例如「要確認的話，週六早上去法服」「這個要找律師，我陪你去」。
5. **之後**：朋友的結果和一句記憶，見第 4 節。

### 年級的差別（保留 `AA_70` 1-7 的四個階段）

| 年級 | 玩家整理幾行 | 多的一題 |
|---|---|---|
| 經濟系大一 | 一行，而且只能「去查」 | 還沒進法律系：他去總圖翻民法 |
| 大一 | 一行（通常是「向誰」） | —（「我也還不會。我們一起查。」） |
| 大二 | 兩行 | —（「你先把合約拍給我看。」） |
| 大三 | 兩行 | **你真正想要的是什麼？**（朋友回答；法律只是其中一條路） |
| 大四 | 兩行 | **要找誰**：法服、法扶、公司法務、律師（他知道自己能做到哪裡） |

- 階段跟著年級走，大一說不出大四的話；但**同一個年級，有去上課的玩家會說得更準**。

## 2. 理解從哪裡來（軟性的回報）

- 「理解」是一個記號。**這學期去過那幾週的課（`attendedAny`）**，或**宿舍讀書選了那一科**，就有。
- 沒有理解：那一行只有老實的選項。有理解：多一個更準的選項，朋友的反應更快、更安心。
- 祐廷**不會因為沒有理解而給錯的建議**。老實的選項就是正確的態度：「我不確定，我們去問。」

| 理解 | 白話 | 從哪裡來（課程依 `AA_103`；週次 LAWWW 照 syllabus 對） |
|---|---|---|
| `U_SALE` | 買到的東西有問題，可以要求修好、換、少付或退 | 民總（大一上，網拍相機那堂）；債各的買賣（大二下） |
| `U_CONTRACT` | 有沒有「說好」：說好了什麼、誰答應了什麼 | 債總（一）的契約成立（大一下） |
| `U_LEASE` | 押金是擔保；正常住的耗損和弄壞不一樣 | 債各的租賃（大二下） |
| `U_TORT` | 因為別人不小心受到損害，可以要求賠償 | 債總的侵權行為（大一下～大二上） |
| `U_ASSOC` | 社團的錢是大家的，要照規則管 | 民總的法人、社團（大一上） |
| `U_CONSUMER` | 向店家買東西或預付，消費者有特別的保障（網購的七天、預付型契約） | 債各的買賣與消保入門、預付型契約（大二下）；之前只能自學（2026-10-13 新增，`AA_119`） |
| `U_PROCEDURE` | 先談，再調解，最後才上法院 | 民訴（大三） |
| `U_WORK` | 員工在工作上出的事，對外通常由公司處理 | 勞動法（大三下選修） |
| `U_COPYRIGHT` | 用別人的作品要對方同意，而且要講清楚怎麼用 | 智慧財產權法（大四上選修）；之前只能自學 |

- 理解只影響「多一個選項」，**不影響任何劇情能不能看**（`AA_104`）。

## 3. 九件事

> 「重點」＝這一件要玩家選的那一兩行。台詞：AA 的人物 AA 寫，BB 的人物 BB 寫（照 `BB_70` 8b 已有的版本改）。

### C0　韋綸的二手腳踏車（經濟系大一上，期中後；`AA_106` 2-5）

- 事情：韋綸跟網路上的個人買了二手腳踏車。一週後，有人在椰影大道攔住他，說那是他被偷的車。
- 重點：**依據什麼**。祐廷還不是法律系，只能去總圖翻民法。玩家選從哪裡翻：「買賣」／「所有權」／「從目錄翻」。三個都會找到，「所有權」最快。
- 方向（LEGAL_REVIEW_REQUIRED）：原車主可以要回車；韋綸可以回頭找賣家要錢；先報案、留下交易紀錄。
- 下一步：一起去報案。
- 全域旗標：`BIKE_LOOKED_UP`（祐廷自己翻過民法，不記在某個人身上；韋綸那邊的記憶是 `BB_112` 的 `WL_BIKE`）。他之後在總圖借入門書（`BB_104` E22b）的原因之一；大二上物權第 4 週的回想讀它。

### C3　阿哲的押金（大二下第 5 週；AA）

- 事情：

> 阿哲：租約到了。房東說牆上有釘子洞，押金不退。
>
> 阿哲：兩個月的押金耶。我的系籃鞋。

- 重點一：**依據什麼**。
  - 沒有理解：「你先把租約和搬進來時的照片給我看。」「……搬進來時要拍照？」
  - 有 `U_LEASE`（債各的租賃，或自學）：多一個「押金是擔保。房東要扣，要說得出弄壞了什麼、修要多少；正常住的痕跡不一樣」（LEGAL_REVIEW_REQUIRED）。
- 重點二：**請求什麼**。「全部退」／「退押金，牆真的要補的話，扣合理的錢」。選後者，阿哲：「……好啦，那個洞是我掛球衣的。」

- 結果：退了大部分，扣了一個洞的油漆錢。
- 記憶：`ZHE_PHOTOS`。大四搬家那天，阿哲在空房間裡拍了二十張照片：「這次我有拍。」

### C4　阿哲的機車（大三上第 11 週；AA；`AA_72` 1-2）

> 阿哲：對方說他趕時間，要給我一千塊，叫我簽一張紙。

# 約會地點底圖規格：AA-B 負責的地點（給 BB-B 彙整，向使用者要圖）

> AA-B 2026-10-16。使用者 2026-10-16：「有需要 CG 圖的話，你請 BB 跟我要」→ **AA-B 只寫規格，BB-B 排進 `BB_132` 的佇列、向使用者要圖、檢查**。格式照 `BB_132`「底圖：D01 華山」。
> 每張都是**沒有人物的底圖**；互動點是畫面上分得開的四塊（台詞在 `date_system/lines/<地點>.py`）。共同條件照 `BB_132` 第 0 節與 D77：**不要任何看得清楚的文字、招牌、店名、路名、號碼、品牌或商標**；**畫面下方三分之一保持簡單（地面）**；不要日本的街景。
> 共同的開頭（每張提示詞都用這段）：
>
> 原創遊戲的場景背景圖，**畫面裡沒有任何人物、路人或動物**。日系青春半寫實插畫風：有插畫質感，不要照片寫實；偏自然的電影光影與景深；線條細、顏色接近輪廓；看得出是畫的，不是照片或 3D 渲染。畫風參考附上的 Café 黃昏圖（`art_reference/from06/style_07_cafe_dusk.webp`）。橫向 16:9（1920×1080，可以的話 2560×1440）。

## D02 松山文創園區・下午（陰天的柔光）
- 互動點（左→右）：①生態池（左下到左中）②製菸工廠的長廊（中間偏左：老廠房的長走廊，高窗把光切成一格一格）③巴洛克花園（中間偏右：修剪成方形的樹籬、小噴水池）④園區裡的書店（右邊：老建築一樓的大片玻璃，看得到書架）。
- 提示詞第二段：
> 陰天的下午，台北一座由老菸廠改成的文創園區：畫面左邊是一個綠色的生態池，池邊有欄杆和水生植物，水面倒映著樹；中間偏左是一棟長長的老廠房，淡色的磚牆和一整排高窗，從敞開的門可以看到裡面的長走廊，光被窗框切成一格一格；中間偏右是一座小小的西式花園，樹籬修剪成方形，中央有一個小噴水池；右邊是一棟老建築的一樓，大片玻璃窗裡看得到木頭書架和暖色的燈。遠處有高樓的輪廓。
- BB 檢查：沒有人和字（書架上的書不能看得清楚書名）；四樣都在、分得開；下方三分之一是空的。

## D07 國家人權博物館景美紀念園區・午後（安靜）
- 基調：**紀念園區，畫面安靜、莊重，不要暗黑或驚悚**；不要任何真實展品上的文字、人名、照片。
- 互動點：①法庭（左：一棟低矮的建築，門開著，看得到裡面的木頭長椅和高起的法官席，只畫輪廓）②看守所的走廊（中左：窄長的走廊，一排一樣的門，光從高處的小窗進來）③名字的牆（中右：戶外一面長長的淺色牆，上面是很多細小、看不清楚的刻字）④園區的小路（右：兩旁矮樹的小路、一張長椅、一棵大樹）。
- 提示詞第二段：
> 安靜的午後，台北近郊河邊一處紀念園區：幾棟低矮的灰白色建築，周圍是修剪整齊的矮樹和草地。畫面左邊，一棟建築的門開著，裡面隱約看得到木頭長椅和高起的審判席；中間偏左是一條窄長的室內走廊，兩側是一排一樣大小的門，光從很高的小窗斜斜照進來；中間偏右是一面戶外的長牆，上面密密的刻字小到看不清楚；右邊是一條兩旁種著矮樹的小路，路邊有一張長椅和一棵很大的樹。氣氛安靜、莊重、明亮，不要陰森。
- BB 檢查：沒有人和字（牆上的刻字一個都不能讀得出來）；不陰森；四樣都在；下方三分之一是空的。

## D08 臺北市立動物園・上午
- 互動點：①貓熊館（左：一棟有大片玻璃的館，裡面是竹子和岩石的展示場，**不畫動物**——動物在台詞裡）②企鵝館（中左：涼爽的室內、藍色水光的入口）③長頸鹿與非洲動物區（中右：開闊的草原展示場、高大的樹）④遊園列車（右：一台小小的遊園列車停在路邊，沒有字）。
- 注意：底圖「沒有動物」是共同規定；動物用台詞與旁白表現。如果使用者想要有動物的版本，另外一張。
- 提示詞第二段：
> 晴朗的上午，台北一座大型動物園的園區：畫面左邊是一棟有大片玻璃的展示館，玻璃後面是竹子、岩石和小水池布置的展示場（裡面沒有動物）；中間偏左是一棟建築的入口，裡面透出涼爽的藍色水光；中間偏右是一片開闊的草原展示場，有幾棵很高的樹和木頭圍欄（沒有動物）；右邊是一條園區道路，一台小小的、像玩具一樣的遊園列車停在路邊，車身沒有字。
- BB 檢查：沒有人、沒有動物、沒有字；四樣都在；下方三分之一是空的。

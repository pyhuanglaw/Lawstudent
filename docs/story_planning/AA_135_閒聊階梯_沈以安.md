## 規則

- **程式規則照 `BB_130` 第 0 節**（`ladder.heroine_01`、`ladderDay.heroine_01`；層 ID `A-L1`～`A-L10`；短招呼和 `SMALLTALK` 同一池）。下面是以安自己的補充。

- **在哪裡觸發**：在任何地方遇到她，主動跟她說話（校園、法律系館A、總圖、Café、麵店、路上）。少數幾層指定地點，寫在「地點」欄。
- **推進**：每天最多推進一層。已經推進過，或條件不到下一層時，她說一句短招呼（下面 5 句輪替，同一句不連續出現）。
- **不重複**：每一層只播一次，記在 `heroine_01` 的記憶旗標。
- **選項**：沒有對錯，不扣分。選項只決定她記住什麼，以後的層可能會提到。
- **和現有事件的關係**：同一天如果已經有她的劇情事件（例：`ev_an_report_split`、`ev_an_library_study`），當天不推進階梯。

## 短招呼（5 句輪替）

1. 「早。你今天有幾堂？」
2. 「我剛從總圖出來。三樓今天很安靜，安靜到有點吵。」
3. 「下一堂在 201。走吧，不然後排沒位子。」
4. 「我剛剛看到一隻貓坐在晨思鐘下面，很像在等下課。」
5. 「今天的進度我抄完了。你要的話晚上傳給你。」

## 規則

- **程式規則照 `BB_130` 第 0 節**（`ladder.heroine_01`、`ladderDay.heroine_01`；層 ID `A-L1`～`A-L11`；短招呼和 `SMALLTALK` 同一池）。下面是以安自己的補充。

- **在哪裡觸發**：在任何地方遇到她，主動跟她說話（校園、法律系館A、總圖、Café、燒臘店、路上）。少數幾層指定地點，寫在「地點」欄。
- **推進**：每天最多推進一層。已經推進過，或條件不到下一層時，她說一句短招呼（下面 5 句輪替，同一句不連續出現）。
- **不重複**：每一層只播一次，記在 `heroine_01` 的記憶旗標。
- **選項**：沒有對錯，不扣分。選項只決定她記住什麼，以後的層可能會提到。
- **和現有事件的關係**：同一天如果已經有她的劇情事件（例：`ev_an_report_split`、`ev_an_library_study`），當天不推進階梯。

## 短招呼（5 句輪替）

1. 「你今天還有課嗎？」
2. 「我剛從總圖出來，三樓今天位子很多。」
3. 「你等一下要去哪？」
4. 「晨思鐘下面有一隻貓，好像每天都在。」
5. 「今天的進度我抄完了。你要的話晚上傳給你。」

看情況的：早上 6～8 點在校園「（她手上拿著豆漿，邊走邊喝）早。」／上午在教室、法律系館A「第三排還有位子，要坐嗎？」／總圖「（她小聲）外面說。」／燒臘店「你點好了嗎？我還在看菜單。」／第 4、8、12 週週五晚上「這個週末我要回台中。」／第 16 週週五晚上「考完我還會留在臺北一個月。」／期末「期末了。我這禮拜只想睡覺。」

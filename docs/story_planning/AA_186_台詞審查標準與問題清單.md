## 1. 十二條台詞標準（Netflix 六部校園戀愛劇）

**樣本**：《無法抗拒的他》（韓，大學美術系）、《戀愛修課》（Heartstopper，英）、《二十五，二十一》（韓）、《First Love 初戀》（日）、《舉重妖精金福珠》（韓，體育大學）、《想見你》（台；台灣 Netflix 目前有沒有上架，來源互相矛盾）。

**從劇裡學到的**：

| 手法 | 劇裡怎麼做 | 我們遊戲裡已經做對的例子 |
|---|---|---|
| 問關係，不說喜歡 | 娜比問「我們到底算什麼關係？」，真正想說的「我喜歡你」沒說出口 | 語彤「……被我分一點時間？」（事件 16） |
| 同一句話，意思越來越多 | 《戀愛修課》的「Hi.」「Hi.」從招呼變成暗號 | 芷若的熱可可加濃縮：Z3 → 「……你記得。」 |
| 比喻或物件一再回收 | 《二十五，二十一》的「彩虹」換了四次意思 | 以安的理由欄：新 5「你說的那一句，我放在第一段」→ 大二室友的政見 |
| 被告白時先用玩笑接住 | 希道：「我好像還沒到那個程度？」 | 可昕 E25：「迎新那天？我那天說我是『邊際效用遞減』。」「……沒有遞減。」 |
| 告白藏在普通的問題裡 | 《First Love》的「你最喜歡吃什麼？」 | 學姊 US3「看雪。跟你。」 |
| 情緒最強的時候，用最小的詞 | 希道邊哭邊跑：「丟臉死了！」 | 子晴「……好爽。好爛。兩個都有。」 |
| 口頭禪用在崩潰那一刻 | — | 學姊「二，我好像有點累。三，我想試一件從來沒做過的事：今天先不改了。」 |
| 裂痕要演出來 | 《二十五，二十一》中段漸行漸遠寫得好，但最後的分手被批評太趕 | 各女主的 `*_talk` 裂縫事件 |

**反面教材**：
- 內心旁白太多（《無法抗拒的他》的劇評）。
- 同一個暗號回收太多次就失效（《想見你》的歌，開心、難過、生氣都放）。
- 尷尬應該是角色本身的尷尬，不能是寫得不好造成的（《戀愛修課》的劇評）。
- 拿身材取綽號（《舉重妖精金福珠》的 Fatty），遊戲不用。

**十二條標準**（每條都是「不及格 → 及格」）：

1. **說 B，其實在說 A（潛台詞）。**
   - 不及格：「我喜歡你，所以想跟你一起去。」
   - 及格：「你明天會去總圖嗎？……喔沒事，我剛好也要去。」
2. **有具體的生活細節**（地點、品項、時間、價錢）。
   - 不及格：「這間咖啡很好喝。」
   - 及格：「拿鐵普通啦，但靠窗那個位子下午三點有太陽。」
3. **接住對方上一句，不是輪流發表。**
   - 不及格：A「刑法期中爛掉了。」B「我今天去了公館。」
   - 及格：B「是爛到要請客，還是爛到不要問？」
4. **先開玩笑，再說真話。**
   - 及格：「你這週第三次吃超商了，要不要幫你登記成住戶？……說真的，還好嗎？」
5. **允許不完整、停頓、改口。**
   - 及格：「昨天那個……謝啦。筆記我印完就還你。」
6. **稱呼和話題隨距離改變。**
   - 第一週叫全名，熟了叫小名，吵架時又叫回全名。
   - 話題從課業慢慢談到家裡。
7. **私人梗要回收，但不要濫用。** 同一個梗最多回收 2～3 次（見第 5 節的口頭禪配額）。
8. **用行動代替宣言。**
   - 不及格：「我會一直支持你！」
   - 及格：讀書會的桌上多了一份她整理的表格，旁邊寫「第 3 頁別看，我也看不懂」。
9. **不讓角色把心情念出來，旁白也不念人物設定。**
   - 不及格：「我現在很失落，因為你沒回我。」
   - 不及格的旁白：「（她）開始懷疑自己為什麼念法律。」
10. **每個人有自己的說話習慣**（句長、標點、貼圖、口頭禪），見第 4-1 節。
11. **衝突要指向已經發生的事。**
    - 不及格：突然一句「我們不適合。」
    - 及格：「你說期末後陪我去看展，期末過兩週了。我不是要怪你，只是不想問第三次。」
12. **角色有自己的生活：會忙、會拒絕、記得你說過的話，也不會每次見面都重新介紹自己。**

## 2. 上下文錨點（「交了」問題）

**檢查法**：把上一則（或上一場）遮起來，玩家還知道在講什麼嗎？不知道，就至少補一個**錨**：

- 什麼事：交了什麼、上了什麼。
- 哪一次：哪天、哪一場。
- 前情：你上次說過的哪一句。
- 附件：照片或檔案，**而且照片要配一句說明**。

**短不是問題，沒有錨才是問題。** 一個錨就夠，不要寫成說明文；說明文正是「跟機器人講話」的感覺。

**遊戲比真實聊天更需要錨**：
- 遊戲裡常隔好幾天的遊戲時間。
- 玩家可能錯過前一場，被記成「聽說」。
- 同一則訊息可能在前置事件**之前**就送到。

**最常見的七種**（附錄 A、B 的 45＋40 處大多是這幾種）：

| 類型 | 例子（改前 → 改後） |
|---|---|
| 結果沒說是什麼 | 「上了。」→「公法所放榜。上了。」 |
| 事件代號進了台詞 | 「模 3 那天我講話太衝。」→「模擬法庭吵架那天，我講話太衝。」 |
| 「那天」「那件事」「上次那個」太遠 | 「你那天裝的。我記到現在。」→「大二那晚在 Café，你幫我裝的是熱水。我記到現在。」 |
| 口頭禪變密碼 | 「理由：關西。」→「理由：這裡是關西，雪留不住。」 |
| 照片沒配字，玩家看不懂 | 公告欄照片「看不懂的那張。」→「町公所公告欄，『請協力』那張。」「最後一行，我看不懂。」 |
| 會被讀成別的意思 | 「……我爸剛走。」（像過世）→「……我爸剛剛來過。搭計程車回去了。」 |
| 錯過前一場的玩家收到後續 | 「我室友的申訴過了一半。」→「我室友晚歸被記點的申訴，結果出來了：減一點。」 |

**選項的錨**：
- 玩家選項也要有上下文。
- 沒看過「吵架」那一場的玩家，不能出現「妳們和好了？」，這種選項要加 `if:{events:[...]}`。
- 玩家不能回答他沒看過的內容。例：沒看過規則就只能選「第五條。」

**「沒回」的一句**：
- 每一則訊息配自己的一句，句子裡帶那則的主題（`AA_179` 第 4 節是範本）。
- 兩週內沒見面就不說。

## 4. 台灣大學生怎麼說話（用語指南）

> 查證方式：見第 0 節。標記：【查到】有來源；【一般認知】沒找到來源，依常識。來源清單在第 8 節。

### 4-1. 傳訊息的習慣 → 誰怎麼說

**大家都有的習慣**：
- **一句一則、連發。**【一般認知】例：「欸」／「你債總筆記可以借我拍嗎」／「上禮拜那堂我睡死了」／「拜託🙏」。
- **句尾加「哈哈」讓語氣軟一點。**【查到】例：「我可能會晚十分鐘到哈哈」。
- **敷衍的回法**：「喔」「哈哈」「笑死」比已讀不回更冷。
- **笑的寫法**：「哈哈哈哈」越長越真心，只打兩個「哈哈」可能是客套。年輕人用 😭、💀 代替 😂；😂、👍 會被當成長輩在用。
- **注音**：ㄅㄅ、好ㄛ、ㄏㄏ（常帶嘲諷）、ㄎㄎ。
- **語氣詞**：
  - 欸、啦、齁、蛤、咧／勒。
  - 「喔」短的冷、「好喔～」拉長的軟。
  - 捏：可愛、緩和。
  - 餒：多半是輸入法打錯的「捏」，語氣重時是不耐煩。
- **先傳訊息再打電話**：突然打來會被當成打擾。
- **已讀不回**：會讓人焦慮，但多半只是沒空。

**遊戲裡的人物照個性用**（不是規定每句都要用；同一個人前後要一致）：

| 人物 | 訊息的樣子 |
|---|---|
| 以安 | 句子完整、標點正確，不用注音也不用貼圖；緊張時突然很客氣。「理由：」照第 5 節的配額 |
| 語彤 | 很短，常常只有照片沒有字；「……」開頭；不用表情符號 |
| 阿哲 | 一句一則連發、「哥」、「齁」；語音訊息 |
| 小語 | 「欸」「欸欸」連發、注音（好ㄛ、ㄅㄅ）、😭；最活網的那個，梗由她用 |
| 柏翰 | 一則一個資訊、不寒暄、會打句號；「……最後一句當我沒說」 |
| 芯慈 | 深夜才傳；「不用回」「當我沒說」；句尾「。」很冷，但內容很軟 |
| 子晴 | 「欸不是」、短句、沒有問號的問句 |

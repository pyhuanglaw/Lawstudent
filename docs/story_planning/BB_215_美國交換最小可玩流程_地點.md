## 2. 回答你的四個
| 地點 | 一定要嗎 | 理由 |
|---|---|---|
| **超市** | **一定要**（US1） | US1 的戲在超市裡：她教他看蛋的日期、在零食區停很久、拿一包貴三倍的台灣泡麵。3D 來不及的話，先用 2D 背景演，但 D47 寫的是 3D |
| **校園** | **可以先不做 3D** | US1～US4 沒有一場要玩家在校園裡走：初雪的台階用 CG 和 2D，帶到場也有保底；上課是 2D。只有「平常可以去校園逛」需要 3D |
| **公車站** | **可以先不做 3D** | 去校園、去巴士站都是出遊選單。社區門口的公車站當成出遊出發點就好，2D 或不畫 |
| **主街（校門前）** | **不需要** | 企劃沒有任何事件在這裡 |

**最小可玩流程要的 3D**：
1. 祐廷的單人戶，加上門外的二樓戶外樓梯平台。
2. 社區裡從祐廷那棟走到 C 棟、走到會所門口的一段戶外，含 C 棟學姊合租戶的共用廚房。
3. 超市。

會所自習室可以先用 2D。

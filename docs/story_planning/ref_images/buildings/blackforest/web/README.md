## 網頁上寫的（建模要對的事實）
- 接近**復興南路口後門**的一片樹林，位於**國青宿舍、新聞所、國發所之間**；栽種密集的**榕樹**。
- 2009 年春天做了校園第一條**木屑步道**：淘汰的杉木支架當路緣、修剪下來的樹枝粉碎成木屑當填充，走起來軟軟的。
- 照片：粗大的榕樹、石板小徑、落葉地；林邊草地、紅土步道（blackforest_web_02、blackforest_web_03）。

## 網頁上寫的（建模要對的事實）
- 人工湖，舊稱「牛湳池」，曾是瑠公圳的調節水塘；1973 年畢聯會命名。
- **分為三個池**，**湖邊有垂柳**，**湖中有湖心亭**；2012 年大規模整修，2017 年南側復舊了瑠公圳舊水道。
- 照片：湖心亭是**六角形、綠色琉璃瓦**；湖邊步道是**紅色木欄杆**；有一座**石砌拱橋**（lake_web_05）、白色木花架＋長椅（lake_web_03）。

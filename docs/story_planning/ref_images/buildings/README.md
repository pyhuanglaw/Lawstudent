## 「可能不一樣」前 10 項（依影響大小）

1. **晨思鐘（傅鐘）整個造型不同**：遊戲是有四坡瓦屋頂的石造鐘亭（`tools/blender/env_second/campus_bell.py` 4、10、116 行；`src/campuskit3d.js` 439 行），真實是紅色鋼管鐘架、沒有屋頂，前面有長方形噴水池（bell/web）。
2. **綜合體育館位置與外觀**：遊戲門在舟山路南側（`src/classes3d.js` 479 行）、外觀是沒有名字的五層平頂方盒（`src/zones3d.js` 377 行）；真實在新生南路與辛亥路路口（校園西北角），圓形、磚紅色基座、一排圓窗、白色膜屋頂（gym/web）。
3. **行政大樓顏色與樓層**：遊戲米黃面磚、3 層（`src/zones3d.js` 226 行；`campus_hall.py` 41～43 行）；真實紅色清水磚、黑瓦、北棟 2 層＋科林斯柱門廊，南側三棟白色 3 層圍成口字形（admin/web）。

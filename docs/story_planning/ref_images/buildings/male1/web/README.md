## 網頁上寫的（建模要對的事實）
- 校園地圖：**地上 4 層、地下 1 層**，1980 年；位在**長興街**的男生宿舍區，男一、三、五舍是同一個舍區；旁邊有男一舍餐廳（1 層，校園地圖 AT5017-A）。
- 住宿組男一舍簡介：長興街 50 號；1980-03-11 落成、2006 年翻修；**地上 4 層、地下 1 層**；**沒有電梯**；約 970 床；**四人雅房 237 間（4.32 坪）**＋雙人身障房 9 間，**公共衛浴**；寢室：木頭床架、書桌、椅子、檯燈、冷氣（冷氣卡）、衣櫃、吊扇、有線網路；**傳達室在一樓**、專員辦公室 2、3 樓；公共區域：交誼廳、洗／曬衣間、資源回收區、自煮廚房；**大門有無障礙坡道**；附近有學生餐廳、便利商店。
- 照片：**灰色清水混凝土**、量體凹凸、**樓梯塔上開圓窗**（male1_web_01、male1_web_02）；正門是**水平的混凝土雨遮**（male1_web_03）；寢室是**上舖床、下面書桌**的木頭家具（male1_web_07～09）。

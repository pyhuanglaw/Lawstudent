## 網頁上寫的（建模要對的事實）
- 校園地圖：**地上 5 層、地下 1 層**，2011 年啟用。
- 可容納 **400 人的大型階梯教室**（華南講堂＝101 教室）以及 20 人左右的小型教室；通識與共同課程的大班教學；經常做考場；**一樓的藝文空間**不定期展覽。
- 景點說明：中大型教室，每間有 E 化講桌。

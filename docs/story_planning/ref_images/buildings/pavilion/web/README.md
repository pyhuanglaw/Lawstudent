## 網頁上寫的（建模要對的事實）
- 校園地圖：**地上 3 層**（欄位），建物年份 1961；說明寫最早建立於 1963 年；2007-01-11 市定古蹟。
- **牆面佈滿白色圓孔**，和旁邊兩棟白色建物（人類系、哲學系，後來的仿作）一起被暱稱「洞洞館」。
- 以**現代材質表現中國建築的傳統元素**；曾是外交貴賓的接待處；現在定期推出主題特展、演講、DIY 活動。

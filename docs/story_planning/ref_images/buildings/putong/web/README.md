## 網頁上寫的（建模要對的事實）
- 校園地圖的欄位：**地上 6 層、地下 1 層**；說明文字寫「**五層樓高**」的普通科目大樓，1993 年落成（兩個寫法不一樣，照片看起來是五層＋屋頂）。
- 前身是 1955 年的二層樓普通教室（南洋風建築）。大學部通識、共同必修、選修課的地方；**地下室是闈場**。2010-06 中文正名「普通教學館」，2020-06 英文正名「Putong Lecture Building」。

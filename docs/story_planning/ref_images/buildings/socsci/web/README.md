## 網頁上寫的（建模要對的事實）
- 校園地圖：**地上 8 層、地下 2 層**，2013 年完工；**伊東豐雄**設計。
- 分成**教育棟**（傳統板狀、簡潔，大量用**特級清水模**；內外交錯的挑空區、公用平台，自然採光通風）和**圖書館棟**（半透明，「宛如置身森林樹蔭下」，周圍是草地）。

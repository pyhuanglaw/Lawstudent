## 網頁上寫的（建模要對的事實）
- 校園地圖：**地上 2 層**，1929 年；市定古蹟；正面車寄外牆 2010 年初整修。
- 椰林大道上的代表建物：**山牆、拱門、車寄、規格化的開窗**；牆上貼**國防色的十三溝面磚**（「國防色係指先紅色再褐色，後期深綠色和淺綠色」，當年為了防空用保護色）。
- 室內：**天花板是半圓穹廬頂**，「方中有圓、圓中有方」的柱子，**環狀樓梯**。
- 後側另有一棟文學院研究大樓（3 層＋地下 1 層，1978 年，一樓大講堂）。

## 網頁上寫的（建模要對的事實）
- 校園地圖：**地上 5 層、地下 1 層**；1997 年（建物年份），1998-11-14 正式啟用；圖書館 1928 年創立，1989 年開始蓋新館。
- 座落在**椰林大道的端點**，是校總區的幾何中心；**承襲舊館（現在的校史館）的山牆、拱窗、迴廊**，巴洛克式；挑高、**鐘塔**。
- **挑高四層樓的大拱窗**：從裡面看得到整條椰林大道（2005 年「臺大校園十二美景」第一名）。
- 校友中心在一樓。緊急電話的位置說明：「新總圖書館北側地下樓（靠一活側）」「南側走廊（靠舟山路側）」——北邊是第一學生活動中心、南邊是舟山路。
- 樓層配置（圖書館網站）：**B1**＝24 小時自習室（A、B 兩區）、討論區、影印中心、置物櫃、國際會議廳、中庭；**1F**＝校友中心、日然廳、服務台、數位媒體區、多元共享區、當月報紙區、輕閱讀區、團體室、演練室、討論室；**2F**＝二樓前廳、人文社會學科的中日韓文／西文圖書、藝術資料區、密集書庫、線裝書區、裝訂報紙區、討論室、研究小間；**3F**＝三樓前廳、期刊、指定參考書、參考書、四庫全書、考古題、臺大人文庫、研究小間；**4F**＝四樓前廳、科技類圖書、書展區、輿圖資料區、東亞資料區、研究小間；**5F**＝特藏資料常設展覽、特藏開架區、微縮資料區、調閱資料閱讀區、服務台、閉架書庫。

## 網頁上寫的（建模要對的事實）
- 校園地圖：**地上 6 層、地下 2 層**，2001 年；位於**新生南路與辛亥路路口**。
- 建築基座維持校園傳統的**磚紅色系**，往上是「力與美」的新穎造型；**屋頂是金屬桁架＋白色覆膜**，白天陽光灑進球場；每年**畢業典禮、新生訓練、慶典集會**在這裡。
- 景點說明：裡面有**游泳池、健身房、地板教室、室內球場**，以及有觀眾席、可以辦大型賽事與典禮的**主球場**。
- 照片：弧形外牆、**一排圓窗**、玻璃樓梯塔、戶外大樓梯（gym_web_06、gym_web_05）。

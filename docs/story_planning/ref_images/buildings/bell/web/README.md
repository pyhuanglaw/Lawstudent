## 網頁上寫的（建模要對的事實）
- 位於**椰林大道中心**，紀念傅斯年校長；每次響 **21 下**（「一天只有二十一小時，剩下的三小時是用來沈思的」）。
- 1951 年植物系柏銓先生提議鑄造，由聯勤兵工廠鑄造；早期人工敲，現在電動。
- **照片看得到的造型**：**紅色鋼管做的鐘架**（幾根細柱＋兩道圓環），鐘吊在架子頂端；下面是**石砌的台座和台階**、幾塊石碑；鐘的一側有**長方形噴水池＋紅色花圃**（bell_web_06、bell_web_01）。**不是有屋頂的鐘亭**。

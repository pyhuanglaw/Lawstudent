## 網頁上寫的（建模要對的事實）
- 校園地圖：舊圖書館**地上 3 層**（欄位），1929 年落成，**經過四個階段增建**；1998 年市定古蹟。
- 最受讚賞的：**入口門廊的三個拱門及柱式**（本地石材雕飾）、**山牆**、**氣派的圓拱形大窗**；**二樓閱覽室高敞、明亮高窗**。
- 景點說明：外觀用拱窗、拱門、山牆及**土黃色的十三溝面磚**（和文學院等臺北帝大時期建築一致）；二樓是校史館、人類學博物館、臺大出版中心書店；部分空間是文學院系所。

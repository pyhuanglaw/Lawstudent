## 網頁上寫的（建模要對的事實）
- 「**口」字型的建築群**：**北側建築 1926 年，二層樓的磚紅色建築、黑色屋瓦**、**科林斯柱式（Corinthian）入口門柱**；1998 年指定市定古蹟。
- **南側三棟白色建築**是 1970 年代陸續增建（校園地圖：1970、1971 年，各 3 層），造型簡潔。紅磚白牆圍出的**中庭**裡有一棟一層樓的紅磚平房＝第一會議室。
- 景點說明：外牆以**紅色清水磚**為主要建材；完工於臺灣總督府臺北高等農林學校時期；**門廊外部四根科林斯門柱**。
- 東側另有一棟「農化新館／敬賢樓（第二行政大樓）」，一樓東側以川堂連到行政大樓（校園地圖 AT2029）。

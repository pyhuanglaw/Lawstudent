# 角色企劃：林芷若

> 一句話：**她記得每個客人點什麼。兩年來，沒有人問過她自己喝什麼。**

### 1-2. 她的核心：被看見

**一個記得所有人點什麼的人，有沒有人記得她喜歡什麼？**

- 她很會社交：第二次來的客人，她就記得對方的點法；她愛用電影接話，讓每個人都覺得被照顧。
- 但真正親近的人很少。週末她大多一個人看電影的早場。
- **照顧別人，是她不用談自己的方法。** 只要一直在問「你今天怎麼樣」，就不會有人問她。
- 她的交換申請拖了兩個月。不是懶，是怕：
  - 只要不交件，就不會被拒絕；
  - 只要不交件，就不用面對「我真的想離開」。
- **家庭的部分改寫**：現有台詞「我媽問我去了誰顧店」說不通，她人本來就在台北（`AA_01`）。改成：
  - 媽媽每天晚上十點打給她，講影印店的事：誰來印考卷、機器又卡紙。
  - 「我去英國，那邊是下午三點。她十點要打給誰？」
  - 她怕的不是店沒人顧，是**自己成為那個把家丟下的人**。

## 8. 綜合版（`AA_30`）：次要戀愛線的前置鏈與關鍵場景

> 使用者 2026-10-10：「其他的也是可以有戀愛，但是你們要綜合我的故事，主要還是以另外兩個為主戀愛線，其他的就會需要多一點事前才有可能能促成。」「我希望感情的成分要合理……感情要有深度。」

綜合版裡，芷若是**次要戀愛線**：故事不會主動把玩家帶到她身邊，玩家要自己走進她的生活。前置沒有達成，她就是很好的朋友，她的感情在方奕廷。三位次要角色的總表見 `BB_30`。

### 8-3. 為什麼這段感情合理

| | 理由 |
|---|---|
| **她為什麼會喜歡他** | 兩年來，她記得所有人的點法，**只有他問過她自己喝什麼**，而且之後他自己記得，沒有人提醒。她用電影接話時，他會反問她自己怎麼想。她在倫敦寄出的明信片，他回的是自己的一句話，不是客套 |
| **他為什麼會喜歡她** | 她是第一個不問「你念法律喔，好厲害」的人。她問的是「你今天過得怎樣」，而且會記得答案。大三他撐不住的時候，她從一杯咖啡就看出來：「你最近不加糖了」 |
| **為什麼是這個時候** | 大三下是她在學校的最後一學期，九月她一定會走。她從來不說自己的事，**只有「快要沒有機會了」能讓她開口**，而她開口的方式是寫在杯子上 |
| **什麼時候不該發生** | 玩家只是常客，從沒問過她自己的事；或玩家大三下不在台灣。那她就是一個很好的朋友，她的感情會在方奕廷 |

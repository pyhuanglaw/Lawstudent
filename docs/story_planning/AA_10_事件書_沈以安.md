  2. 她穿著學士服，手上拿著那本黑色手帳。
  3. 她翻到第一頁。
  4. 她唸出玩家大一第二天的回答。
  5. 她問第五次。
- **主要台詞**：
  - 小安：「四年前，你說『{第二天的回答}』。」
  - 小安：「我記到現在。我其實每年都想問，可是後來是別人在問。」
  - 小安：「最後一次。為什麼念法律？」
- **玩家的第五個回答**：由祐廷四年的落點決定可選項（`AA_12`），例如：
  - 落點 A：「因為有人說不清楚自己的事。」
  - 落點 B：「因為我找到一個不問會睡不著的問題。」（呼應許教授）
  - 落點 C：「我不念了。可是我很高興念過。」
  - 任何人都可以選：「我還不知道。但這次我不急。」
- **她的回應**（依關係）：
  - 交往中：她在手帳最後一頁寫下回答，把手帳給玩家：「這本給你。下一本我們一起寫。」
  - 好朋友：「好。這個答案比四年前好。」她闔上手帳，拍拍封面。
  - 熟度低：她笑了一下：「你可能不記得了。第二天，Café。……恭喜畢業。」（就算沒有交集，她也記得那一天）
- **影響**：四年的結局判定點。
- **所需畫面**：
  - 3D：椰林大道畢業典禮人潮（大量 NPC 穿學士服，需開發組評估效能）、傅鐘。
  - 2D：**formal 套改成學士服**（新服裝，需外部立繪），smile、embarrassed、laugh。
  - **CG 4：`cg_graduation_heroine01`**「第五次」：椰林大道、學士服、她把手帳翻開給玩家看，第一頁是四年前的字跡。
- **驗收要點**：
  - 她唸的回答必須真的是玩家第二天選的那一個（`G.choices.whyLaw`）。
  - 玩家第二天拒絕邀約（沒有回答過）的版本：她會說「你那天說『今天有點累，改天』。所以這是第一次，不是第五次。」

### 尾聲　畢業五年後的同學會（全體尾聲的一段）

- 依結局，各一段台詞，例如：
  - 民法研究者：小安：「我在寫論文。題目是網拍標錯價。你不要笑，真的是。」（呼應大一第二天的案例）
  - 理解媽媽的人：小安：「我現在每天打筆錄。我媽說我打得比她慢。」
  - 還在路上：小安：「我在一間小公司做法務。我睡得很好。這是我這五年最大的成就。」
  - 淡掉：小安：「好久不見。你過得好嗎？」（客氣，但真心）

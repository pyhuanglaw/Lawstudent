# 「不該知道／沒發生當發生」台詞清查（唯讀）

## 怎麼查的

- 程式碼：`scratchpad/devwt`（唯讀，沒改任何檔）。
- 查了哪些檔：
  - `src/data/events.js`：421 個事件全部展開，連同每句的 if/unless 和事件 prereq，逐句看。
  - `src/data/ladder.js`：約 450 層閒聊階梯，連同 if、linesIf、extraIf、LADDER_WEEK_IF、LADDER_CHOICE_IF。
  - 手機訊息池：約 570 列，加上 msg3d 的 tag 判斷。
  - `src/story3d.js` 主線程式：meetAn、noodleScene、talkAn、talkKai、宿舍旁白、Y0 手機排程。
  - 其他資料檔：`invites.js`、`encounters.js`（加 `encounter3d.js` 的 Q6_GATED）、`group_events.js`、`termend_lines.js`、`vac_activities.js`、`y2r2_3d.js`、`r2y3b3d.js`。
- 量：去掉註解後，`src/data/*.js`＋`src/*3d.js` 裡帶中文句讀的字串約 38,000 個。
- 篩法：
  - 先用關鍵字篩出約 1,000 句，再逐句看條件：上次、那次、那天、去年、你說過、你答應、照去年、又、還是、這次，加上所有角色名、交往／分手字樣。
  - 主線另外直接讀程式流程。主要是第二天拒絕小安（`F.anSkipped`）、沒等到小安（`F.anMissed`）兩條路線，看哪些後續台詞沒有分支。
- 判斷原則：
  - 只列真的找得到一條玩家路線會聽到矛盾的。
  - 條件已經保證的不列，例如 y2r2 子晴演唱會、明軒 M2、`ev_an_report_split`、予樂／邵鈞／詹靖（metZhan、metShao、NCCU_MET）、子晴 Q6 遊戲秘密、手機池、E14／E05 制服順序。
  - 只是文筆的也不列；D01～D32 不在範圍內。
- 三類的結果：
  - 第 1 類（知道別人的感情／私事）：**沒找到**。ROM.knowsOf／GFN 的守門都在，子晴遊戲秘密的 Q6_GATED 也守住了。
  - 第 2 類（選擇性事件當發生過）：大部分問題在這一類。
  - 第 3 類（提到玩家可能沒見過的人）：只有幾筆低嚴重度的。

嚴重度：
- **高**：主線、玩家做了遊戲明確給的選擇就一定撞到。
- **中**：支線或特定路線，一定撞到但比較少人走。
- **低**：一句帶過、或替玩家編了一個小動作。

### H1　阿哲在麵店問「下午你跟小安去哪了」，拒絕或沒等到小安的玩家也會被問
- 位置：`src/story3d.js:2967`（noodleScene）
- 原句：阿哲「所以下午你跟小安去哪了？我在球場看到你們往校門走。」
  - 接著是選項「總圖。她在整理今天的筆記。」或「溫州街的咖啡廳。她在整理今天的筆記。」，以及「沒有啊，剛好同路。」。
  - 選後者，阿哲回「同路。從霖澤館走到校門要「剛好同路」二十分鐘喔。」
- 條件：
  - 只看「阿哲在座位旁、`!F.zheNoodleDone`」。
  - 阿哲出現在麵店的條件是 `F.afternoonDone && 17.5≤hr<20.5`（story3d.js:332）。
  - **不看 `F.plan`、`F.anSkipped`、`F.anMissed`。**
- 問題：
  - 第二天下課，小安約玩家，玩家選第三個「拒絕」（meetAn，story3d.js:2924）。程式設 `anSkipped=true; afternoonDone=true`，小安自己往校門走掉。

  - `anMissed`（story3d.js:971，也設 afternoonDone）的玩家根本沒跟小安說到話，也會被問同一句。
- 建議：需要加條件，檢查 `F.plan`（有跟小安走才有值）。
  - `anSkipped`／`anMissed` 時跳過這句和整組選項，阿哲改說：「下午沒看到你，我還以為你先回宿舍了。」
  - 接下來的法服那句照舊。

# AA_1024　店門口互動點：店名＋今天的營業時間（通用格式；LIMAO-DOOR-HOURS-TEXT-1114，P3）

- AA-C 2026-11-14 11:3x。
- 起因：店面標準 §12 第 1、6 點——門口互動點要寫店名和今天的營業時間，打烊、還沒開門的句子由 AA 寫。
- 開發分支 `tingzhou3d.js` 現在只寫「進禮貌生財」「看禮貌生財」。別條街也還沒有帶時間的格式，所以這裡定一套通用的，汀州路先用，其他街照用。
- `{店名}` 用使用者給的店名（D147），程式不自己取。時間用 24 小時制、全形「～」。

## 1. 互動點的標籤（按鈕上的字）

| 狀態 | 進門那一個 | 看外觀那一個 |
|---|---|---|
| 營業中 | 進{店名}（今天 {開}～{關}） | 看{店名}（今天 {開}～{關}） |
| 今天還沒開門 | {店名}（今天 {開} 開） | 看{店名}（今天 {開} 開） |
| 今天已經打烊 | {店名}（今天已打烊） | 看{店名}（今天已打烊） |
| 今天公休 | {店名}（今天公休） | 看{店名}（今天公休） |

- 例：營業中「進禮貌生財（今天 19:00～23:30）」；下午「禮貌生財（今天 19:00 開）」。
- 一天開兩段的店（中午、晚上），寫今天還沒結束的那一段；兩段都過了才算「已打烊」。

## 2. 沒開的時候點下去（旁白，一句）

| 狀態 | 旁白 |
|---|---|
| 今天還沒開門 | （鐵門還拉著。今天 {開} 才開。） |
| 今天已經打烊 | （燈都關了。裡面的椅子倒放在桌上。） |
| 今天公休 | （鐵門拉下來，上面貼了一張「本日公休」。） |
| 颱風天停業 | （鐵門拉下來，貼了一張手寫的紙：颱風停業。） |

- 這四句是通用句，各店不用另外寫。哪一間店想要自己的一句，AA 再補。
- 「人在店裡、打烊時被請出去」那一句另外有（§12 第 4 點），不在這份。

## 3. 給 LAWWW

- 汀州路各店的門口互動點，照第 1 節換字。開門、關門時間照各店的 hours（禮貌生財 19:00～23:30）。
- 點下去照第 2 節：沒開門的狀態不進門，只出旁白。
- 其他街的店要換成這個格式的話，等 BB 判，排下一批。

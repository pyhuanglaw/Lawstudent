## 1. 結論（照嚴重程度）

### 1-1. 選項幾乎都沒有效果（使用者要的第二點，現在做不到）
| 哪裡 | 現況 |
|---|---|
| 校外約會（`date_lines`） | 1,765 個選項只有「選項字＋她的回答」，沒有任何友情、愛情欄位。程式（`date3d.js`）只看互動點她喜不喜歡，跟選哪一句無關。選項只在**第一次**到那個互動點出現；第二次以後、交往版、到達、收尾都沒有。影城（D33）八個人都沒有選項 |
| 一起活動（吃飯、咖啡、電影、書店） | 98 場只有 15 場有選項；電影 21 場、書店 21 場是 0；輪換的 98 則是 0 |
| 一起念書 | 42 場有 21 場有選項；第 6 場（算一次正式約會）七個人都沒有 |
| 閒聊階梯（`ladder`） | 每層固定熟悉 +2，選項只加自在或信任，**沒有愛情**；187 層（42%）選哪個都一樣；11 層沒有選項 |
| 期末飯、心意邀約 | 飯桌沒有選項（祐廷由程式輪流回「嗯。」「真的假的。」）；告白的三個選項七個人共用，選哪個結果一樣 |

| 邀約見面 | 有選項的 13 處都沒有加減 |
- 全部檔案沒有一個選項會扣分、沒有一個選項會讓她不高興。

### 1-2. 每個人只剩一個梗，套在每一個地點（AI 味最重的地方）
- 以安「我查過了」「行程只寫一行」「規則第幾條」；芷若「光、電影、拉花」；語彤「秀琴姨」（約 90 句）「嗯。」開頭、「嗯。下次。」；子晴「遊戲詞、怕曬、插座」；學姊「保溫瓶」（72 句，而且是已經說要拿掉的）「今天不談論文」；沛珊「早餐店」（127 句）「問問題」；可昕「外校室友」（97 句）「行程表」「你們學校／四十分鐘」（還違反不跟祐廷比學校）。
- 跨人物的模板：「地名？……好。」超過 110 句；第一次約外出六個人都是「……只有我們兩個？」；`remember` 都是「上次那個 X，今天 Y」；故事線 56 拍都是「她講三句 → 你呢？ → 三個選項 → 重複你的話加『……』」；「……」在階梯 604 次、故事線 116 次。
- **告白是同一套**：六位都是「你不說，那我說 → 我喜歡你 → 換你 → ……你終於講了。好。」；芷若和子晴幾乎逐字相同。有自己場面的只有以安（手帳）、語彤大四上、學姊（共創版）。

### 1-3. 階層
- 閒聊階梯最高只到「朋友」，**沒有交往階**（只有學姊在美國那 8 層是交往專屬）；朋友階只占一成、都排在期末；「認識」常常比「熟」還私人。
- 約會的交往版和朋友版分不出來（以安、學姊交往了還在「碰到手、找藉口」）；學姊交往後該叫「林{name}」，約會稿裡 0 次。
- 可昕分手以後 32 個地點照播交往句。可昕是女朋友、念過首都帝大，卻被寫成第一次來的客人。

### 1-4. 設定錯
- 語彤：舊設定殘留很多（麵店、阿姨、省錢、媽媽住院、「妳想接嗎？」）。
- 沛珊：大二下以後「人在臺北」的句子和規則（和現行相反）；重考期的訊息沒交往的玩家也收得到；大一就對「台南」有反應。
- 學姊：大四那年就有論文、教授、研究室。
- 其他：兩處名字寫死「祐廷」；芷若被寫成越熟越安靜的文藝少女、可昕被寫成又甜又可愛（都和設定相反）。

### 1-5. 寫得好、當標準、不要動的
- 階梯：語彤整份、學姊美國 8 層、子晴大一上、阿凱宿舍 6 場。
- 一起活動：邀約／可昕買外套、念書／可昕／5、念書／子晴／3、吃飯／可昕／2。
- 邀約：`invite_replies`（七階分得清楚）、`rel_lines` 的見面旁白。
- 偶遇的階層分得最清楚。各報告最後都有「不要動」的清單，改稿的人先看。

## 2. 要 LAWWW 加的機制（不加，改稿也達不到「選項會加友情或愛情」）
1. **選項統一多一個效果欄位** `fx`：`{fr:n, love:n}`（fr＝友情那三項照現有加法多加 n；love＝她的戀愛；可以是負的）。適用：`date_lines` 的選項、`ladder` 的選項、一起活動／念書的 `opts`、期末飯、手機回覆、邀約見面。沒有 `fx` 的照舊。朋友以下 love 不加。
2. **校外約會的選項每次去都出**（現在只有第一次）：每個互動點可以有 `first`（第一次）和 `again`（第二次以後輪流）的選項組；`dating` 版另一組。
3. **閒聊階梯加「交往中」一階**（每人每學期至少 2 層）和**愛情效果**。
4. **期末飯桌給玩家選項**（取代程式輪流回「嗯。」）。
5. 一起活動的電影：照 `AA_745`（已交，LAWWW 已開 MOVIE-TALK-1110）。

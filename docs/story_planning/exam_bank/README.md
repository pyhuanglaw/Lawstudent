## 2. 每一題的欄位

| 欄位 | 內容 |
|---|---|
| `id` | `<課程代號>_<兩位數>`，例如 `const_1_07` |
| `course` | 課程代號 |
| `week` | 哪一週教到（照 `syllabus/<學期>.json` 的週次；期中考週 8、9 不放） |
| `type` | `tf` 是非、`mc` 選擇 |
| `q` | 題目 |
| `options` | 是非題 `null`；選擇題四個選項 |
| `answer` | 是非題 `true`（○）／`false`（×）；選擇題是正確選項的索引 0～3（照檔案裡的順序） |
| `core` | 這題的觀念，一兩句。交卷以後寫在成績單上 |
| `basis` | 法條：條號＋原文（「……」是省略） |
| `checked` | 誰、哪一天對過全國法規資料庫 |
| `status` | 一律先標 `LEGAL_REVIEW_REQUIRED` |
| `note` | （有才寫）給審查的人看的提醒，不放進遊戲 |

## 3. 遊戲怎麼用（給 LAWWW）

- **期末考**：從這一科全部的題目隨機抽 5 題，不重複。
- **期中練習**（不計分）：從 `week` ≤ 7 的題目抽 5 題。
- **暑修、重修的考試**：先抽這個玩家沒考過的題目，不夠再從全部抽。
- **選擇題的選項要打亂順序**（`answer` 指的是檔案裡的順序；檔案裡正確答案的位置沒有刻意平均）。
- **交卷以後**：成績單列出 5 題、玩家的答案、對錯，每題附 `core` 和 `basis`。
- 計分、書卷獎、被當照 `AA_126` 1-2、第 2 節、1-6。讀書、準備值都不改答題結果。
- `note` 不顯示在遊戲裡。

## 4. 出題原則（`AA_126` 1-5）

- 只出「看法條就能判斷對錯」的題目：條文的要件、效果、期間、主體。
- 不出判決字號、不出學說爭議；題意清楚到只有一個答案。
- 題目的週次對得上那一週課堂的板書（`syllabus`），上過課的玩家答得出來。
- 是非題的 ○ 和 × 大約各一半；選擇題的錯誤選項不能是「也說得通」的答案。

## 5. 核對

```bash
python3 docs/story_planning/tools/check_exam_bank.py docs/story_planning/exam_bank
```

- 檢查格式（欄位、id、答案型態、週次、`status`、每科至少 15 題），並下載全國法規資料庫的現行條文，確認 `basis` 引用的每一句原文都對得上。
- 這只抓抄錯的條文，**不是法律審查**：答案對不對、題意清不清楚，還是要人看。
- 2026-10-14 AA 跑過：45 題，問題 0 個。故意改錯的條文（「滿二十歲為成年」「十年間不行使」）和引錯法（把憲法第 172 條的原文寫在民法底下）都抓得到。

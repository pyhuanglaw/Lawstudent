# AA_353　畢業後到國考放榜：跳日期時日期卡下面那一句

> - AA-C 2026-10-21，劇情總監自主補寫（使用者 10-21：「畢業前後缺乏日常互動的時段」「玩家能感受到時間流逝」）。屬於非關鍵的小型補寫，不加停點、不加場景、不動 `AA_319` 的事件。
> - **現況**（開發分支 `postgrad3d.js`）：
>   - 畢業以後是「跳到下一件事」：站著不動、或睡覺，就跳到下一件事。
>   - `S.advance` 跳過日子時會出日期卡，可是卡下面那一行是空的（`GM.titleCard(S.dateLabel(...),'',1800)`）。
>   - 臺灣路線、有報名國考的玩家（典型），會停的日子：6/2 畢業 → 6/9 可昕典禮（交往中）→ 6/28 宿舍期滿 → 7/12 總圖 B1 → 7/13～14 心意邀約（只有選過「讓我想想」的）→ 8/3 便條 → 8/4 一試 → 9/1 明軒出發（群組）→ 9/7 一試放榜 → 10/20～21 二試 → 12/14 二試放榜。
>   - 中間一段常常一跳就是三到七個禮拜，日期卡空白，**感覺不到這半年在做什麼**。
>   - 有律師讀書小組（`BAR_STUDY_GROUP`，2-Y4-33）的玩家，週末讀書會本身就會停，空白比較少；這一句一樣出（每句一次）。
> - **做法**照經濟系那一年（`AA_348`、`econff3d.js` 的 `CARDS`）：每一段空白一句，跳日期的範圍和那一段重疊、這句還沒用過才出，**一句只出一次**。

## 1. 句子

### 2030（交換延畢第一次考、2029 一試沒過再考；日子照 `S.Y[2030]`）
| 範圍 | 條件 | 句子 |
|---|---|---|
| 2030-06-01～07-10 | `S.sits(G,2030)` | （又是一個要讀書的夏天。總圖 B1 的位子，你坐的還是同一張。） |
| 2030-07-12～08-01 | 同上 | （考前三個禮拜。這次的讀書計畫表，你自己排。） |
| 2030-08-04～09-05 | 考了 | （一試考完。這一次，你沒有把法典放到書架最上面。） |
| 2030-09-07～10-18 | 一試過了 | （二試的書還是很厚。你讀得比去年快一點。） |
| 2030-10-21～12-12 | 考了二試 | （等放榜的七個禮拜。你去打工，晚上照樣翻一下考古題。） |

- 交換延畢的玩家（日本、美國路線）：2030 是第一次考，「這一次」「比去年快」「還是同一張」這幾句不適合。**2030 那一表只給 2029 考過的人（`S.retaker(G)`）**；交換延畢的照 2029 那一表的句子，日子換成 2030 的。
- 句子都是旁白，沒有人物台詞，不提誰陪你（陪的人各有各的場景）。

## 2. 給 LAWWW（事件規格）
- **在哪裡**：`postgrad3d.js` 的 `S.advance`，跳完日期出卡那一行，`''` 改成 `S.cardLine(G,d0,G.day)`。
- **怎麼選句**：照 `econff3d.js` 的 `S.cardLine`。
  - 範圍和「跳過的日子（d0+1～d1−1）」重疊、條件成立、還沒用過的第一句。
  - 用過記在 `G.flags.PG.lines`（陣列，舊存檔沒有＝空）。
  - 同一天、隔一天的跳不出。
- **條件**：照第 1 節，用 `S.sits`、`S.stage`、`S.retaker`、`S.delayed` 判斷。一試、二試有沒有考，照 `BAR_SIT_<年>`、`BAR_STAGE_<年>`。
- **日期卡時間**：有句子的用 3200 毫秒（同經濟系）。
- **錯過**：沒有錯過的問題（只在跳的時候出）。不新增停點、不新增旗標（`PG.lines` 是一般狀態）。
- **測試**：
  - 典型玩家從 6/3 跳到 12/14，每一段各出一句、不重複。
  - 沒報名的玩家，不出「總圖 B1」那幾句。
  - 一試沒過的出「明年你還會坐在這裡」。
  - 交換延畢的 2030，出 2029 那一表的句子。
- **BB**：照第 1 節兩種玩家（有報名／沒報名）各跳一次，看句子順序和時間對不對。

## 二、所有場景共用的變數（台詞裡的大括號）

| 變數 | 意思 | 寫法 |
|---|---|---|
| `{她}` | 另一位交往對象 | 用她的名字；學姊用「書瑀學姊」（以安說）、「學姊」（祐廷說） |
| `{期間}` | 祐廷和 `{她}` 交往到今天的長度 | 未滿 7 天＝「這禮拜才開始」；7～27 天＝「{n} 個禮拜」；28～59 天＝「一個多月」；60 天～11 個月＝「{n} 個月」；滿一年＝「一年多」 |
| `{重疊}` | 兩段交往同時存在的天數 | 只用來選句子，不念出數字 |
| `{最近一次}` | 發現前 7 天內，祐廷和發現的人實際有沒有單獨約會、吃飯 | 有才可以說「你前幾天還跟我……」 |
| 「曾說謊」 | 祐廷被問過時否認過（只算玩家真的選過的否認） | 沒有＝不能說「你騙我」，只能說「你沒講」 |
| 「曾同意」 | 她曾明確知道並接受祐廷同時和 `{她}` 在一起 | 有＝不演第一次發現，只演「新的資訊」 |

- **「重新開始」只在已經分手或說好暫停的時候用**；還在交往中的一律用「繼續」（子晴那份原文第七節）。
- 任何回憶（旅行、節日、承諾）只能用玩家**真的演過**的事件；沒有就用不提具體事件的句子。

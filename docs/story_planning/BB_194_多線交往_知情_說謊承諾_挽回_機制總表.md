## 4. 交往先後與時間（全部從存檔算，不寫死）
- 每段交往：`romance[X].since`（開始日）、`romance[X].history`（每一次開始、結束、重新開始，`by`、`day`）。
- 提供給台詞的值（LAWWW 做成函式）：
  | 值 | 算法 |
  |---|---|
  | `first(X,Y)` | 兩段的 `since` 誰早；差 14 天以內＝`'same'` |
  | `dur(X)` | 今天 − `since`（天）→ 說法表（`BB_192` 4-7：這禮拜／一個多禮拜／快一個月／一個多月／兩個多月／n 個多月） |
  | `sinceSpoken(X)` | `since` → 「這禮拜」「上禮拜」「{月}月{初中底}」（跨年加「去年」） |
  | `overlap(X,Y)` | 兩段都在的天數（較晚的 `since` 到今天，或到其中一段結束） |
  | `lastDate(X)` | 她和祐廷最近一次 L2／L3 的日子 |
  | `sharedAfter(X,d)` | 日子 d 以後、她和祐廷**實際發生過**的事（`events.done` 的日子＋`dateLog`）：生日、節日、旅行、週年 |

## 7. 關係狀態（發現不等於分手）
`REL_STATE[X]`：`dating` → `strained`（她發現了，還在交往）→ `thinking`（她說要想）→ `dating`（修復）／`ended`（她或他說分手）；`ended` 以後照一般告白可以重新開始（不鎖、沒有冷卻天數）。

## 2. 說謊、閃避、坦白（只記玩家真的選過的）
| 紀錄 | 什麼時候寫 | 定義 |
|---|---|---|
| `YT_HONEST[X]` | 她問「你不是有女朋友？」「她知道嗎？」「你們現在還在一起嗎？」時，祐廷的回答**符合事實** | — |
| `YT_DODGED[X]` | 同上，祐廷**沒有回答**或岔開（「就吃飯而已」） | 不算說謊；她記得 |
| `YT_LIED[X][Y]` | 祐廷的回答**和事實相反**（說分了但沒分、說沒有但有、說是誤會） | 只有在選項裡**真的選了**那一句才記；劇本不能補 |
| `YT_CONFESSED[X][Y]` | 祐廷主動說「我有件事要跟妳講」，告訴她 Y | 坦白＝同時寫 `knowsRel[X][Y]`（來源 `yt_told`）和 `ytKnows[X][Y]` |
- **選項只給符合事實的句子＋最多一個說謊的句子**：系統先讀實際狀態（`REL_STATE[Y]`），產生「照實」的說法；說謊的那個是另外標的選項。例：「我跟她分了」只有 `REL_STATE[Y]='ended'` 時是照實，不然就是說謊選項。
- 坦白之後，同一件事不能再說謊（她是從他那裡知道的）。

## 4. 交往先後與時間（全部從存檔算，不寫死）
- 每段交往：`romance[X].since`（開始日）、`romance[X].history`（每一次開始、結束、重新開始，`by`、`day`）。
- 提供給台詞的值（LAWWW 做成函式）：
  | 值 | 算法 |
  |---|---|
  | `first(X,Y)` | 兩段的 `since` 誰早；差 14 天以內＝`'same'` |
  | `dur(X)` | 今天 − `since`（天）→ 說法表（`BB_192` 4-7：這禮拜／一個多禮拜／快一個月／一個多月／兩個多月／n 個多月） |
  | `sinceSpoken(X)` | `since` → 「這禮拜」「上禮拜」「{月}月{初中底}」（跨年加「去年」） |
  | `overlap(X,Y)` | 兩段都在的天數（較晚的 `since` 到今天，或到其中一段結束） |
  | `lastDate(X)` | 她和祐廷最近一次 L2／L3 的日子 |
  | `sharedAfter(X,d)` | 日子 d 以後、她和祐廷**實際發生過**的事（`events.done` 的日子＋`dateLog`）：生日、節日、旅行、週年 |
- 規則：「前幾天」「上禮拜」只在 `lastDate` 在 Y 開始以後而且 7 天以內才用；「那天你也已經跟她在一起了？」只在 `sharedAfter` 真的有那件事才用；**不編造**玩家沒經歷過的事。

## 5. 承諾以後看實際行動
- 祐廷說出口的承諾才記（選項）：
  | 承諾 | 記 `YT_PROMISED[X]` | 實際要發生的事 |
  |---|---|---|
  | 「我會處理」「我會跟她講清楚」 | `'handle:<Y>'` | 和 Y 談（Y 的發現事件或坦白發生） |
  | 「只有妳」「我會跟她分手」 | `'exclusive'` | `REL_STATE[其他每一位]='ended'` |
  | 「以後有什麼我先講」 | `'tell_first'` | 之後他開始的任何新交往，X 要在 7 天內由**祐廷**告訴她（③），不是從別人那裡知道 |
- **檢查**：每天換日時看一次；承諾成立後，X 經第 3 節的來源知道「實際沒做到」（例：她知道 Y 還在交往）＝寫 `YT_BROKE_PROMISE[X]`（新的資訊，不是同一件事重播），各人的「第二次」版本（比第一次重）。
- 沒有被 X 知道的違約**不觸發任何事**（她不會憑空知道）；但記錄留著，之後她知道時一起算。

## 7. 關係狀態（發現不等於分手）
`REL_STATE[X]`：`dating` → `strained`（她發現了，還在交往）→ `thinking`（她說要想）→ `dating`（修復）／`ended`（她或他說分手）；`ended` 以後照一般告白可以重新開始（不鎖、沒有冷卻天數）。
- **誰可以讓它變成 `ended`**：她說分手（各人的條件，第 9 節）；祐廷說分手（玩家選）；**系統不會自己**分手。
- `OPEN_OK[X][Y]` 有值的那一段：之後 X 知道 Y 的事**不是**劈腿，不進 `strained`。
- `strained` 時：L1、L2 照常；L3 依人：以安婉拒一半、書瑀「今天不要講那件事」、可昕、子晴、芷若照各人的 `BB_192`／`BB_193`。

### 1-2. 她的核心：信任

**她能不能讓一個人，看到她沒有計畫的樣子？**

- 她看起來是全班最有規劃的人：筆記有目錄，報告提前寫完，總圖幾點會被太陽曬到都知道。規劃是她的保護殼。
- 她**不會拒絕別人**：借筆記、印講義、當組長，大家都找她，她都說好。
- 壓力大的時候會**失眠**，但不會告訴任何人。
- 她的問題不是「要不要念法律」（這一題交給祐廷）。她的問題是：**「這個計畫是我的，還是我媽的？」**
  - 她從小聽媽媽講法院發生的事：誰哭、誰吵、誰被帶走。
  - 媽媽希望她念法律，因為穩定。她念了，而且念得很好。
  - 她其實是**真的喜歡民法**：喜歡「每個人的權利和義務，都能被寫清楚」的感覺。但她不確定這份喜歡是不是自己的。
  - 四年後她要學會：喜歡一件事和媽媽希望她做這件事，可以同時成立。

**「慢熱」的重新定義**：現有設定寫她慢熱，但第二天她就主動約祐廷。我們的定義是：**她相處不慢熱，信任慢熱。** 她很容易約人一起讀書；真正的心事，要等很久才說。

**她不要用的話**：現有劇本已經被很多人用過的句型，以安一律不用：
- 「大家都只問 X，只有你問 Y」「謝謝你沒有 X」：小安、芷若、溫學姊、沛珊已經在用；
- 「不要跟別人講」：五個人在用；
- 「你不用那個表情」：語彤、明軒在用。

她也少用語助詞（現有台詞的「很敢耶」「好啦」可以保留少量），重要時刻的台詞一律不加。

> （典禮結束。椰林大道上都是穿學士服拍照的人。以安的媽媽站在傅鐘旁邊，手上拿著花。）
>
> （以安和媽媽拍完照，走過來。手上拿著那本黑色手帳，封面已經舊了。）
>
> 小安：全班都借過我的筆記。這本，沒有人借過。
>
> （她翻到第一頁，轉過來給祐廷看。）

**手帳第一頁上是她的字，整齊得像印的**（中文字由遊戲疊在 CG 上，不畫進圖裡）：

> **{name} 為什麼念法律**
> 大一・十月：（玩家第二天的回答）
> 大一・六月：（事件 8 的回答）
> 大二・六月：（玩家回答溫學姊的，她事後問來的）
> 大三・六月：（玩家回答子晴的）

> 小安：四年前，我說一年後再問你一次。
>
> 小安：其實我每年都想問。只是後來，是別人在問。
>
> 小安：最後一次。為什麼念法律？

**玩家的第五個回答**：依祐廷四年的落點出現不同的選項（`BB_02` 第 1-3 節）：

| 落點 | 選項 |
|---|---|
| A 替別人開口的人 | 「因為有人說不清楚自己的事。」 |
| B 自己的答案 | 「因為我找到一個不問會睡不著的問題。」（回收許教授的話） |
| C 離開也是回答 | 「我不念了。可是我很高興念過。」 |
| 任何落點 | 「我還不知道。但這次我不急。」 |

> （她把回答寫在最後一行。）

**她的最後一句，依關係**：

| 關係 | 她做的事與最後一句 |
|---|---|
| 交往中 | 把手帳交給祐廷：「這本給你。下一本我們一起寫。」 |
| 好朋友 | 闔上手帳，拍拍封面：「好。這個答案比四年前好。」 |
| 告白被拒後 | 「那段路還是算數。這本也算數。」 |
| 她和明軒在一起 | 「明軒在那邊等我。」她笑。「但這一頁是你的。」她把第一頁撕下來給他 |
| 不熟 | 不會有前面那段。她在人群裡看到祐廷，走過來：「你可能不記得了。第二天，Café。……恭喜畢業。」（就算沒有交集，她也記得那一天。借自《建築學概論》：錯過的人，很久以後才知道錯過了什麼） |

- **補位規則**：
  - 某一年的重訪日玩家錯過了，那一行寫：「（那年你不在。我猜你會說：……）」由她猜一句。這是一個溫柔的補位，不是懲罰。
  - 第二天拒絕邀約、沒有回答過的玩家，她會說：「你那天說『今天有點累，改天』。所以這是第一次，不是第五次。」
- **影響**：四年的結局判定點。
- **所需畫面**：
  - 3D：椰林大道畢業典禮的人潮（大量 NPC 穿學士服，效能需開發組評估）、傅鐘、以安的媽媽拿著花。
  - 立繪：**學士服（新服裝，需外部立繪）**；smile、serious、embarrassed、laugh。
  - **CG 4「第五次」（必要）**：椰林大道、學士服，她把手帳翻開給祐廷看，第一頁是四年前的字跡。
- **驗收條件**：
  - 手帳上的每一個回答，都必須是玩家真的選過的。
  - 典禮一定會發生，任何關係狀態都有對應的台詞。

## 9. 企劃組替使用者做的決定（使用者看過後隨時可以推翻）

| 決定 | 理由 | 被放棄的做法 |
|---|---|---|
| **選沈以安當第一位角色企劃** | 和祐廷同屆、四年都在；「為什麼念法律」頭尾都是她；現有素材最多；3D 也是第一個在做的角色 | 陳語彤（使用者的範例事件主角）。語彤列為下一位 |
| **住中和、和媽媽同住，媽媽在台北的地方法院** | 旁聽可以由刑訴課帶全班去，不用做新地區；「家裡晚上很安靜」解釋她為什麼在 Café 待到很晚 | 新竹人、住宿舍、寒假回家鄉旁聽（多一整個新地區，BB 原案） |
| **父母在她國小二年級離婚，爸爸住高雄，每年過年見一次** | 「單親」需要一個說法，但不能太重；保留以後的可能 | 父親過世（太重）；完全不說（設定會空著） |
| **刑事訴訟法移到大三** | 真實課程多在較高年級（需查證）；大三旁聽剛好接上。題庫答案一律不改 | 留在大一（和旁聽、寫實性都衝突） |
| **明軒的界線**：她和祐廷到「有點在意」以上就婉拒，否則和明軒在一起；一定先有徵兆 | 示範「玩家不是宇宙中心」，又不讓認真經營的玩家覺得被搶走 | 不論玩家怎麼做她都選明軒（太懲罰）；完全不寫（浪費現有設定） |
| **可以提到學校的心理諮商與保健中心** | 失眠是很多大學生的真實經驗，看醫生是正常的事；不寫藥名、不給醫療建議 | 不碰心理健康（會讓失眠線變得空洞） |
| **大四仍然綁馬尾**，只是改綁低一點 | spec 12 說「女主角髮型固定為馬尾」；用綁的高度表現她的放鬆，不違反使用者的設定 | 放下或半紮（BB 原案，和 spec 12 衝突） |
| **法院只做 2D 背景**，不做 3D 法庭 | 只出現一次；省下的美術工作留給 Café、溫州街這些每天會去的地方 | 新做一間可以走進去的 3D 法庭 |
| **「工具人」只做大一下的早期警告，而且一定能修補** | 讓玩家早點知道她在意這件事，還有四年可以改；不在大四突然揭穿 | 大四告白點才揭穿（BB 原案，太晚也太刺痛） |
| **她大部分路線會考上** | 她是前段班；結果不該懲罰玩家，只改變台詞的溫度 | 結果完全由數值決定（違反「結果是故事，不是分數」） |
| **這一輪不寫她和明軒分手** | 她的感情是她的人生，不是為了讓玩家有第二次機會 | 大四讓她分手、回到玩家身邊（等於把她當攻略對象） |

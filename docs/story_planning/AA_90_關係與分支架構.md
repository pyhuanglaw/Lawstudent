## 10. 節奏：週曆＋精華日（`AA_95` 試玩發現的第一個問題）

- 四年約一百四十週，不能每一天都玩完。提案：
  1. **週日晚上排下週**：在手機的課表上決定社團、打工、和誰有約（`AA_70`）。
  2. **只玩精華日**：有事件、有約、有共同活動的那一兩天，用現有的 3D 世界自由走動、對話。
  3. **其他日子用摘要帶過**：一段旁白＋幾則手機訊息（「這週你去了三次總圖，柏翰的考古題做完了一半」「阿哲在麵店團傳了豬腳照片」）。
  4. **密度**：大一上（序章）每週兩天；之後每週一天；考試週、重大事件的日子一定玩。
- 這樣一學期大約玩二十天左右，四年約一百六十天；每天十分鐘上下。實際長度由開發組評估。
- 類似的做法：心跳回憶的週行程、女神異聞錄的日曆。
- **BB 補的四點（AA 同意）**：
  1. **空白日不是鎖起來**：週曆上可以點「這天出門走走」，照樣進 3D 自由走動。自由走動是現有遊戲的核心，不能變成選單遊戲。
  2. **摘要日要有日常**：摘要不能只有一句旁白，要帶手機上的小事（`BB_70`、`AA_70` 的日常小事件做成一兩則訊息或照片）。
  3. **NPC 邀約在週間跳出來**（每週一兩個），答應就自動變成精華日；「改天」一定落在週曆的某一天。
  4. **條件事件剛好落在被略過的日子，順延到下一個精華日**，不准因此永久錯過（CLAUDE.md「不製造不合理的門檻」）。

## 11. 旗標與記憶的寫法（給 BB 和開發組對齊用；開發組可以改名）

- **人物**一律用現有的 `character_id`（`src/data/characters.js`）：`heroine_01` 沈以安、`heroine_02` 林芷若、`heroine_03` 陳語彤、`heroine_04` 高子晴、`heroine_05` 溫書瑀、`zhe` 阿哲、`kai` 阿凱、`yu` 小語、`classmate_bohan`、`classmate_xinci`、`classmate_mingxuan`、`classmate_peishan`……；新角色開發組再給 id。
- **記憶**（記在某個人身上，沿用現有 `SOCIAL.remember(npc, TAG)`）：全大寫底線，例如 `REMEMBERED_HER`（芷若）、`SHARED_UMBRELLA`（語彤）、`ZHE_SAID_IT`（阿哲）。
- **全域旗標**（記在玩家身上）：全大寫底線，例如 `EXCHANGE_ROUTE`（值：`TW`／`JP`／`US`）、`SAID_FOR_HER`、`ROMANCE_WITH`（值：character_id 或空）、`WED_CLUB`（值：`LAWCLUB`／`GUITAR`）、`JOB_*`（目前做的打工）。
- **關係階段**沿用現有系統的階段名稱，企劃裡寫「認識／熟悉／朋友／好朋友／在意／說不清楚／交往」，開發組對應到程式裡的值。
- **事件編號**沿用各企劃（以安「事件 n」、語彤「事件 n」、學姊 W／M／US、芷若 Z、子晴 Q、配角「哲 n」「F-」……），開發組做成事件 id 時可以加前綴，例如 `ev_heroine05_W2b`。

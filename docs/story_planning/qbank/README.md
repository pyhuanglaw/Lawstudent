# 期末考題庫（`AA_126` 第 1-5 節）

- **規則**：每一門法律課一個 JSON 檔；期末從全學期抽五題，期中練習只抽第 1～7 週的；答對幾題就是成績（`AA_126` 1-2）。
- **狀態**：每一題都是 `LEGAL_REVIEW_REQUIRED`。條文文字已經用 `tools/law_article.py` 對過全國法規資料庫（2026-10-14）；之後由使用者抽查，或在大四開放前一起審。
- **出題原則**：只出看條文就能判斷對錯的題目（要件、效果、主體）；不出判決字號、不出學說爭議；題意只有一個答案。

## 格式（每一題）

| 欄位 | 內容 |
|---|---|
| `id` | `<課程代號>_<兩位數>` |
| `course` | 課程代號，和 `syllabus/*.json` 一樣 |
| `week` | 哪一週教到（照那門課的課表：第 8、9、17、18 週是考試週，上課週是 1～7、10～16） |
| `type` | `tf`（是非）或 `mc`（選擇） |
| `q` | 題目 |
| `options` | 只有 `mc` 有：選項陣列 |
| `answer` | `tf`：`true`／`false`；`mc`：正確選項的**索引**（從 0 開始） |
| `core` | 一句話的解說（答錯時給玩家看） |
| `basis` | 法條 |
| `status` | `LEGAL_REVIEW_REQUIRED` |

## 1. 人物卡（新）
| 欄位 | 內容 |
|---|---|
| 家庭 | 台北人。爸媽一起經營公司，很忙、很疼她，從小給她最好的。國小到高中都念私立學校（補習、才藝、暑期遊學都排好）。**爸媽反對她打工**：「家裡又不缺，妳去端茶做什麼？」 |
| 住處 | 爸媽在學校附近（溫州街，新生南路那一側）買了一間**兩房一廳**給她住。一間是臥室，一間堆滿書和紙箱，她說是「書房」。週末偶爾回台北的家吃飯 |
| 為什麼打工 | 想知道打工是什麼感覺，想認識社會。上大學是她第一次覺得「終於自由」。高三暑假瞞著家裡去一盞茶屋應徵，一直做到現在 |
| 個性（照舊） | 話少但每句都在點上；對人的直覺很準；停頓多、常用「嗯」開頭；幽默很淡但突然很準；社會學理論很強 |
| **核心問題（新）** | **第一次自己選**：從小什麼都被安排好，大學是她第一次自己選要做什麼。打工、社會系的田野、雙主修法律、後來考律師，都是她自己選的。四年裡她學到：自己選的路，自己扛，也可以請人幫忙 |
| 阿姨（新） | **秀琴姨**（林秀琴，五十出頭），一盞茶屋的前輩員工，不是親戚。茶屋開店第二年就在，語彤第一天上班就是她帶的（AA_610 那一段原本寫語彤帶祐廷，照舊；秀琴姨帶過語彤）。一個人住在溫州街巷子裡的老公寓，租了十幾年；兒子在台中工作 |
| 她自己的東西 | **田野筆記**：大三開始記錄溫州街小店老闆、茶屋熟客、秀琴姨說的話。後來變成畢業專題 |
| 怎麼不讓人知道 | 打工時不提家裡。祐廷要等**熟了**（熟度到「朋友」）第一次去她家，才發現 |

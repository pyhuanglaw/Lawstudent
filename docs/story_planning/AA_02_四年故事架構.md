# ④ 四年故事架構（AA 初稿，PROPOSAL，等 BB 挑戰）

## 先看一個結構性事實：大學是「人陸續離開」的四年

照正式資料換算成祐廷的年級：

| 祐廷 | 沈以安（同屆） | 陳語彤（同屆） | 林芷若（大一屆） | 高子晴（大一屆） | 溫書瑀（大兩屆） |
|---|---|---|---|---|---|
| 大一 | 大一 | 大一 | 大二：Café 打工、通識課 | 大二：吉他社、常缺課 | 大三：法服社長、讀書會 |
| 大二 | 大二 | 大二 | 大三：交換申請季（多半在這一年申請，需查證） | 大三：實驗室、比賽、實習的壓力 | **大四：申請季、畢業典禮 → 第一個離開的人** |
| 大三 | 大三：分岔 | 大三 | 大四：交換回來或沒去、最後一年 | 大四：畢業專題、和家裡攤牌 | 畢業後：本校法研所（可能變成助教）／出國／先工作 |
| 大四 | 大四 | 大四 | 已畢業 | 已畢業 | 研究生、或「外面的大人」 |

不管選哪個架構，這張表都成立：**溫學姊在祐廷大二結束時畢業，芷若、子晴在祐廷大三結束時畢業。** 四年故事的骨架天生就是「一個一個人離開，留下來的人繼續長大」。這比設計人為的離別更自然，也最符合 spec 03 那句：「我們以前明明坐在同一間教室，現在大家的人生已經完全不一樣了。」

## 架構 A：一年一個問題（四章制）

每一學年是一章，章名是祐廷那一年面對的問題。

| 學年 | 章名 | 祐廷的問題 | 這一年會發生的大事 |
|---|---|---|---|
| 大一 | 我為什麼在這裡 | 分數到了就填了，然後呢？ | 第一次被點名、第一次考爛、認識大部分的人；學年最後一天，小安兌現「一年後我再問你一次」 |
| 大二 | 我想成為什麼樣的人 | 民、刑、公法開始分化，喜歡哪一個？ | 社團變成幹部、第一次接觸實務（法服、模擬法庭）；溫學姊的申請季與畢業典禮（第一次有人離開）；芷若決定要不要交換；郭沛珊轉系 |
| 大三 | 選擇有代價 | 交換、研究所、國考、工作，只能選一兩個 | 祐廷自己的岔路；芷若、子晴的最後一年；語彤家裡出事；小安的分岔；如果有感情，第一次真正受考驗 |
| 大四 | 離開之前 | 畢業以後，我要去哪裡？ | 國考、研究所、求職；最後一個學期；畢業典禮；最後回到兩點半 Café 窗邊同一張桌子。第一部結束，第二部（考試、職涯）從這裡開始 |

- **優點**：主題清楚，每一章可以單獨完成、單獨發布；玩家知道自己在故事的哪裡。
- **缺點**：比較像電視劇季數，世界的時間被章節框住；容易變成「每年固定上演的事件」。

## 架構 B：群像時間表（世界照每個人自己的人生走）

每位重要人物有一份四年的人生時間表，**不論玩家在不在場都會發生**。例如：

- 芷若在祐廷大二的某天 23:59 送出交換申請。
- 溫學姊在某個晚上研究計畫被退回。
- 子晴在比賽那天沒去會場。
- 語彤的媽媽某學期住院。

玩家每天只能在一個地方。這一天去了咖啡廳，就會錯過總圖門口的雨。故事是「玩家的人生和她們的人生在哪些時刻交會」。

- **錯過不是損失資料**：錯過的事會變成傳聞、訊息、朋友轉述（「你那天不在，子晴在社辦哭了」）。之後見面時，對方的態度會帶著那件事。
- **每學期結束有一場大家都在的聚會**（期末火鍋、成發、宿營），讓玩家重新跟上所有人的近況。
- **優點**：最符合「她們有自己的人生」「玩家不是宇宙中心」；重玩價值高；「如果那天我沒有去咖啡廳」會真的發生。
- **缺點**：內容量最大；節奏難保證，玩家可能整年什麼都沒遇到；需要「轉述」的寫作量（需開發組評估）。

## 架構 C：一件事貫穿四年（扣住《法條之外》的標題）

用一個虛構的「法律之外的問題」當四年的背景線，隨祐廷的法律能力成長，他的理解一年比一年深，但最後發現法律只能解決一部分。

**範例（全部虛構，不影射任何真實爭議）**：溫州街那棟日式老屋（已經在美術規劃裡）住著一位獨居的老太太，房子面臨租約、繼承或拆除的問題。

| 學年 | 祐廷看到的 | 他能做的 |
|---|---|---|
| 大一 | 一棟老房子，院子裡有那隻貓 | 什麼都不懂，只是常經過 |
| 大二 | 法服接到諮詢，他跟去做紀錄 | 只能抄筆記；第一次發現課本的「所有權」是一個人的家 |
| 大三 | 學了物權、繼承、行政法 | 看得懂爭點了，但也看懂了法律的極限 |
| 大四 | 結果出來（不一定是好結果） | 決定自己要當哪一種法律人 |

- **五位女主角可以自然靠近這件事，但不是被這件事驅動**：
  - 語彤：社會系的田野訪談，記錄這條街的口述歷史。
  - 芷若：電影課的短片。
  - 子晴：為這條街做一個小地圖或遊戲。
  - 溫學姊：法服社長帶這個案子。
  - 小安：她媽媽在法院看過「另一邊」。
- **優點**：給法律知識一個真正的意義，標題《法條之外》有了故事上的答案；把溫州街這個場景變成有故事的地方；美術資產（日式老屋、小公園、貓）可以重用。
- **缺點**：可能讓所有人繞著一件事轉（要控制在一學期約一個事件）；涉及真實法律要有人審查（需法律審查）；題材要避開真實的溫州街爭議。

## 架構 D：學期循環＋稀疏主線（最容易做出來）

- 每學期是一個可以重複的生活循環：選課 → 開學 → 日常 → 期中 → 下半學期 → 期末 → 放榜 → 寒暑假。
- 每學期只有 2–3 個**一定會發生**的主線節點（例如開學、期中、成發、期末聚會），其餘全部是看關係、地點、時間觸發的人物事件。
- 學期之間用「回顧」跳過時間：手機訊息、照片、宿舍書桌的變化、一句旁白。
- 四年主線很細：祐廷每年被問一次「為什麼念法律」。
- **優點**：最接近現有系統，最容易一學期一學期做出來（大一上先完成，符合 spec 03 的 vertical slice 要求與 D21「不要過度設計」）；每學期都是可以發布的完整單位。
- **缺點**：戲劇性最弱；如果人物事件寫得不好，四年會很平。

## AA 的建議（只是建議，等 BB 挑戰、等使用者決定）

**以 D 為骨架，用 A 的「每年一個問題」當敘事主題，把 B 的「人物時間表＋錯過後的轉述」用在五位女主角身上；C 要不要做，請使用者決定。**

理由：
1. D 決定「做得出來」：大一上可以先完成，之後一學期一學期加。
2. A 決定「玩家知道故事在往哪裡走」：每年結束時有同一個問題，四年的答案會不一樣。
3. B 決定「她們有自己的人生」：女主角的轉折照她們自己的時間發生，不等玩家。
4. C 是最有作品個性的選項，但風險最高（法律審查、題材敏感、所有人繞著一件事轉），所以列為待決。

### 每學期的固定節點（D＋A 的初步排法）

| 學期 | 一定會發生的節點（不論關係） | 那年的人物轉折，照人物時間表發生，玩家可能錯過 |
|---|---|---|
| 大一上 | 開學第三週的網拍相機案例（保留現有開場）、期中考、期末考 | 雨天總圖門口（只在下雨的晚上）、吉他社、法服讀書會 |
| 大一下 | 選課沒選上、期末、**學年最後一天：小安「一年後我再問你一次」** | 子晴比賽那天、芷若的電影早場 |
| 大二上 | 社團交接、第一次實務見習 | 芷若交換申請截止那晚、溫學姊研究計畫被退回 |
| 大二下 | 溫學姊畢業典禮（第一個離開的人） | 沛珊轉系、子晴的遊戲完成或放棄 |
| 大三上 | 祐廷自己的岔路：交換、研究所、國考 | 芷若出國或留下、語彤家裡出事 |
| 大三下 | 芷若、子晴的最後一學期 | 小安的分岔 |
| 大四上 | 研究所推甄或國考準備（需查證時程） | 溫學姊回來當助教（如果她念本校研究所） |
| 大四下 | 畢業典禮、兩點半 Café 同一張桌子 | 每個人的去向 |

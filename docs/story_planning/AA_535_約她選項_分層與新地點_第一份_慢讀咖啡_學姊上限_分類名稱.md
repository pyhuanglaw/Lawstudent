## 4. c 之一：慢讀咖啡當邀約地點（七位全套）

### 4-1　地點設定（給 `INVITE_DATA.places`）
- `{id:'slowread', zone:慢讀那一層, name:'慢讀咖啡', verb:'去慢讀咖啡念書', kind:'reason', minStage:'ACQUAINTANCE', stay:1.5, memory:'SLOWREAD_TOGETHER', sitAct:'read', days:[0,1,3,4,5,6], hours:[9,16.5]}`
- 規則：
  - 開始到結束都要在營業時間內（最晚 16:30 開始）。
  - 週二休。
  - 有伴侶也可以約（`reason`，和 Café、總圖一樣）。
  - 下雨照常。
  - **只在法律系的年級**：經濟系那一年不出（118 巷的場景本來就只在法律系，`law(G)`）。
- 約的時間：
  - 平日照現有的 12:10、15:30；
  - 週末加 10:00、14:00（LAWWW-B 說的「多週末時段」）。
- 階段不夠：只有「只打過招呼」的人約不了，照系統的 `why.stranger`，不用個人台詞。
- 「她本來就在那裡」（3-1 的常客時段）照 `here` 的做法：不算邀約、不接改天，玩家直接去。

# AA_97　國考與畢業後：工作規劃

## 0. 原則

1. **國考是法律系生活真實的一部分**：大三、大四的日常裡，「要不要考、什麼時候開始準備」是大家每天在聊的事。
2. **不是刷數值**：準備國考是**時間的選擇**（每週留幾個晚上念書），不是小遊戲或數值累積。
3. **沒考上不是壞結局**：可以隔年再考、先去工作、或發現自己想做別的事。溫暖基調（`AA_60`）。
4. **每個人的時程不一樣**：朋友們有人大三就開始、有人畢業後才開始、有人不考。玩家看見不同的選擇，不是只有一條標準答案。

## 1. 一般的時程【待考證】

| 時間 | 一般的情況 |
|---|---|
| 大三 | 有些人開始準備：買函授課程、參加補習、組讀書會 |
| 大四上 | 想考的人大多已經開始；研究所推甄也在這個時候（秋天到冬天） |
| 大四下 | 研究所考試（春天）；國考的人進入衝刺 |
| 畢業（六月） | 畢業典禮 |
| 畢業後的夏天 | **律師、司法官考試的第一試**（一般在夏天；兩種考試的第一試目前是一起考，【待考證】） |
| 秋天 | 第一試放榜；**第二試**（申論） |
| 年底前後 | 第二試放榜；司法官還有後面的階段（例如口試，【待考證】） |
| 之後 | **律師**：職前訓練＋到事務所實務訓練（約半年左右，【待考證】）→ 執業。**司法官**：進司法官學院受訓（約兩年左右，【待考證】）→ 法官或檢察官 |

- 還有其他相關考試（例如公務人員考試的法制類科、司法事務官、檢察事務官等），【待考證】。

## 2. 遊戲裡怎麼做

### 2-1. 什麼時候決定

- **大三下期末**（交換回來、或留在台灣的學期結束時），祐廷要回答一個問題：「大四要怎麼過？」選項：
  1. **認真準備國考**（律師、司法官，或兩個都考）：大四每週固定留兩到三個晚上（函授、讀書會、總圖 B1）。
  2. **準備研究所**（推甄或考試）：許教授、學姊的研究助理。
  3. **先不考，找工作或做別的事**：實習、營隊、家教、跨領域。
  4. **還沒決定**：可以；大四上期中前再問一次。
- 這個選擇和祐廷的**落點**連在一起（`AA_12`）：1 → 用法律幫人；2 → 把法律想得更深；3 → 把法律帶到別的地方。但**選了以後可以改**（祐廷是會換方向的人）。

### 2-2. 準備國考的日常（不是刷題）

| 日常 | 內容 |
|---|---|
| 函授課程 | 一次性的大支出（方案 A 之下付得起；`AA_72` 5c-2）；**真正的成本是時間** |
| 讀書會 | 和阿哲、小語（想考司法官）每週一晚（以安選公法研究所【已定案】，不考國考，`AA_113`） |
| 總圖 B1 | 期末前和考前，凌晨的自習室（開發組預計的區域） |
| 朋友的狀態 | 阿哲第二週就只看一堂函授：「我在培養感覺。」；小語每週一個晚上一個人在總圖（`AA_40`）；柏翰「我考研究所，但我陪你們念。順便。」 |
| 學姊 | 主線：她幫他排讀書計畫，便條又變回三件事（`BB_90` 大四）；她自己在寫論文，兩個人在總圖各念各的 |
| 不會變成苦讀地獄 | 準備國考的玩家，每週仍然有邀約、共同活動、麵店；**每週至少一個「不念書的晚上」**（企劃的規則） |

### 2-3. 結果怎麼決定（企劃建議：不用隨機）

- 結果看**準備的程度**（大四有沒有固定留時間念、有沒有參加讀書會、考前那一週怎麼過），**不靠運氣**：
  - **認真準備、一直沒放掉**：第一年就考上（律師；或司法官，需要更多準備）。
  - **有準備但時斷時續**：第一試過、第二試沒過 → **隔年再考，尾聲時已經考上**。
  - **沒有準備或沒報考**：走其他的路。
- **沒考上的那一場**寫成溫暖的：放榜那天，同場考試的人**各依自己的結果**出現（2026-10-13 改）：交往中的可昕（她準備的是律師考試，`AA_112`）、阿哲、小語；麵店團群組的訊息；熟的學姊或以安傳一句。阿哲：「我也沒上。明年一起。」

## 3. 畢業後篇（新增：畢業典禮到第一份工作之間）

畢業典禮之後、五年後的同學會之前，加一個短篇章（約五到八個精華日；`AA_90` 第 10 節）：

| 時間 | 事件 | 內容 |
|---|---|---|
| 畢業後的七月 | **搬出宿舍之後** | 祐廷租了公館的套房，或回嘉義念書（依選擇）；麵店照樣週二週四有人 |
| 七月 | **最後衝刺**（國考的人） | 讀書會最後一次；阿哲帶滷味：「考前一個月，吃好一點。」 |
| 夏天 | **第一試那天** | 考場外的早上；群組裡大家互相加油；考完走出考場（`AA_13` G1 的畢業版：「第二題你寫哪個？」「……有第二題？」） |
| 秋天 | **第一試放榜** | 手機查榜；誰過、誰沒過，群組安靜三秒，然後有人說「宵夜」 |
| 秋天 | **第二試** | 考前一晚；學姊的便條 |
| 年底 | **放榜** | 考上 → 職前訓練或司法官學院的入學通知；沒考上 → 「明年」 |
| 隔年 | **第一份工作** | 依路線：事務所的第一天、司法官學院的宿舍、研究所的研究室、公司的法務部、學校的講台……；第一天下班，群組裡大家互傳「我的第一天」照片 |
| 隔年 | **兵役**（**【待考證】、是否寫入由使用者決定**） | 台灣男性畢業後要考慮兵役（服役或替代役）的時間安排，會影響考試和工作的順序。企劃先不寫細節，等使用者決定要不要放進遊戲 |

## 4. 工作規劃：可能的路

| 路 | 在遊戲裡的樣子 | 誰可能走這條 |
|---|---|---|
| **律師**（大型或中小型事務所） | 職前訓練、實務訓練、第一份書狀被改得滿江紅 | 阿哲（中型事務所、還在打社會人籃球）、祐廷（落點 A） |
| **法律扶助、公益律師** | 和「付不起律師的人」一起工作 | 祐廷（落點 A，學姊主線）、語彤（社工）是合作對象 |
| **法官、檢察官**（司法官） | 司法官學院兩年、第一次開庭 | 小語（想考司法官；五年後是檢察事務官、還在考，`AA_13` G7） |
| **企業法務、法遵** | 合約、公司內的規則 | 明軒（科技公司法務）、芯慈（會計師事務所的法遵） |
| **公職**（法制） | 政府機關的法規工作 | 選擇性 |
| **研究、學術** | 研究所、博士班、教學 | 柏翰（博士班）、學姊（法律扶助制度的研究）、祐廷（落點 B） |

| **跨領域** | 遊戲公司的法務、出版、媒體、創作 | 子晴的工作室需要懂法律的人；祐廷（落點 C） |

## 1. 角色設定

| 項目 | 內容 |
|---|---|
| 攤名／稱呼 | 攤名「禮貌生財上師」。玩家叫他「老師」（規格書原句）；熟了以後他叫祐廷「同學」，再熟叫「林同學」。他不報自己的名字。 |
| 年紀、樣子 | 六十多歲男性；有點舊的中式外套；精明、帶一點戲謔；不是仙風道骨，也不是神棍（規格書 6.1） |
| 個性 | 嘴賤、幽默、觀察力強；偶爾刻薄；對真的難過的人意外溫柔；用反話提醒人；同一題問太多次會不耐煩；記得熟客的事；不解釋自己的過去（規格書 6.1） |
| 怎麼「算」 | 先問再算：每次都先問玩家兩三句（書讀了沒、跟她講過話沒），再開口。籤筒、命盤是道具，他真正靠的是看人。**他不預言結果**（不說會不會上、會不會在一起），只講玩家現在的狀況。 |
| 說話 | 短句、台灣口語；一句話裡先損你再給你台階；講到正經的事會停一下、喝口茶，講完馬上岔開。不說格言、不總結人生。 |
| 小習慣 | 舊茶杯從不離手；手寫筆記本只記熟客（玩家第三次來才發現自己被記了一行）；收費木牌上的字很久沒描，他從來沒收過錢。 |
| 不做的事 | 不在玩家落榜、分手的時候開過頭的玩笑；不替玩家做決定；不洩漏任何角色的好感或還沒發生的事；不講別的客人的事（最多一句「上一個坐這張椅子的比你慘」）。 |
| 出攤 | 跟夜市營業時間（LAWWW 定）。另有「攤開著、人不在」的狀態（規格書第三節 11）：桌燈亮、茶杯還有煙、椅背掛著外套——用在第 5 節的 H4。 |

## 2. 三條支線的事件大綱

格式：編號｜什麼時候可以發生｜大概內容。**每一件都要玩家自己走到攤前、選那個選項才發生；不來也不影響任何主線或結局。**

### A.〈命裡缺一張榜單〉學業與國考

| 編號 | 條件 | 內容 |
|---|---|---|
| A1 | 大一上起，第一次選「問學業／考試」 | 規格書原句（「你是來替教授報案的」）。接著他問準備到哪：照玩家這學期實際的學習進度分三種回答（幾乎沒讀／讀了一半／讀完了）——不看讀書天數，看現有的學習進度資料（D118）。 |
| A1b | 期中、期末考前一週，問過 A1 | 一句短的：「又是你。這次書帶了沒？」玩家把書拿出來，他翻兩頁：「這頁折角折得不錯。內容我看不懂。」 |
| A1c | 某一科被當以後回來，問過 A1 | 他先損一句，看玩家沒笑，把茶推過來：「重修的人我看多了。第二次坐在那間教室，聽得懂的東西不一樣。」 |
| A2 | 大四上起、國考報名後、考前，選「問學業／考試」 | 規格書原句（「前者我不用負責，後者我更不敢負責」「先講講你今年準備得怎麼樣」）。然後照玩家的在校成績和準備狀況說一段他的觀察，不說上不上。 |
| A3 | 國考或研究所落榜、之前問過 A2 | 規格書 6.3 A3：先一句玩笑，看反應，再認真談一次。不說「命中注定」。重點句方向：「榜單是一張紙。你這一年讀進去的東西，沒有印在上面，也沒有被收回去。」然後問：「你要再考，還是想先喘一下？兩個我都不笑你。」（選項只影響他下一次的開場，不影響主線。） |
| A3b | 落榜後決定重考、再來 | 他從桌下拿出一支用到很短的鉛筆：「借你。考完還我。沒考完也要還我。」 |
| A4 | 律師或司法官上榜後 | 規格書原句（「我剛剛不是叫你別再考了嗎？這就是恭喜」）。 |
| A5 | 沒考上司法官、當了律師以後 | 「律師也好。法官要坐著聽人講一整天，你這個人坐不住。」（對應 D118：沒考上司法官不是失敗。） |

### B.〈你這個人桃花不是問題〉感情

| 編號 | 條件 | 內容 |
|---|---|---|
| B0 | 沒有任何認識的可交往角色 | 選項不出現（規格書：沒認識的人不觸發）。 |
| B1 | 至少一位到朋友以上、還沒交往 | 規格書原句（「你們兩個裡面至少有一個人不知道」）。**他不知道、也不說對方是誰、喜不喜歡玩家**；玩家不用說名字。 |
| B2 | 同時和兩位以上走得近 | 「你剛剛講『她』的時候，停了一下。你是在想要講哪一個吧。」「我不管你。你自己的帳自己記清楚。」（遊戲允許同時交往，他不審判，只點破。） |
| B3 | 交往中，一個人來 | 問兩人未來。他反問：「她知道你來問這個嗎？」→ 知道／不知道，兩種回答。 |
| B4 | 交往中，約會時一起到夜市、走到攤前 | 規格書 B2：依人物個性每人一小段。**每位女主角的反應由 AA 另寫、照人物口氣表**，這一份只給兩個示範（第 6 節）；不是每個人都有——個性上不會坐下來算命的人（例如以安）就是站在旁邊等，上師只對祐廷說一句。 |
| B5 | 吵架後 | 他不勸和：「你是來問誰對誰錯的吧。我這裡不辦那個。」「我只問你：你現在比較想贏，還是比較想見她？」 |
| B6 | 分手後 | 不開玩笑。倒茶。「坐一下再走。今天不收你時間。」下一次來才恢復嘴賤。 |

### C.〈命不是拿來算的〉人生

| 編號 | 條件 | 內容 |
|---|---|---|
| C1 | 大二下，交換申請前後 | 玩家問該不該去。他抽一支籤、看都沒看就放回去：「籤上寫什麼不重要。你剛剛看我抽的時候，心裡希望它寫什麼？」 |
| C2 | 大三下或大四上，選研究所／國考／就業前 | 他拿筆記本翻到玩家那一行，念出玩家大一問過的第一個問題：「你那時候只怕被當。現在怕的東西比較貴了。這算進步。」 |
| C3 | 延畢、休學、重考（經濟系線的玩家）等任何「晚一年」的狀況，自己提起 | 「晚一年的人我這裡很多。晚的那一年，沒有人回來跟我說後悔。回來說後悔的，都是那年沒有去的。」（一句，不延伸。） |
| C4 | 畢業前最後一次來 | 他不給建議，把收費木牌翻過來，背面是空的：「這一面是給你們自己寫的。我寫了也不準。」 |

## 3. 跨學年的觸發原則

1. **全部是玩家主動**：走到攤前、攤位營業、上師在，才有選單；選單照規格書第九節，沒解鎖的選項不顯示。
2. **每次來最多一件新事件**，其餘是短的閒聊（閒聊池另寫，照學期換）。同一題同一學期問第三次：「你再問一次，我就要收錢了。」（不會真的收。）
3. **只讀現有的狀態**，不另建系統：學年學期與日期、學習進度與成績（D118 的資料）、被當／重修、國考與研究所的報名和放榜結果、交往旗標（`dating_*`）與關係階段、交換路線、延畢、經濟系線。
4. **不劇透**：他不說任何好感數字、不暗示誰喜歡誰、不提玩家還沒遇到的人和事。B 線的台詞只用「她」。
5. **錯過不補、也不鎖**：A1 可以大三才第一次發生（台詞換成「大三才第一次來問會不會被當，你也滿特別的」）；A3、A4 只要求「之前問過考運」，沒問過就是一般的恭喜或安慰短句。
6. **人在外地時沒有**：交換（日本、美國）期間、休學在家那半年離開臺北的日子，攤位照開，玩家到不了。回來第一次見面有一句：「這麼久沒來，我以為你考上了。」

## 4. 身分【已定案】：退休的刑法教授（使用者 2026-11-10 選定；原本的三種候選已刪）

- **真相**：他是已經退休的刑法教授，法律圈沒有人不知道的人物；現在很多教授都是他的學生。他不喜歡認識的人在夜市揭穿他。
- **玩家這一邊**：祐廷四年裡一直從別的地方聽到「那位已經退休的刑法老教授」——上課時老師提起自己的老師、教科書的作者欄、學長姊講的傳說、系館牆上的老照片——知道有這個人、知道他以前怎樣、知道很多老師是他教出來的，**但不知道夜市那個算命的就是他**。尾聲才對起來。
- **他為什麼擺攤**：他不缺錢。他就是喜歡找人聊天，尤其是法律系的學生（使用者 11-10）。坐在夜市，學生不知道他是誰，才會跟他講真話。
- **全部是虛構人物**：不影射、不對應任何真實的教授；姓名、著作、學說都另外虛構（名字待定，定了寫進 WORLD_NAMING 與總表）。
- **兩條平行的線（定稿時要寫的）**：
  1. **夜市這一邊**（第 5 節 H1～H6）：他偶爾講出太內行的刑法觀察（A1 之後玩家問刑總的題目，他兩句講完，比課本清楚，然後說「夜市聽來的」）；有來逛夜市的教授看到他，愣住、想開口，他先說「先生要算命嗎？不算不要擋到後面的人」；收納箱裡有一枝舊鋼筆。
  2. **學校這一邊**（新增，要 AA 另寫、放在現有的課堂與系館裡）：刑總課老師說「這個見解是我老師的，他退休以後誰都找不到他」；教科書上的名字；學姊或學長講他以前上課的傳說（點名方式、口頭禪——口頭禪和上師在夜市講過的某一句一樣，這是玩家對起來的鑰匙）。
- **揭曉**：尾聲，祐廷在一個正式的場合（待定：畢業典禮來賓、系上的榮退紀念演講、或書的新版序）看到那個名字和那張臉。他回夜市，上師照樣坐著。祐廷沒有揭穿他，只叫了一聲「老師」——和四年來同一個稱呼，意思不一樣了。上師：「叫這麼大聲幹嘛。坐。」
- **未完全揭曉**：學校這一邊的傳說照樣聽得到，但沒收齊夜市的線索，尾聲對不起來；玩家只覺得這個算命的怪怪的。

## 5. 隱藏線的結構與兩種揭曉

| 編號 | 條件 | 內容 |
|---|---|---|
| H1 | 來過 3 次以上 | 他說出一句對法律或考試異常內行的話，玩家問，他岔開：「夜市待久了，什麼客人都有。」 |
| H2 | 大二起，來過 6 次以上 | 一位熟客用另一個稱呼叫他。他裝沒聽到。 |
| H3 | 大三起，問過 A、B、C 各至少一次 | 收攤時玩家幫他撿掉在地上的東西，看到一件不像算命攤的舊物。他收起來：「看到就看到了。不要問。」 |
| H4 | 大四，H3 之後；日期待定（例如系上辦他的榮退紀念活動那一天——他沒去活動，也沒出攤） | 攤開著，人不在。桌燈亮、茶還熱、外套在椅背。筆記本攤開在玩家那一行。 |
| H5 | H4 之後再來 | 他回來了，什麼都沒解釋，只多說一句平常不會說的話。 |
| H6 | 畢業後的尾聲 | 揭曉。 |

- **完整揭曉**（H1～H5 都發生過）：尾聲有一場專屬的戲，他自己講，講得很短；最後一句回到嘴賤。之後攤位照舊，稱呼不變——玩家知道了，他還是「老師」。
- **未完全揭曉**（線索沒收齊，或很少來）：尾聲沒有那場戲。夜市照開，他照樣坐在那裡。最後一次對話他說：「你有事想問我吧。下次。」——玩家只知道他不只是算命的，不知道是誰。**兩種都不影響任何結局。**

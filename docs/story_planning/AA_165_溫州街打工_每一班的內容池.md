## 1. 半熟早午餐（週末早班外場，07:30～11:30）

### 1-1. 開店（輪流）

1. 鐵捲門拉起來的聲音，是整條溫州街第一個醒來的聲音。你擺好十二副餐具。
2. 小米姐在試今天的第一顆蛋。三分四十秒。她點點頭，算是早安。
3. 小蕙已經在擦桌子了。她說她從來沒遲到過，因為公車只有一班。
4. 你在黑板寫今日推薦。（選擇）「寫得漂亮一點」／「寫得大一點」／「畫一顆蛋」
   - 漂亮：小米姐：「字很好看。可是坐最後一桌的阿伯看不到。」
   - 大：小米姐：「好，阿伯看得到了。」
   - 畫蛋：小蕙：「這是蛋還是馬鈴薯？」
5. 騎樓的兩張桌子要擦乾。昨晚下過雨，椅子背面還是濕的。

### 1-2. 尖峰的小狀況（每班一件，輪流）

| # | 狀況 | 選擇與結果（只改旁白） |
|---|---|---|
| 1 | 「我的蛋太熟了。」 | 「我請廚房重做」→ 小米姐重做，看了你一眼：「下次先看蛋再出餐。」／「我去問一下」→ 客人：「……好啦，其實也還好。」 |
| 2 | 小孩打翻柳橙汁 | 「先拿抹布」→ 媽媽一直道歉，小孩一直笑／「先問小孩有沒有怎樣」→ 小孩：「我的衣服喝到了。」 |
| 3 | 兩桌同時舉手 | 「先去先舉手的」→ 另一桌等了三分鐘／「先去離你近的」→ 小蕙接走了另一桌，對你比了個讚 |
| 4 | 有人點菜單上沒有的東西 | 「我問廚房」→ 小米姐：「可以。只有今天。」／「說沒有」→ 客人點了別的，吃得很高興 |
| 5 | 排隊的人在門口吵誰先 | 「拿候位單」→ 隊伍突然變得很文明／「讓他們自己說」→ 兩個人吵到一半，一起笑了 |
| 6 | 同一桌點錯一份 | 「直接換」→ 客人：「其實這個也不錯，我吃這個好了。」／「先道歉再換」→ 客人說不用換 |
| 7 | 熟客說「老樣子」 | 「記得」→ 你沒問就送上去，對方愣了一下，笑了／「不記得」→ 小蕙在你耳邊說了三個字 |
| 8 | 外送的單和內用的單疊在一起 | 「先做外送」→ 外送員：「謝謝，下一單在公館」／「先做內用」→ 外送員坐在門口的凳子上滑手機等 |

### 1-3. 收尾（輪流）

1. 員工餐是今天剩下的吐司和一顆半熟蛋。小米姐：「蛋是我煮的。你的那顆，下次自己煮。」
2. 你洗完最後一個杯子，十一點半。外面的隊伍換成了午餐的人。
3. 小蕙說她要去補習。她每個週末都是這樣：早上打工，下午補習，晚上念書。
4. 小米姐把黑板擦乾淨，說明天的推薦還沒想好。
5. 騎樓的桌子坐著一對老夫婦，你收走他們的盤子。他們說：「下週見。」

### 1-4. 熟練的描述（依熟練值換一組）

| 熟練 | 描述 |
|---|---|
| 0～2 | 你一次只敢拿一個盤子。 |
| 3～5 | 你可以一手拿兩個盤子，但走路時會看著它們。 |
| 6～8 | 你已經可以一手拿三個盤子，而且不看。 |
| 9～10 | 小米姐出門買菜的時候，把店交給你和小蕙。 |

### 1-5. 沒去的那一週（下一班開場，輪流）

1. 小米姐：「上週少一個人，蛋煮壞了兩顆。不是怪你，只是告訴你。」
2. 小蕙：「你上週沒來，我一個人端了八十盤。我數過。」
3. 老夫婦裡的太太：「上週沒看到你，我們還以為你考試。」

## 2. 阿德影印輸出（平日晚班，18:00～22:00；考試週可以加班 21:00～24:00）

### 2-1. 接單（輪流）

1. 「雙面、縮印、兩頁一張、三十份、膠裝。」你一個字一個字複述，客人點頭。
2. 一個研究生把隨身碟交給你，說「最後一版」。檔名是「最終版_真的最終_改3」。
3. 社團的人要印一百張傳單，問能不能打折。阿德在後面說：「一百張不算多。」
4. 一位阿嬤拿著一張紙，要印十份：是里民活動的通知。她付的是硬幣。
5. 有人只印一張，彩色的。是一張狗的照片，下面寫「走失」。阿德說這張不用錢。

### 2-2. 做的時候的小狀況（每班一件，輪流）

| # | 狀況 | 選擇與結果 |
|---|---|---|
| 1 | 膠裝的書背歪了 | 「重做」→ 阿德沒說話，把歪的那本收進抽屜：「這本給我女兒當計算紙。」／「問客人要不要」→ 客人：「……我要重做的。」 |
| 2 | 海報的顏色和螢幕上不一樣 | 「先印一張小的給他看」→ 客人改了三次顏色／「照檔案印」→ 客人：「……好像也可以。」 |
| 3 | 卡紙 | 「自己拆」→ 你的手沾了一片碳粉／「叫阿德」→ 阿德一隻手就拆好了：「它認識我。」 |
| 4 | 一份報告少了第 7 頁 | 「打電話問」→ 客人說第 7 頁本來就不存在／「先印其他的」→ 客人跑回來：「第 7 頁！」 |
| 5 | 有人要印一整本書 | `AA_164` WZ-C2 那一次以後，這一格換成：你指了指牆上那張紙，對方說「喔，好」 |
| 6 | 騎馬釘釘歪了 | 「拆掉重釘」→ 紙上多了兩個小洞／「就這樣」→ 阿德：「歪一點的，客人比較記得我們。」 |
| 7 | 三組人同時要在十點前拿 | 「照先來後到」→ 最後一組十點零五分拿到，說謝謝／「先做最少的」→ 三組都在十點前拿到 |
| 8 | 掃描的文件是手寫的情書 | 「趕快掃完不看」→ 客人：「你有看吧。」「沒有。」／「問要不要掃雙面」→ 客人臉紅了：「背面也有。」 |

### 2-3. 交件（輪流）

1. 研究生拿到論文，翻了一下書背：「好整齊。」他好像快哭了。
2. 社團的人說傳單發完了會再來。阿德：「每次都這樣說。」
3. 十點，阿德把鐵捲門拉下一半。最後一位客人彎著腰鑽進來。
4. 阿芃寫完功課，趴在桌上睡著了。阿德把外套蓋在她身上，繼續裝訂。
5. 你走出店門，手上還有紙的熱度。

### 2-4. 考試週加班（21:00～24:00，輪流）

1. 店門口排了十二個人，每個人手上都有一個隨身碟。阿德說：「今天是法律系。下週是醫學系。」
2. 有人印到一半，發現自己檔案打錯字，在櫃台前面改。後面的人沒有催他。
3. 十二點，最後一份筆記印好了。阿德請你喝一罐飲料：「每年這一週，都一樣。」

### 2-5. 熟練的描述

| 熟練 | 描述 |
|---|---|
| 0～2 | 膠裝的書背歪了，阿德沒說話，重做了一本。 |
| 3～5 | 你學會先看紙的方向，再按按鈕。 |
| 6～8 | 你看一眼就知道這份要裝幾公分的書背。 |
| 9～10 | 客人進門，阿德說：「問他就好。」 |

### 2-6. 沒去的那一週（輪流）

1. 阿德：「上週有一份論文，我自己裝的。裝得沒有你好。……騙你的，跟你差不多。」
2. 阿芃：「上週有人問你在不在。是一個印很多筆記的人。」
3. 阿德：「機器上週卡了三次。它想你。」

### 2-7. 阿芃的三個問題（WZ-C7；第 2、5、9 班；`LEGAL_REVIEW_REQUIRED`）

| 次 | 阿芃問 | 祐廷的回答（依年級） | 阿芃的下一題 |
|---|---|---|---|
| 1 | 「老師說未滿十八歲不能自己簽約。那我昨天買飲料，算什麼？」 | 大一：「呃……那種小東西應該可以。」大二起：「老師說得太簡單了。日常生活需要的、用零用錢買的，法律讓妳可以自己買。」（BB-B 審：民法 §77 但書、§84） | 「那手機呢？手機是日常生活需要的。」（買手機要爸媽同意，§79，BB-B 審） |
| 2 | 「我在網路上抽到一張演唱會的票。我媽說我不能去。那這張票是誰的？」（原本的「撿到東西」和 BB 的 WZ-P4 重複，換掉） | 大一：「……應該是妳的吧？」大二起：「白白拿到、不用付出什麼的東西，法律讓妳自己就可以收。去不去，是另一件事。」（BB-B 審：§77 但書、§1084 II） | 「所以票是我的，可是我不能去。……法律好奇怪。」 |
| 3 | 「我爸說他不印整本書是因為法律。可是如果那本書已經絕版了呢？」 | 大一～大三：「這題我要回去想。」大四上起：「這題很好。老師上課剛好講到這個。」 | 「那你想好了再跟我說。我不急。我才國二。」 |

- 回答的法律內容不寫成定論，只寫到「法律讓妳可以」這種程度；條文與用語由 BB-B 審（第 1 題 BB-B 已審：民法 §77 但書、§84、§79；第 2 題 BB-B 已審：收下是民法 §77 **但書**〔純獲法律上之利益〕，「去不去」是父母的保護教養 §1084 II，另一件事（`BB_148` 8d-4）；第 3 題著作權法 §65）。

## 3. 一盞茶屋（週末下午外場，13:00～17:00）

### 3-1. 院子（依季節換）

| 季節 | 旁白 |
|---|---|
| 春（3～5 月） | 樟樹換葉，落葉比秋天還多。你掃了一下午，蘇姨說：「它在換衣服。」 |
| 夏（6～8 月） | 蟬很吵。石板路曬得發燙，你潑了一桶水，院子安靜了一點。 |
| 秋（9～11 月） | 風一來，葉子就往緣側的方向飛。你掃了三次，蘇姨說：「掃一次就好。剩下的是院子的。」 |
| 冬（12～2 月） | 苔在石板縫裡變綠。蘇姨說冬天最好看的是苔，不是樹。 |

### 3-2. 泡茶（每班一種，輪流；只寫做法的感覺，不寫精確的溫度與秒數）

1. 烏龍。蘇姨：「第一泡不要給客人。那是洗茶，也是叫醒它。」
2. 綠茶。蘇姨：「水放涼一點。綠茶怕燙，跟人一樣。」
3. 東方美人。你倒得太急，茶湯起了泡。蘇姨：「沒關係，它很甜，會原諒你。」
4. 普洱。蘇姨讓你聞茶罐：「這罐比你老。」
5. 白茶。蘇姨：「這個不用急。你等它，它就好了。」
6. 冬天的熱可可。不是茶。蘇姨：「呂老師的孫子要來。小孩不喝茶。」

### 3-3. 收席（輪流）

1. 你把茶巾一條一條晾在緣側。蘇姨泡了一杯給你：「今天你泡得最好的那一種。」
2. 呂老師的位子空了。他喝完會把杯子倒扣，說這樣下一個人知道他走了。
3. 最後一桌是兩個學生，聊了三個小時，茶續了五次。他們走的時候很小聲地說謝謝。
4. 你把燈籠點亮。院子裡的樹一下子變成了另一棵樹。

### 3-4. 熟練的描述

| 熟練 | 描述 |
|---|---|
| 0～2 | 你把水沖得太急，蘇姨說水會被你嚇到。 |
| 3～5 | 你學會溫杯的時候，順便溫自己的手。 |
| 6～8 | 你等水的時候，已經不會一直看沙漏了。 |
| 9～10 | 呂老師說：「今天是你泡的吧。」你沒問他怎麼知道。 |

### 3-5. 沒去的那一週（輪流）

1. 蘇姨：「上週落葉沒人掃。院子很高興。」
2. 呂老師：「上週的茶是蘇姨泡的。好喝。可是我習慣你泡的那種不太好喝。」
3. 蘇姨：「你來了。」（就這樣，沒有別的話。她把竹掃把遞給你。）

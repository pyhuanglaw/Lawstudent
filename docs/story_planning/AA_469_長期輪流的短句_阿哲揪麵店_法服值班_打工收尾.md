## 1. 阿哲揪麵店（`story3d.js` 959、1818～1826 行）

- **現在的樣子**：
  - 麵店日（週二、週四）17:30，上一個麵店日你沒去，阿哲就在群組傳一句；
  - `NDL_PINGS` 四句輪：「麵店 我揪了」「麵店 我先到」「今天阿姨有滷蛋」「麵店 不用回」。
- 很少去麵店的玩家，一週兩次、四年下來會收到兩三百次，四句輪。
- **改法**：
  1. **加四句**，八句照順序輪：
     - 長桌還有位子
     - 阿姨問你今天會不會來
     - 七點 老位子
     - 今天下雨 麵店比較近
  2. **連續揪三次你都沒來，就不揪了**。第三次沒來之後的下一個麵店日，阿哲改傳一次（一學期最多一次）：
     > 阿哲：你最近都沒來 還好嗎
     - 之後不再揪，直到你又去了一次麵店，從頭算。
  3. 口氣照原本：阿哲的訊息不加句號（口氣表 2-1）。
- 朋友揪三次沒回就不揪，會問一句還好嗎，這是真的會發生的事。也讓不去麵店的玩家，群組不會一直有同樣的訊息。

## 2. 法服週六值班（`story3d.js` 604～690 行）

- **現在的樣子**：單週週六、第 3 週以後、不是考試週，大二起最多四十次左右。每次：
  - 開場一句：`FAFU_OPEN`，三句輪；
  - 一位民眾：`FAFU_CASES`，八件輪；
  - 「你先問什麼？」三選一；
  - 語彤在的時候她一句：`FAFU_YT`，三句輪。
- 問題：
  - 第九次值班，騎樓被拖吊的那位大學生又來了，問同一件事；
  - 開場、語彤的話，每三次就重複。
- **改法**：

### 2-1. 民眾：第一輪八件；第二輪是同一個人回來說後續；之後只寫流水帳

- **第一輪**：八件照現在。
- **第二輪**：同樣八個人照順序回來，只講後續：不給法律結論，不問「你先問什麼？」。

| 第一輪的人 | 第二輪（回來） |
|---|---|
| 機車被拖吊的大學生 | 旁白：（上次機車被拖吊的大學生又來了。）／民眾：單子找到了。時間我照你們說的寫下來了。／研究所學長：好。下一步我們一起看。 |
| 樓上漏水的阿姨 | 旁白：（樓上漏水的阿姨又來了，手上拿著一疊照片。）／民眾：樓上終於開門了。……他也不知道在漏。／雅筑學姊：照片還是留著。 |
| 冰箱壞了的先生 | 旁白：（冰箱那位先生又來了。）／民眾：那一頁我帶去了。店家說可以換。／研究所學長：換好以前，紀錄先不要丟。 |
| 借錢沒寫借據的年輕人 | 旁白：（借錢給朋友的那位年輕人又來了。）／民眾：我截圖了。……他昨天先還了一萬。／雅筑學姊：剩下的，也照這樣記。 |
| 修繕費的阿嬤 | 旁白：（一樓的阿嬤又來了。）／民眾：規約我找到了。字好小，我孫子念給我聽。／研究所學長：下次開會的紀錄，也請他幫您拍。 |
| 替媽媽來的女兒 | 旁白：（替媽媽來的那位女兒又來了。）／民眾：我媽說，下次她會先打給我。／雅筑學姊：這樣最好。 |
| 打工的高中生 | 旁白：（那個高中生又來了，制服還沒換。）／民眾：我沒有簽。……老闆說再想想。／研究所學長：有什麼變化，再來跟我們說。 |
| 房子的那位太太 | 旁白：（那位太太又來了。）／民眾：律師那一週我們去了。……大家有坐下來講。／雅筑學姊：坐下來就好。 |

- **第三輪起**：不再寫一位民眾，只寫一句旁白，三句輪。這是值班的流水帳，重複沒關係：
  - （今天來的都是第一次來的人，學長一個一個接。你把紀錄抄完。）
  - （上午很安靜。帶橘子的阿伯又來了，坐了一下就走。）
  - （今天人多，你只負責寫日期和原話。）
- 第二輪的句子都只講「有在做」，不講結果對不對：照 `AA_184`「不給結論」。
- 繼承那件照原本「要請律師一起看」。
- 這些是旁白和民眾的話。`BB` 查過的法律句子（學長、學姊在第一輪的回覆）不動。

### 2-2. 開場：六句，只在第一輪

- 原本三句加三句，照順序各一次；用完以後不說開場，直接接民眾：
  - 雅筑學姊：今天先跟我。紀錄你寫。
  - 研究所學長：今天下雨，人應該不多。
  - 雅筑學姊：（遞給你一枝筆）上次那枝你帶走了。

### 2-3. 語彤在法服（`FAFU_YT`）：六句，用完就不說

- 原本三句加三句，照順序各一次；用完以後她在、不說話：
  - 今天阿姨問我，法服的人是不是都很會講話。我說不是。
  - 這個月第三個漏水的。……台北的房子都在漏嗎。
  - 我今天一個人接了一位。學長說可以。
- 口氣照她：短、句號，偶爾自言自語。

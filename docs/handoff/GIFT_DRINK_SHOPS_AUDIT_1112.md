# 有賣飲料的店盤點：哪些可以「買一份帶走送人…」（GIFT-ALL-DRINK-SHOPS-1112）

使用者 2026-11-12：「你現在應該要認真審查游戲裡面有哪些有賣飲料的店都可以送不是嗎 不是我跟你說哎這家為什麼不行你才加這一家 你應該要自己決定啊 游戲裡的店面現在已經確定了不是嗎」

- 做法：`src/gift3d.js` 的 `GIFT.SHOPS`（一張表）＋`GIFT.menu(G, 店)`；各店的點餐程式只加一兩行（`GIFT.shopOpt` → 選了走 `GIFT.buy`，和便利商店、2:30 AM 原本的接法一樣）。每間店賣的是**它自己菜單上的飲料、照它自己的價錢**，品名照菜單一字不改。
- 收到的反應：用她飲料那一格的一般句子（`gift_lines.js` 的 yes／no／ctx 不綁品項）。fav、opinion、只配某一樣的組綁的是別的品項名，對不上、不會出現。**沒有新台詞。**
- **2026-11-12 更新（STALE-SOURCES-1112，AA_710 @ 86619c1195，X350）**：AA 新增八格 opinion——七格綁各店菜單上的品名（以安檸檬綠茶、芷若珍珠奶茶、語彤冬瓜茶、子晴檸檬多多、學姊紅茶、沛珊葡萄柚多多、可昕百香果綠茶；在哪一間買的都算），那個人收到那一樣會演那一格；其他照上一點。第八格是語彤「一盞茶屋的茶（任何一樣）」（照店，`shopAny`）：**一盞現在不能買來送人（第 2 節），這一格送不到**——AA_710 `_meta` 寫「一盞…也開」，和第 2 節的決定相反，等 LAWWW、AA 定一盞外帶賣什麼；定了以後在 `GIFT.SHOPS` 加一列（`name:'一盞茶屋'`）就會通，`tools/story/import_gifts.py` 的 `[提醒]` 會自己消失。匯入工具核對品名用 `tools/story/gift_shop_menus.js`（問 `GIFT.menu`，不另外抄菜單）。
- **2026-11-12 更新（YIZHAN-TAKEOUT-1112，AA_710 `_meta.lawww_1112b`「一盞茶屋外帶」＠335301d353）**：AA 定了——一盞開外帶，只賣冷泡茶兩樣（冷泡烏龍（一瓶）90、冷泡紅玉（一瓶）90），不賣壺裝。`GIFT.SHOPS` 加了「溫州街・一盞」（記的店名「一盞茶屋」），語彤「一盞茶屋的茶（任何一樣）」那一格送得到了；上一點寫的「這一格送不到」「匯入工具印提醒」已經不適用（`SHOP_PENDING` 清空）。買的時候蘇姨一句「外帶的在這裡。喝之前搖一下。」，語彤當班＝換成旁白；語彤當班、送她在一盞買的＝她收禮換一句（其他時候照原本的）。這三句是 AA 的新字，從稿匯進 `GIFT_LINES.takeout`，src 不手打。冷熱：品名沒有「冰」「熱」字＝不算冷也不算熱（第 4 節的規則，不從「冷泡」猜）。測試 `tests/gift_unit.js` 第 14 節。
- 選項、提示、旁白都是原本的字（「買一份帶走送人…」「飲料、早餐，帶在身上，見面的時候送人」「算了」「錢不夠」「你買了…，帶在身上。」）。
- 選項放在每份選單的最後，原本的選項位置不動。
- 盤點方法：搜 `GM.money(-`、`G.money-=`、`counter(`、`S.order`、`EAT.choose`、`' 元'`、`不用了`、`算了`，和 `src/data/*` 裡有飲料字的菜單（茶、咖啡、拿鐵、豆漿、果汁、可可、奶茶、可樂…）。

## 3. 哪些算飲料

1. 店的資料自己有分的照它的：118 巷 `shops[].drink`、洋洋 `drinks`、泰米 `TAIMI_CAT`。
2. 沒有分的照品名對 `gift3d.js` 的兩張表（只有這一處）：
   - `GIFT.DRINK_WORDS`：茶、咖啡、拿鐵、美式、濃縮、卡布奇諾、摩卡、手沖、可可、鮮奶、牛奶、豆漿、米漿、果汁、甘蔗汁、多多、可樂、汽水、氣泡、運動飲料、可爾必思、冰沙、奶昔。
   - `GIFT.NOT_DRINK_WORDS`（有上面的字、但不是拿在手上喝的一杯）：茶葉蛋、茶葉、茶點、茶碗蒸、蛋糕、糕、餅、塔、派、布丁、吐司、三明治、套餐、飯、麵、湯、鍋、愛玉、仙草、（一壺）、禮盒、酒；另外「冰」結尾的＝冰品。
3. 早餐（飯糰、三明治）照舊只有便利商店，這次沒有擴大。

## 4. 冷熱（冬天送冰的、夏天送熱的那兩種反應）

- 和 `GIFT.ITEMS` 同名的照它（鮮奶茶＝冰、拿鐵＝熱、美式咖啡再選冰的熱的）。
- 店的資料有寫的照資料（目前只有泰米的泰式奶茶）。
- 品名本身有「冰」「熱」字的照字（冰拿鐵、熱咖啡、黑糖珍珠鮮奶（熱））。
- 一盞茶屋外帶的冷泡茶兩樣＝算冰的（2026-11-12 AA_710＠f6aa917593 `_meta.lawww_1112b`「一盞茶屋外帶」的 note：「冷泡茶算冰的（冬天送的反應照冰飲那一套）。」；`import_gifts.py` 匯成 `GIFT_LINES.takeout['一盞茶屋'].temp`，`gift3d.js` 那一列的 `temp` 照它）。
- 其他＝不算冷也不算熱（紅茶、冬瓜茶、甘蔗汁…不會出「這麼冷的天，你買冰的？」）。不從品名猜。

# DATE-S6：約會選互動點的 2D 圖層（使用者要的 I07、I08）

分支 `dates6-wt`（從開發分支 `claude/adoring-meitner-mqzst8` 的 `84e0fa0bed` 開）。LAWWW-C 的子代理做，等 LAWWW-C 合併。

## 改了什麼（玩家會看到的）

校外約會到了現場、要選「去哪個互動點」的時候，原本是一列文字選單。現在改成：

- 畫面是這個地點的 2D 底圖（和抵達時同一張），每個互動點一個可以點的金色圓圈標記，下面是互動點的名字＋時間、花費（字和原本選單那一項一模一樣，沒有新寫的字，D79）。
- 她的去背人物站在畫面一邊，不擋標記；剛做完咖啡館、茶館、長椅、泡腳池這類坐著的互動點，回到選單時她是坐著（坐的高度對齊畫面下緣，像坐在前景）。
- 時間不夠、下雨停用（淡水長椅）、館休館的互動點：標記灰掉、按不下去，下面那一行寫原因（和選單的提示同一句）。
- 畫面下方一顆結束鍵，字和原本選單最後一項一樣（「就這樣回去」／「差不多了，回去吧」；兩天一夜是「今天先到這裡」）。
- 手機直向：底圖照高度放滿，左右可以滑（邊緣有淡淡的陰影提示還有），一開始捲到她站的那一邊；橫向：照寬度放滿，上下被裁掉的部分不放標記（往內收，不壓到上面的「紀錄／略過對話」和下面的結束鍵）。safe-area 照 `env(safe-area-inset-*)`。按鈕至少 44 px。
- 圖層開著的時候 ADV 的立繪先藏起來（不會同時出現兩個她），選完就收掉，接著照原本的台詞流程。

選了哪個點、扣多少錢、時間推多少、她說哪句話、存檔：全部和原本的文字選單一樣（圖層只換「怎麼選」，回傳的是選單的第幾項）。

## 什麼時候照原本的文字選單

- 網址加 `?nodatelayer`（強制舊選單）。
- 這個地點有任何一個互動點沒有位置（整個地點都照文字選單，不會一半一半）。
- 這張底圖沒有登記、`OUT.BG` 沒有這張圖、`DATE_HOTSPOTS` 沒有載、位置不在 0～1。
- 2D 畫面（ADV）沒開。
- 底圖載不到（4 秒內沒載好也算）、圖層排版或任何地方丟出錯誤：收掉圖層、出原本的選單（同一列選項）。
- 快速約會的「自己選／快速約會」、看電影的固定段落、告白等其他選單：沒有動，照舊是文字選單。
- 她的去背圖載不到、或這個人沒有去背圖（芯慈）：圖層照開，只是不放人（不畫代替的，D8）。

# 遊戲的大改動（接班必讀；D166，2026-11-14）

> 用途：**讓沒參與的帳號知道「遊戲已經不是你記得的樣子」。** 交班紀錄只講上一班；這一份是累積的，隔了好幾班回來也看得到。
> 什麼要寫：拿掉、取代、改掉了玩家會遇到的東西或大家做事的前提——開局與主線流程、人物設定與關係、整套系統、地點、存檔格式、分工、規則的大改版、發布（線上版和開發分支差在哪）。
> 一般的 bug 修正、加一間店、加幾句台詞不用寫（那些在 tasks.json、RELEASES.md）。
> 怎麼寫：一件一行，最新的在最上面——`- 日期｜D 編號或任務｜原本 → 現在｜所以不要再做什麼｜細節在哪`。誰做的誰當天寫（不是 LAWWW 的交一行給值班 LAWWW）。
> 起因（使用者 2026-11-14）：「你做了很多的改動……那如果下一個帳號只讀你交代他要做的事情，那他根本就不知道遊戲已經有很大的變動的話怎麼辦」。
> `tools/handoff/takeover.py` 會把「你上次工作以後新增的」每一行印在接班那一頁；`check_handoff.py snapshot`（交班）沒有寫「大改動：」一行不給過。

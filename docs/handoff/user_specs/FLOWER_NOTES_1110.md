三、地圖與街道整合

3.1 地點

店鋪位於公館商圈的羅斯福路沿線。

應依據遊戲現有公館地圖的道路方向、街廓、建築尺度及可用店面位置安排。

不得任意改變：

* 羅斯福路道路方向
* 汀州路與羅斯福路的連接關係
* 水源市場與周邊街道的相對位置
* 既有商店排列
* 玩家行走與進出建築的動線

3.2 建築型態

花序為雙層建築中的大型店面，可佔用較寬的街邊門面。

建議採兩層連續立面設計，讓玩家從街上就能辨識整間店。

應融入台北都市環境，而非設計成孤立的郊區別墅或大型百貨商場。

3.3 舊攤販遷移

原花店攤販必須從原本地圖位置移除。

原攤販的商店入口、互動點、商品與相關事件應轉移至新店。

必須確認：

* 地圖上不會同時出現新舊兩間花店
* 不留下無效攤販模型
* 不產生重複 NPC
* 不留下錯誤導航點
* 不讓舊事件繼續指向不存在的攤販
* 既有存檔能正常讀取與使用新店

如既有任務或對話使用舊花店識別碼，應優先維持相容性，而不是直接刪除資料。

四、建築外觀設計

4.1 設計核心

米白洞石、香檳金、大面積玻璃、雙層精品花藝店。

4.2 一樓外觀

一樓以透明落地玻璃為主，搭配精緻金屬框架。

包含：

* 大型櫥窗
* 清楚可辨識的主要入口
* 花序 Flower Notes 招牌
* 季節花藝櫥窗展示
* 少量大型植栽
* 具有設計感的室內燈光

店門口避免擺放過多花桶、塑膠籃及雜物。

不要形成傳統花市或花店攤販的視覺印象。

4.3 二樓外觀

二樓延續米白洞石與香檳金金屬語言。

使用較大面積的玻璃窗，讓玩家從外面隱約看到花藝教室的工作桌、花材及室內植栽。

建築外觀必須清楚表達這是一間雙層花藝店。

4.4 招牌

主名稱：

花序

副名稱：

Flower Notes

建議以細緻香檳金立體字呈現，搭配簡潔現代字體。

文字必須正確，不得出現錯字、隨機英文或不必要的其他品牌。

4.5 外觀場景需求

日間應呈現：

* 自然日光照射米白洞石
* 透明玻璃與柔和反射
* 店內花藝展示可從街上辨識
* 與羅斯福路街景自然融合

若現有遊戲支援日夜變化，夜間可讓暖色室內燈光透過櫥窗呈現。

不必為此重新製作整套日夜系統。

一樓的主要視覺焦點。

* 當季花束
* 精品訂製花束

B. 鮮花花束區

* 單支花
* 小型花束

* 大型花束
* 畢業及生日花束

C. 永生花精品區

這是花序的重要特色。

以玻璃展示櫃、開放層架及精緻展示平台陳列：

* 永生玫瑰玻璃罩
* 永生花禮盒
* 永生花桌上擺飾
* 小型永生花作品
* 高級紀念花禮

永生花的陳列方式應更接近精品店，而非傳統花市。

D. 包裝及收銀區

設置整潔的包裝工作桌與收銀櫃檯。

可見：

* 花束包裝紙
* 緞帶
* 花藝剪刀
* 小型工具
* 收銀設備
* 訂製花禮樣本

此區可作為主要 NPC 與購物互動點。

E. 通往二樓的樓梯

一樓須設置明確且自然的樓梯入口。

樓梯使用符合整體風格的淺色材質及香檳金細節。

不要為了讓畫面漂亮而設計無法實際通行的樓梯。

5.3 動線

建議：

入口 → 中央展示 → 左右商品區 → 收銀櫃檯。

樓梯位於空間側邊或後方，避免阻擋主要購物動線。

需符合目前專案場景互動方式，不強制實作自由 3D 走動。

八、送禮系統

花序的重要功能是讓玩家購買花束並送給遊戲角色。

8.1 基本原則

花束與永生花應優先接入既有送禮功能。

如果專案已經有角色禮物偏好、好感度及送禮冷卻機制，不得自行建立第二套平行系統。

8.2 角色反應

不同角色可以對花禮產生不同反應。

建議依照：

* 角色個性
* 角色既有設定
* 商品類型
* 當前關係
* 特殊節日

決定對話與好感度效果。

不要讓所有角色對花束都說相同的制式稱讚。

不要直接假設特定角色喜歡玫瑰、向日葵或昂貴花禮。

角色偏好必須先確認現有劇情及人物設定，再交由 AA 規劃。

8.3 平衡

送花不應成為無限制快速提升好感度的方法。

應沿用既有送禮平衡規則。

價格較高的花束，不應自動代表更高好感度收益。

九、重要節日事件

事件範圍以一般購物與重要節日為主。

不新增獨立花店經營線，也不新增花藝師職涯結局。

優先事件

1. 角色生日

玩家可購買花禮作為生日禮物。

若已有生日及送禮系統，直接沿用。

2. 畢業典禮

花束可以作為畢業典禮相關道具。

可配合既有畢業事件增加選擇或對話。

3. 情人節

可提供節日限定商品及相關對話。

事件應尊重角色關係進度，不可強制觸發戀愛劇情。

4. 聖誕節

可設定季節花藝展示及部分限定商品。

5. 母親節

可提供節日商品或相關情境。

若目前遊戲沒有可自然承接的家庭互動，先不強制新增事件。

事件設計限制

* 不打亂既有年度與學期流程
* 不新增與既有時間系統衝突的日期判定
* 不覆蓋已完成的戀愛事件
* 不強迫所有玩家進入節日事件
* 不因商店升級而改寫既有主線
* 新增角色台詞須交由 AA 依現有角色語氣審核

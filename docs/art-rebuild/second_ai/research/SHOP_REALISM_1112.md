# 店面不要再是「塑膠方塊」：開源資源與 Blender 做法（LAWWW2-C 2026-11-12）

使用者 11-12 20:2x 對 LAWWW2：
> 所有店面都是方塊 請去查blender開源要怎麼做到不同形狀還有材質好嗎 什麼都是塑膠方塊 醜死了

（同一天 19:5x 對溫特寶邸 v1 也說過：「醜到爆又沒質感…停止複製貼上一樣大小的方塊」。）

## 1. 為什麼現在看起來像塑膠方塊（查我們自己的腳本）
| 原因 | 現在的做法 | 結果 |
|---|---|---|
| 形狀 | 店內幾乎都是程式拼的長方體和圓柱：`vb()`、`box()`、`xf_cyl`。層架、商品、桌椅、櫃台、衣服，全是同一種方塊縮放 | 一眼看得出是積木；同一種方塊一直重複 |
| 顏色 | 一個物件一個純色，常常是頂點色，沒有貼圖 | 沒有木紋、布紋、髒污、磨損 |
| 表面 | 粗糙度整面同一個值，沒有法線、粗糙度貼圖 | 「塑膠感」最主要的原因：同一個粗糙度看起來就是射出成形的塑膠 |
| 邊 | 邊角是銳利的直角，沒有倒角 | 邊緣不吃光，真實的東西都有小圓角 |
| 光影 | 遊戲裡店內只有平均的環境光，沒有接觸陰影、反彈光 | 東西像浮在地上、貼在牆上 |

## 2. 開源資源（都是 CC0，這個雲端容器連得到，11-12 實測）
| 來源 | 內容 | 店裡用得上的（數量＝實際查到的） |
|---|---|---|
| **Poly Haven 模型**（api.polyhaven.com，CC0，glTF＋1k～8k 貼圖） | 真實掃描或手工建模，附完整貼圖組（顏色、法線、粗糙度、金屬度、AO），共 521 個 | 家具 85、座椅 34、桌子 27、層架櫃子 16、燈具 29、裝飾 76、容器 68、餐具 13、食物 19、盆栽 6、書 3、電器 22、文具辦公 12。例：`CashRegister_01` 收銀機、`vintage_suitcase` 舊皮箱、`ornate_mirror_01` 鏡子、`wooden_display_shelves_01` 木展示架、`vintage_cabinet_01` 古董櫃、`hanging_industrial_lamp` 吊燈、`potted_plant_02` 盆栽、`bar_chair_round_01` 吧台椅、`dining_chair_02`、`coffee_table_round_01`、`tea_set_01`、`croissant`、`steel_frame_shelves_01`… |
| **Poly Haven 材質**（已經在用，`tools/blender/env_second/textures/`） | 木頭、石材、灰泥、地磚 | 地板、牆、櫃台 |
| **ambientCG**（ambientcg.com，CC0，2000＋材質） | 顏色＋法線＋粗糙度＋位移完整一組 | 布料 106 組（`Fabric0xx`、地毯 `Carpet0xx`）、皮革、木頭、金屬、塑膠、紙箱 |
| 不用的 | Kenney、Quaternius（CC0，但都是低面數卡通風，違反美術底線）；Sketchfab、CGTrader（大多不是 CC0，要逐件查授權） | — |

Poly Haven 沒有衣服、店員、商品包裝。這幾類用下面第 3 點的方法自己做，但一定要套 ambientCG 的布料組。

## 3. Blender 做法（照這個順序）
1. **現成的掃描模型優先**：收銀機、椅子、桌子、燈、鏡子、盆栽、皮箱、餐具、食物這些，直接用 Poly Haven。步驟：匯入 glTF → 用 Decimate 減面到店內能負擔的量（一件 1～5 千面）→ 擺進房間。
2. **自己做的東西不准是方塊**：
   - 所有硬邊加倒角（Bevel 2 段）。
   - 衣服、布料用**布料模擬**（Blender Cloth，背景也能跑）：衣服版型掛在衣架上讓它自然垂下，會有皺摺和重量。
   - 商品包裝用真實比例，印刷面用貼圖，不是一塊純色。
   - 同類的東西（一排衣服、一層商品）每一件的大小、角度、顏色、皺摺都不一樣（隨機加變化）。
3. **每個材質都要一整組貼圖**：顏色＋法線＋粗糙度（＋AO）。粗糙度不准整面同一個值。木頭、布、皮革、金屬、紙箱用 ambientCG 或 Poly Haven 的材質組。
4. **光影烘進貼圖**：Cycles 把燈光、接觸陰影、反彈光一起烘成一張貼圖（溫特寶邸 v2 的 `tz_wente_interior.py` 已經有這一段）。遊戲裡用不受光的材質顯示，手機也跑得動。
5. **驗收**：用同一個鏡頭，把成品和使用者給的參考圖或概念圖並排；看起來比參考圖廉價就不交。

## 4. 要套用的範圍（使用者說「所有店面」）
- 先做**溫特寶邸**當樣板：v2 的衣服、假人留著，但布料改用 ambientCG 的布料組；收銀機、鏡子、皮箱、盆栽、檯燈、展示櫃換成 Poly Haven 掃描模型。做好後並排比給使用者看。
- 樣板通過以後，逐間重做店內道具：
  - 汀州路 7 間：`tz_shops_interior.py`
  - 新生南路 6 間：`xs_*` 室內
  - 公館：青木、頁間、日和、慢輪、洋洋、Afar、轉角、Daybreak…
  - 118 巷 9 間：`lane118_shops`
  - 溫州街各店
  
  每一間的清單和進度寫在 `SHOP_STANDARD_STATUS.md` 新的一欄「質感（不是方塊）」。
- 店面外觀（招牌、門窗）同一套：倒角、貼圖組、燈光烘焙。

## 5. 授權與檔案大小
- 用到的每一件 Poly Haven 模型、ambientCG 材質，都在 `LICENSES.md` 登記一列（CC0，作者照 API 的 authors 寫）。
- 遊戲裡一間店：一個網格、一張 2048 烘焙貼圖（WebP，約 0.5～1.5 MB），三角形 3～8 萬。原始的高解析貼圖只在 Blender 裡用，不進遊戲。

## 6. 提給 LAWWW-C 的規則（請寫進 ROLE_LAWWW2／§9）
> 店內、店面的道具：能用 CC0 掃描模型（Poly Haven）的一律用；自己做的要有倒角、完整貼圖組（顏色、法線、粗糙度），同類物件要有變化；不准用程式拼的純色方塊當正式道具。交件附同鏡頭和參考圖的並排圖。

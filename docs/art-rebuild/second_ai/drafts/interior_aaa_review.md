## 26. 校內室內第一輪：七間的光照烘焙、家具、擺設（INTERIOR-AAA-REVIEW-1028；2026-10-28～30）

- **起因**：使用者 10-28 P0（UA-LAWWW2-1028-01、X125）原話：「我仍然覺得 校內建築 空間內配置 有很大的美術提升空間 現在是一個廉價手遊感 請你去參閱3A大作好好檢討」。
- **檢討報告**：`second_ai/INTERIOR_AAA_REVIEW_1028.md`。
  - 原因 1：光是平的。室內只有一盞方向光加半球光，整間一樣亮，東西像貼在地上。
  - 原因 2：鏡頭在牆外時看到天空。
  - 原因 3：地板像佔位素材。
  - 原因 4：擺設照網格排、沒有人用過的痕跡。
  - 原因 5：建築細部、燈具不夠。
- **這一輪做的七間**（2026-10-30 的狀態）：

| 房間 | 做了什麼 | 狀態 |
|---|---|---|
| 霖澤館 201 階梯教室 | 家具、天花板、細部重做＋光照烘焙＋牆外暗殼 | 已在 v9.10.13 |
| 霖澤館 202 | 家具、天花板重做＋光照烘焙＋牆外暗殼 | 已在 v9.10.13 |
| 萬才館多功能教室 | 只加光照烘焙＋牆外暗殼 | 已在 v9.10.13 |
| 霖澤館一樓大廳 | 擺設＋光照烘焙 | 已在 v9.10.13 |
| 萬才館一樓大廳＋二樓 | 擺設＋光照烘焙 | 已整合進開發分支，還沒發布 |
| 男一舍門廳 | 擺設＋光照烘焙 | 已整合進開發分支，還沒發布 |
| 總圖大廳 | 擺設＋光照烘焙＋大樓梯改模型 | 已交付（`c48a5c310`），v9.10.14 後整合 |

- **做法都一樣**：
  1. Blender 建模、擺設。
  2. Cycles 烘白天、晚上兩張光照貼圖：
     - 白天＝窗外天光＋太陽＋室內燈；
     - 晚上＝只有室內燈。
  3. 遊戲照時段混合兩張。
- **驗收狀態**：七間都是 `READY_FOR_ART_REVIEW`。建築、場景只有使用者能標 `ART_APPROVED`。
- **截圖條件**：
  - 遊戲內、玩家鏡頭。
  - 手機橫向 844×390，Playwright＋SwiftShader 模擬，**不是 iPhone 實機**。
  - 讀檔進房間、人放到指定位置是 [捷徑]。
  - 白天 14:00、晚上 20:30。
  - 除非另外寫明，左邊是改前、右邊是改後。

### 26.8 七間共同的缺點、下一輪

- **共同的缺點**：
  - **人物沒有吃到烘焙的光**：人物照舊是半球光＋方向光，和房間的光不完全一致。
  - **烘焙的太陽不會動**：白天只有一張（固定的時刻），17:00～18:36 慢慢換成晚上那張。
  - **細小零件照即時光**：門框以外的小東西、鐵腳、盆栽。晚上在暗處原本比旁邊亮 2～3 倍；RT-NIGHT 那一包讓它們晚上跟著暗。
  - **效能**：
    - 每間兩張 1024 的光照貼圖（WebP 約 60～90 KB），執行時幾乎不增加計算。
    - 家具重做的房間 draw call 多一些：201 進門 105 → 146，含人物。
    - **手機實機的 fps 沒有量**，SwiftShader 量不出意義。

## 3. 生成的規格（給 BB-B 寫進提示詞）
- **比例**：一樓橫招牌是 **10.2:1**，很扁，生成工具通常做不出來。
  - 請生成 **3:1 或 21:9** 的圖，字和圖案放在中間。
  - 左右兩端留一段**純底色、沒有圖案**的區域：我往兩邊延伸底色，補到 10.2:1，字不會被拉寬。
  - 二樓大招牌 3.4～4.8:1、屋頂看板 3.75:1，照實際比例生成就好。
- **直立招牌**（1:3.5 和 1:5.7）：
  - 請生成 **9:16 或 1:3** 的直圖，字由上往下排。
  - 上下兩端留純底色，我補到實際比例。
- **解析度**：長邊 **至少 1536 px**，PNG 或高品質 WebP。我縮進遊戲的貼圖集。
- **畫面要求**：
  - 正面、平的招牌**板面本身**：不要透視、不要拍到牆和天空、不要外框陰影。
  - 我會裁到板面的邊。
- **字**：繁體中文；字體要像台灣街上的招牌（粗黑體、圓體、毛筆字、霓虹管字都可以）。這次就是要換掉現在的系統字。
- **同一家店**：一樓橫招牌和直立招牌**分開生成**（比例差太多）。但配色和字體要一致，請在提示詞寫明同一家店。
- **夜間**：不用另外生成夜間版。
  - 晚上照現在的做法：整面招牌當燈箱亮（同一張圖當發光貼圖，入夜調亮）。
  - 想要「只有字亮、底不亮」的霓虹效果，請在那一面註明，我再做字的遮罩。

## 4. 遊戲端（LAWWW-B）：照 G03 的做法，`zones3d.js` 不用改
- 圖片招牌我直接放進 GLB，用 G03 已經在用的做法：
  - 設計稿招牌是 `sk_sign_<店>` 節點（`wz_signs` 貼圖集＋夜間發光 `wz_signs_lit`）；
  - 同時拿掉那一面的 `SIGN_FACE_<店>`／`VSIGN_FACE_<店>`。
- 遊戲只對 `*_FACE_*` 節點畫 canvas 字，所以拿掉以後就不會再被系統字蓋過去，**`wzSignTex` 不用改**。
- 只有公館整合測試的招牌數量要跟著改：`DESIGNED` 清單加上換掉的店。這份 patch 我附在交件裡（scooters_v2.patch 已經有 `DESIGNED = ['G03']` 的寫法）。
- 夜間亮度照現有的 `wz_signs_lit`。

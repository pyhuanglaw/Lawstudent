## 2. 原則
1. **有人用才開房間**。課表、社課、劇情、日常（吃飯、讀書、等人）至少要有一個真的用途。
2. **關著的門都要有真的理由，而且看得懂**。
   - 「整修中」只在真的有整修劇情時用；
   - 其他用「上課中」「今天沒有借用」「要刷卡」「研究室」。
3. **不做為了填樓層的空房間**。
   - 上面幾層沒有用途的，就留在電梯裡「按不亮、刷卡」；
   - 不用走得進去、裡面什麼都沒有的樓層冒充完成。
4. **公共空間優先於房間**。玩家每天會經過、會停下來的地方：
   - 吃午餐、讀書、等下一堂課、跟同學討論；
   - 比一間只演一次事件的房間值得做。

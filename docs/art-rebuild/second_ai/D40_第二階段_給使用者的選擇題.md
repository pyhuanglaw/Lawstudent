# D40「健身與體態」第二階段：給使用者的選擇題（LAWWW2-C 2026-10-27；交 BB-C 照 D97 一起整理）

- **背景**：第一階段（姿勢）已經在開發分支（`eedf57f21`，FIT-3D-BODY-1027）：體能越高，祐廷站、走、跑、說話越挺。說明和對照圖在 `test_shots/fit_posture_1027/README.md`。
- **第一階段的限制**：遊戲平常的鏡頭看得出來，但差別很細。經常鍛鍊的祐廷是「站直了」，還不是「變壯了」。
- **第二階段要問的**：要不要讓身形本身也變？這會改主角外觀，所以要使用者決定（D111）。D99 人物美術凍結期間，使用者沒說要做就不動。
- 祐廷的 3D 模型身體和衣服在同一個網格（`Body.baked`），加一個「結實」形狀鍵就能涵蓋目前的服裝。估計 1～2 個工作階段：Blender 加形狀鍵，接上 `FIT` 的四階，再檢查走、跑、坐、騎車、羽球、開門有沒有穿模。

## 問題（建議一次問完；括號是我的建議）

**Q1. 體能練高以後，祐廷的 3D 身形要不要變？**
- A. 不要，維持現在：只有姿勢變挺。
- B. 輕微（建議）：肩膀寬約 3%，胸口、上臂厚一點，腰不變。穿便服看得出「有在運動」，不會變成另一個人。
- C. 明顯：肩膀寬約 6%，胸口、上臂更厚，腰收一點。一眼看得出有在練。

**Q2.（Q1 選 B 或 C 才問）幾階開始變？**
- A. 只有最高的「經常鍛鍊」才變。
- B. 「結實」變一半，「經常鍛鍊」全部（建議；和第一階段姿勢的分法一樣）。
- C. 「有在運動」就開始一點一點變。

**Q3.（Q1 選 B 或 C 才問）不再運動、體能掉回去的時候，身形要不要跟著退？**
- A. 跟著退：照當下的體能值（建議；和姿勢一樣）。
- B. 練出來就留著。

**Q4. 決定前要不要先看圖？**
- A. 要：我做一張「普通／輕微／明顯」三欄並排（正面、側面，同一套衣服）。只是預覽，不進遊戲，不算改人物。
- B. 不用，照選的做。

## 照答案怎麼做（給 LAWWW-C）

- **Q1＝A**：結案，第一階段就是全部。
- **Q1＝B 或 C**：
  - Blender 給 `Body.baked` 加形狀鍵「結實」。
  - `fit3d.js` 照 Q2、Q3 把權重放到 `E.player` 的 VRM。
  - 跑會載入 `character3d.js` 的 Node 測試，加上穿模檢查的截圖：站、走、坐、騎車、羽球、開門。
  - 美術狀態先標 `READY_FOR_ART_REVIEW`。角色美術由 BB 驗收（D59）；外觀變更本身已經由使用者在這裡選了。

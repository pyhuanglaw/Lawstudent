# 兩點半 Café 配置調整（ART-WZ4）——給 LAWWW-B 的整合說明

LAWWW2-B，2026-10-16。規格：AA_164 第 4 節（AA-B）。模型：`tools/blender/env_second/cafe_layout.py` 的 `interior()`＋`wz4_details()` → `assets/models/env/second_ai/cafe_interior.glb`。

## 原則

**格局不動**：吧檯、門、窗邊吧台、四張桌子的位置都和現在一樣。故事站位、`seatApproach`、存檔都不受影響。

AA 的版面圖是「門在側邊、窗在上面」。現有的 cafe 區域是門在店面正中間、兩側是窗邊吧台，硬照版面重排會動到所有站位。

所以只加 AA 第 4-3 節「劇情一定要有」的東西，再補座位種類。**座位總數 +7，沒有減少。**

## 要改 zones3d.js（cafe 區域）的地方

```js
// 1) 四人桌：導航從圓改成長方；兩端多兩個座位（原本兩個不動）
//    twoTop(0,1.5) 裡的 nav.blockCircle(0,1.5,0.5) → nav.blockRect(0,1.5,1.1,0.84,0,0.1)
z.seats.push({x:-0.85,z:1.5,yaw:Math.PI/2,pair:'0,1.5'},{x:0.85,z:1.5,yaw:-Math.PI/2,pair:'0,1.5'});
// 2) 角落沙發、矮桌、立燈、傘桶
nav.blockRect(-6.35,3.4,0.9,2.2,0,0.1); nav.blockRect(-5.3,3.4,0.5,0.8,0,0.1);
nav.blockCircle(-6.55,4.85,0.18); nav.blockCircle(-1.05,5.15,0.2);
z.seats.push({x:-5.95,z:2.85,yaw:Math.PI/2,sofa:true},{x:-5.95,z:3.4,yaw:Math.PI/2,sofa:true},{x:-5.95,z:3.95,yaw:Math.PI/2,sofa:true});
E.interactables.push({x:-5.0,z:4.2,radius:1.1,label:'坐在角落的沙發',seat:{x:-5.95,z:3.4,yaw:Math.PI/2}});
// 3) 吧檯座 ×4（現在吧檯椅只是畫面、沒有座位）：BCG-36 要坐吧檯
//    椅子 x −4.5、−2.9、−1.3、0.3，z −3.3，面向吧檯（yaw π）
for(const sx of [-4.5,-2.9,-1.3,0.3]) z.seats.push({x:sx,z:-3.3,yaw:Math.PI,bar:true});
// 4) 備用模型（g）：照上面加簡單量體（第四張吧檯椅、四人桌、沙發、傘桶），正式模型載入失敗時不會撞到看不見的東西
```

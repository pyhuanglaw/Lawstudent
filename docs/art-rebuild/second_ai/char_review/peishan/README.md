- 遊戲裡的沛珊用的是這個 Blender 版（LAWWW 分支 `char.classmate_peishan`），不是換色模型。
- 第一版的顏色（T 恤 (118,38,44)、裙子 (36,42,64)）在遊戲裡畫出來：
  - T 恤是鮮紅 `#540510`；
  - 裙子幾乎是黑 `#0a0e1f`。
- 立繪（`assets/portraits/classmate_peishan/campus/neutral.webp` 取樣）：T 恤偏咖啡的暗酒紅 `#603835`，裙子深藍灰 `#343740`。

## 第三批：日劇穿搭（nf9–20、nm9–20；2026-10-17 10:3x）
- manifest 條目：`docs/art-rebuild/second_ai/patches/npc_manifest_batch3.js`（LAWWW-C 的格式）。
- 做法：`tools/blender/char_second/npc_layered.py`。

  - 顏色低彩度，不用紅色。

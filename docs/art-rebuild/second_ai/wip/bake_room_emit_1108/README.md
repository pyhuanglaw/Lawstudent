# bake_room.py：--emit／--dayemit 調過的材質，匯出前設回原本的發光強度（LAWWW2-B 2026-11-08）

**狀態：交件**。只是烘焙工具，不影響遊戲、不用換任何資產。

## 問題
- `bake_room.py` 第 6 步（匯出前清掉烘焙用的節點）會把 `--emit`／`--dayemit` 調過的材質的 Emission Strength 一律設成 1.0，不是設回原本的值。
- 原本是 1.0 的材質沒差。原本不是 1.0 的就會在遊戲裡變暗或變亮。
- 發現經過：新生南路大口一樓的燈板原本 26，本來想用 `--emit dk_lightpanel=2.4` 壓低烘焙時的光，試了才發現。最後改用 `--hide`。
- 到 11-08 交過、用過 `--emit`／`--dayemit` 的 13 個材質，烘焙前都是 1.0（逐個查過 git 歷史），**已交的檔都沒受影響**。

## 修法：`bake_room_emit_1108.patch`
- 對開發 `95566d0b5`（和 `51d7f0ff6` 同一份 bake_room.py）`git apply --check` 過。
- 第 4 步前面：記下符合 `--emit`／`--dayemit` 的材質原本的強度（`ORIG_EMIT`）。
- 第 6 步：設回 `ORIG_EMIT`，找不到才用 1.0。
- 我分支上的同一個修正是 `f6b2caf18`。

## 測試
用開發的 `dakou_1f.glb` 原檔（燈板 26）極小試烘：取樣 1、64 px，`--emit dk_lightpanel=2.4`，看匯出的 dk_lightpanel 強度。
- 開發原樣：**1.0**（錯）。
- 套 patch：**26**（對）。

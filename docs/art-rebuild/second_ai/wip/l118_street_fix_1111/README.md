## 還沒做、要知道的

1. **室內重做以後要重跑**：LAWWW2 正在做 118牛排、水上便當、清州、辛亥韓食的第 3 版。新 GLB 進來以後跑
   `/opt/blenv/bin/python tools/blender/env_second/l118_peek_tex.py` → `/opt/blenv/bin/python tools/blender/env_second/wz_street.py -- --set lane118` → `node tools/gen_zone_assets.js`，玻璃後面那張圖才會跟上（現在是第 2 版的樣子）；桌椅樣子變了就改 `wz_shopkit.py` 的 `L118_FRONT`。
2. **迪倫窗內的窯爐位置移了**：外觀參考圖的窯爐在窗的左邊、室內參考圖在店後方正中間，兩張圖本來就對不上。原本街上會同時看到兩座（窗邊立體的一座＋圖上的一座），所以把立體的那一座移到窗的右半、擋住圖上那一座，製作檯換到左邊。要照外觀參考圖放回左邊的話改 `SF_L118['noodle2']` 的 `oven`（那樣街上會看到兩座）。
3. **水上便當**新室內的前半間是空的（BB_341：「右半邊和後牆空」），所以玻璃後 2.6 m 以內沒有放桌椅，等第 3 版。外帶保溫櫃裡一格一格的單色「菜」是原本就有的（第 1 版街景），不在這四項裡，沒動。
4. **九間室內 GLB 裡的備用圖**（`WALL_S_view`，門外照片還沒載入的那一瞬間、或載入失敗時畫的）還是 10 月舊街景的算圖：沒有字、沒有店名，但店面是舊的樣子。要換得重產室內 GLB（`lane118_shops.py` 的 view），這次規定不動室內 GLB。
5. 立面的白磁磚、紅磚柱、木作店面（BB_341「記缺點、不擋」）沒有做。
6. 建置時發現：`wz_street.py` 要的 `textures/gen/` 有兩百多個檔只在 LAWWW2 的分支（`claude/second-ai-env-art`），開發分支沒有；另外要 Poly Haven 的 `floor_tiles_06`、`concrete_floor_painted`（`lib2.fetch`）。這次是從 LAWWW2 分支取出來建的，沒有把那些檔加進開發分支。

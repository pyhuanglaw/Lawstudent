# 法圖討論室：講座日坐下以後鏡頭在東牆外（BUG-CAM-LAWLIB-DISCA-1108；BB-B 11-08 P2；LAWWW2-B 修，D108）

## 現象
- 出處：BB-B 00:43；CC 的截圖在 cc-testing `f40ffa537a`，`docs/story_planning/CC/logs/AA613_cloud/eacc/02、05`。
- 情境：大一上講座日 15:30，坐在討論室 A 西側的空位 (−6.2, −6.8)，面向東。
- 整場講座鏡頭停在 (−2.3, 3.21, −6.8)。討論室 A 的範圍是 x −7.1～−3.7，所以鏡頭在東牆外 1.4 m，也就是隔壁討論室 B 裡面。
- 結果整張畫面都是隔間牆的米色，看不到人。549020850 就已經這樣。

## 原因
- 法圖（`src/lawlib3d.js`）沒有 `zone.camCols`。跟隨鏡頭（engine3d.js `followCam`）只撞得到 `E.colliders`（戶外建築）和 `zone.camCols`。
- 外牆會淡出（`fadeWalls`）；北側房間的隔間牆、前牆不會淡出，也擋不住鏡頭。
- 坐下以後鏡頭還是原本的方向。這一次是進法圖時的方向：鏡頭在人的東邊，也就是在人前面。往東退 4.4 m（`camDist`），就穿過了隔間牆。
- 坐著的時候 `autoSwing` 不轉，鏡頭不會自己避開。

## 做法（`cam_lawlib_disc_1108.patch`，對開發 `eacc5837d`；`39bc9275e` 的 lawlib3d.js 一樣，可以直接套）
- `src/lawlib3d.js` 加 `camCols(L,g)`：北側房間（討論室 A／B、影印室、館員辦公室）放看不見的板子，給 `zone.camCols[0]` 用。和教學館 `teach3d.js camColliders` 同一套：
  - 隔間牆：`L.partitions` 的 −3.6、0、3.2，從北牆到前牆、到天花板。
  - 前牆：門洞兩側到天花板，再加門洞上面 2.4 m 以上那一段。討論室的玻璃也擋，鏡頭不會退到玻璃另一邊。
  - 規格：厚 0.24 m、兩端各多 6 cm、不參加合併。
  - 二樓不加：二樓是書架，本來就有網點透空。
- 撞到板子後，照引擎原本的規則處理：拉到牆前 0.35 m，再抬高。
- CC 那個畫面：鏡頭從 (−2.11, 3.28, −6.80) 變成 (−4.04, 2.88, −6.80)，在討論室 A 裡面、離頭 2.6 m，從桌子對面看人和旁邊的芯慈。
- 不動 engine3d.js，也不動劇情、座位、導航。
- 隔著牆的人不能說話（`E.talkWalls`）也會用到這一組板子：大廳裡隔著討論室的玻璃，叫不到裡面的人；從門洞看進去照樣叫得到。

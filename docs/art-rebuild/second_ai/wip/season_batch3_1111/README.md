## 程式（`src/season_deco3d.js`）

- `SD3.on(代號, 日期, ctx)`：多兩種規則——`weather:'rain'`（只看天氣、不看日期）、`hours:[17,23]`（再加上時段）。ctx＝`SD3.ctx(E)`：天氣、時間先拿遊戲狀態（`GAME.G.weather`／`hour`），沒有才拿 `E` 的。**只在進區域那一刻判斷**：在溫州街裡面開始下雨，傘架要下次進來才出現；中秋 16:50 進公館待到 18:00，烤肉架不會自己出現。
- `blocks`：那一組今天要顯示，就在區域建好的當下（玩家站上去以前）擋起來；`SD3.block` 只記這一次新擋的格子，模型載不到時 `SD3.unblock` 只放回那些（原本就擋著的不動、不留看不見的牆）。
- 烤肉架的阻擋比東西大一圈 0.5 m：引擎的「站得住」只看人的前後左右四個點，阻擋只和東西一樣大的話，人可以斜站到離烤肉架 7 cm（新測試第一次跑抓到的，見下面）。
- 平常日還是不載入模型：3/15、3/25、11/12 兩個區域都沒有任何一組（四季的水果、花是「當季」那一段，不是一整季）。

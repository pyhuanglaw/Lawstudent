# FLOWER-2F-TAPNAV-1112（P1；CC SSB_gg2_r2 run.log 100～126）

- 現象：花序二樓坐下、起身以後點一樓門口「離開花序」(0,6.6)，點 13～16 次，人都停在二樓欄杆前 (−0.76,−0.07)；搖桿下得去。
- 原因：從二樓往挑高看，一樓門口被二樓樓板邊緣擋住，點下去射線先打到二樓樓板最外緣那一條（欄杆內不到 0.5 m）→ 目標是二樓那一點 → 找路走到欄杆前就停，再點一次還是同一條。找路本身沒問題（Node：從二樓任何座位起身的位置都走得到門口）。
- 改法：`src/engine3d.js` screenToFloor 多一步 `E.tapThroughEdge`：第一個打到的點在樓板邊緣 0.5 m 內（沿射線再往前 0.5 m 就沒有那一層的地板）、射線後面打到別層的地板、那一點正上方沒有被這一層樓板蓋住 → 改用下面那一層的點（找路會帶人走樓梯下去）。
  - 不會誤判：二樓點桌子、靠牆、離欄杆 1 m 的地方照舊是二樓；中間先打到樓梯的照舊（不穿過樓梯）；一樓點一樓照舊。
  - 共用引擎：所有有兩層可點地板（walkMeshes）的區域都會用到（霖澤館、萬才館、總圖、社科院、山嵐、花序……），只在「點樓板邊緣、底下是挑高看得到的下一層」時才變。

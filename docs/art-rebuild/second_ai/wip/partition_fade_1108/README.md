# 隔間牆的零件跟主牆一起淡出（BB-B 11-08 光照第二級雲端判 P2；LAWWW2-B 修，D108）

## 現象
- BB-B 06:13 的判定，證據在 cc-testing `42fdce568` `CC/logs/LM2_cloud/library_b1_1400.jpg` 的 studyA_back。
- 畫面：總圖 B1 自習室 A 區往回看，左邊那面長牆（P2，自習室和國際會議廳中間）。
- 烘後牆的下三分之一變成一條深藍黑的帶子，上緣切得很硬，一路到門口；烘前那裡是一整面淺灰牆。

## 原因（不是光照貼圖壞了）
1. P2 自習室那一面，0.12～1.03 m 有一片木護牆板 `WALL_P2_woodwain`，貼在牆前 3.7 cm。
   - 烘焙時，牆被護牆板蓋住的那一段照不到光，烘出來是黑的。這是對的，那一段本來看不到。
   - 護牆板本身是亮的（整片取樣平均 0.53，和上面的牆一樣）。
2. **畫面上護牆板淡出了、牆沒有**，所以露出牆上那一段黑的。烘前的截圖也看不到護牆板，只有一整面灰牆：同一個淡出，只是那時牆被擋住的地方不是黑的。
3. 為什麼只有護牆板淡出：
   - `zones3d.js` 的 `fadeWalls` 對隔間牆（`extras.partition`）是「鏡頭和玩家在牆的兩邊才淡出」，每個 `WALL_` 網格用**自己的外框中心**判斷。
   - P2 主牆的中心在 z −2.40，木護牆板在 −2.47，海報、收邊條也各差幾公分。
   - CC 那一張，玩家站在 B1 入口 (−20.5, −2.4)，剛好在這兩個平面中間，只有零件被判成「在牆的另一邊」。
   - 實際玩的時候，玩家在西段走道剛好站在這條線上，也會遇到。
4. 同樣的情形六間都有：總圖 B1、研究小間、霖澤 5F、體育館 B1、美國公寓、合租戶。

## 怎麼修（不用改程式、不用重烘）
- 新工具 `tools/blender/env_second/lightbake/glb_partition_at.py`。
- 每個隔間牆零件，在 extras 寫 `at`＝主牆的淡出判斷點。主牆＝同一個 dir、外框包住它、面積大 1.5 倍以上的那一塊；大的先處理，不會一串指下去。
- 遊戲的 `attachRoomGLB` 已經認 `extras.at`（118 巷店門外的鄰居店面卡用過）。
- `at` 不四捨五入，算法和遊戲算主牆中心一樣（float32 頂點範圍的中點）。主牆自己不寫，照舊用外框中心。
  - 玩家剛好站在牆的中線上時，零件和主牆的判斷才會一模一樣。
  - 試過四捨五入的版本：整面 P2 變成一起藏起來，會露出關著的國際會議廳，比原本更糟。
- **只改節點的 extras**：幾何、材質、第二套 UV、光照貼圖都不變（逐節點比過，節點、材質一樣）。

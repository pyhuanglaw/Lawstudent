# GG-ZEBRA-FOG-1104：校門口過羅斯福路的斑馬線＋公館遠方不要那麼霧（使用者 2026-11-04 04:3x）

使用者原話：「從學校到對面要斑馬線　天空遠方太模糊」
狀態：程式 patch，接在開發分支 b1ea98f26；瀏覽器畫面還沒看（D131：等 PC）。

## 原本的問題（Node 量的）
- 公館的羅斯福路（z −31～4，35 m 寬）沒有斑馬線，只有車道線。從校門出來，看不出要從哪裡過馬路；導航整條路都走得到。
- 公館區域沒有設定視距：霧從 40 m 開始，140 m 全白。gongguan_far.glb 的遠景樓房從 x ±232 起一路延伸，往東西看過去，大半都被霧吃掉了。

## 改了什麼（只改 src/zones3d.js）
1. `zebraMesh(L,Wd)`：斑馬線網格，用溫州街巷口斑馬線那張貼圖。白條寬 0.5 m，每 0.9 m 一條。
2. 公館：校門口畫一條斑馬線，x −6～6（12 m 寬，蓋住校門兩側通道 x ±5.27），z −30.6～3.6（北側人行道到南側人行道），對面是輪轉單車。
3. 校園的遠景（從校門往外看）畫同一條斑馬線，座標照公館 → 校園換算：x −173.6～−139.4、z −6～6。
4. 公館 `viewFar:240, fogNear:90`：照椰林大道的做法（校園是 260／100）；低畫質照引擎原本的 75 折。

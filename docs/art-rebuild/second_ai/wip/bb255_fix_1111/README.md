## 一、機車第 3 版（D141 第三版、最後一版；只改擺放規則，模型沒有重做）
| BB 要的 | 做法 | 量到的（48 台） |
|---|---|---|
| 顏色照色系分，相鄰兩台不同色系 | `TZ3.colorFam()` 把顏色分成白／米／銀灰／黑與深藍／紅／藍／綠／黃橘；挑車的時候和前一台同色系就換 | 相鄰同色系 0 |
| 黑與深藍全街不超過四分之一 | 挑到黑、深藍而且會超過 22% 就換別的顏色 | 9／48＝19% |
| S1A＋S1B＋S2 當同一種車尾，合計四成以下 | 權重改成三款各 12%，再加上限 38% | 16／48＝33% |
| 同一群裡車尾形狀相同的不連三台 | 前兩台同車尾就換款 | 0 |
| S3、S4、S5、S7、S9 拉高 | 權重 9／11／10（＋掛安全帽 6）／9／6% | S3 6、S4 5、S5 4＋1、S7 4、S9 6 |
| 每台前後錯開（±15 cm 上下）、車頭左右轉幾度 | 前後 ±16 cm、車頭左右各到 6 度（原本 ±12 cm、4 度） | — |
| 配件隨機（後箱、擋風鏡、掛安全帽、袋子、雨衣） | **只做到現有模型有的三種**：外送箱（S1B_D）、掛安全帽（S5_H）、機車罩（S1A_C）的比例拉高。擋風鏡、腳踏板的袋子、蓋座墊的雨衣模型裡沒有，要加模型，這一版沒做 | S1B_D 1、S5_H 1、S1A_C 4 |

- 動到 LAWWW 的檔：`src/zones3d.js` 的 `attachWzScooters` 加兩行（清單裡有 `code`、`pcol` 就照用；沒有的照舊照位置挑——公館、溫州街、118 巷不受影響）。
- 款式和配色表寫在 `TZ3.SC`，和 `scooter.glb` 節點的 palette 一樣（測試對）。
- 測試：`tests/tingzhou_unit.js` 第 10b 節四項（新）。

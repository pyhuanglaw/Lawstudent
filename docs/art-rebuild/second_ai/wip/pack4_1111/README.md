## 二、同弦樂器的招牌（XS-TONGXIAN-SIGN-1111；BB X323 招牌拉正小結的 P2）

BB：「招牌裝在二樓鐵窗後面，整塊隔著欄杆；右邊的冷氣室外機擋住最後一個字。玩家從街上看不出店名。」預覽：`blender_tongxian_before_after.jpg`（左：現在遊戲裡的模型；右：這一包）。

- 原因有兩個：①`XS_FRONTS.tongxian` 早就有「招牌後面那一段不開窗」（`blank`），但**遊戲裡的 `xinsheng_street.glb` 是加這一段以前匯出的**，鐵窗和冷氣還在；②照現在的腳本重匯，這一段會把同一層旁邊的吉他櫥窗也一起刪掉（蓋窗的範圍用一般窗的寬度算）。
- 修法：蓋窗只蓋原本的窗（`kind` 不是 `'xs'` 的）；不開窗的那一段用同一種外牆補滿（原本另外補一塊平塗的顏色，看得出一塊方形）；重匯 `xinsheng_street.glb`。
- 重匯前後材質、節點都一樣，物件 183 → 181（招牌前面的鐵窗、冷氣各少一個）；新生南路其他店沒有動（十四支 `xs_*_unit` ALL PASS）。
- 新測試 `tests/xs_tongxian_sign_1111_unit.js`（腳本＋模型統計；畫面要看 CC 的遊戲截圖）。

## 原因
- 第 1 版的葉片卡全部是垂直的（垂下的枝條），從上面看只看到卡的邊，樹冠中間是空的，只看得到樹幹和幾根粗枝。
- 貼圖也稀：5 條細枝、75% 的節有葉子，不透明的部分只有 22%，顏色偏暗。

## 改了什麼（`tools/blender/env_second/campus_lake.py`，重匯 campus_lake.glb）
- **樹冠**：樹頂往外、往下斜的一圈葉片卡，每棵 30 片，長 2.0～2.8 m、寬 0.45～0.65 m，像傘一樣。從上面看蓋住樹冠，從旁邊看是垂柳上半部往外垂。
- **垂下的枝條**：46 條變 84 條，每條兩片交叉（原本一片）。從哪個角度看都是面，不是一條線。
- **葉子貼圖**：
  - 細枝 5 條變 8 條，每一節兩邊各長 1～2 片葉子，葉子長一點；
  - 顏色綠一點、亮一點，細枝也帶綠。
  - 不透明 22% → 63%，平均綠色比例 0.453 → 0.494。
- json 多寫 `willow_tex`（不透明的比例、綠色比例），給測試讀，因為 GLB 裡的貼圖是 webp。
- 數字：整顆 GLB 9,462 → 10,098 個三角形；樹幹、湖、亭子不動，導航不動。

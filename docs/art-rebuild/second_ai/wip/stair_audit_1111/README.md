## 測試怎麼掃

`tests/stair_levels_audit_1111_unit.js`：在 Node 建出遊戲真正的每一個區域（index.html 到 teach3d.js 為止的區域檔），挑出有兩層導航的，找每座「兩層共用」的樓梯段（兩層的 surf 都有、有坡度的那一段）：

- (a) 資訊（`info_a.txt`）：上層在樓梯下半段站得住幾處、下層在上半段站得住幾處。雙跑樓梯（霖澤館、萬才館、宿舍、法圖、社科圖、共同、博雅、普通）的上一跑本來就兩層共用（中間的平台兩層都有），不算錯。
- (b) 用引擎真正的 `E.stepEntity` 照搖桿推（和木曜日那支測試同一個做法）：每座樓梯左中右（樓梯中間那一條橫線上站得住的最左、中間、最右）× 上樓、下樓 × 走、跑 × 30、10 fps，每座 24 趟。要走到那一端（樓梯外面站得住、高度對的地方；樓梯端直接接牆的就是樓梯上最靠端那一點）、而且在那一端「站得住、高度對」的那一層；每一步都站在那一層站得住的地方。
- (c) 單跑樓梯（下端在地面）下樓：過了樓梯的一半以後還在上面那一層的步數——木曜日 ② 的徵狀，算失敗。

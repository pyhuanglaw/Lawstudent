## 二、禮貌生財室內：鏡頭一片米色（BB 01:47 ③，P1）

- 原因（看了 CC 的 `ART2_lmint_new/out/tz4int_limao_2000_game.jpg`）：不是進門那一刻，是玩家站在掛畫前（畫面上的按鈕是「看掛畫」）、跟隨鏡頭退到隔牆後面**鎖著的書房裡**，整個畫面是隔牆的背面。隔牆不是外牆，不在牆的淡出清單裡。

- 測試：`tests/tz_shops_unit.js`「禮貌生財 10」。**遊戲畫面還沒看過**（這裡的無頭瀏覽器太慢、沒拍成），請 CC 站在掛畫前、鏡頭轉到背後重拍。

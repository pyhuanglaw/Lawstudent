# 新生南路西側二樓的窗景照片（LAWWW2 11-04）

- `tongxian_view_day.jpg`：同弦樂器二樓窗外，白天，1024×640（1.6:1）。給 CC 的同弦 v4c，換 `tongxian_props.png` 的 view 那一格。
- 腳本：`tools/blender/env_second/xs_window_view.py -- -10.9 out.png --layout <開發分支的 src/data/xinsheng_layout.js>`
  - 眼睛在店面二樓外牆外 0.25 m（x −12.75）、高 5.75 m（二樓地板 4.2＋1.55），z −10.9（同弦二樓窗的中間）。
  - 往東看，稍微往下。焦距 28 mm，Cycles。
- 照地圖：同弦在新生南路西側，窗往東看，看到的是：
  - 四線道、分隔島；
  - 對面紅磚人行道上的大王椰子和樟樹（位置照 xinsheng_layout.js 的 trees）；
  - 路燈；
  - 首都帝大的紅磚圍牆（照 campusWall，暫代的套件是紅磚＋米色壓頂）；
  - 牆裡面是校園的樹，遠遠有系館。
- 樹用 ⑦ 行道樹的 street_trees.glb，和遊戲是同一組模型。
- **和遊戲不一樣的地方**：遊戲裡圍牆後面現在是空地（側門外的遠景還沒做），這張照片先放了校園的樹。之後做側門外遠景時照這個方向做。
- 其他店的二樓也可以用同一支腳本拍，給店的 z 中心就好（大口漢堡、運動廣場、山嵐的二樓都朝東）。
- 晚上的版本：加 `--night`。這次還沒拍。

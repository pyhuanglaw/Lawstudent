## v2 怎麼做（`tools/blender/env_second/tz_wente_interior.py`）
照概念圖 `ref/tingzhou_1110/concept/shop_wentebaodi.webp` 做一顆獨立的店內模型，再把光影烘進貼圖：
- **衣服是衣服的形狀**：肩線斜下、袖子、下擺微彎，擠出厚度後磨圓，再加一層雜訊做皺摺。每一件的寬窄、長短、厚薄、角度、間距都不一樣；外套比襯衫厚、長。木衣架是彎的，掛鉤是鐵的。
- **布料**：格子（兩個方向的條紋疊起來）、丹寧（斜紋雜訊）、燈芯絨、素色。全部疊一層亞麻貼圖（Poly Haven `rough_linen`，CC0）。
- **假人**：用車削做出平滑的人台（腰細、胸寬、肩膀圓），頭是沒有五官的人台頭。身上穿開襟皮夾克，有翻領和兩隻袖子，裡面是米白襯衫，下面是牛仔褲，腰間有皮帶和黃銅扣。
- **木頭**：Poly Haven 胡桃木（`walnut_veneer`，CC0）。下半牆是深色木作牆板，有直條和壓條；上半牆是深橄欖綠灰泥；地板是淺色木（`laminate_floor_02`，D112）。
- **擺設**（從街上看，左到右）：
  - 櫥窗木台：假人、彩色玻璃檯燈（會發光）、皮公事包、一疊牛仔褲，左上掛一盆黃金葛。
  - 左牆：木層架，上面是一疊疊折好的衣服，最下層放三雙靴子。
  - 後牆：黃銅吊衣桿上掛滿衣服；上面兩層木層板，放毛衣、帽子、舊皮箱、書、相框。
  - 中間：木頭移動衣架，掛一件丹寧外套和幾件格子襯衫。
  - 右邊門後：一排外套、木框穿衣鏡、木櫃台（收銀機、舊收音機、小盆栽）。
  - 地上一塊古董地毯。
- **燈**：三盞黃銅吊燈、四盞軌道投射燈打在後牆的衣服上、一盞投射燈打在假人身上、檯燈。Cycles 把直接光、反彈光、陰影和顏色一起烘進一張貼圖。
- **輸出**：`tz_wente_interior.glb`，一個網格、一個材質、一張圖。遊戲不用即時光，`shopInsideReal` 換成不受光的材質。

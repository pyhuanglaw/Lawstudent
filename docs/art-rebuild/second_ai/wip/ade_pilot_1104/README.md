# 阿德影印外觀照參考圖重做＋開源素材試做（WZ-FIVE-1104 阿德轉角／OPEN-SRC-2D3D-1104；LAWWW2-C，2026-11-04）

狀態：`MODEL_READY`。等 BB 用同角度疊圖判 ART（D120／D133），遊戲畫面要 CC 在 PC 上拍。

## 為什麼這樣做（使用者 14:1x：「從 GitHub 開源找…2D 圖片轉換成 3D 的時候好看…還有很多你需要用的美術內容」）
- 「單張圖直接變 3D」的 AI（TRELLIS.2、TripoSR、Hunyuan3D、SF3D）都要 NVIDIA 顯示卡。
  - 雲端沒有顯示卡。使用者的電腦是 AMD RX 6600M（BB-C 查的），也跑不了。
  - 這類 AI 做店面、招牌字會糊，只適合小物件。
- 改用三件事，雲端都做得到：
  1. 平面的東西照參考圖做：
     - 招牌、價目表、軟木公告板：從參考圖校正透視裁下來（`xs_front_tex.py`，之前就有的流程）。
     - 玻璃上的白字：本作自己畫（PIL）。原因是從參考圖裁下來，背景會是店裡的灰色。
  2. 立體的生活道具改用 **Poly Haven 的 CC0 實景掃描模型**，減面後放進遊戲：
     - 新工具 `lib2.ph_model`：自動下載、只取要的節點、減面，貼圖先在磁碟上縮成 512 px RGB，回傳一個可以 instancing 的網格。
     - Poly Haven 有 521 個 CC0 模型，repo 之前只用過它的貼圖。
  3. 同一個 Blender 鏡頭拍修改前／修改後，和參考圖並排比。

## 改了什麼（`wz_shopkit.py`、`wz_street.py`、`lib2.py`）
A1（預設：還沒決定搬不搬，玩家最常看到的那一間）：
- 外牆從米色長條磁磚改成白色小方塊馬賽克，和參考圖一樣。
- 招牌（照舊是 BB-B 通過的設計稿）上面加三盞鵝頸燈，晚上會亮。
  - `hsign` 的燈箱招牌也可以加鵝頸燈。原本只有木招牌可以，其他店的行為不變。
- 鋁框改銀色，門窗改成落地玻璃：
  - 拿掉 1 m 高的腰框，左邊玻璃中間加一根直框；
  - 窗上貼一條藍色飾條（門不貼）。
- 玻璃右邊改成一段白磁磚壁面，上面掛參考圖的軟木公告板、價目表（NT$2，AA_655）和一盞壁燈。
- 左邊玻璃貼白字服務項目：影印・複印／掃描建檔／彩色列印／論文裝訂，字有描邊。
- 拿掉的：鐵皮雨遮、門口的販賣機和紙箱（參考圖沒有）。
- 加上的 Poly Haven 模型：
  - 冷氣室外機 `exterior_aircon_unit`：9,493 → 1,517 面；
  - 門口一盆陶盆合果芋 `potted_plant_02`：69,806 → 約 3,000 面。

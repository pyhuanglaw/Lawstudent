# 阿德影印外觀 v2（ADE-V2-1104：BB-C 15:0x 退回 v1 0a6f626be 以後重做；WZ-FIVE-1104／OPEN-SRC-2D3D-1104；LAWWW2-C，2026-11-04）

狀態：`MODEL_READY`。等 BB 用同角度疊圖判 ART（D120／D133），過了才請 LAWWW-C 接進開發分支。遊戲畫面（14:00、20:30、搬到轉角的 moved）和 lane_west 效能，要 CC 在 PC 上拍、量。

## v1 被退回的原因（BB-C 15:0x），v2 怎麼改
1. 外牆不對：v1 換成 `rounded_square_tiled_wall` 染白，看起來是灰綠色、有斑點的石材，比修改前還不像參考圖。
   - v2 改用 ambientCG 的 CC0 小方磚 `Tiles139`：暖米色、磚縫細、每塊深淺不一樣。
   - 一塊 10 cm。7 cm 的時候從街上看磚縫太密，整面偏灰。
   - 外牆新的種類叫 `tile_sq`，貼圖放在 `tools/blender/env_second/textures/acg_tiles139/`。
2. 店裡是空的。v2 玻璃後面 1.0～2.5 m 排出前後層次：
   - 三台大小不同的影印機：大型的有出紙盤和一疊紙，另外一台中型、一台桌上型放在櫃子上，離玻璃的距離都不一樣。
   - 後牆一整排層架（鐵柱＋木板四層），放大小不同的紙箱、一包包彩色影印紙、一排排資料夾。寬、高、深都不同，不是同一個東西換顏色。
   - 右邊木頭櫃台：前面一條藍色，上面有螢幕、一疊紙、筆筒。
   - 地上疊著紙箱。
   - 店內的牆改暗一點（#dfe1dd），白色影印機才看得出來。
3. 植物和雜物：
   - 門左邊：Poly Haven 陶盆合果芋。
   - 門右邊：大葉盆栽＋Poly Haven 白盆多肉（放大 1.5 倍）。三種植物，大小、角度都不同。
   - 壁面前一個水泥花箱，裡面三叢植物。用共用的 instancing 原型，不多三角形。
   - 招牌兩端有從二樓垂下來的常春藤（長短不一）。
   - 樓上每一扇鐵窗放三盆，蕨類和大葉輪流，位置、角度不同。A1 每一扇窗都有鐵窗。
   - Poly Haven 冷氣照舊。
4. 玻璃白字放大到 1.2 m 寬，字加粗深色描邊，圖示底下墊一塊深色。v1 的白字疊在店裡白色的東西上看不見。
5. 軟木布告欄（0.6×0.9 m）、價目表（0.56×0.67 m）放大，壁面加寬到 1.35 m。轉角店的鵝頸燈改回三盞。
6. 鏡頭：從參考圖招牌的四個角反推（xs_front_tex 量過的點）。
   - 參考圖招牌的左右兩邊完全垂直，所以用「水平鏡頭＋上下移軸」的兩點透視模型，用最小平方法解。
   - 光靠招牌決定不了焦距：21～43 mm 的誤差都差不多，每個點約 4 px，所以取 30 mm。
   - 解出來的鏡頭：眼睛 (−3.0, 1.61, −2.97)、看 (−6.33, 1.61, 6.46)、30.1 mm、shift_y 0.0733。解析度和參考圖一樣是 1672×941，可以直接疊圖。
   - `wz_window_view.py` 多兩個選項：`--shift-y`，以及 `--place`（把另一顆 GLB 放到遊戲裡的位置）。

## 沒做的（照實說）
- 紅色路緣、導盲磚：遊戲的溫州街是沒有人行道的巷子，路邊畫的是停車格。參考圖是有人行道的路口。
  - 加路緣會變成有高低差，要改導航，也和停車格衝突，所以不做。
- 參考圖的轉角在左邊、有兩面。遊戲的 A1 是巷子中間的店，旁邊是一盞的前院，沒有第二面店面。轉角的那一間是 `COPY_CORNER_OPEN`（劇情選「搬到轉角」以後才出現）。
- 前面那根電線桿是街景本來就有的，導航也綁著，不動。
- 店內是玻璃後面的淺店內（頂點色、不受場景光），不是 CC 的室內 GLB。CC 的 `wz_print_interior` 寬 4.4 m，A1 店面寬 8 m，直接拍下來貼上去比例對不起來。

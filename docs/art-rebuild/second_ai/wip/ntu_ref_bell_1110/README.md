## 照片和原本的差距
- 官網照片（`docs/story_planning/ref_images/buildings/README.md` 傅鐘那一列）：紅色鋼管鐘架，細柱、兩道圓環，鐘吊在頂上，沒有屋頂；下面是石砌台座和石碑。
- 原本的模型：石材台基、四根石柱、梁、四坡瓦頂的鐘亭，是照套件做的。

## 保留／不照抄（D136）
- 保留：
  - 沒有屋頂；
  - 細的金屬柱，鐘吊在架子頂上；
  - 石砌台座兩階和石碑（碑面「晨思鐘」）；
  - 銅鐘、鐘舌、地燈、光暈。
- 不照抄：
  - 只有一道水平圓環（真的有兩道）；
  - 頂上四道弧形拱肋在中間交會，鐘從那裡吊下來；
  - 顏色是深古銅 #3d3428（真的是紅色）；
  - 柱子往上微微往內收。

## 做法（`tools/blender/env_second/campus_bell.py`）
- 拿掉石柱、梁、線腳、瓦頂、屋簷板、垂脊、木橫梁，也拿掉柱面的暖光（石柱沒了）。
- 加上鐘架，材質 `seethru_bell_steel`：
  - seethru_ 開頭，所以擋住玩家時會網點透空，和原本的石柱一樣（CAM-BELL-1031）；金屬度 0.4。
  - **四根柱腳照舊在原本石柱的位置（±1.3 m）**：遊戲的導航阻擋來自套件 bell() 的 blocks，不用改，zones3d.js 也不用改。
- 2,728 個三角形，7 個網格。

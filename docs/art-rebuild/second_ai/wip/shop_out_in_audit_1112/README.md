# 店外看進去 vs 走進去：逐間自查（LAWWW2-C，2026-11-12）

起因：使用者 11-12「大步球鞋店外面看進去牆壁是灰色，可是人在店裡面居然牆壁是木頭的……你應該審查所有的店面會不會有一樣的問題」（§12 第 1 點）。
做法：遊戲裡（開發分支 f8a00372bb 之後，雲端 SwiftShader）每一間拍兩張——左＝從街上正對店面往裡看、右＝走進去從門口往裡看——並排，看牆、地板、主要擺設（櫃台、桌椅、廚房）對不對得上。

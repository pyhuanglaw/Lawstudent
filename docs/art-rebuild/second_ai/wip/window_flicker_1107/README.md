# 大口漢堡晚上窗外一直閃（WINDOW-FLICKER-1107；LAWWW2-B 2026-11-07）

- 起因：使用者 11-07 試玩 v9.10.21：「大口漢堡可以點餐但櫃檯沒店員 真詭異 外面窗景一直閃」（UA-LAWWW-1107-01）。LAWWW-B 03:37 派給我。
- 狀態：已修，Node 測試重現得到、修好也驗得到。**瀏覽器、手機實機沒看過**（D131 排 CC）。

## 原因

- 大口的一樓、二樓是 BB 的兩顆模型（`dakou_1f.glb`、`dakou_2f.glb`）。**兩顆各有一張夜景卡 `NIGHT_FRONT`（店外 z 16）和 `NIGHT_WEST`（x −14），位置、大小都一樣**。
- `dakou3d.js` 晚上把四張都打開，同一個平面上疊了兩張不同的圖 → z-fighting：鏡頭一動，畫面就在兩張圖之間一格一格地跳，看起來就是「一直閃」。
- 白天夜景卡藏起來，所以只有晚上閃（使用者那時大概是晚上）。
- 開發分支上 XS-WINCARD（帳號 C，還沒發布）把正面的 `NIGHT_FRONT` 換成視差窗景、藏起來了，但西側 `NIGHT_WEST` 照樣兩張疊著，晚上照樣閃。

## 修法（`src/dakou3d.js`，patch：`dakou_nightcard_1107.patch`，對開發分支 `77195b12a`）

- 載入時替每一張夜景卡標上是哪一層的（`userData.dkLv`：一樓 0、二樓 1）。
- 晚上只顯示玩家那一層的那一張；上下樓時（`player.lv` 變了）在 `z.update` 切換。白天照舊都不顯示。
- 沒改模型，也沒改視差窗景那一段。

## 測試（`tests/dakou_nightcard_unit.js`，Node）

- 檢查：晚上一樓、二樓各自「看得到的夜景卡沒有兩張在同一個平面」、看得到的都是那一層的；回到一樓換回來；白天不顯示。
- v9.10.21（main `92c3daad8`）：**FAIL 5**（正面、西側各兩張疊著）——就是使用者看到的。
- 開發分支 `77195b12a` 原樣：**FAIL 5**（西側兩張疊著）。
- 加 patch：**ALL PASS**。`dakou_unit`、`xs_wincard_1105_unit` 也 ALL PASS。
- patch 是對開發分支做的；v9.10.21 那一版的 `dakou3d.js` 不一樣，`git apply --check` 套不上（要熱修 main 的話照同一個做法改那幾行）。

## 問題
新生南路的校園圍牆（x 18.4）後面只有一片灰色地面，從人行道、從側門門洞看進去是空的。

## 做法（只改 `src/xinsheng3d.js`，接在開發分支 637ee6982）
用校園的配置換算位置：新生南路 (x,z) → 校園 (x−142.4, z−94)；側門 (18.4,10) 就是校園的側門 (−124,−84)。
- 草地：圍牆後面 140×170 m，貼圖和校園相同（`W3.grassTex`）；門洞裡面一小段紅磚。
- ① 樹林：側門北邊（校園西北角走不到的樹林，校園 z ≤ −88、x −121～−62），樟樹和榕樹，高 9.5～15 m。
- ② 圍牆內側一排矮樹：草地那一段，門洞前後各留 4 m 不種。
- ③ 側門南邊的草地上零星幾棵大樹。
- ④ 遠處的農業陳列館（洞洞館）、校史館：載入校園原本的 Blender 正式模型（`bldg.campus_pavilion`、`bldg.campus_hist`，16 個 primitive），整組平移到新生南路座標；載入失敗就用 CK 套件。不投影。
- 樹用 `TK.tree`，再用 `W3.mergeGroup` 合併：有正式樹模型時走 TreeField 的 instancing。
- 導航：圍牆後面原本整片擋住，沒改；走不到，鏡頭也進不去。

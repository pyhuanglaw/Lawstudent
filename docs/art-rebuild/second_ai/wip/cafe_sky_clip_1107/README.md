# 兩點半 Café 左邊的橘色斜面（BB-B 11-07 05:20 P3；LAWWW2-B 2026-11-07）

## 回報

BB-B 回報（截圖在 elegant-brown `18d820c63` 的 `docs/story_planning/test_shots/pt1107/gift718_01_gift_1.png`、`gift718_02_gift_2.png`）：

- 拍攝條件：LAWWW-B 718b59ec7、10/24 16:27、下雨；玩家站在角落沙發和小圓桌中間。
- 現象：畫面左邊三分之一一整塊橘色斜面。

## 原因

是 X132（CAFE-WINDOW-LIVE-1030，我 10-30 做的「Café 窗外 3D 溫州街」）。

- Café 是室內區域，沒有引擎的天空。所以當時在街景後面放了一個半徑 140 m 的天空半球，白天、黃昏、晚上換顏色。
- 街景的模型都加了裁切平面，只畫玻璃外面；**天空半球沒有加**。
- 鏡頭在側牆外、牆淡出以後，看到的就是半球的內壁。
- 16:27 用的是黃昏那一組顏色，下半部是 `#d98a5e` → `#f3c58e`，所以是一大塊橘色斜面。

順便查到的另一個問題：Café 門口的燈光圈（半徑 3.6 m，中心在玻璃外 1.45 m）也沒有裁切，有一截畫在店內的地板上。

## 修法（`cafe_sky_clip_1107.patch`，對開發 c244ce20e，只改 zones3d.js＋測試）

- 天空的材質加上同一個裁切平面 `clippingPlanes:clip`：
  - 從店裡透過玻璃看出去，照樣有天空；
  - 側牆外不會再露出來，那裡變成和其他室內一樣的背景。
- 燈光圈的材質也加上裁切。`TK.lightPool` 每次都新建材質（只有貼圖共用），所以不會動到溫州街本身的光圈。
- 其他沒有裁切的東西（行道樹、路口的路燈、斑馬線）都量過：整個在玻璃外（最靠近玻璃的一點在 Café z 8.43，裁切平面 6.35）。

## 測試

`tests/cafe_street_live_unit.js` 加第 5 節：

- 天空有裁切；
- 光圈有裁切；
- 沒有裁切的東西整個在玻璃外。

結果：

- 開發原樣：**FAIL 2**（天空、光圈）；
- 加 patch：**ALL PASS**。
- Café 相關 11 支（cafe230_*、cafe_barista、cafe_customers、cafe_kit_glow、cafe_refresh、cafe_rota、cafe_seethru、cafe_street_live、cafe_wz4）都過。

## 還沒驗

- 瀏覽器（CC）：同一個角度（角落沙發和小圓桌中間，16:27 下雨）再拍一次，左邊應該不再是橘色；透過玻璃往外看，天空照舊。

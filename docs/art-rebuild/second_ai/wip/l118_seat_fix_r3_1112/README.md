# L118-SEAT-FIX-1112 r3：點被桌子擋住的椅子，走到半路、按鈕變旁邊那一張（LAWWW2-C 2026-11-12）

## 原因（從 CC L118_CAM36_a_r2／b_r2 的「點擊打到」紀錄查到）
- CC 點的是椅子在畫面上的位置。射線第一個打到的卻是前面那張桌面（`fallback`，高 0.69～0.9 m）或展示櫃玻璃（`l118_tea_caseglass`）：從玩家背後的鏡頭看過去，椅子被桌子擋住了。
- 地板那一點（`screenToFloor`）正好就是椅子中心。但這幾間的椅子沒有擋導航，那一點站得住，所以 `tapToSeat` 不改去椅子的走近點。
- 結果是人直接走向椅子底下，被桌子卡住，1.5 秒沒前進就停下（stallStop），停在走道上離走近點 0.2～0.8 m。這時離他最近的「坐下」是旁邊那一張。

  - 點走道不受影響：辛亥韓食走道離椅子 0.6 m，其他店也都在 0.5 m 以上。
  - 點兩張椅子中間也不受影響：兩張都超過 0.25 m。

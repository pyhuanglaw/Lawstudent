## 二、節日的紅燈籠、聖誕燈串在遊戲裡是白光（我的錯）

- 原因：這些會發光的小東西顏色放在頂點色，Blender 裡發光接的也是頂點色；但 glTF 的發光只能是一個固定顏色（匯出成白色 ×1.2），遊戲的發光不會乘頂點色 → 紅燈籠、四種顏色的燈串、南瓜燈全部發白光。我只看了 Blender 預覽、沒有讀回模型的材質確認。
- 改法（`src/season_deco3d.js` 的 `SD3.glowFix`）：載入季節模型時，把 `season_glow` 換成不受光的頂點色材質（顏色＝頂點色、白天晚上一樣亮）。模型不用重匯，兩個區域（溫州街、公館）都適用。
- 測試：`tests/season_deco_unit.js` 多兩項。

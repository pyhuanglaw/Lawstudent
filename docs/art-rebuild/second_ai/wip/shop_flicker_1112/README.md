# 兩個「一直在閃」（L118-DRINK-WALL-FLICKER-1112＋WZ-OFFBEAT-WINDOW-FLICKER-1112；LAWWW2-C 2026-11-12）

使用者 11-12：118 巷「飲料店牆壁一直在閃」（喝不喝咖啡）、溫州街「日常失速還好，但從店外面看進去會一直閃」。

## 原因（同一種：兩片牆疊在同一個平面）
用 `tools/glb_coplanar.py` 掃兩條街的模型：

| 哪裡 | 疊在一起的兩片 | 面積 |
|---|---|---|
| 118 巷 喝不喝咖啡（東側 z −7～−2）後牆 x＝8.1 | 外帶店自己畫的白磁磚後牆 × 通用店內畫的後牆 | 23.2 m²（含牆背面） |
| 118 巷 果茶社（西側 z −9～−6）後牆 x＝−8.15 | 米白後牆 × 通用店內的後牆 | 12.5 m² |
| 溫州街 日常失速 西牆 x＝−47.2 | 立體店內的牆 × 這一棟外殼牆的內面 | 36.1 m² |
| 溫州街 日常失速 北牆 z＝−8.0 | 同上 | 33.2 m² |

果茶社使用者沒提，但是同一個錯，一起修了。118 巷其他九間店（有室內的那幾間）掃過沒有這種店內的疊面。

## 改法
- 不重建整條街，只挪頂點：新工具 `tools/blender/env_second/glb_shift_plane.py`（把某個材質、落在某個平面上的頂點沿一個軸挪一點）。
  - 118 巷兩間：外帶店自己那片後牆往店裡挪 1.2 cm。
  - 日常失速：店內那兩面牆往店裡挪 8 mm（挪 2 cm 會撞到離牆 2 cm 的掛板）。
- 建模腳本一起改（重建不會又疊回去）：`wz_shopkit.py` 的 `_drink` 後牆、`wz_street.py` 匯入日常失速店內之後挪那兩面牆。
- patch：`shop_flicker_v1.patch`（`git apply --binary`；在開發分支 `e300b47d8` 上 `--check` 過）。動 `lane118_street.glb`、`wenzhou_street.glb`、兩支建模腳本、新工具、新測試。

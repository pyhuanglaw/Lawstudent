# 辛亥路往東南彎（萬才館 r2 補充，BB 的驗收條件）——LAWWW2 11-03，READY_FOR_ART_REVIEW

官方地圖（`../law_relayout_r2/map_law_xinhai_curve.jpg`）：辛亥路二段沿校園北邊筆直，過了霖澤館往東南彎成三段，萬才館順著它斜放。
遊戲原本是一條直路（中線 z −156，x −260～260），萬才館轉 42° 以後，背面對著的還是直路。

## 改了什麼（`src/zones3d.js` 校園背景 campusBackdrop；全部是走不到的背景，導航不變）
- **路線 `XH`**：
  - 直路到 x 61.9，接半徑 60 m 的彎道，再接東南段。
  - 東南段的方向＝萬才館長軸（42°）。
  - 中線＝萬才館本地 z −38.5，所以校園側圍牆（離中線 15.4 m）剛好在萬才館背後那塊導航阻擋的外緣（本地 z −23.3）。
- **路面**：
  - 彎道＋東南段的柏油、兩側人行道、白虛線、雙黃線，用 `ribbon()` 沿著中線各合成一個網格。
  - 直的那一段照舊：人行道、車道線只畫到彎道起點。
- **校園圍牆**：直的那段到 x 61.9，接著沿彎道走到地圖邊界外。
- **路燈、行道樹**：直的那段到彎道起點，彎道上沿著校園側人行道（燈臂朝馬路）。
- **背景房子**：
  - 拿掉剛好在新馬路上的 3 棟系館（原本 (140,−120)、(140,−75)、(172,−100)），以及東側那排城市大樓在馬路附近的那幾棟。
  - 照地圖補兩排：對面（往世貿那一側）是城市大樓，校園側是教職員宿舍（低的公寓）。都順著馬路、正面朝馬路，沒有名字。
- 舊配置（`!LR`，載入舊版黑森林配置時）：照舊一條直路，行為不變。

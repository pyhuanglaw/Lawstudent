# 單面網格「正面朝錯邊」離線掃描（LAWWW2-B 2026-11-09；BB-B 16:45 請求）

起因：好拍右牆洞洞板正面朝牆（`haopai_interior.py` 的 `reversed`），遊戲裡被背面剔除、看不到；Cycles 烘焙兩面都擋光，把看得到的牆擋暗（XS9）。

- 工具：`tools/blender/env_second/lightbake/backface_scan.py`。不用跑遊戲，Blender 只用來讀 GLB、建 BVH。
  - 用法：`/opt/blenv/bin/python tools/blender/env_second/lightbake/backface_scan.py -- <glb>... [--json 輸出]`
- 判定（面積加權）：
  - 只看單面材質的網格，而且是板狀：整片同一個方向，平均法線長度 ≥ 0.8。盒子、圓柱本來就有朝各方向的面，不看。
  - 正反兩片拼成的雙面卡不算：前後 3 mm 內有一片反方向的。
  - 「貼著東西」：每個面上取樣，每 0.05 m² 一點，最多 64 點。從取樣點沿正面射 5 cm，打到一個朝回來的面（例：牆的內面），就算這一點貼著東西。
  - 「貼著東西」≥ 50% 的網格列出來。
- 「朝室內中心」只當參考，不列：
  - 好拍的球拍故意轉 30～40° 朝店門，會被算成背對中心；
  - 好拍的電視朝店門（法線 0.48, 0, 0.88），也會被算成背對中心，其實從門口看得到。BB-B 在 door 那張看到的就是它，沒有問題。
- 第一版只射三角形中心：天花板只有 2～4 個大三角形，中心剛好在木作上方，就被算成 100%（實際約 20%）。已改成照面積取樣。

## 怎麼修（好拍）
- `tools/blender/env_second/lightbake/glb_flip_faces.py`：照法線方向挑三角形，交換頂點順序、頂點法線乘 −1。
  - 安全檢查：要翻的頂點不能和不翻的共用、accessor 不能共用、不能是 instancing。
  - `--opaque-copy`：洞洞板換一份不透明材質 `hp_peg`。
- `tools/blender/env_second/lightbake/glb_split_tile.py`：把貼圖集裡洞洞板那一塊（u 0～0.25、v 0.5～1）拆成自己的 512×512 貼圖，UV 改成鋪滿。
  - 板面線性亮度 ×2.5：0.222 → 0.554。暗色的洞不動。
  - 原本 #8c7f68 的反照率 0.19，只有灰泥牆 0.53 的 1/2.7：翻正以後同樣的光照會比現在的淺牆暗很多。BB-B 的目標是「跟現在的淺牆差不多」。
  - 光照貼圖和板子的顏色無關（DIFFUSE 只烘光）。要換回原本的灰褐色，只換貼圖、不用重烘。
- 原始腳本 `haopai_interior.py` 也改了：`peg_wall` 不再 `reversed`；`wall_grid` 左右對調。
  - 重新匯出以後就不用翻。
  - 拆貼圖、調亮兩步要照 `bake_xs.sh` 好拍那一段再做。
- 烘焙（`bake_xs.sh` 好拍）：`HIDE='glass'`（不再藏鏤空）；洞洞板加進烘焙名單。

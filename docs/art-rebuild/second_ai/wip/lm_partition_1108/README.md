# 隔間牆背面光照壓成一點（LM-PARTITION-1108；LAWWW2-B 2026-11-08；BB-B 01:46 PC GPU 回報 L5FLM 研究室左牆「整片泛白」）

## 原因：烘焙工具的 bug
- `bake_room.py` 的 `hidden_faces()` 會把一面牆「背對 dir（淡出方向）」的面當成看不到，把它的光照座標壓到整個物件最大那一面中間的一點。
- 外牆這樣做沒問題，背面在建築外面。
- **隔間牆兩面都看得到**（遊戲的 `fadeWalls` 也照兩邊判斷）。被壓掉的那一面整片只讀到另一面中間的一個值：
  - 霖澤 5F 研究室那面借到走廊那一面的 0.745，所以整片泛白、沒有明暗。
  - 總圖 B1、研究小間、體育館 B1、美國公寓、合租戶也一樣。
- 修法（`eb857ec65`）：
  - `extras.partition` 的牆兩面都烘。
  - 加 `lm_partition_check.py`：找出隔間牆上超過 0.3 m²、光照座標卻不到 1 像素的三角形。
  - 加 `lm_partition_stats.py`：量隔間牆兩面的明暗。

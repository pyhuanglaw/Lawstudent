## 給 LAWWW 接的
- `zone.tzStalls`（汀州路）、`zone.ggStalls`（公館）：每一攤 `id、kind、name、x、z、yaw、isOpen`。
- `zone.tzStallsClosed＝true` 全部收（颱風，照舊）；**新** `zone.tzStallOff＝{id:true}` 單獨一攤今天不擺（套圈圈只有週五六日：配置 `kinds.ring.days＝[5,6,0]`，星期幾要 LAWWW 接）。
- 品項、價錢（以圖為準）：配置 `stalls.kinds[kind].items`。**和 AA_744 的商品表不一樣的**：紅豆餅 20（原 15；口味紅豆、奶油、花生）、地瓜球 50／55／60（原 40）、玉米 70（原 80）、粉圓冰 50／燒仙草 55（原 45）、蔥油餅 45～65、雞蛋糕 30～45（一份 5 個、小豬形）、甘蔗汁 50／65、鮮奶 50～65、炸豆腐 70＋泡菜 10、胡椒餅 60。

## 已知的缺點（第 1 版）
- 攤主：沒有（LAWWW 的 NPC）。圖上的攤主是真人樣子，不照圖。
- 蒸氣、炭火的動態特效沒做（規格寫「可」）；炭火、燈泡、燈籠是發光材質 `tzs_glow`，晚上調亮。
- 食物是簡單形狀（球、圓柱、方塊）；近看不精緻。
- 皇冠是簡化的；胡椒餅的金色雕花只在正面貼圖上，柱子和頂是素的金色。
- 甜湯夏冬換展示內容沒做（P3）。
- 公館三攤的位置只照導航格量；人行道上有沒有只畫不擋的東西（樹、地磚花紋）要看遊戲截圖。
- 招牌自己發光（整張貼圖），白天 0.25、晚上 1.1；白天會不會太亮要看遊戲。

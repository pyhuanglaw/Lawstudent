## 原因

- 吧檯 10～13 號是高腳椅（坐姿抬高 lift 約 0.25～0.27），跟隨鏡頭看的點＝人＋1.45 m；俯角 0.38（BB 那時候）、距離 4.2 m → 鏡頭高 3.46 m，**已經比天花板（3.4 m）高**。
- 天花板下面有三根水泥大梁（`tools/blender/env_second/aa_support/cafe230_interior.py`：深 0.42，底在 2.98 m）、風管（底在 2.78 m），材質 `a23_vc`／`a23_vc_metal`。中間那張（−1.3,−3.3）鏡頭在人背後 (−1.3,3.46,0.6)，梁的側面在 z 0.2、離鏡頭 0.44 m——**整個畫面就是那根梁**（不是牆）。
- 鏡頭轉到別的方向（吧台那一邊、店的後牆外面）還有吧台後面的胡桃木層架、吊燈、燈泡、黃金葛擋住。

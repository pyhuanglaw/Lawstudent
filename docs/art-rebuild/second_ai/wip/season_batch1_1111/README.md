## 做法：街景模型不動，另外一顆季節模型

- 街景生成器（`wz_street.py`）建每一間店面、住家門的時候**多記一筆門的位置**（`season_door`：只記錄，街景模型的輸出一個位元都沒有變——這一包沒有重匯 `wenzhou_street.glb`、`gongguan_shops.glb`）。

- 遊戲：`src/data/season_deco.js`（日期表）＋`src/season_deco3d.js`（`SD3`）。進區域時照遊戲日期決定（和溫州街小公園的杜鵑、楓香同一個時機）：
  - 那一天沒有任何一組 → **不載入模型**（平常日零成本）；
  - 有 → 載入、照代號顯示／隱藏、掛進區域的群組（不投影）。
  - 接法＝包住 `Z3.ZONES.wenzhou／gongguan` 的 `build`（和 `tz_shops3d.js`、`flower_notes3d.js` 同一種），**沒有改 `zones3d.js`**；`index.html` 多兩行。

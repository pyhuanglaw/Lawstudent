# #204 外牆腳黑線盤點（LAWWW2-B 2026-11-09；LAWWW-B 18:37 派：先盤點、不改檔，照「玩家看得到、常去」排前幾間）

狀態：盤點完成，**沒有改任何檔**。要做哪幾間由 LAWWW-B 決定。

## 這是什麼問題
- 烘光照時，貼在牆前面的東西會擋光，被擋住的那一塊烘成暗的。貼著牆的東西包括：櫃子、書架、木護牆板、柱子、裝飾條、海報、門框。
- 牆或那個東西在的時候，暗的地方本來就看不到。
- 遊戲的 fadeWalls 會把擋在鏡頭和人中間的 WALL_ 網格藏起來。一藏，就露出暗的那一塊：牆腳、櫃子背後一條黑的。
- 11-08 已經修過六間：總圖 B1、研究小間、霖澤 5F、體育館 B1、美國兩間（`wip/lm_reveal_1108/`）。這次是其他有光照貼圖的房間。

## 怎麼量（兩支工具都只讀）
1. `lm_fill_covered.py --dry`（`fill_covered_dry.txt`）：
   - 每間「被蓋住（2 cm 內貼著別的 WALL_ 網格）、而且至少一組鏡頭會露出來」的光照格子數。
   - 這就是 `lm_fill_covered.py` 能補的部分。
2. `lm_fade_reveal_check.py --samples 400`（`fade_reveal.txt`，只跑格子 ≥ 1% 的 30 間）：
   - 每一對「接收面 ← 擋住它的網格」：面積、400 組鏡頭／玩家位置裡會露出來的比例、亮度（被擋／沒被擋）。
   - 擋光距離算到 30 cm，比 fill 的 2 cm 寬：2～30 cm 的接觸陰影是真的看得到的陰影，不補。
   - 嚴重度＝Σ 面積 × 露出比例 × (1 − 亮度比)，單位 m²。
- 限制：鏡頭／玩家位置是在房間外框裡隨機取的，沒有限定玩家站得到的格子；比例是近似值。

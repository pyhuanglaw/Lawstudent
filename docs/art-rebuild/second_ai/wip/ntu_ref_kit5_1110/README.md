## `src/campuskit3d.js` 加的參數
四個參數，不給的時候行為和原本一樣。
- `CK.hall`：
  - `topArch:true`：其他樓層方窗、最上面一層拱窗。
  - `stairTower:{w,d}`：正面中間一座玻璃樓梯塔，從地面到屋頂上 1.6 m。
    - 三面玻璃，每層一片，晚上有亮有暗；
    - 有角柱、樓板線、塔頂、一樓玻璃門；
    - 塔擋導航；
    - 塔後面那一列不開窗；招牌移到塔的旁邊；
    - 只在沒有拱廊的時候用。
- `CK.modern`：
  - `bays:{floors,col}`：最上面幾層，正面、背面各一排凸窗（凸出 0.7 m，前面有玻璃）。
  - `roofCol`：屋頂面的顏色。預設照舊是深色。
- `userData.ck` 多回傳 `stairTower`、`topArch`、`bays`，給測試用。

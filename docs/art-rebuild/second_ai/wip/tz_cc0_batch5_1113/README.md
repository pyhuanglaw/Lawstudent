- **主角（書）**：
  - 每本書＝一塊紙張材質的書塊（Paper001）＋朝外的書背印刷
  - 寬 2.5～5 cm、高低不一，偶爾空一小格
  - 前半命理館：線裝書、舊命理書的書背（米白書籤條、裝訂線、燙金框）
  - 後半書房：刑法教科書、德文書、法典、期刊合訂本（精裝布面、上下燙金帶、金線書名）
  - 不寫書名、不像任何出版社（D77）
- **自畫印刷**：
  - 隔牆上的水墨山水掛畫
  - 東牆書法掛軸
  - 書房學術合照、兩張獎狀
  - 書房舊地毯
  - 書桌上攤開的信和講義
- **材質組**：
  - 茶壺茶杯、玻璃櫃裡的茶壺：白瓷
  - 陶罐、櫃頂籤筒：陶
  - 門框、畫框：深色木頭
- **Poly Haven 模型**：
  - 木椅：painted_wooden_chair_02，原本 chair() 就有
  - 門口落地盆栽、書櫃旁小盆綠蘿
- **書房平常要藏**：印刷面照節點分組分開匯出。
  - STUDY_packs 跟著 STUDY_ 一起藏
  - 隔牆上的掛畫是 PART_packs，跟著 PART_ 一起藏
  - 其他店照舊只有 S_packs
- **面數**：45,326 面。
- **光照烘焙**：`bake_tz_shops.sh limao`，新的 case：
  - 三盞紙燈籠、書房綠罩銀行燈、東牆壁燈、一點天花板補光
  - 白天天光 0.8
  - 白瓷、陶的小東西不烘：第一次烘時茶壺被烘黑，改成照即時光
- **營業時間**：19:00～23:30，截圖都是 20:00。

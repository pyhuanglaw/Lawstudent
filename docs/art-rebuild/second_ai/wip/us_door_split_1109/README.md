# #204 美國公寓兩片開著的門板拆成兩個節點（LAWWW2-B 2026-11-09；LAWWW-B 18:37 派「直接做」，美國交換＝D99 第三項）

狀態：`READY_FOR_REVIEW`（只改 GLB 的節點，幾何、材質、光照貼圖都不變；遊戲內等 CC 拍、BB-B 判）。

## 為什麼
- `docs/art-rebuild/second_ai/wip/lm_reveal_1108/README.md` 的「沒修、記下來的」第 1 點。
- 美國公寓（`us_apartment.glb`）的 `WALL_bath_n_door` 一個節點裡有兩片開著的門板：衣物間（西，x 1.52～1.63）、衛浴（東，x 4.57～4.68）。
  - 兩片都轉了 95°，各貼一面不同的牆：西邊那片貼臥室牆 `WALL_bed_w_wall`，東邊那片離外牆 `WALL_E_wall` 22 cm。
  - 但它們跟著門洞那面牆 `bath_n` 淡出。
- 結果：
  - 臥室牆、外牆淡出時，門板還在，看得到門板朝牆那一面（烘成暗的）。
  - `bath_n` 淡出時，門板跟著不見，露出它烘在臥室牆上的影子。
- `glb_partition_at.py` 的規則 B 會把「轉了 90° 貼著別面牆的門板」改成跟那面牆淡出。但兩片在同一個節點，外框不薄，認不出來。

## 做法（不用 Blender）
1. **新工具 `tools/blender/env_second/lightbake/glb_split_node.py`**：照三角形中心的位置把一個節點切成兩個。
   ```
   python3 tools/blender/env_second/lightbake/glb_split_node.py us_apartment.glb out.glb --node WALL_bath_n_door --axis x --cut 3.1 --name WALL_bath_n_door_e
   ```
   - 兩個節點各自一個網格，頂點只留用得到的，POSITION 的 min／max 照新的頂點算（規則 B、遊戲的淡出判斷點都看外框）。
   - 同一個父節點、同一個材質；extras 照抄；第二套 UV 照抄，光照貼圖不用重烘。
   - 結果：留下 156 個三角形（衣物間）、`WALL_bath_n_door_e` 156 個三角形（衛浴）。
2. **再跑 `glb_partition_at.py`（規則 B）**：
   - `WALL_bath_n_door`（衣物間那片）：dir [1,0,0]、partition、at 照 `WALL_bed_w_wall`，跟臥室牆一起淡出。
   - `WALL_bath_n_door_e`（衛浴那片）：dir [−1,0,0]、at 照 `WALL_E_wall`（外牆，不是隔間牆，所以沒有 partition），跟外牆一起淡出。
3. `us_apartment.py` 加了註解：重新匯出要再做這兩步。`glb_partition_at.py` 的舊註解（「要在 Blender 拆」）也改了。

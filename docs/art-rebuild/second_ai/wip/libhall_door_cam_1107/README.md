# CAM-LIBHALL-DOOR-1107：總圖大廳一進門，鏡頭卡在玻璃門框後（LAWWW2-B 2026-11-07）

派工：LAWWW-B 11-07 16:13（BB_255 CC 試玩第 8 件前半，P3，D108）。patch 對開發分支 `claude/modest-rubin-2lyp7g` `03e92c411`：`libhall_door_cam_1107.patch`（`git apply --check` 過）。

## 原因
- 從校園進總圖大廳，出生點在門廳 (0, 6.6)、面向北；進區域時鏡頭在人背後（`cam.yaw = spawn.yaw + π`），往南退 4.8 m（俯角 0.38）→ 鏡頭停在 **(0, 3.43, 11.06)**，在正面玻璃帷幕（z 8.90～9.02）**外面**。
- 帷幕的直櫺、橫櫺、玻璃、自動門五金和整棟的框合成同一個網格（正式模型 `L0_frame`／`L0_glass`／`L0_vcm`），**不跟著南牆淡出**（會淡出的只有兩側實牆 `WALL_S0E`／`WALL_S0W`）→ 一進門畫面就是隔著門框、玻璃看人。
- 不只出生點：門廳裡鏡頭朝南（正南、±45°）的 534 個位置／方向，**440 個**鏡頭在帷幕外面。

## 改了什麼（`src/library_hall_v2.js` 的 `camCols`，+4 行）
- 門廳寬（x ±5.2）、到屋頂高（9.6 m）、厚 0.12 m 的看不見的板子 `CAMCOL_facade`，放在帷幕的位置（z 8.95），兩層都加（二樓那一段也是帷幕）。
- 交給 `engine3d.js` 的 `followCam` 當隔間牆（`zone.camCols`）：擋到就停在玻璃內側、拉近時抬高、`autoSwing` 照舊——和台階書牆、中庭柱子（BUG-CAM-LIBHALL-CORE-1031）同一套，**不改引擎**。
- 正式模型、配置、導航都沒動。

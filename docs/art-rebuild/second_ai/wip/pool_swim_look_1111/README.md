## 查到的原因

- ②「腿偏灰白」**不是人物模型的問題**：在遊戲裡把水面拿掉，腿和手臂的膚色一樣。原因是腿在水面下，被原本那片淺藍、透明度 0.42 的水面蓋成灰白色；手臂在水面上，所以是原色。
- ①原本的水面是一片單色、沒有任何起伏、沒有反光的淺藍，看不出是水面。泳客的臀部骨頭只在水面下 9 cm、整個人水平，所以背和臀部浮在水面上，腳一直踢出水面——看起來就像趴在水上。

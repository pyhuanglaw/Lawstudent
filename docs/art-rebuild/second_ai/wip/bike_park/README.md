## 做了什麼
- `zones3d.js` 開頭加一份 `BIKE_RACKS`（`[x,z,ry]`），由 `Z3.BIKE_RACKS` 匯出。
  - 校園、公館、新生南路三個區域照這份擺停車架：`W3.bikeRack(7)`，和校園原有的同一款；導航阻擋 4.6×1.6。
  - `bike3d.js` 的 `PARKS` 也讀同一份，所以這些架子就是合法停車處。
- 溫州街巷子窄、不放架子，改在 `PARKS.wenzhou.spots` 加單一停車位：兩點半 Café 門口兩側、往新生南路的橫巷。新生南路的溫州街巷口、校園後門（往 118 巷）也各加一個。
- 位置怎麼挑的：用 Node 建出真正的區域，掃每一個候選位置，條件是：
  - 架子站得住、不在台階或平台上；
  - 靠牆或靠台階（車頭朝牆）；
  - 不壓到任何出入口；
  - 擋掉的格子不超過架子本身（不切斷走道）；
  - 架子兩端停得下車（`BIKE.parkOK`）。
  - 腳本在我的 scratchpad，沒有放進 repo，結果都寫在下面的表裡。
- `NavGrid.blockRect` 的旋轉方向和 three.js 的 `rotation.y` 相反，所以傳 `-ry`。萬才館那一座轉 42°，只有它會受影響，`bike_park_1104_unit` 第 ② 項會驗。

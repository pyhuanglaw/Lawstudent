- 門打不開，也走不進去。這幾棟目前都是外觀，門只是畫面上的改善。
- 門的木作很深：在拱廊最深的陰影裡（文學院），下半的凹板、門把幾乎看不出來；陰影淺一點的地方（行政大樓）才看得到。真的老建築的門也是深色木頭，這一版不調亮（木作和窗框共用一個材質，調亮會連整棟的窗框一起變）。

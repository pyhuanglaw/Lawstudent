### 照使用者給的照片改了什麼（v3）
- 照片是新聞照，有版權，**沒有放進 repo**，這裡只用文字記重點。
- 新生：幾乎都穿白色 T 恤，坐滿場地的紅色折疊椅和下層看台。
- 舞台：
  - 整片紅地毯，前面有三階紅地毯台階；
  - 背板是淡色插畫：紅磚建築的拱廊、中間的塔樓和圓頂、杜鵑花，大字「開學典禮」＋"Opening Ceremony"。
- 會場：
  - 舞台外圍有鋁合金方形燈架和舞台燈；
  - 兩側一紅一綠交錯的吊旗；
  - 大螢幕轉播講台。
- **不寫校名、不放校徽**（D77）。插畫的建築是虛構的，沒有照任何一棟真的畫。

## 怎麼做的
- Blender Cycles，96 samples。
- 腳本：
  - `tools/blender/env_second/bg_gym_ceremony.py`（場景、舞台、燈、鏡頭）；
  - `tools/blender/env_second/vrm_crowd.py`（把 VRM 人物擺坐姿、烘成靜態網格、換衣服顏色）。
- 指令：
  ```
  /opt/blenv/bin/python tools/blender/env_second/bg_gym_ceremony.py -- <輸出.png> --res 1920x1080 --samples 96 --lens 24 --eye 0.35,2.3,17.4 --look 0,3.8,-21
  ```
- **場景**：遊戲裡同一個 3F 主球場模型 `gym_arena.glb`。
  - 打開舞台＋典禮布置，藏起演講、演唱會布置。
  - v3 把原本的布幕、鋼構、橫幅藏起來，換成上面那套紅地毯舞台和插畫背板。
- **人群**：2,955 個坐著的新生，全部是遊戲裡的學生人物 `vroid_npc_m1／m2／f1／f2`。
  - 姿勢 3 種（手放腿上、轉頭、低頭），共 12 款；每個人隨機轉一點角度、大小差 ±3%。
  - 衣服：白 T 恤為主，少數淺灰、淺藍、黑；頭髮黑、深棕。
  - 場地折疊椅坐約 93%；下層看台越後排越少；**上層看台不放人**。
  - 座位位置照 `gym_arena.py` 的算法，和模型裡的椅子同一組座標。
- **舞台**：七位來賓坐在來賓桌後面、一位在講台致詞，深色西裝（同一批人物換顏色）。
- **大螢幕**：另外用一台鏡頭（70 mm）拍講台，模糊、調暗以後當螢幕畫面。
- **鏡頭**：站在南看台第一排前面（眼睛 2.3 m），中央走道正對舞台，24 mm，對焦在舞台。

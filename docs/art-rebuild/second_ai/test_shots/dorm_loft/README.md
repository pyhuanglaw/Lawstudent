- 左右兩面牆各兩組床桌，階梯都在靠門那一端：
  - R1（右後，靠窗）＝祐廷；
  - L1（左後）＝阿凱，桌上的東西在 `ROOMMATE_KAI`；
  - R2、L2＝另外兩個床位（`ROOMMATE_C`／`ROOMMATE_D`），有生活痕跡、人不在。要不要有室友由 AA-B／使用者決定。

- 前左角：鞋櫃、垃圾桶、資源回收、曬衣架。
- 給遊戲的配置：`layout_v1.json`（每組的佔地、書桌中心、椅子位置與朝向、階梯前的點、洗手間門口、窗景）。

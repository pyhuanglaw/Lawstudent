## 鏡頭遮擋（`audit_l118_shops.py`：進門、點餐、每個座位的走近點，鏡頭轉四個方向，看鏡頭到人物頭部那條線）
- 算出來的「被擋住」大部分不是真的：
  - 店的天花板只有朝下那一面，鏡頭在天花板上面時看不到它，量的時候卻會算進去；
  - 鏡頭在牆外面時，那一面牆會淡出，也不算。
- 扣掉這兩種，剩下的：

| 慢讀咖啡 | 兩個座位 | 書櫃上的木頭零件 | 鏡頭轉到書櫃那一側才會；擋一下人物的腳 |
| Pasta 118 | 點餐、吧檯 3 個座位 | 吧檯上方的不鏽鋼層架 | 鏡頭轉到吧檯後面（廚房那一側）往外看時才會 |

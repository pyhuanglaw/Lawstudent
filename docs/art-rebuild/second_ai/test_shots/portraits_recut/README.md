# 對話立繪重切（BB-B D59 退件）｜LAWWW2-B

## 曾品妤 pinyu（2026-10-16）

BB-B 退件的兩處（`8fbe1e1a` 那一版）：
- ① 臉兩側、耳朵高度的頭髮外緣有一圈白邊，看起來像白色髮絲；
- ② 兩腿中間膝蓋到腳踝留著一塊半透明的灰底。

### 原因

isnet-anime 的遮罩把「人物裡面露出來的背景」也當成人物，包括兩腿中間，以及側邊髮絲和脖子之間。

### 改法

`tools/portraits/cut_reference_portraits.py` 加了 `key_holes()`，只對 `HOLES = {'pinyu'}` 套用；其他人的立繪不重切、不變。

1. **挖洞**：和背景色接近、又沒有顏色的淺色區塊（連成一片）直接挖掉，不管遮罩怎麼判。鞋子在最下面 8%，有白色的部分，不碰。
2. **重算洞邊的半透明**：洞旁邊 3 px 照亮度重算 alpha，算的是這個像素落在「背景」和「附近最暗的人物顏色」之間的哪裡。舊做法會留一圈白，放大 2.2 倍後還有鋸齒。
3. **頭部高度補挖（上面 17%）**：髮絲和脖子之間的背景被皮膚染成微暖的淺色；只要這種顏色貼著已經挖掉的洞，也挖掉。
4. **脖子兩側殘留的白點**：
   - 範圍是貼著透明區 2 px 以內、到全身高的 20%；
   - 依 R−B 分辨：帽兜是中性灰，R−B 小於 8；皮膚的 R−B 在 30 以上；只挖介於中間、帶一點暖色的白點，帽兜和皮膚都不動。

### 對照

舊版和新版各放在深色底、紅底上：

- 脖子邊緣有 1 px 的淡色，這是原圖頸部的亮邊。

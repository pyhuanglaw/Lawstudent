  - `openNow` 多認 `dating`（角色 id）：`flags['dating_'+id]===true`，或 `romance[id].status==='dating'`。和各支線的 `S.dating` 同一個判斷。LAWWW-B 07:20 說「多認 flags」，我做成 `dating`：交往紀錄存在 `romance` 裡的存檔也算。

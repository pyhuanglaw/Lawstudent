**航空公司、店名全部虛構**（D77：曜光航空 LUMEN AIR、太平洋風箏航空 PACIFIC KITE、南風航空 NANFENG AIR、港灣捷運航空 HARBOR JET；日日便利、雲端咖啡、旅人書店）；看板上的城市是真的地名，航班號碼是虛構代碼。

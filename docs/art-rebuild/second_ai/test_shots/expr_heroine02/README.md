## 做法（`tools/portraits/overlay_expressions.py`）

**不重畫、不換臉**：頭、頭髮、眼鏡、表情全部是使用者那張圖的原圖，只做縮放、平移、微轉（−7.5～+5°）。

1. **去灰底**：每一格依和底色的距離去背，半透明的髮絲邊緣去掉灰色。
2. **對齊**：每一格的眼睛＋眼鏡那一塊，在全身圖頭部附近找最像的位置（縮放 × 角度 × 平移）。
3. **合成**：
   - 頭和頭髮整個換掉；
   - 下巴以下淡出，脖子、領口、衣服、包包都是全身圖原本的（差異只在第 24～224 列，也就是頭部）；
   - 全身圖舊的頭髮在新頭的範圍裡擦掉，避免兩層頭髮；
   - 髮尾那一段：全身圖原本有半透明灰邊，擦掉；
   - 表情圖的肩膀比全身圖高，會淡淡透出一道弧線，那裡只留深色的頭髮。
4. **輸出**：600×1000 RGBA，WebP 品質 92，每張約 62 KB。

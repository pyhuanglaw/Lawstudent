## 為什麼選「手臂擺幅」
- 裙襬加寬：手在裙子外面的那一側也會變成在裡面（裙子更寬），而且會改到 BB 驗收過的輪廓。
- 裙子加骨頭（彈簧骨）：當初刻意不用（`peishan_clothes.py`：坐下時裙子會炸開）。
- 手臂擺幅：不動模型，只改動畫。
  - 長 A 字裙的人手本來就會離身體遠一點；
  - 只對沛珊這個模型生效（manifest 的參數，其他人物是 0）。

## 學姊 heroine_05

**底圖**：照 BB-B 的建議，比照芷若，改用約會圖 `heroine_05_date_shirt` 姿勢①（白襯衫＋卡其長褲，和 campus 同一套）。
- 新切的底圖是 `heroine05_campus_v2_neutral_trial.webp`。
- 去背用 alpha matting：白襯衫和灰底只差 7，一般去背會在髮絲邊留一圈淺灰，還會把衣領挖一個洞。

**疊法：只換臉**（眉毛到下巴的柔邊橢圓），頭髮、耳朵、馬尾、下巴輪廓都留底圖的。
- 試過整個頭換掉。表情圖的頭是 3/4 側臉、有馬尾，結果耳朵下面破洞、出現兩個耳朵、馬尾斷一截、脖子有一道階。不用這個做法。
- 對齊方式：
  - 先用「眼睛最像」的那一格（sad，0.883）對到底圖；
  - 其他格用頭頂＋耳朵（不隨表情變）對到那一格。
  - 原因：閉眼、低頭的格子用眼睛對會偏 15 px。
- 用 8 格，thinking 不用（BB-B 的指示）。

**看得出來的缺點**
- embarrassed 是低頭的表情，下巴的位置和底圖不一樣，右下巴有一點不自然。
- 表情圖的嘴比底圖低一點，所以臉的範圍要蓋到下巴。範圍再縮小，會出現兩張嘴。

對照圖：`heroine05_heads.png`（深色底、紅底交替）。

## 子晴 heroine_04

**底圖**：照 BB-B 的指示，用現在的 campus 立繪。約會圖姿勢①的頭是轉向側面的，和正面的表情頭對不起來。

**疊法**：整個頭換掉（短髮、正面），下巴以下淡出。
- 對齊方式和學姊一樣（anchor＝annoyed，1.0）。
- 九格都用。

**問題：清晰度差太多**，就是 BB-B 擔心的第 ① 點，見 `full_body_clarity.png`。
- 現在的立繪是從 768 px 標準圖切的，全身只有約 160 px 寬，放大後整個人很糊。
- 疊上去的頭是清楚的插畫，放在對話框大小也看得出「頭清楚、身體糊」。

**建議**：請使用者生成一張子晴正面全身的高解析度圖。
- 要和 campus 同一套：灰色連帽上衣、牛仔短褲、黑色後背包、白球鞋；
- 頭的角度要和這組表情相同（正面）。
- 有了就照芷若、學姊的做法：先切成新底圖，再疊頭。

另外，現在的立繪身體左側有一塊半透明的灰影（後背包旁），是 8fbe1e1a 第一版就有的去背問題，換底圖時一起解決。

對照圖：`heroine04_heads.png`。

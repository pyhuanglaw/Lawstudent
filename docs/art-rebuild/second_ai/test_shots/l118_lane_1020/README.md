## 已知缺點、還沒做
- 電線是細的四角管：遠一點會斷斷續續（鋸齒）。
- 盆栽只有一種植物；回收桶、保麗龍箱同一款。
- 直立招牌的字由遊戲畫（和公館樓上的一樣），沒有設計稿。
- 巷口那一段機車格停滿以後，從後門一進來兩側都是機車，中間留約 3 m。
- 晚上的光是地上的光圈，不是真的燈光；牆、機車不會被照亮。
- iPhone 實機沒有測過。

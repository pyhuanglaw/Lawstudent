# BG-05 dorm_roof（宿舍頂樓）｜LAWWW2-B 2026-10-16（ART-BG05）

**事件**：跨年頂樓 `ev_nye_roof`（CG-15），12/31 23:45；v0 E24c 也是晚上。

**AA_147 要求的元素**：
- 水泥平台、矮牆（女兒牆）、水塔、一盞昏黃的燈；
- 矮牆上有便利商店的塑膠袋、飲料；
- 遠方最高的大樓放煙火，很小、很遠，**煙火不打出字或數字**。

## 成品

- 檔案：`assets/bg/dorm_roof.webp`，1920×1080、96 samples。
- 腳本：`tools/blender/env_second/bg_roof.py -- <out.png>`。
- 為什麼新做：遊戲裡的男一舍沒有頂樓，所以用 Blender 蓋一個台灣宿舍常見的頂樓。
- 畫面內容：
  - 左邊是樓梯間出口：磁磚外牆、綠色鐵門，門上一盞昏黃的壁燈，就是唯一的燈；不鏽鋼水塔架在小屋屋頂。
  - 前面是女兒牆，牆上放著白色塑膠袋（沒有字和標誌）、兩罐飲料、一瓶茶。
  - 右邊兩台冷氣室外機、空的曬衣架；地上有水管、伸縮縫、排水孔。
- 遠景：
  - 校園樹木的剪影（女兒牆上面露出一點）；
  - 再遠是城市的燈光、盆地邊緣的山；
  - 遠方最高的大樓只有細長分節的輪廓，不畫成任何特定建築的細節；
  - 樓頂附近五朵小煙火，只有放射狀的光點。
- 貼圖：Poly Haven（CC0）`concrete_wall_006`、`rectangular_facade_tiles`；遠景是本作程式畫的。

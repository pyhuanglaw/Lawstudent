## 這一張還不到參考品質的地方

- 沒有照片，整張的配置是推估的。真的醉夢溪可能比較窄、彎，護岸也可能不一樣。

- 楓香用樟樹的模型代替（遊戲裡沒有楓香），秋天會變紅的特徵沒有表現。
- 山上的樹是卡片：遠看是森林，鏡頭貼近會看出是平的；樹種只有樟樹、榕樹兩種。
- 只在 Blender 算圖看過，**還沒在遊戲 ADV 畫面、手機上看過**。

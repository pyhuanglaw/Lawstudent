## ③ 博雅的燈：9 盞 → 3 盞跟著玩家

- **改法**（`src/teach3d.js`，`patches/teach_lights_econ_1025.patch`，接在 ①② 的 patch 後面）：

  - 點光源不擋牆、不擋樓板：離玩家遠的燈原本也只照到牆後的教室；照到玩家附近最亮的就是最近的那幾盞。

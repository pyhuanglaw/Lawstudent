# 汀州路商圈 參考圖分析（TINGZHOU-AREA-1110，X321；LAWWW2 帳號 A 2026-11-10）

## 使用者指示（11-10，對 LAWWW2，原文摘要）
- 「這次要做的是『汀州路商圈』而不是 generic 台北街景」。關鍵字：台大學生、平價、日常、混合店種、東南亞美食、人文咖啡、傍晚熱鬧。
- 主街是台北舊式中低樓層街屋：一樓店面密集；二樓以上老公寓、鐵窗、招牌。
- 店型混合：平價小吃、飲料、咖啡、運動用品、手機通訊、日常生活店。
- 汀州路要有「東南亞美食街」特徵：泰式、馬來西亞、印尼、緬甸餐館的外觀。
- 優先做傍晚到夜間：店招亮起、人潮增加，但保留日常通行的街道感。水源市場附近人流較高。
- 不要觀光夜市、不要西門町步行街、不要高級新商圈。

最重要的那一塊（每一版都不能丟）：
1. **兩側老公寓＋一整排直立燈箱招牌**（圖 5、6）：遠看就知道是台北的老商店街。
2. **傍晚到夜間的光**（圖 4、6）：店招、一樓店面亮，天空還有餘光。
3. **東南亞餐館混在一般店裡**（地圖 3、使用者指示）：泰式、馬來、印尼、緬甸的招牌和門面，不是整條街都是。

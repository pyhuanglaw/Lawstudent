（2026-10-10 使用者需求原文）

《法條之外：台灣法律人生》3D 全面美術升級＋可探索多樓層建築施工指令
請依照目前 GitHub `pyhuanglaw/Lawstudent` 的最新原始碼，持續完成全遊戲 3D 美術與建築互動升級。
這次我明確要求：
遊戲不是只有漂亮的建築外觀，而是一個玩家真的能自由探索、進出建築、走樓梯、搭電梯、到不同樓層上課與生活的 3D 大學世界。
請保留現有 Three.js 架構、劇情、人物關係、法律題庫與存檔，全面升級 3D 美術資產與必要的移動能力。
不要把目前「所有人物只能在 y=0 移動」視為永久規格。這是需要克服的技術限制，不是我接受的遊戲設計。
1. 霖澤館與萬才館
指定工具：

* Blender 5.2.2 + Python bpy：建立正式建築模型
* Poly Haven：PBR 磚牆、石材、混凝土、玻璃等材質
* Blender UV / Texture Baking：材質烘焙
* glTF / GLB Exporter：輸出模型
* Three.js GLTFLoader：整合遊戲

主要修改：

* `src/campuskit3d.js`
* `src/zones3d.js`
* `src/assets3d.js`

要求：
依照現有真實照片與配置資料，製作外觀完整、比例自然、具細節的霖澤館與萬才館。
建築應分為外牆、樓板、室內、樓梯、電梯、門窗等組件，不要製作成完全不能互動的單一裝飾模型。
霖澤館的穿堂必須真正能走進去、穿過建築，而不再只是遠看得到、實際被碰撞牆阻擋的裝飾。
萬才館的弧形大樓梯必須能讓玩家走上去。
需要保留建築真實可辨識的外觀；沒有照片支持的室內部分可以進行合理的遊戲化設計，但不能假稱完全還原真實建築。
2. 多樓層導航系統
指定工具：

* Three.js
* 現有 `src/engine3d.js` 的導航與碰撞系統
* Blender 建立可行走表面及碰撞幾何
* 必要時評估 `recast-navigation-js` 或等效的 Navigation Mesh 工具

這是本次重大功能升級。
目前 D26 的 y=0 平面移動限制需要解除。
要求：

1. 玩家具有真正的三維位置 `(x, y, z)`。
2. 支援不同高度的地板。
3. 支援斜坡、樓梯與平台。
4. 玩家能從室外地面走上樓梯，到達二樓平台。
5. 支援多層樓建築內部探索。
6. 電梯可以選擇樓層，並正確抵達。
7. 樓層間的導航必須正確連通。
8. NPC 能依照日程前往不同樓層。
9. 鏡頭能跟隨高度變化，避免穿牆、穿天花板。
10. 家具、座位、NPC、互動點都要有正確樓層高度。
11. 存檔必須記錄所在建築、樓層與位置。
12. 舊版只有平面座標的存檔必須仍可讀取。

請先比較兩種方案：
A. 擴充現有 NavGrid 為樓層導航格＋樓梯／電梯連結。
B. 使用 Navigation Mesh 進行立體尋路。
請選擇對現有程式改動風險較低、手機效能較穩定的方案。
不要直接把所有舊導航程式刪掉重寫。 必須先完成技術示範，通過測試後逐步整合。
3. 教室、圖書館、宿舍與其他室內
指定工具：

* Blender bpy：教室、桌椅、書架、床、沙發、櫃子等模型
* PBR Material：木材、布料、金屬、塑膠與地面
* Three.js：場景配置與互動
* GLB Instancing：重複使用家具

要求：
教室內所有可使用的座位，都必須真的能走到、坐下、站起來。
不得以瞬移到座位代替尋路。
教室可以有階梯式座位，人物必須能正確站在階梯平台上，不再因 y=0 限制陷入地板。
圖書館可進入閱讀區、自習區。
宿舍可進入房間、走廊，並與床、書桌互動。
樓層與房間不必一次全部完成，但已開放的區域必須完整可玩。暫未製作的房間可以合理關閉，不得以隱形牆製造無法理解的阻擋。
4. 公館與溫州街
指定工具：

* Blender bpy：台北公寓、騎樓、店面、招牌、機車等
* Poly Haven PBR：牆面、磁磚、柏油、地面
* Three.js：動態光影、路人、交通與互動
* InstancedMesh / LOD：重複物件與遠景

修改：

* `src/townkit3d.js`
* `src/world3d.js`
* `src/zones3d.js`

要求：
近景建築改用正式 GLB，美術品質必須高於目前的程序化版本。
保留台北街景特徵：騎樓、招牌、機車、電線、店面、行道樹。
不能變成沒有台灣特色的歐洲街景或普通現代城市。
遠景與背景建築可繼續使用輕量程序化模型。
5. 人物模型與動畫
指定工具：

* Blender：人物模型修整、服裝、髮型
* VRM / three-vrm：人物模型與表情
* 現有骨架動畫系統：走、跑、待機、坐下
* Blender Action / NLA：補足必要的上下樓、開門等動畫

主要修改：

* `src/character3d.js`
* `src/assets3d.js`
* `src/data/characters.js` 中的模型引用

要求：
維持成人比例與日系青春生活模擬風格。
主要人物有各自不同的臉、髮型、服裝與辨識度，不能只是同一個 VRoid 樣本換顏色。
新增上下樓梯、轉身、坐下、站起來、開門等動作，保持與移動系統同步。
不允許模型在樓梯上滑行、腳穿過台階或人物漂浮。
6. 材質、光影與效能
指定工具：

* Poly Haven PBR：真實材質
* Blender：UV 與 Baking
* glTF Transform：模型最佳化
* Meshopt：幾何壓縮
* KTX2 / Basis Universal：貼圖壓縮
* Three.js：載入與渲染

要求：
對正式模型進行尺寸、三角面數、材質數量、draw calls 與記憶體盤點。
壓縮技術需確認與現有 Three.js 載入器相容。
不能因為使用 PBR 或高解析度貼圖，讓手機版無法正常遊玩。
正式環境的畫面品質要提升，但必須保留適當的近、中、遠景細節分級。
7. 全遊戲測試
指定工具：

* Python Playwright
* Chromium
* 現有回歸測試
* 多樓層測試腳本

要求測試：

* 地面走到建築入口
* 進入霖澤館穿堂
* 由一樓走樓梯至二樓
* 從二樓走回一樓
* 搭電梯到其他樓層
* 走進教室並坐下
* 坐下後正常站起
* NPC 跨樓層移動
* 鏡頭與人物不穿模
* 手機觸控操作
* 場景切換與日夜變化
* 存讀檔與舊存檔相容

測試禁止使用瞬移或跳過關鍵互動。
允許在電梯內透過正式的樓層切換機制轉換場景，但玩家必須看得到完整的操作與過程。
自動測試通過不等於實際手機驗收完成。

完成一個真正可玩的霖澤館多樓層示範區，包含外觀、穿堂、樓梯、二樓、教室、坐下互動。

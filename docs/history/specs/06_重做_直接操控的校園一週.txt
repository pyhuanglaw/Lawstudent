目前版本需要大幅重做。我的主要不滿是：

1. 人物與場景不好看，缺乏美術設計。
2. 每天都只是選「上課、讀書、打工」，玩法重複。
3. 缺乏角色在世界中生活的感覺。
4. 整體像文字問卷加數值面板，玩起來很無聊。

這次先暫停增加職涯和事件數量，集中改善美術與核心操作。保留原本法律人生的長期方向，先交付一段真正漂亮、好玩的「法律系校園一週」。

【一、重新定義遊玩方式】

我要直接操控人物，在校園、教室、圖書館、咖啡店與住處之間移動。

- 電腦支援 WASD／方向鍵移動，也能點擊地面走過去。
- 手機支援點擊移動。
- 靠近人物或物品，出現清楚的互動提示。
- 點擊座位坐下、走到書架找書、在櫃檯接工作、靠近同學交談。
- 有基本碰撞，人物不能穿過桌子和牆壁。
- 場景間有自然的出口與切換。

「上課、打工、讀書」要透過走到地點、與物件互動開始，不能只放在主畫面的選單中。

保留選項式對話來處理真正需要選擇的劇情。平常的移動、探索與活動，使用直接操作。

【二、美術請整套重設】

採用一致、精緻的 2D 手繪感 Q 版美術，使用斜俯視場景。氣氛是有生活細節的台灣校園，溫暖、清爽、有青春感。

人物要求：
- 約三頭身，頭身比例、臉型與四肢有完整設計。
- 有辨識度的髮型、衣服、鞋子及配件。
- 主角與重要 NPC 使用同一套美術規格。
- 至少有正面、背面與側面造型。
- 有待機、走路、坐下讀書等動畫。
- 移動時有腳步、身體起伏與方向變化。
- 對話顯示較精緻的半身頭像，具有基本表情。
- 不要使用 emoji、火柴人或隨意拼湊的幾何人物作為正式角色。

場景要求：
- 圖書館有木桌、檯燈、書架、書包、窗戶與樹影。
- 教室有講台、黑板、階梯座位與同學。
- 校園有步道、植物、公告欄、腳踏車與可坐的長椅。
- 住處有書桌、床、書本和可以逐漸增加的生活物件。
- 咖啡店有工作區、座位與會進出的客人。
- 有清楚的前後遮擋、接地陰影與統一比例。
- 早上、傍晚與夜晚有不同光線。

請先訂出色票、角色比例和場景尺度，再製作素材。若無法取得外部圖片，就以細緻的自製 SVG 或 Canvas 素材完成一致的美術，不要把簡陋占位圖當作完成品。

【三、上課要有參與感】

玩家走進教室，選擇座位，上課時透過場景演出與短互動參與：

- 老師在黑板上呈現一個簡短案例。
- 玩家從案例裡點出關鍵事實。
- 把兩三張概念卡放到筆記中的適當位置。
- 有時與鄰座同學討論，或被老師問一個問題。

每次互動控制在 20～40 秒，不需要閱讀整頁文章。

不是每堂課都要玩小遊戲。已熟悉的課程可快速完成，關鍵課堂才有特別內容，避免反覆勞動。

【四、讀書要能看見自己累積了什麼】

玩家在圖書館找座位，把書與筆記放到桌上，進入簡短的讀書介面。

- 從當週課程選擇閱讀內容。
- 透過整理概念、連接關係或標記案例重點完成學習。
- 成果會出現在自己的筆記本裡。
- 準備充分時，考試能直接運用先前整理的內容。
- 書桌、筆記與書架會隨進度產生可見變化。

不要只顯示「智力＋3」。玩家要知道自己今天學會什麼，以及之後在哪裡用得到。

避免每次讀書都強迫解題，提供一般讀書與重點互動兩種節奏。

【五、打工要有不同的操作】

第一版先完整做好一種咖啡店打工：

- 接單、備餐、送到正確客人桌上。
- 以簡單的移動、點擊或拖曳完成。
- 一次約 45～60 秒。
- 新手節奏寬鬆，熟悉後可以挑戰更忙的時段。
- 店長、同事與熟客有小故事。
- 薪水可以買看得見的東西，例如衣服、書桌燈、書籍與房間裝飾。

工作成果除了金錢，也能帶來人物關係或新事件。

【六、讓校園值得探索】

每天要有少量可以發現的變化，例如：
- 公告欄出現交換說明會。
- 熟悉的同學今天坐在不同地方。
- 傍晚有人在練社團表演。
- 圖書館某張桌子留下讀書會招募單。
- 常去的店有新餐點。
- 路邊的貓開始願意靠近主角。

玩家可以走過去探索，也可以繼續原定行程。不要每件事都自動跳出視窗打斷遊戲。

重要 NPC 有簡單的日程與移動，不要永遠站著等玩家點擊。

【七、時間安排融入場景】

每天分為上午、下午、晚上，完成主要活動才推進時段。自由走動、查看環境和簡短交談不持續扣時間，讓玩家能安心探索。

課表、考試日期與約定放在可隨時打開的手機或手帳中。

主畫面只保留：
- 時間與日期。
- 精力。
- 金錢。
- 一行目前目標。

其他數據放進手帳。畫面大部分空間留給遊戲世界。

【八、先做出完整的一週】

第一個可玩版本需要包含：

- 一位美術完整、能換基本造型的主角。
- 三位外觀與個性不同的固定 NPC。
- 校園主地圖及教室、圖書館、咖啡店、住處五個可進入場景。
- 一堂有互動的法律課。
- 一次能留下筆記成果的讀書活動。
- 一次完整咖啡店打工。
- 一場與所學內容連動的小考。
- 一條交換學生申請的伏筆。
- 一次與朋友共同經歷的小事件。
- 一個能用打工收入購買、並放進房間的物件。
- 存檔與繼續遊戲。

一週結束後，玩家應該記得某個同學、某個場景，以及自己做過的一件事。

【九、完成標準】

這次優先順序是：
美術一致性 → 移動與互動手感 → 活動差異 → 人物與生活感 → 內容數量。

請實際檢查：
- 人物在遊戲正常顯示尺寸下是否清楚、好看。
- 行走方向與動畫是否正確。
- 角色是否穿牆或卡住。
- 每種活動是否真的有不同操作。
- 是否仍存在大量只讓玩家選選項、看數值的重複流程。
- 場景切換與存檔是否正常。

請直接重做可玩的版本，不要只寫改善企劃，也不要只改配色、圓角和按鈕，就當成美術升級。這一版的目標是讓人一打開就想走進校園，玩完一天還想繼續。

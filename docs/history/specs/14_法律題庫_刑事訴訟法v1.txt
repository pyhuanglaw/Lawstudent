第一篇　基本原則、法院、當事人
Q001–Q030
━━━━━━━━━━━━━━━━━━━━

Q001【是非】
刑事訴訟的目的只有發現真實，程序保障在真實發現面前均應退讓。
答案：錯
核心：真實發現與程序保障並重。

Q002【單選】
無罪推定原則下，犯罪事實原則由何方負實質舉證責任？
A 被告 B 辯護人 C 檢察官 D 法官
答案：C
核心：控方舉證。

Q003【是非】
被告沒有義務證明自己無罪。
答案：對
核心：無罪推定。

Q004【單選】
「罪疑唯輕」主要作用於：
A 犯罪事實仍有合理懷疑
B 法官不知道法條號碼
C 被告拒絕認罪
D 辯護人缺席
答案：A
核心：合理懷疑。

Q005【是非】
法院得因被告保持緘默而直接推論其有罪。
答案：錯
核心：緘默權。

Q006【單選】
審判公平最直接要求法院：
A 幫檢察官補強證據
B 維持中立第三者地位
C 說服被告認罪
D 主動追求重刑
答案：B
核心：法院中立。

Q007【是非】
法定法官原則包含案件分配不應針對個案任意操縱。
答案：對
核心：法定法官。

Q008【單選】
刑事程序中的被告是：
A 單純調查客體
B 程序主體
C 證人的一種
D 法院助手
答案：B
核心：程序主體。

Q009【是非】
被告具有程序主體地位，因此享有防禦權。
答案：對
核心：防禦權。

Q010【單選】
下列何者最接近不自證己罪？
A 被告有義務回答一切問題
B 國家不得強迫被告積極供述自己犯罪
C 被告不得提出證據
D 被告不得認罪
答案：B
核心：不自證己罪。

Q011【是非】
被告自願認罪與不自證己罪原則必然衝突。
答案：錯
核心：權利可自主行使。

Q012【單選】
被告防禦權最核心的功能是：
A 幫法院快速結案
B 使被告能有效參與並反駁國家追訴
C 增加訴訟費用
D 取代法院調查
答案：B

Q013【是非】
形式上稱某人為「證人」，即可排除其實質上已成為犯罪嫌疑人的可能。
答案：錯
核心：實質判斷。

Q014【單選】
偵查機關明知甲已是犯罪嫌疑對象，卻刻意以證人身分訊問以規避被告權利，最重要問題為：

Q015【是非】
程序身分的判斷不能只看偵查機關貼上的名稱。
答案：對

Q016【單選】
被告選任辯護人的主要目的為：

Q017【是非】
辯護人只是法院的輔助人，與被告防禦權無關。
答案：錯

Q021【是非】

Q023【是非】

Q028【單選】

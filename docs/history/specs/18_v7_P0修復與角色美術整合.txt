==================================================
P0 — 霖澤館前玩家無法移動
==================================================

實際情況：

遊戲開啟後，我在「台大校園／霖澤館前」出現，
畫面與 UI 正常，
但玩家角色無法正常移動。

這是 BLOCKER。

優先檢查：

- mobile joystick input
- touch / pointer event
- pointer capture
- ADV overlay 是否仍攔截 input
- invisible DOM overlay
- player controller enabled state
- movement lock flag
- event lock
- dialogue lock
- collision
- nav/collider
- spawn point 是否生成在 collider 內
- camera/controller state
- save/load restore state
- orientation change 後 input state
- loading GLB/VRM 時是否意外 disable controller
- enter event 是否留下 movement lock
- z-index / pointer-events
- iOS Safari touch handling

不要只在 desktop keyboard 測試。

建立 regression test：

BOOT
→ spawn at 霖澤館
→ joystick up
→ player position 必須改變
→ joystick left/right
→ player 必須轉向／移動
→ run
→ movement 正常
→ trigger dialogue
→ exit dialogue
→ movement 必須恢復
→ save
→ reload
→ movement 必須仍正常

任何情況下：

dialogue / ADV 結束後都必須可靠 unlock player control。

若 spawn point 與 collider 重疊，
修正 spawn point / collision，而不是關掉 collision。

P0 驗收標準：

我重新開啟遊戲，
不需要任何額外操作，
在霖澤館前可以立即用手機虛擬搖桿正常走動。

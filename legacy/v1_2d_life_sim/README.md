# v1 — 2D 回合制法律人生養成（2026-09-27）

對應需求：`docs/history/specs/01`、`02`、`03`（以及 `04`、`05` 國考參考資料）。

## 遊玩

直接用瀏覽器開 `index.html`（單檔，已內嵌全部程式）。存檔用 localStorage（key `fatiao_autosave_v3`、`fatiao_slot_v3_*`），可匯出／匯入 JSON。

## 檔案

`index.html` 是由 `00_head.html` ＋ `01`～`10` 模組串接而成（`all.js` 是純 JS 串接版，供 Node 測試用）。

| 檔案 | 內容 |
|---|---|
| `00_head.html` | 標題、CSS（暖米色／木質棕／深綠／酒紅色票，含深色模式） |
| `01_data.js` | 虛構學校「北辰大學法律學系」、國考科目、教授風格、四年課程、學習活動、生活小事件、考試案例、民總小考 |
| `02_npcs.js` | 小安（安佳蓉）、阿哲、溫學姊、阿凱、小語、媽媽、店貓阿判，以及職涯後的人物；NPC 人生軌跡；記憶旗標說明 |
| `03_events_uni.js` | 大學事件（大一上深化＋各學期通用） |
| `04_engine.js` | 狀態、存檔、學習模型（理解／體系／記憶／提取／爭點／涵攝）、回合結算、學期流程 |
| `05_exam.js` | 期中期末策略作答、小考、分組報告 |
| `06_exchange.js` | 交換學生：申請、出發前、海外學期、返台 |
| `07_bar.js` | 國考：備考、一試二試、口試、訓練、落榜分岔 |
| `08_career.js` | 職涯：律師／法官／檢察官／公司法務、進階階段、合夥、開業、結局 |
| `09_scenes.js` | SVG 場景與角色 |
| `10_ui.js` | 介面 |
| `test.js`、`scan.js`、`roles.js`、`debug.js`、`svgcheck.js` | Node `vm` 無頭測試（讀 `all.js`）：`node test.js` |
| `svgs.txt` | `svgcheck.js` 的輸出（SVG 檢查用傾印） |

這一版之後，使用者覺得「像文字問卷加數值面板」，要求改成直接操控人物（spec 06），開發轉向 3D。
